## 一、一句话说明这是什么

**这是 20 本随身携带的运营作业手册。**

你把问题说出来，AI 会翻开出最对的那一本，照着上面写好的**步骤、门槛、判据和坑**回答你 —— 而不是给你一堆资料让你自己读。

三个特点：

| 特点 | 说明 |
|---|---|
| **不是资料摘抄** | 每一本都写清"什么时候用、怎么做、什么时候别这么做" |
| **数字是真的** | 所有门槛、比例、案例都来自真实课程与实战记录，没有编造 |
| **敢说不确定** | 素材本身有矛盾时，两套说法都写出来并标出处，不替业务方瞎猜 |

## 三、20 本手册怎么分工

### 用一家电商公司来打比方

| 层级 | 本数 | 相当于公司里的 | 回答哪类问题 |
|---|---|---|---|
| **L0 总纲层** | 1 | **总经理的经营手册** | 我现在卡在哪一环？该找谁办？关键公式是多少？ |
| **L1 体系层** | 8 | **八个部门主管的手册** | 这条业务线整体该怎么打？（诊断／货盘／投放／爆款／客户／利润／每日巡店／全域增长） |
| **L2 域层** | 9 | **九个专项岗位的手册** | 这个具体活儿到底怎么做？ |
| **L3 工具层** | 2 | **两个开箱即用的作业包** | 直接给我能执行的东西，不用再问 |

> **另有一本直接连数据库的**：`daily-store-patrol` 每日巡店属于 L1，它把 PG 里的每日订单/成本/推广费用与店铺侧流量/客户资产/万相台推广，连成一条每天跑的巡店流水线（详见第四节）。

**一条铁律**：L0 管全局，L1 管"一条业务线怎么打"，L2 管"这个具体活儿怎么做"，L3 给成品。

**使用上的含义**：
- 不知道该翻哪本 → **先翻 L0**（它有完整的"症状 → 该找哪本"分流表）
- 已经在某个具体环节卡住 → **直接跳到对应的 L1/L2**
- 要的是"直接能用的东西"（一张开款表、一份需求地图）→ **用 L3**

## 四、20 本手册逐本介绍

### 第一层：总经理经营手册（1 本）

| 手册 | 一句话 | 什么时候打开它 |
|---|---|---|
| **skill-ecommercial** | 全链路总纲与导航 | "我整体该按什么顺序做""这个指标怎么算""我该找哪本手册" |

它还负责讲清 **2026 年四个已经不可逆的变化**（流量格局倒挂、考核口径改看 GSV、爆款降级为引流工具、流量资产化），以及**四大金刚指标**和 **10 条最常用公式**。

2026-10-26 审计重写后，这本手册还多了六块「怎么用」的东西：

| 新增 | 作用 |
|---|---|
| **铁律** | 一句话覆盖式规则：先定位环节 → 再取公式阈值 → 最后才谈动作 |
| **何时用 / 何时不用** | 5 条「不用」场景各自给了去处，避免拿总纲当执行手册用 |
| **五步路由流程** | 定位 → 取数 → 取阈 → 选路 → 执行，每步带落点 |
| **常见误区与红线** | 4 条常见推托 + 5 条「发现即停」 |
| **输出格式** | 用这本手册回答时的四行固定交付格式 |
| **验收清单** | 6 条自查项，交付前自己先过一遍 |

### 第二层：部门主管手册（8 本）

| 手册 | 一句话 | 什么时候打开它 |
|---|---|---|
| **store-diagnosis** 店铺诊断 | 钱花在哪、投产是不是假好、该停哪个定向 | 推广费比异常；投产好看但没利润；不知道该停哪条计划 |
| **sabc-product-tiering** 货盘分级 | 给商品分 S/A/B/C 级、定预算比例、建全店矩阵 | 决定哪个链接加预算、哪个该停；做产品矩阵盘点与动态调级 |
| **wanxiangtai-wujie** 全域投放 | 万相台（无界）推广怎么搭、怎么诊断 | 搭或调全域推广计划；算成交机会；计划组合与预算加减 |
| **hit-product-lifecycle** 爆款周期 | 判断链接在爆款哪个阶段、标签怎么叠、该不该继续投 | 新品要打爆；判断现在该加投还是该收；阶段切换 |
| **customer-asset-ops** 客户资产 | 人群分层运营、老客召回复购、潜客培育 | 做人群分层；召回老客；判断人群准不准；给拉新定预算 |
| **profit-model** 利润算账 | 这个链接赚不赚钱、投产是不是真的、该投多少、什么时候停 | 算盈亏平衡与斩杀线；去伪投产；看顺逆差；利润分红 |
| **domain-growth-ops** 全域增长操盘 | 智篆商业·老草方法论：推广红绿灯、费比红线、系列化核算、人群资产分层、**推广目标制定与红绿灯报表生成** | 判断该不该加推广预算；费比是否超标；引流款该不该砍；做收割还是拉新；系列怎么打包核算；推广投产假好怎么诊断；**目标该定多少**；**要一份推广红绿灯报表** |
| **daily-store-patrol** 每日巡店 | **直接连数据库逐日体检**：红绿灯表、问题与机会清单、今日行动项 | **每天开店第一件事**；费比/投产/退款异动排查；推广计划体检；重点商品与计划筛选 |

### 第三层：专项岗位手册（9 本）

| 手册 | 一句话 | 什么时候打开它 |
|---|---|---|
| **selection-testing** 选品测款 | 七维选品、五大选款法、测图测款标准流程 | 新品立项、选类目、测款、测图；新品失败要找原因 |
| **keyword-promo** 关键词推广 | 搜索流量怎么拿：选词分层、大词卡位、竞品截流、品牌攻防 | 有展现没点击；点击率低；搜索排名被竞品抢走；做测图选品 |
| **conversion-optimization** 转化优化 | 有流量没成交怎么救；SKU／主图／详情页／客单价怎么优化 | 点击高但转化低；SKU 没人选；客单价上不去；详情页跳失严重 |
| **pricing-margin** 定价费比 | 新品怎么定价、活动还有多少利润空间、最低价怎么管 | 定价；倒推活动空间；判断能不能报秒杀；控费比；分配利润款/引流款/形象款 |
| **campaign-playbook** 大促作战 | 618／双 11 全年节奏、报什么活动、蓄水与价盘管控、**双11 三层口径**（2026 备战方法论／2024-2025 官方走查／**2026 官方规则与报名时间表**） | 排大促节奏；活动报名与备货；蓄水；大促付费节奏；双11 备盘与链接矩阵；**双11 报名截止与官方立减玩法**；活动后复盘 |
| **data-metrics** 数据指标 | 平台到底考核什么、报表先看哪个数、该走小建模还是大建模 | 不清楚平台考核口径；拿到报表不知从哪看；跳失率/退款率归因；费比与红绿灯 |
| **visual-material** 视觉素材 | 主图点击率、铺素材拿免费流量、站外内容变站内流量 | 主图点击率低；想铺素材；做视觉升级；做爆品裂变 |
| **toolchain-ai** 工具链与 AI | 千牛／生意管家怎么用、怎么用 AI 提效、怎么搭团队知识库 | 工具选型；AI 巡店与商品诊断；AI 生成主图；搭运营智能体；团队分工 |
| **compliance-medical** 医械合规 | 医疗器械的红线在哪、怎么每周巡检、违规会怎样 | 医械店每周文案巡检；大促前全店审查；查禁用词；判断资质与处罚 |

## 五、怎么用（调用方式）

### 方式一：直接说人话（推荐）

**不用记手册名字，也不用记顺序。** 把你的情况和问题讲清楚，AI 会自己挑对应那本。

```
我的天猫店推广费比最近从 12% 涨到 19%，GSV 掉了 15%，帮我查一下钱花在哪没生效
```

### 方式二：点名要哪本（结果更聚焦）

```
用 store-diagnosis 帮我做一次完整的店铺诊断
用 profit-model 算一下这个链接的盈亏平衡 ROI 和斩杀线
用 campaign-playbook 倒推 618 的备货与蓄水节奏
```

### 方式三：串起来用（推荐给复杂问题）

```
先按 store-diagnosis 诊断出问题属于哪一层，
再按 profit-model 算清楚继续投和不投分别能赚多少，
最后按 sabc-product-tiering 给出预算重新分配方案
```

### 提问的四个要素

问题问得越全，答案越能落地：

| 要素 | 举例 | 不给会怎样 |
|---|---|---|
| **对象** | 哪个店 / 哪个链接 / 哪个类目 / 什么产品 | 只能给通用答案 |
| **症状** | 哪里不对、什么时候开始的 | 只能给罗列式清单 |
| **数据** | 具体的数（费比、转化率、客单价、毛利率） | 判断不了轻重缓急 |
| **时间** | 上周？上个月？某个大促之后？ | 分不清是趋势还是波动 |

### 三个对照范例

**❌ 问法太虚**
> "我的店铺最近生意不好，怎么办？"

AI 只能回一份"应该都做一下"的清单。

**✅ 补齐四要素**
> "我是做家用血压计的天猫店。8 月开始推广费比从 12% 涨到 19%，GSV 掉了 15%，主推款是客单价 189 元的礼盒装。以前靠搜索流量，现在推荐流量占 85%。帮我诊断一下钱到底花在哪没生效。"

AI 会自动走：**先诊断 → 判断是哪一层的问题 → 给出对应动作和停手标准**。

---

**❌ 问法太虚**
> "618 怎么打？"

**✅ 补齐四要素**
> "我要报 618。主推款客单价 189 元、毛利率 42%，目前推广费比 15%，历史最低价定了 169 元。帮我倒推一下活动价还有多少利润空间、值不值得报名，并给一份倒排 30 天的备货与蓄水表。"

---

**❌ 问法太虚**
> "给我几个爆款方向。"

**✅ 补齐四要素**
> "我要开一款家用血压计的新品，预算 3 万，目标 30 天起量。帮我按七维选品法评估一下要不要做，再给测款测图的标准流程和判断停手的门槛。"

---

### 怎么判断它答得对不对

三处可以核对：

| 看什么 | 在哪看 | 说明 |
|---|---|---|
| **出处** | 手册里会写"来源：某某笔记" | 每个数字都能回溯到原始课程/实战记录 |
| **冲突提示** | 出现"口径冲突，需复核" | 素材本身有两种说法，两套都给你，**要你自己选** |
| **未验证标记** | 出现"素材未覆盖，未验证" | 原始资料里没这块，AI 不会替业务方编 |

**特别注意**：标记了"口径冲突"的地方，**必须由你按当前平台规则拍板**，别直接照抄任一套。

## 七、使用注意

| 事项 | 说明 |
|---|---|
| **数据有时效** | 里面的门槛是 **2026 上半年**的口径快照。平台规则会变 —— **引用具体数字前先核对当期平台公告** |
| **只覆盖淘系** | 淘宝／天猫。京东、拼多多、抖音的对应方法论在知识库里另有笔记，本轮没有做进来 |
| **医械手册只适用医械类目** | 别的类目不要套用 `compliance-medical` 的禁用词表 |
| **灰色手法已做风险分级** | 买家秀 P 图、多账号问大家、差评折叠这类素材里的灰色做法，**只标注了风险等级，不提供规避平台检测的方法** |
| **部分内容未验证** | 如关键词推广后 8 式、RFM 八分类阈值、尖刀连原稿等，原始资料本身有缺口，库里已逐条标注 |
| **口径冲突要人来裁决** | 库里不替你做这个决定 |
