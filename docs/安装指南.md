# 安装指南 · skill-ecommercial

本文回答三个问题：**装到哪里去**、**怎么装**、**不确定用哪本技能时怎么调**。

---

## 一、装到哪里去

### 技能本体长什么样

一个技能 = 一个目录，核心是 `SKILL.md`：

```
skills/daily-store-patrol/
├── SKILL.md          ← 必需：frontmatter(name, description) + 正文
├── chapters/         ← 分册（详细展开）
├── glossary.md       ← 术语表
├── patterns.md       ← 套路库
├── cheatsheet.md     ← 速查表
└── scripts/          ← 可执行脚本（可选）
```

`SKILL.md` 的 frontmatter 只有两个字段，是 **Anthropic Agent Skills 开放格式**，
Claude Code / Claude Code 桌面版（cc-haha）/ MiniMax Code / Cursor / Codex 等都认：

```yaml
---
name: daily-store-patrol        # 必须与目录名一致
description: "淘宝/天猫店铺每日巡店：……关键词：每日巡店、巡店、红绿灯、费比异常……"
---
```

`description` 里那一串**关键词**就是自动触发器 —— 用户说"帮我巡个店""费比怎么这么高"，
宿主会靠它匹配到这本。

### 本机的实际安装位置

| 宿主 | 技能目录 | 说明 |
|---|---|---|
| **Claude Code / cc-haha** | `C:\Users\Duanyi\.claude\skills\` | 真实路径是 `E:\Users\Duanyi\.claude\skills\`（C 盘那个是符号链接，同一处） |
| **MiniMax Code** | `E:\Users\Duanyi\.minimax\.minimax\skills\` | C 盘同名目录是空壳，以 E 盘为准 |

> 本机 `C:\Users\Duanyi` 与 `E:\Users\Duanyi` 下都有配置根，**装之前先确认哪个是空的**。
> 下面脚本会自动判断。

## 二、怎么装

### 方式 A：一条命令（推荐，跨平台）

```bash
# 方式 A1：skills 官方 CLI（已实测对本仓库有效：--list 能正确识别出 20 本）
npx skills add https://github.com/kizemo/skill-ecommercial --list    # 先看有哪些，不装
npx skills add https://github.com/kizemo/skill-ecommercial -g -a '*' -s '*' -y --copy
#                 ↑ -g 全局   ↑ 装给所有 agent  ↑ 全部技能        ↑ 复制而非符号链接

# Windows 注意：默认建符号链接，需要管理员权限；普通权限请加 --copy。
```

```bash
# 方式 A2：仓库自带安装脚本（自动识别本机 Claude Code / MiniMax Code 路径）
python scripts/install_skills.py --list-hosts   # 先看装哪里
python scripts/install_skills.py --host claude  # 或 --host minimax
python scripts/install_skills.py --host claude --only daily-store-patrol,store-diagnosis
python scripts/install_skills.py --host claude --dry-run   # 只看不装
python scripts/install_skills.py --host claude --force    # 仓库更新后覆盖
```

`skills` CLI 与本仓库脚本的分工：前者面向"我拿到一个 GitHub 仓库想装"，
后者面向"我知道要装给哪个宿主、想精确控制装哪几本"。

脚本只复制目录，**不改宿主配置、不写口令**。默认 `copy` 模式，任何平台都行；
想省磁盘可用 `--mode symlink`（Windows 需要管理员权限）。

### 方式 B：手动拷贝（不想跑脚本时）

把 `skills/` 下需要的目录整个复制到宿主的 skills 目录即可：

```powershell
Copy-Item -Path 'F:\soft\00selfmade\skill-ecommercial\skills\*' -Destination 'C:\Users\Duanyi\.claude\skills\' -Recurse -Force
```

### 方式 C：Claude Code 插件市场（一键，适合团队分发）

本仓库已带 `.claude-plugin/marketplace.json`，可以直接当市场用：

```
/plugin marketplace add kizemo/skill-ecommercial
/plugin install skill-ecommercial@skill-ecommercial
```

- **必须用 Git 方式 add**（仓库名形式）。若用 `marketplace.json` 的直链 URL，相对路径不解析，会装空。
- 装完技能带命名空间：`/skill-ecommercial:daily-store-patrol`。
- 插件方式会把仓库复制到 `~/.claude/plugins/cache/`，所以 `scripts/` 里的相对路径引用仍然有效。

### 方式 D：GitHub 用户拿到这个仓库后

给终端用户的三条路，按省事程度排：

```bash
# 1) 最省事：让 Claude Code 直接装（无需 clone）
/plugin marketplace add kizemo/skill-ecommercial
/plugin install skill-ecommercial@skill-ecommercial

# 2) 手动：clone 后跑安装脚本
git clone https://github.com/kizemo/skill-ecommercial.git
cd skill-ecommercial
python scripts/install_skills.py --host claude      # 或 --host minimax

# 3) 纯拷贝：只要 skill 不要脚本和文档
git clone --depth 1 https://github.com/kizemo/skill-ecommercial.git
cp -r skill-ecommercial/skills/* ~/.claude/skills/
```

### 方式 E：团队内部分发（项目级自动安装）

在项目仓库的 `.claude/settings.json` 里写：

```json
{
  "extraKnownMarketplaces": {
    "skill-ecommercial": {
      "source": { "source": "github", "repo": "kizemo/skill-ecommercial" }
    }
  },
  "enabledPlugins": {
    "skill-ecommercial@skill-ecommercial": true
  }
}
```

团队成员信任这个项目文件夹时，Claude Code 会提示安装。

### 装完必做

**重启宿主**。Claude Code / cc-haha / MiniMax Code 都是在会话启动时索引技能目录的，
不重启的话新装的技能本轮不会出现在可用列表里。

### 装完验一下（可选，但建议）

```bash
python scripts/verify_install.py            # 全部宿主
python scripts/verify_install.py minimax   # 只查 MiniMax Code
```

它会自动探测本机各宿主目录（和安装脚本同一套逻辑），逐文件比对 **SHA256**，
确认宿主里的内容与仓库完全一致：

```
✅ 验收通过：2 个宿主、20 本技能，文件与仓库一致、frontmatter 均为 name+description
```

**它能抓什么**：文件多/少了、文件同名但内容是旧版（没重装）、`SKILL.md` 的 frontmatter 被改坏、
整本技能缺失。报不一致时的修法就是重跑安装脚本加 `--force`：

```bash
python scripts/install_skills.py --host claude  --force
python scripts/install_skills.py --host minimax --force
```

> 装了多个宿主的话，**每个宿主都要跑一次** —— 脚本只覆盖本仓的 20 本，宿主目录里的其它技能不动。

## 三、不确定用哪本技能时，怎么调

### 1. 先走 L0 路由

`skill-ecommercial` 是这套技能库的总入口，它自己不执行动作，只回答
「我现在在哪一环 / 这一环该用哪本 / 关键公式和阈值是多少」。

```
/skill-ecommercial
```

或直接说人话，宿主会靠 description 匹配到它：

> 帮我看看这个店现在到底卡在哪一环，该用哪本技能。

### 2. 症状速查表（挑技能的最快路径）

`docs/使用说明书.md` 里有完整表，日常最常用的一条：

| 你遇到的情况 | 打开哪本 |
|---|---|
| 每天开店要做一次全店体检 | `daily-store-patrol` |
| 费比突然变高，投产好看却不赚钱 | `store-diagnosis` → `profit-model` |
| 不知道哪个链接该加钱、该停 | `sabc-product-tiering` |
| 钱花在哪没生效 | `store-diagnosis` |
| 搜索没点击、排名被抢 | `keyword-promo` |
| 有流量没成交 | `conversion-optimization` |
| 算不清这个链接赚不赚钱 | `profit-model` |
| 想知道买过的人怎么再买一次 | `customer-asset-ops` |
| 大促节奏、蓄水、价盘 | `campaign-playbook` |
| 双11 备盘、链接矩阵、资产召回 | `campaign-playbook` |
| 新品测不出结果、测款没转化 | `selection-testing` |
| 费比红线、推广红绿灯、该给谁加钱 | `domain-growth-ops` |
| 指标口径搞不清、老板要什么数 | `data-metrics` |
| 禁用词、资质、处罚风险 | `compliance-medical` |
| 想看某个功能怎么做（AI 工具、千牛、生意管家） | `toolchain-ai` |
| 主图/详情页/视觉素材 | `visual-material` |

### 3. 让 AI 自己选（最省事的用法）

不指定技能名，把问题丢进去即可 —— 每本技能的 `description` 都带触发关键词：

> 帮我巡一下店，看看费比和投产有没有问题。
> 这个链接投产很高但不赚钱，是真的吗？
> 大促前 30 天该做什么准备？

宿主会自动挑对应技能；**若拿不准，它会先走 `skill-ecommercial` 路由**。

### 4. 手动指定（斜杠命令）

```
/skill-ecommercial           # L0 总纲 / 路由
/store-diagnosis               # L1 店铺诊断
/daily-store-patrol            # L1 每日巡店（直连数据库）
/profit-model                  # L1 利润算账
/customer-asset-ops            # L1 客户资产
```

以插件方式安装时带命名空间：`/skill-ecommercial:store-diagnosis`。

### 5. 只想让 AI 当资料查

把技能目录当普通文档读也行 —— 每本都有 `cheatsheet.md`（一页速查）和 `glossary.md`（术语表），
直接让 AI 读这两个文件就能拿到最密的信息。

## 五、常见问题

**Q：装完 `/skill-name` 提示找不到？**
A：没重启宿主。技能目录是在会话启动时索引的。

**Q：Claude 里同时出现 `skill-ecommercial` 和 `taobao-ops-playbook` 两个入口？**
A：旧的 L0 入口目录残留。入口已改名为 `skill-ecommercial`，但改**不会自动清掉**宿主里的旧目录 —— 重装后手动删掉它即可（路径按 `--list-hosts` 输出的 ★ 位置为准）：

```bash
rm -rf ~/.claude/skills/taobao-ops-playbook            # Claude Code
rm -rf ~/.minimax/.minimax/skills/taobao-ops-playbook  # MiniMax Code
```

**Q：Claude Code 装插件后说找不到技能？**
A：多半是用 URL 直链加的市场。要用 Git 方式：`/plugin marketplace add kizemo/skill-ecommercial`。

**Q：`daily-store-patrol` 报错连不上数据库？**
A：这本技能要连 PostgreSQL 才有意义。先设好环境变量（口令别写进仓库）：

```powershell
$env:PGHOST='127.0.0.1'; $env:PGPORT='5432'; $env:PGUSER='<用户>'
$env:PGPASSWORD='<口令>'        # 或写进 ~/.pgpass
```

其它 19 本是纯方法论，不需要数据库。

**Q：装在 C 盘还是 E 盘？**
A：跑 `python scripts/install_skills.py --list-hosts`，看 ★ 标记 —— 那就是脚本实际会写的位置。
本机 C 盘的 `.claude` 是指向 E 盘的符号链接，同一处；`.minimax` 那套 C 盘是空壳，要装 E 盘。
