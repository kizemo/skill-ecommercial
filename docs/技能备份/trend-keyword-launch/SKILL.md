# 趋势词开款与投放自动化引擎

**来源**：`taobao-operation` 知识库（智篆商业 少壮老师，第二次线下坐诊 2026-05-10）｜**层级**：L3 工具层｜**版本**：2026.10

把一份**搜索增速词榜单**直接转成产品开发与投放方案：趋势词 → 开款结构 → 标题 → 词包 → 人群 → 分级 → 表格。

**这是知识库里现成的两个「技能包」之一**，本身就带完整的判断引擎与输出字段定义 —— 不需要另造方法论。

---

## 一、这个工具解决什么问题

| 现状 | 本工具的输出 |
|---|---|
| 看到趋势词，不知道能开什么款 | 每个可开款词 → 元素 + 结构 + 材质 + 风格 |
| 开了款，不知道标题怎么写 | 结构化标题公式 |
| 上了架，不知道投什么词 | 核心词 / 扩展词 / 长尾词三层词包 + 拉新/收割标注 |
| 词定了，不知道投给谁 | 性别 / 年龄段 / 消费力 / 兴趣标签 |
| 一堆品，不知道先做哪个 | SAB 分级 + 操作优先级 |

**与三阶引擎的衔接**：本工具输出的 **SAB 分级 + 优先级**，就是三阶引擎**第一层（SAB 分级确定推广优先级）的输入**。趋势词开款方向还可对接 8 维度考核（第二层）。

---

## 二、核心概念：热搜词 vs 趋势词

| 类型 | 特征 | 策略 |
|---|---|---|
| **热搜词** | 当前热门，**已被市场验证** | 竞争激烈 = **红海** |
| **趋势词** | **搜索增速高**，尚未被验证 | 先发优势 = **蓝海机会** |

**这是本工具的核心判断**：不做热搜词做趋势词。热搜词证明"这个需求存在"，但也证明"所有人都能做"。趋势词只证明"需求在涨"，还没证明"你能吃到"。

---

## 三、10 步流水线

| 步骤 | 内容 |
|---|---|
| **1. 数据输入** | 搜索词 / 搜索增速 / 类目 |
| **2. 词语分类** | 保留 / 剔除 / 弱价值（核心判断引擎） |
| **3. 筛选过滤** | 满足设计/结构元素，排除品牌/泛化词 |
| **4. 开款结构** | 元素 + 结构 + 材质/风格 |
| **5. 标题生成** | 核心元素 + 结构 + 人群 + 风格 + 场景 |
| **6. 词包生成** | 核心词 / 扩展词 / 长尾词，**标注拉新/收割** |
| **7. 人群匹配** | 性别 / 年龄段 / 消费力 / 兴趣标签 |
| **8. SAB 分级** | S级爆款 / A级放量 / B级利润 |
| **9. 最终输出** | 结构化表格（11 个字段） |

---

## 四、步骤 2：词语七分类（核心判断引擎）

每一个词都必须打上分类标签：

| 分类 | 策略 | 说明 | 示例 |
|---|---|---|---|
| **1. 强设计元素词** | ✅ **保留** | 核心视觉元素 | 魔鬼鱼、月牙、流苏、荷鲁斯之眼 |
| **2. 结构词** | ✅ **保留** | 产品形态 | 锁骨链、吊坠、链条 |
| **3. 材质词** | ✅ **保留** | 材料属性 | 珍珠、宝石、金属 |
| **4. 风格词** | ⚠️ **辅助参考** | 调性描述 | 轻奢、复古、少女 |
| **5. 品牌词** | ❌ **剔除** | 知名品牌 | 蒂芙尼、克罗心、英文品牌 |
| **6. 无效词** | ❌ **剔除** | 泛化词汇 | 夏天、新款、百搭、999 |
| **7. 场景词** | ⚠️ **弱价值** | 使用场景 | 送妈妈、礼服、约会 |

**判定要点**：保留的是「**能变成具体产品**」的词（元素/结构/材质），辅助的是「**修饰**」的词（风格/场景），剔除的是「**跟产品无关或不能独占**」的词（品牌/无效）。

---

## 五、步骤 3：筛选过滤（可开款判据）

**必须满足：**
- ✔ 至少包含「设计元素」**或**「结构元素」

**必须剔除：**
- ✘ 品牌词
- ✘ 无法形成具体产品结构的词
- ✘ 纯形容词（高级感 / 夏天）

> **纯形容词是最大的漏斗** —— 「高级感」「夏天」「新款」这类词搜索量可能很大，但**开不出款**。它们进不了标题的核心位置。

---

## 六、步骤 4：开款结构公式

对每一个「可开款词」自动拆解生成四要素：

- **核心元素**（如：魔鬼鱼）
- **结构**（吊坠 / 锁骨链 / 鱼线链）
- **材质**（珍珠 / 金属 / 透明）
- **风格**（轻奢 / 复古 / 少女）

组合为：

```
开款结构公式：【元素】+【结构】+【材质/风格】
```

---

## 七、步骤 5：标题生成

```
标题结构：【核心元素】+【结构】+【人群】+【风格】+【使用场景】
```

**要求**：
- 符合淘宝搜索习惯
- 覆盖核心关键词
- 可直接用于直通车 / 自然搜索

> 与 `[[keyword-promo]]` 的标题权重规则一致：**核心词放两端，长尾词布局中间**。

---

## 八、步骤 6：投放词包（三层 + 标注）

为每个产品生成关键词包：

| 层级 | 示例 | 作用 |
|---|---|---|
| **核心词** | 魔鬼鱼项链 | 卡主战场 |
| **扩展词** | 小众项链 / 设计感项链 | 扩量 |
| **长尾词** | 轻奢魔鬼鱼锁骨链 | 精准 |

**每个词必须标记：拉新词 / 收割词。**

> 标记直接对接投放策略：拉新词用广泛匹配 + 低出价拓人群，收割词用精准匹配 + 高出价拿成交（见 `[[keyword-promo]]`）。

---

## 九、步骤 7：人群匹配

| 维度 | 示例 |
|---|---|
| 性别 | 女性 |
| 年龄段 | 18-35 |
| 消费力 | L3-L5 |
| 兴趣标签 | 轻奢 / 小众 / 设计感 / 潮流 |

> 消费力层级（L1-L5）与人群资产分层的关系见 `[[customer-asset-ops]]`。

---

## 十、步骤 8：SAB 分级

依据「**趋势强度 + 通用性**」两轴分级：

| 等级 | 描述 | 示例 |
|---|---|---|
| **S 级（爆款）** | 强趋势 + 强设计 | 魔鬼鱼 / 荷鲁斯之眼 |
| **A 级（放量）** | 通用设计 | 星 / 月牙 / 花朵 |
| **B 级（利润）** | 材质类 | 珍珠 / 宝石 |

**输出：SAB 等级 + 操作优先级。**

> ⚠️ **口径提示**：这里的 SAB 是**趋势词视角**的分级（看趋势强度与通用性），与 `[[sabc-product-tiering]]` 的 S/A/B/C **货盘视角**分级（看流量/利润占比与生命周期）判定标准不同。两套的 S/A/B 字母相同但含义不同，**不要混用同一张表**。

---

## 十一、步骤 9：最终输出表格（11 字段）

| 趋势词 | 核心元素 | 结构 | 材质 | 风格 | 开款方向 | 标题 | 投放关键词 | 人群标签 | SAB分级 | 优先级 |
|---|---|---|---|---|---|---|---|---|---|---|

---

## 十二、数据输入规范

读取数据时提取三个字段：

| 字段 | 说明 |
|---|---|
| **搜索词** | 必填 |
| **搜索增速** | 如有；**这是趋势词与热搜词的分界依据** |
| **类目** | 默认值：饰品-项链/耳环 |

> 类目默认值来自素材原始场景（智篆陪跑的饰品类目）。换类目时必须显式改写，否则会产出饰品结构套到别的类目上。

## Scope & Limits

- 本 skill 是**选品与投放的前置引擎**，不是完整运营流程。产出的品仍需过 `[[selection-testing]]` 的七维选品与测款验证。
- **类目默认值是饰品**（项链/耳环）。其他类目必须改写结构词与人群标签的映射。
- 词语分类与 SAB 分级是**经验规则**，素材未给出量化阈值 —— 不同类目的保留/剔除边界需要重新校准。
- 搜索增速词榜单**需要自己去生意参谋/生意管家拉**，本 skill 不含数据获取能力。
