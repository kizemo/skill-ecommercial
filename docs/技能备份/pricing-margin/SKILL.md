# 定价、费比与活动价盘

**来源**：`taobao-operation` 知识库（GBRain source `taobao-operation`，2013 页）｜**版本**：2026.10｜**层级**：L2

本 skill 回答三个问题：**① 这个品该定多少钱？② 报活动还剩多少利润空间？③ 费比超了会被降权吗？**

定价不是"拍脑袋 + 跟竞品"，是**倒推**：先定角色毛利率 → 倒推可承受底价 → 再把跨店满减/购物金/淘金币/扣佣的空间预留进去 → 最后才设活动价。

---

## 一、先记住这三条（最高频）

**① 定价预留空间公式**（报任何活动前必须先算）

```
最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1−扣佣比例)
```
（来源：`2026淘宝运营完整知识体系` §9.2）

⚠️ **口径冲突，需复核**：`爆款叠标打法全解` §5.2 把同一公式写成 `× (1 + 扣佣比例)`，与上式不一致。但该笔记 §5.3 的扣佣利润案例只有 ÷ (1−扣佣比例) 能精确复算：

```
成本 40 元、毛利率 80%、预留 25% 扣佣空间
40 × 1.8 × 1.2 × 1.05 × 1.1 ÷ 0.75 = 133.05 ≈ 133 元 ✓
```
→ **本 skill 统一采用 `÷ (1−扣佣比例)`**。

**② 最低价管控两条清单**（决定你能不能用"不降价"的手段做活动）

| 不计入最低价 | 计入最低价 |
|---|---|
| 首单礼金 / 新品礼金 / 店铺优惠券 / 购物金 / 淘金币 / 超级立减 / 会员专享 / 营销托管 | 百亿补贴 / 秒杀 / 跨店满减 / 直降 |

（来源：`2026淘宝运营完整知识体系` §9.3、`爆款叠标打法全解` §5.1）

**③ 价格力 = 第一权重**（2026 平台规则变化，取代五星价格力）

| 变化 | 说明 |
|---|---|
| 比价机制 | 活动报名自动对比**全网同款/相似款**价格 |
| 消费券分级 | 根据营销投入、价格力、体验分划分 |
| **后果** | **价格不达标直接被踢出活动** |

（来源：`爆款三板斧-平台规则` §1）

> 推论：**优惠方式的选择就是价盘的选择**。想保价盘 → 用不计入最低价的手段（首单礼金/购物金/淘金币/超级立减）；想拿秒杀流量 → 必须真降价，且要跟得住全网比价。

## 二、三种定价法（打底用）

| 方法 | 公式 | 什么时候用 |
|---|---|---|
| **成本定价** | 成本 × (1 + 毛利要求) | 成本结构清晰、差异化强、不打价格战 |
| **竞品定价** | 基于竞品价格带 | 标品、类目价格带清晰 |
| **价值定价** | 基于客户感知价值 | 有品牌溢价、非标品 |

（来源：`爆款三板斧-产品布局`）

**进阶层：价格带怎么选**（来源：`大体系利润篇-电商高利润定价策略` 2/3）

- **利润规模定价法** —— 梳理类目所有价格带，找"赚钱商家比例、单利、年盈利额、动销率、点击率、转化率、广告费占比、人工成本"综合最优的价格带。
- **投产胜率定价法** —— 先用"鄙视对手"（找对手短板）判断自己在哪个价格带**打得赢**，再在该带里用利润规模法定具体价。**顺序不能反**。
- **性价比定价法** —— 双向操作：最大化提升消费者感知价值，最小化控制实现成本。**"想卖 30 元，就塑造成 60 元价值；想卖 100 元，就塑造成 300 元价值。"**
- **黄金定价法** —— 划价格段（低价/中价/高价）→ 采每段销量 TOP8 的定价与月销量 → 剔异常值算各段平均定价 → 对各段平均价做**二次加权平均**得黄金定价 → 对各段平均销量做二次平均得预期日/月销目标。

> 核心命题：**电商赚钱的核心能力是"卖贵"而非"卖便宜"**。低利润区间聚集 80% 的竞争对手，是血流成河的红海；高利润区间几乎无竞争。

## 三、四种角色的毛利率分工

| 角色 | 毛利率 | 职责 |
|---|---|---|
| **利润款** | **≥30%** | 店铺利润核心 |
| **引流款** | **15-20%** | 带流量为主 |
| **形象款** | **≥40%** | 拉高店铺调性、撑客单价 |
| **清仓款** | 可低 | 回款为主、清理库存 |

（来源：`电商功守道 3384 利润公式` §3.2）

配套的 3384 目标线：**净毛利率 ≥20%、净利率 ≥10%**；全店动销率 ≥60%；客单价高于类目均价 20%+；复购率 ≥15%。

## 四、科学定价（2026 新政）

```
定价毛利率 = 固定费用率(约20%) + 可变费用率(约33-38%) + 目标净利率(建议10%)
定价倍率   = 1 ÷ (1 − 定价毛利率)
```

- 可变费用率拆解：包装物流 3-5% + 平台扣点 8% + 推广费（按去年 ×1.2）+ 税点 5-10%
- **建议定价毛利率 ≥64% → 倍率约 2.78 倍**；50 元成本产品 → 定价 **139 元**
- 2026 新政背景：平台补贴加剧 + 税务合规，推广费从占 GSV 的 10% 跳到 20%；100 元产品卖家到手收入从 90 元降到 80 元
- 涨价时间线：2023 价格力概念淡化 → 2024 头部率先涨价 → 2025 全行业涨 → **2026 强制涨**；涨价后消费者到手价不变（平台补贴抵消），卖家收入恢复

（来源：`2026新政下新品速爆1科学定价`）

> ⚠️ **口径差异**：2026-07-27 批次给出"**定价倍数 2-2.5 倍最优**（2 倍毛利 35% vs 3 倍毛利 36.6%）"，低于科学定价的 2.78 倍。两者场景不同——科学定价是新政下的成本倒推保命线，2-2.5 倍是常规利润率反推的最优区间。**新店/高成本品先按 2.78 倍起算，跑通后再向 2-2.5 倍收敛。**

**核心认知转变：从"控费降 ROI"转为"稳 ROI、高花费、高规模"。** 平台补贴的本质是"羊毛出在羊身上"——消费者少付的钱，最终通过提高推广费的方式转移给了卖家。

## 五、费比与商业化保费比

**费比 = 推广花费占成交金额的比例**（MTD 费比 = 月度累计口径）。

| 规则 | 内容 |
|---|---|
| **费比强制要求** | 广告花费占比**不低于去年同期** |
| **不达标后果** | 消费券从"平台全资"降为"**商家混资/全资**" |
| **⚠️ 淘客无效** | **淘客佣金不计入商业化权重**，无法提升店铺权重——只能短期冲量 |
| 天猫 vs 淘宝 | 天猫权重 > 淘宝（扣点更高，权重天然更高） |

（来源：`爆款三板斧-平台规则` §2）

**费比参考区间**

| 场景 | 费比 |
|---|---|
| 行业均值（2025 口径） | 约 5%，上下浮动约 1% |
| 万相台无界 · 矩阵模式 | 3%-5% |
| 万相台无界 · 动销模式 | 5%-8% |
| 万相台无界 · 爆款模式 | 8%-10% |
| 直通车 · 营销托管（非标新品） | 约 20-25% |
| 直通车 · 老品走全站 | 可达 5-10 倍营销托管 |

**红绿灯判费比**（来源：`P4-多端数据融合调研`）

| 条件 | 灯 |
|---|---|
| 实际费比 ≤ 目标费比 | 🟢 绿 |
| 目标费比 < 实际 ≤ 目标费比 × 1.2 | 🟡 黄 |
| 实际 > 目标费比 × 1.2 | 🔴 红 |

> ⚠️ **MTD 费比**在知识库中是低密度概念笔记，素材未给出完整口径与计算细节 → **未验证**。

## 六、算账四公式

```
盈亏平衡投产比 = 1 ÷ (毛利率 × (1−退款率))          ← 定价与投放的共同约束
盈亏平衡 ROI   = 1 ÷ 毛利率                          ← 毛利 60% → 1.67
斩杀线        = 固定成本 ÷ (毛利率 − 推广费用占比)      ← 月销 > 1.5 倍斩杀线 = 健康经营
真实投产      = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交
```

（来源：`爆款三板斧-七维选品`、`淘系运营核心公式`、`2026淘系电商斩杀线破局`、`2026-07-27` 每日学习批次）

## 使用说明

1. **定角色** → 定毛利率（利润款 ≥30% / 引流款 15-20% / 形象款 ≥40% / 清仓款 可低）
2. **算底价** → `成本 × (1+毛利率)`，再用预留空间公式放大成对外定价
3. **选优惠手段** → 想保价盘用不计入最低价的，想拿秒杀流量用计入最低价的
4. **算活动利润空间** → 用 `盈亏平衡投产比` 和 `真实投产` 复核，别只看成交额
5. **算费比** → 对齐去年同期，低于同期直接补预算或降费比策略，否则消费券降级

**配合使用**：`[[campaign-playbook]]`（报名与节奏）、`[[profit-model]]`（算账与投产去伪）、`[[sabc-product-tiering]]`（角色分配与预算）、`[[selection-testing]]`（测款与毛利空间评估）、`[[hit-product-lifecycle]]`（叠标与阶段定价）、`[[wanxiangtai-wujie]]`（费比与人群资产）、`[[skill-ecommercial]]`（总纲与公式索引）。

## Scope & Limits

- 本 skill 覆盖淘系（淘宝/天猫）定价与费比。**京东/拼多多/抖音的定价规则在知识库中另有笔记，本轮未 skill 化。**
- 所有阈值与数字均为知识库原文快照（2026 上半年口径）。**平台规则会变，落地前核对当期平台公告。**
- 定价预留空间公式存在**口径冲突**（÷ 与 × 两种写法），本 skill 已选边并给出复算依据，仍需向原作者确认。
- `2026-07-27` 批次与"价盘管控方法""优惠券定时失效对冲法"相关内容来自 **KB 盘点报告的二次转录**，非原笔记直读，落地前应核对原笔记。
- 医疗器械类目的定价与资质约束另见 `[[compliance-medical]]`；本 skill 不覆盖广告法禁用词与资质分级。
