# 工具链与 AI 提效

**来源**：`taobao-operation` 知识库（千牛AI生意管家实战指南 + AI智能体应用 + 多Agents配置方案）｜**层级**：L2 域层｜**版本**：2026.10

工具不是目的。这个 skill 回答：**哪些活该交给 AI、哪些绝不能交、以及怎么把 AI 接进现有流程。**

## 一、先分清三层：千牛 AI / 生意管家 / 生意管家 AI 经营

知识库里至少有三套切法，**说的不是同一层的东西**。先对齐层级，再谈功能：

| 层 | 名称 | 定位 | 能力范围 |
|---|---|---|---|
| **平台层** | **千牛 AI** | 千牛工作台内置的 AI 经营**平台**，底层通义大模型 | **5 大能力**：诊断/报告/客服/内容/数据 |
| **模块层** | **生意管家** | 千牛 AI 下的**功能模块** | **4 大功能**：诊断/报告/客服/内容 |
| **工具层** | **生意管家 AI 经营** | 面向商家的免费 AI 经营 agent | **1 店长 + 6 数字员工** |

**类比**（原文口径）：千牛 AI 像「App Store」，生意管家像「App Store 里的某个 App」。

**数据范围**：仅阿里系店铺（天猫/淘宝/天猫国际/淘特）—— **拼多多店不适用**。

**核心价值**（全功能免费）：

| 价值 | 说明 |
|---|---|
| **效率提升** | 人工 2-3 小时的工作，AI 1 分钟完成 |
| **风险规避** | 实时排查违规、库存、物流、推广异常 |
| **增长挖掘** | 从商品、人群、行业三维度找机会 |
| **降本增效** | 中小商家也能实现专业化运营 |

## 二、六大核心功能（商家感知口径）

### 1 · AI 巡店（全店诊断）

**1 分钟完成店铺全维度巡检**，四大模块：

| 模块 | 功能 | 价值 |
|---|---|---|
| **订单巡检** | 排查发货超时、物流异常 | 杜绝发货超时，提升物流体验分 |
| **商品巡检** | 排查标题违规词、库存、质量分 | 保住商品流量，避免降权 |
| **推广巡检** | 对标同行推广数据 | 优化广告投放效率 |
| **店铺巡检** | 排查体验分、违规记录 | 合规经营 |

**入口**：千牛 AI 版模式 → 全店诊断 → 执行巡检任务

**使用节奏**：
- **每日必巡** —— 每日早上 5 分钟完成全店异常处理
- **大促加倍** —— 大促期间每 4 小时巡检 1 次
- **重点盯爆款** —— 单独对 TOP3 爆款做专项巡检

### 2 · 商品运营小助手

| 功能 | 说明 | 案例 |
|---|---|---|
| **店铺装修选品** | 基于库存、销量、类目趋势智能划分首页区域 | 某服饰店首页点击率 +25% |
| **营销卖点挖掘** | 基于消费场景自动提炼高频标签，输出 3 套场景化卖点方案（视觉/文案/拍摄建议） | 某猫条店点击率 3% → 5.2% |
| **GMV 波动分析** | 从流量渠道、竞品流失、新老客、类目趋势四维归因 | 某家居店 3 天内 GMV 恢复到下跌前水平 |
| **潜力品筛选** | 五力评估模型科学打分 | **得分 ≥80 分**的潜力品重点运营 |

**节奏**：新品上架先做潜力品筛选 + 卖点挖掘｜每日对 TOP 爆款做 GMV 波动分析｜大促前 1 周完成店铺装修 + 活动页选品。

### 3 · 人群策略小助手

**适用**：服饰、美妆（其他类目逐步开放）

- 自动解析 **500+ 高价值人群标签**
- 输出新客拉新、老客复购策略
- 一键生成人群包同步至**达摩盘 / CRM**

**实操案例**（某修身女装店）：新客拉新成本 −35%｜老客复购率 +28%｜人群投放 ROI 2.0 → 3.5

### 4 · 行业洞察小助手

**开放对象**：天猫服饰类目商家。免费获取行业趋势报告、爆款特征、流量规则。

**推荐流量的基础规则（门槛）**：
```
店铺体验分 ≥ 4.3
商品质量分 ≥ 60
价格力三星以上
主图 ≥ 4 张，近 30 天有动销
支持七天无理由 / 包邮
```

> ⚠️ **口径提示**：这里的体验分门槛是 **4.3**、商品质量分 **60**；`[[compliance-medical]]` 与 `[[data-metrics]]` 记录的是 **4.6 / 4.2** 与 **PXI 70/60** 三套阈值。**来源不同、用途不同**（这里是"拿推荐流量"的门槛，那里是"不掉权重/能报名"的门槛），落地前确认你要问的是哪一个。

### 5 · AI 店长小助理

对话式 AI，一句话拿针对性建议：
- 「店铺转化率下降怎么办？」
- 「如何提升商品搜索流量？」
- 「大促期间怎么优化推广投放？」

### 6 · AI 数据分析

覆盖销售、流量、商品、竞争、市场、客户**六大核心场景**：
- 「帮我分析昨日店铺销售情况」
- 「帮我分析店铺销量下滑的原因」
- 「帮我筛选店铺潜力主推款」

## 三、AI 主图制作四大方法

| 方法 | 操作 | 注意事项 |
|---|---|---|
| **竞品主图模仿法**（最常用） | 找竞品优质主图 → AI 指令「换一个模特，其他场景保持 80% 不变，文案改成<你的文案>」 | **不要完全复制**，注意细节修改避免被判盗图 |
| **同款模特多产品生成法** | 豆包 AI 创作 → 上传模特照 → 让 AI 反推提示词 → 上传白底图 → 用提示词生成 | 节省拍摄成本，保持店铺主图风格统一 |
| **市场爆款主图学习法** | 指令「分析女士内裤类目的点击标准，学习前 20 的商品主图，并生成我自己的商品图」 | AI 自动学习前 20 名主图 |
| **竞品风格复刻法** | 上传竞品主图 + 自己白底图 → 指令「将竞品的风格沿用到我的白底图上，生成 8 个场景图」 | 产出 8 张场景图 |

> ⚠️ 医疗类目用 AI 做主图，必须过 `[[compliance-medical]]` —— **AI 生成的画面也可能带违规词或医疗效果暗示**（如生成"治疗""治愈"字样）。

## 四、AI 智能体搭建五步

1. **选择 AI 平台** —— 选支持自定义训练的平台
2. **上传知识库** —— 产品信息、平台规则、运营流程
3. **训练 AI** —— 通过对话和示例训练
4. **集成工具** —— 与千牛、达摩盘、生意参谋集成
5. **测试优化** —— 对输出持续测试与调优

**训练良好的智能体**：可替代 2-3 个运营助理的工作｜每年节省 10-20 万元人力成本｜效率是人工 10 倍以上｜可 24 小时不间断工作。

## 六、多 Agents 电商知识库配置（团队级）

**核心目标**：为 **12 个电商专属 Agent** 分别搭建精准匹配其工作领域的 Obsidian 知识库，实现「**Agent 职责 - 知识库内容 - 电商场景**」三者完全对齐。

| Agent | 工作领域 |
|---|---|
| **operation-assistant** | 运营助理 |
| **taobao-operation** | 淘宝运营 |
| **jd-operation** | 京东运营 |
| **pdd-operation** | 拼多多运营 |
| **designer** | 设计 |
| **it-engineer** | IT 工程 |
| **finance** | 财务 |
| **musk** | 全权限协调 |
| **data-analyst** | 数据分析 |
| **content-promotion** | 内容营销 |
| **hr-zhixindajie** | 人力资源 |
| **trainer** | 总管理 |

**目录结构**：`~/obsidian-vaults/` 下每个 Agent 一个目录 + 共享 `public/`（电商通用规范 / 大促活动资料 / 合规文档 / 工具素材）

**权限分层**：musk = admin（全权限）｜trainer = manager｜其余 = 对应专业角色

**前置要求**：OpenClaw v2.3.x+｜Node.js v18.0.0+｜Git v2.30.0+｜Obsidian v1.0+｜内存 16GB+（多 Agent 并发建议 32GB）｜存储 50GB+

**价值预期**：效率 +40%｜大促响应速度 +50%｜运营成本 −30%+｜数据安全合规｜知识沉淀自动化

> 本仓库 `skill-ecommercial` 就是这套思路的轻量化实现 —— **把一个知识库编译成 18 个按角色划分的 skill**，而不是给每个 Agent 挂一整个 vault。

## 七、工具选型建议

| 商家类型 | 推荐功能 | 优先级 |
|---|---|---|
| **新手商家** | 全店诊断 + AI 店长小助理 | 高 |
| **成熟商家** | 商品运营 + 人群策略 | 高 |
| **天猫服饰** | 行业洞察 | 必用 |
| **所有商家** | 每日 AI 工具，形成「巡检 → 优化 → 复盘」闭环 | 高 |

## 八、四条注意事项

1. **AI 只是工具，不能完全替代人类**
2. **AI 生成内容需人工审核和优化**
3. **要不断学习掌握新的 AI 技术保持竞争力**
4. **智能体是未来电商运营发展方向**

> 第 2 条不是形式主义 —— 医械类目一次未审核的 AI 主图可能就是一次违规。

## Scope & Limits

- **千牛 AI / 生意管家仅覆盖阿里系店铺**（天猫/淘宝/天猫国际/淘特）—— **拼多多店不适用**，须用拼多多商家版。
- 千牛 AI 的**功能开放范围按类目限制**（人群策略：服饰/美妆；行业洞察：天猫服饰），换类目要先确认是否已开放。
- 本 skill 讲**怎么用工具**，不讲工具背后的诊断逻辑 —— 诊断走 `[[store-diagnosis]]`，指标走 `[[data-metrics]]`。
- 「多 Agents 配置方案」与提效数字（效率 +40%、运营操作 −60% 等）来自原文，**未经独立验证**。
- 多 Agent 方案的**前置版本要求**（OpenClaw v2.3.x+ 等）是原文快照，落地前核对当前版本。
- 第 4 章的**更新日志**（截至 2026.3.26）与 **Claw 开放时间**（「预计 4 月中开放」）同为原文快照 —— **功能是否开通以千牛后台实际入口为准**。
