# 店铺经营诊断

**来源**：`taobao-operation` 知识库（GBRain source `taobao-operation`，2013 页）｜**版本**：2026.10｜**层级**：L1 专项

诊断不是"看报表"，是把**假好拆开**，找到第一处漏点。投产高不等于赚钱，店铺整体漂亮不等于单品赚钱，砍预算不等于降销售。所有报表最终要回答三件事：

1. 这个链接的钱花在哪？
2. 投产是真好，还是收割老客换来的假好？
3. 下一个动作是停哪个定向、补哪条链路？

---

## 一、入口指标：领先率（前比）

**领先率 = 新客成交 ÷ 总成交**

| 领先率 | 判定 | 动作 |
|---|---|---|
| ≥ 80% | 普通店铺合格线 | 拉新正常，按 [[hit-product-lifecycle]] 推进 |
| 70-80% | 头部 KA 可接受区间（基数高，难拉高） | 继续积累，不急加投 |
| 50-70% | 资源浪费在收割 | 查定向与出价 → 第四层 |
| < 50% | 主要在跑收割 | 停掉收割型定向 |
| < 30% | 几乎全是老客在买 | 拉新链路已断 → 转 [[customer-asset-ops]] |

领先率是**唯一**入口指标：它同时回答"新客进没进来"和"钱是不是花在了收割老客上"。

> 口径注：80 / 70 / 50 / 30 四条线出自《店铺诊断四层分析法》（源：2025 年 6 月淘系电商精细化运营培训）；"50-70% = 资源浪费在收割"这一档出自 [[skill-ecommercial]]，原文只有三档（80 / 50 / 30）加 KA 70。**口径冲突，需复核**。

## 二、四层分析法（诊断主干）

四层**必须按顺序**跑：上层说"店铺有问题"，下层说"问题在哪一层"，第四层才落到"停哪个计划"。

| 层 | 报表 / 视角 | 核心问题 | 判定 |
|---|---|---|---|
| 1 | 营销产品报表（店铺报表） | 整体费率是否异常？哪个品在拖？ | 整体漂亮但销售下滑 = 问题被整体数据掩盖 |
| 2 | 商品报表（按推广花费排序） | 该品的直接 / 间接成交比 | 间接 ≈ 2× 直接 → 该品投放完全无效 |
| 3 | 单品视角 | 该品领先率多少？ | < 50% = 该品在收割 |
| 4 | 定向分析 | 哪些定向在跑收割？ | 转化主要发生在"最后一次访问来源" = 收割 |

### 第 1 层：营销产品报表（店铺报表）

目的：看整体费率、找异常品。两个必答问题：

- 哪些品费率异常高？
- 哪些品投产特别好但销售没增长？

**不合格表现**：店铺整体数据"很漂亮"（投产高）→ 但每月销售持续下滑 → 问题被整体数据掩盖。**店铺整体投产不是诊断结论，只是起点。**

### 第 2 层：商品报表（按推广花费排序）

| 指标 | 含义 |
|---|---|
| 直接成交 | 用户通过广告直接点击后成交 |
| 间接成交 | 用户点击广告后，又通过其他渠道（如搜索）成交 |

判断标准：

- 间接成交 >> 直接成交 → 广告基本在跑收割，拉新无效
- 极端情况：间接成交 = 直接成交的 2 倍 → **该品投放完全无效**

真实案例：某商品月花费 8000 元，投产"看起来很好"，但直接成交 13 笔、间接成交 24 笔 → 财务数据反馈该品实际亏钱 → 结论：该品不值得投放任何广告。

### 第 3 层：单品视角（领先率）

```
领先率 = 新客成交 / 总成交
领先率 ≥ 80% → 拉新正常
领先率 < 50%  → 主要跑收割，资源浪费
领先率 < 30%  → 几乎全是老客在买
```

典型问题表现：某商品花费排名前 5，但领先率只有 50% → 这个品主要在收割，不是在拉新 → 花的广告费只是让老客重复购买。

### 第 4 层：定向分析

目的：找到**具体哪些定向**在跑收割。判据：哪些定向的转化主要发生在"最后一次访问来源"？这些就是在跑收割。

优化动作三步：

1. 找出跑收割的定向 → 直接暂停或关闭
2. 省下的广告费 = 直接的利润增加
3. 不影响销售（因为本来就在收割老客）

真实案例：某同学店铺有 4 个定向，其中 2 个明显跑收割（智能推荐等）；去掉这 2 个后**每月省下 4 万元广告费，销售没有任何变化**。

## 三、生意参谋归因切换法

| 归因方式 | 用途 |
|---|---|
| 每一次访问来源 | 默认归因，容易重复计算（**不推荐**） |
| 第一次访问来源 | 看**拉新**渠道：转化率高 = 主要拉新渠道 |
| 最后一次访问来源 | 看**收割**渠道：转化率高 = 主要在收割 |

判断广告是否在跑拉新：

```
第一次访问转化率 > 最后一次访问转化率 → 广告在跑拉新 ✓
最后一次访问转化率更高              → 广告主要在跑收割 ✗
```

不切换归因，投产"假好"永远查不出来。

## 四、广告三要素与诊断对应

| 要素 | 诊断重点 | 常见问题 |
|---|---|---|
| 定向 | 哪些定向在拉新，哪些在收割 | 智能推荐容易跑收割 |
| 创意 | 点击率是否达标 | 差创意拉高整体点击成本 |
| 出价 | 出价模式是否匹配阶段 | 用了不适合的出价导致成本高 |

排查顺序：**先定向（钱去哪了）→ 再创意（拿不拿得到点击）→ 最后出价（拿不拿得起）**。定向不对，后面两项都是白调。

## 五、日常节奏

```
每天：
1. 看营销产品报表 → 整体费率是否异常
2. 看商品报表 → 花销前 5 品是否间接成交比过高
3. 看单品领先率 → 是否 < 80%

每周：
1. 做定向分析 → 清理跑收割的定向
2. 监控竞品 → 调整出价策略
```

## 六、定向分类速查

| 定向类型 | 倾向 | 说明 |
|---|---|---|
| 关键词（手动） | 拉新为主 | 精准锁定搜索人群 |
| 引力魔方（半智能） | 拉新+收割混合 | 看具体配置 |
| 全站 | 收割为主 | 基于店铺人群资产快速收割 |
| 智能推荐 | 收割为主 | 系统探索，不可控 |
| 货品加速 | 渠道扩充 | 不具备人群放大作用 |

## 使用说明

1. **先跑领先率**再跑四层。领先率决定这次诊断是"查拉新"还是"查收割"。
2. 四层是**漏斗**，不是并列清单：第 1 层圈出异常品，第 2 层判定投放是否有效，第 3 层确认拉新/收割属性，第 4 层才动计划。
3. 第 4 层动计划前，先用归因切换验证一遍（第一次 vs 最后一次访问来源），避免砍错。
4. 每层结论都要落到**具体单品 + 具体定向**，不接受"整体费率偏高"这种结论。
5. 本 skill 只回答"钱花在哪、该停该补"。调级、调计划、算账分别转 [[sabc-product-tiering]] / [[wanxiangtai-wujie]] / [[profit-model]]。

## Scope & Limits

- 覆盖淘系（淘宝/天猫）店铺与链接的**数据诊断**，不负责执行投放、算账、调级。
- 所有阈值与案例来自知识库原文快照（《店铺诊断四层分析法》，源：2025 年 6 月淘系电商精细化运营培训）。平台报表口径会变，**落地前先核对当期生意参谋字段**。
- 直接/间接成交依赖生意参谋归因字段，切换归因方式数值会变；本 skill 的判据只在"同一张报表、同一归因方式"内成立。
- 案例中的金额与笔数为原案例数据，不能直接套到自己店铺的量级上做判断。
