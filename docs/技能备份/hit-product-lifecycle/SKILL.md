# 爆款全生命周期

**来源**：`taobao-operation` 知识库（爆款打造体系 / 爆款打造四阶段运营SOP / 爆款叠标打法全解 / 2026淘宝运营完整知识体系）｜**版本**：2026.10｜**层级**：L1

**爆款是验证出来的，不是打造出来的。**

核心公式：`销售额 = 展现量 × 点击率 × 转化率 × 客单价`；**爆款基因 = 产品力 × 时机力 × 价格力**，三者缺一不可。

**① 这个链接现在在哪个阶段？② 还值不值得继续投？③ 标签该叠哪些、能不能叠？④ 什么时候切阶段？**

---

## 一、四阶段总览

| 阶段 | 时间 | 核心动作 | 目标 | 阶段切换信号 |
|---|---|---|---|---|
| **打标期** | 第 1-7 天 | 多渠道打标 + 基础销量 + 素材 | 新品标签初始化 | 搜索流量开始自然增长，转化率稳定 |
| **起量期** | 第 8-15 天 | 超级短视频 + 首单礼金 + 秒杀 | 进类目前 20 | 付费 ROI 达到预期，人群规模足够大 |
| **爆发期** | 第 16-30 天 | 全站推广放量 + 叠标 + 竞品截流 | **进类目前五** | 销量增长放缓，接近天花板 |
| **稳定期** | 第 31 天+ | 降付费占比 + 多链接矩阵 + 私域复购 | 整体盈利 | — |

**为什么必须分清**：打标期做爆发期的动作 = 标签被冲散；爆发期做打标期的动作 = 错过放量窗口。**每个阶段的动作是唯一的。**

**硬指标**：打标期 10-30 单真实成交、收藏加购率 ≥10%、人群溢价 ≥70%、只打精准长尾词；起量期达 50 单立即报秒杀、礼金提到 20%-30%、收藏加购率维持 8%+、搜索流量每天增长 10%+。

**打标期三条禁忌**：标签未明确时大量投放（浪费预算）｜用低价 SKU 引流非目标人群｜找鱼塘做非标签流量。

## 二、三个阶段判定公式

不要凭感觉判断"这个链接行不行"。

```
LQ = 收藏加购率 × 40% + 关键词质量 × 30% + 价格力 × 30%
     > 0.6 具备爆款潜力   |   < 0.4 建议放弃

BQ = 坑产超越系数 × 45% + 增长率 × 35% + 转化率 × 20%
     > 1.2 进入爆款通道   |   > 1.5 爆款确认

CQ = 利润率 × 40% + 复购率 × 30% + 客户满意度 × 30%
     > 0.8 可持续爆款     |   < 0.5 昙花一现
```

- **LQ 是投放前的准入闸门**，<0.4 就别往下走；权重最高的"收藏加购率"判的是"用户要不要"，不是"用户买不买"。
- **BQ 权重最重的是坑产超越系数**（45%），衡量你的单坑产出比类目平均高多少。**坑产超越不过关，增长率再好看也起不来**——坑位本来就是别人的。
- **BQ 爆了不代表该长期投**：CQ 三个因子全是长期指标，>1.5 却 CQ<0.5 的链接很多，属昙花一现，冲量的钱会被退款吃掉。

**顺序**：LQ（要不要投）→ BQ（能不能爆）→ CQ（值不值）。

**另一套阶段命名**（`爆款打造体系`）：测款期↔打标期/LQ 导入期｜冲量期↔起量期+爆发期前半/BQ 成长期｜提率期↔爆发期后半/BQ 成长期｜稳价期↔稳定期/CQ 成熟期。

## 三、爆款基因

```
爆款基因 = 产品力 × 时机力 × 价格力
```

乘法意味着**任何一项为 0，整体为 0**：**产品力**（点击率 × 转化率，主图/SKU/详情页/评价）、**时机力**（市场窗口、类目周期、竞争密度）、**价格力**（2026 年平台第一权重指标，活动报名自动比价全网同款，**价格不达标直接被踢出活动**）。

**查基因的顺序**：先查价格力（能不能报名活动）→ 再查产品力 → 最后查时机力。价格力是硬门槛。

## 四、叠标体系

叠标是 2026 年打爆款的核心逻辑：叠加多个平台活动标签，让链接获得最高权重和流量扶持。

```
爆款权重 = 基础权重 × (标签1权重 + 标签2权重 + ... + 标签n权重) × 叠加系数
```

多个标签叠加产生"1+1>2"的加权效果，权重呈**指数级增长**。**标签是放大器，不是发动机**——基础权重不够，叠再多标也起不来。

| 标签 | 权重 | 互斥 | 适合阶段 |
|---|---|---|---|
| 秒杀 | ★★★★★ | **百亿补贴**、国家补贴 | 起量期、爆发期 |
| 百亿补贴 | ★★★★★ | **秒杀**、国家补贴 | 成熟期 |
| 超级单品标 | ★★★★★ | 无 | 稳定期 |
| 首单礼金 | ★★★★☆ | 无 | 新品期、起量期 |
| 热销爆品标 | ★★★★☆ | 无 | 爆发期 |
| 新品标 | ★★★☆☆ | 无 | 打标/起量期 |

其余可叠加标签（均无互斥）：超级立减 ★★☆☆☆、次日达 ★★☆☆☆、免息分期 ★★☆☆☆、淘金币 ★★☆☆☆、购物金 ★★★☆☆、品类券 ★★★☆☆。

> ⚠️ **重要**：**秒杀和百亿补贴互斥，不能同时参加**（二者权重都是 ★★★★★，只能二选一）。

**四阶段标签组合**

| 阶段 | 组合 | 关键参数 |
|---|---|---|
| **打标期** | 新品标 + 首单礼金 + 超级立减 | 上新即申请新品标；礼金 10%-20%；完成 50-100 单基础销量和评价 |
| **起量期** | 新品标 + 首单礼金 + 秒杀 | 达 50 单立即报秒杀；礼金提到 20%-30%；日均销量目标 100 单 |
| **爆发期** | 热销爆品标 + 秒杀 + 首单礼金 + 购物金 + 淘金币 | 日均 100 单自动获热销爆品标；持续报秒杀；开购物金和淘金币 |
| **稳定期** | 超级单品标 + 百亿补贴 + 购物金 + 淘金币 | 冲进类目前五自动获超级单品标；礼金降到取消；**百亿补贴替代秒杀**；降全站预算 |

**四段递进**：打标期**单一精准标签**（把标签打准，不铺数量）→ 起量期**扩展** → 爆发期**多标签叠加**（堆权重）→ 稳定期**优化**（把冲量活动换成计入最低价的百亿补贴/超级单品标，降付费占比）。

**搭配禁忌**：① 秒杀与百亿补贴/国家补贴互斥；② 跨阶段乱叠会把权重打散；③ 基础权重（销量、评价、体验分）不够时叠标无效；④ 报活动前先过价格力比价，不过线直接被踢出活动。

**超级单品标申请门槛**：店铺层级 H4 以上 + 近 30 天 GMV 达类目 TOP10 + 动态体验分 ≥4.8 + 好评率 ≥98%。

## 五、爆款三型与品类周期

| 类型 | 特征 | 打法 |
|---|---|---|
| **标品爆款** | 销量主导 | 阵地战、价格战 |
| **非标品爆款** | 款式主导 | 布局战、测款战 |
| **半标品爆款** | 混合型 | 偏标/偏非标差异化 |

**为什么必须分型**：标品拼同款内的销量和价格，货品只有一个维度 → 靠**场景裂变**（5-8 个子链接）撑开货品维度再打价格战；非标品拼款式和上新速度 → 靠**高频上新 + 测款淘汰**；半标品两头沾边，所以要"差异化"——**不能按标品的打法做价格战（打不过资本），也不能按非标的打法做测款（没有那么多款可测）**。

| 品类类型 | 全周期 | 特点 |
|---|---|---|
| 非标品（服饰） | **15-20 天** | 决策快、复购低 |
| 中客单标品（家居） | 约 **3 个月** | 决策周期中等 |
| 低客单标品 | 约 **5 个月** | 竞争激烈、规模效应 |
| 高客单（1000 元以上） | **45 天+** | 竞争小、利润高、决策长 |

**四阶段时间表要按品类等比缩放。** 非标品 15-20 天走完，动作要快；低客单标品 5 个月意味着打标期可能拖很久，**别在第 8 天就判定"这个品没起来"**——看 LQ 是不是还在 0.6 以上；高客单 45 天+ 且决策长，**必须上追投计划**（转化周期 >15 天）。

## 六、阶段动作与放量

| 阶段 | 核心动作 | 主投工具 |
|---|---|---|
| **打标期** | 多渠道打标、基础销量、素材 | 直通车 ★★★★★、超短 ★★☆☆☆ |
| **起量期** | 超级短视频、提礼金、报秒杀 | 引力魔方 ★★★★☆、超短 ★★★☆☆ |
| **爆发期** | 全站放量、叠标、竞品截流 | 全站推广 ★★★★★、超短 ★★★★☆ |
| **稳定期** | 降付费、多链接、私域复购 | 全站推广 ★★★★☆、超短 ★★★☆☆ |

**爆发期放量公式**：`爆发量 = UV价值 × 人群规模 × 标签匹配度`

**人群放量三步法**：① 精准蓄水（直通车+超短+小红书种草）→ ② 标签放大（**转化率下降不超过 20%**）→ ③ 全站放量（ROI 达标 + GSV 增长）。

**三大营销场景的铁律**：搜索建样本 → 推荐放大 → AI 收割，**无样本不碰 AI 智能场景**。这正是"打标期不上全站推广"的根本原因——没样本时上全站等于花钱买泛流量。

## 八、使用说明

1. **先定阶段，再定动作**。阶段判错，后面所有动作都是浪费。
2. **三公式各管一段**：LQ 判"要不要投"，BQ 判"能不能爆"，CQ 判"值不值"。三个都要过。
3. **标签顺序不能反**：先打标（打准）→ 再叠标（堆权重）。反了就是标签互相打架。
4. **时间轴按品类缩放**，不要拿非标的 15-20 天去卡标品的 3 个月。
5. **爆款不是利润来源**：爆款 = 引流工具 + 层级工具。利润靠 A 级承接、靠私域复购（见 [[skill-ecommercial]]）。
6. **阈值来自知识库原文快照**（2026 上半年口径）。标签规则、类目门槛、活动政策会变，报名前核对当期平台公告。

## Scope & Limits

- 覆盖**单个链接的爆款生命周期**。货盘分级见 [[sabc-product-tiering]]；投放计划搭建见 [[wanxiangtai-wujie]]。
- **口径冲突（需复核）**：
  1. **四阶段时间轴**：`爆款打造四阶段运营SOP` 记 1-14 / 15-30 / 31-60 / 60天+；`2026淘宝运营完整知识体系` 与 `爆款叠标打法全解` 记 1-7 / 8-15 / 16-30 / 31天+。本 skill 采用后者（与 [[skill-ecommercial]] 一致）。
  2. **四阶段命名两套**：`爆款打造体系` 用 测款期/冲量期/提率期/稳价期（对应 LQ/BQ/CQ），其余笔记用 打标期/起量期/爆发期/稳定期。映射见 §2。
  3. **S/A/B/C 预算口径**：`2026淘宝运营完整知识体系` 与 `产品分级与全店矩阵` 记预算占比 50%/30%/15%/5%；`爆款三板斧-产品分级` 记 S 级 20%-25%、C/D 级 0-5%。两套并存，落地时先确认用哪一套。
  4. **定价预留公式**：`爆款叠标打法全解` 记 `... × (1 + 扣佣比例)`，`2026淘宝运营完整知识体系` 记 `... ÷ (1 - 扣佣比例)`（[[skill-ecommercial]] 采用后者）。扣佣 20% 时两版差 40% 以上，定价前确认当期口径。
- 平台规则、价格力、标签申请门槛均以 2026 上半年口径为准，**报名与投放前核对当期平台公告**。
