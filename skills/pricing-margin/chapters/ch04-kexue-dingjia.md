# 第 4 章 · 科学定价（2026 新政）

> 来源笔记：`2026新政下新品速爆1科学定价`
> 用途：新品上架前的财务测算、老品调价前的利润空间体检、大促前的货盘规划。

---

## 一、2026 新政改变了什么

**核心逻辑**：平台补贴加剧 + 税务合规 → 推广费从占 GSV 的 **10% 跳升到 20%**，卖家实际到手收入从 **90 元降到 80 元**（以 100 元产品为例）。

| 环节 | 变化 |
|---|---|
| 平台 | 补贴加剧 + 税务合规 |
| 商家推广费 | 占 GSV 10% → 20% |
| 卖家到手收入 | 100 元产品：90 元 → 80 元 |

> **平台补贴的本质是"羊毛出在羊身上"**：消费者少付的钱，最终通过提高推广费的方式转移给了卖家。

---

## 二、科学定价公式（核心）

```
定价毛利率 = 固定费用率 + 可变费用率 + 目标净利率
定价倍率   = 1 ÷ (1 − 定价毛利率)
```

### 三段拆解（素材原文数字）

| 组成 | 数值 | 说明 |
|---|---|---|
| **固定费用率** | 约 **20%** | 人员、场地、仓储等不随销量变的费用 |
| **可变费用率** | 约 **33-38%** | 见下方拆解 |
| **目标净利率** | 建议 **10%** | 真正想留下的钱 |

**可变费用率 33-38% 的构成**：

| 项 | 占比 |
|---|---|
| 包装物流 | 3-5% |
| 平台扣点 | 8% |
| 推广费 | 按去年 × 1.2 |
| 税点 | 5-10% |

### 结论数字

```
固定 20% + 可变 34% + 净利 10% = 定价毛利率 64%
定价倍率 = 1 ÷ (1 − 0.64) = 2.78 倍
50 元成本产品 → 定价 139 元
```

**建议定价毛利率 ≥64%，倍率约 2.78 倍。**

### 适用场景

- 新品定价
- 老品调价前的财务测算，**避免定价低于成本 + 费用**
- 大促前货盘规划与成本预留
- 判断现有产品定价是否仍有利润空间

## 三、涨价时间线与平台补贴绑定规则

**2026 年平台补贴与卖家推广费比例强制挂钩**（电子合同白盒化）。

| 年份 | 状态 |
|---|---|
| 2023 | 价格力概念淡化 |
| 2024 | 头部商家率先涨价 |
| 2025 | 全行业涨 |
| **2026** | **强制涨** |

**涨价后消费者到手价不变（因为平台补贴抵消），但卖家收入恢复。**

**算例**（素材原文）：

```
100 元产品涨价到 110 元
→ 消费者实付 100 元（平台补贴 10 元）
→ 卖家收入 = 110 − 20 = 90 元，与涨价前收入持平
```

## 四、三高打法

| 打法 | 内容 |
|---|---|
| **高利润** | 科学定价：定价毛利率 = 固定费用率 + 可变费用率 + 目标净利率，建议 ≥64%，倍率约 2.78 倍 |
| **高费比** | 接受推广费比例 ×1.2，**不再盲目追求高 ROI** |
| **高补贴** | 消费券 / 品类券 / 百亿补贴 / 淘金币 **全渠道报名** |

### 核心认知转变

> 从"追求低费比、高 ROI"转变为"**追求稳 ROI、高花费、高规模**"。

**高补贴的具体动作**：

| 补贴 | 动作 |
|---|---|
| **消费券** | **必须全店报名** |
| **品类券 / 充值红包** | 提前规划预留空间 |
| **百亿补贴** | 优先主爆款或第二梯队 |
| **淘金币** | **2026 年重点**，平台补贴返还，可选单品报名 |

> **淘宝秒杀/百亿补贴逻辑**：平台从卖家推广费抽资注入补贴池，**卖家不参加则补贴被竞品拿走**——必须参加。

## 五、新品孵化五大能力

1. **定高价会装逼强种草** —— 高价本身是内容素材
2. **多上新快测款选好款**
3. **稳 ROI 多花钱**
4. **免费流量破天花板**
5. **用户运营降成本**

> **核心认知**：头部卖家的优势是"**能花更多钱**"而非"ROI 更高"。

## 七、⚠️ 口径差异提示

| 来源 | 倍率建议 | 场景 |
|---|---|---|
| `2026新政下新品速爆1科学定价` | **≥2.78 倍**（定价毛利率 ≥64%） | 2026 新政下的成本倒推保命线 |
| `2026-07-27` 每日学习批次 · 利润率反推 | **2-2.5 倍最优**（2 倍毛利 35% vs 3 倍毛利 36.6%） | 常规利润率反推的最优区间 |

**两者不是同一件事**：科学定价是"把费用率摊到定价里，确保不亏"；2-2.5 倍是"在多档定价中找毛利与规模的最优点"。

**建议**：新店/高成本品先按 2.78 倍起算保命，跑通数据后再向 2-2.5 倍区间收敛。
