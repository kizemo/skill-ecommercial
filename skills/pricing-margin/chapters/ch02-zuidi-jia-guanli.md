# 第 2 章 · 最低价管控与价格力

> 来源笔记：`2026淘宝运营完整知识体系` §9.3、`爆款三板斧-平台规则` §1、`淘宝活动体系与参与策略`
> 用途：判断一个优惠手段能不能用、保不保价盘、活动报不报得上。

---

## 一、最低价管控两条清单

这是 2026 年最重要的运营规则之一。**优惠手段选错，直接决定你会不会被踢出活动。**

### ✅ 不计入最低价（可放心用来让利）

| 手段 | 说明 |
|---|---|
| **首单礼金** | 佣金 10%-30%，流量扶持 ★★★★★ |
| **新品礼金** | 佣金 10%-20%，新品期专用 |
| **店铺优惠券** | 店铺自主，不进平台比价 |
| **购物金** | 券类标签 ★★★☆☆ |
| **淘金币** | 券类标签 ★★☆☆☆ |
| **超级立减** | 佣金 3%-5%，适合日销期 |
| **会员专享** | 面向已沉淀会员 |
| **营销托管** | 佣金 5%-15%，全阶段可用 |

### ❌ 计入最低价（会让你的"最低价"往下掉）

| 手段 | 说明 |
|---|---|
| **百亿补贴** | 佣金 5%-10%，流量扶持 ★★★★★ |
| **秒杀** | 佣金 3%-8%，流量扶持 ★★★★★ |
| **跨店满减** | 商家承担部分，摊到单品约 20% |
| **直降** | 直接降价 |

（来源：`2026淘宝运营完整知识体系` §9.3、`爆款叠标打法全解` §5.1）

> **跨店满减出现在"计入最低价"这一侧**，但同时又出现在定价预留公式的系数里（×1.2）。两处不矛盾：公式是在告诉你"要为它预留空间"，清单是在告诉你"它会拉低你的最低价"。

---

## 二、策略推论（这是清单真正的用法）

### 推论 1：想把活动价做成"名义价不变" → 全用不计入最低价的手段

```
标价（最低价）保持不变
+ 跨店满减（会被计入，但已是既定基准）
+ 首单礼金 20-30%
+ 购物金 + 淘金币
+ 超级立减
= 消费者到手价大幅下降，而你的"最低价"记录没被拉低
```

代价：这些手段的**流量扶持权重普遍低于秒杀/百亿补贴**（超级立减只有 ★★☆☆☆），且不产生"活动资格"。

### 推论 2：想报秒杀 / 百亿补贴 → 必须真降价，且要跟住全网比价

秒杀与百亿补贴**互斥**，不能同时参加（`爆款叠标打法全解` §2）。同时报等于浪费一次机会。

### 推论 3：日常价必须提前铺好历史低位

活动价格必须 **≤ 近 30 天最低价**（`淘宝活动体系与参与策略`）。所以日常价的"最低价记录"不是结果，是**活动资格的前置条件**。

> 这就是"日常与大促同价"思路的来源：用**优惠券定时失效**让日常也跑在大促到手价上，而**标价（最低价）保持不动**——具体方法见 `[[campaign-playbook]]` 蓄水章节。⚠️ 该方法在素材中只有方法名与场景标注，**具体参数未验证**。

## 三、价格力 = 第一权重（2026 平台规则变化）

来源：`爆款三板斧-平台规则` §1

| 变化 | 说明 |
|---|---|
| **取代五星价格力** | 成为平台流量分配核心指标 |
| **比价机制** | 活动报名自动对比**全网同款/相似款**价格 |
| **消费券分级** | 根据营销投入、价格力、体验分划分 |

**后果：价格不达标直接被踢出活动。**

### 平台盈利逻辑（理解规则为什么这么设）

| 类别 | 内容 |
|---|---|
| **硬性商业化收入** | 天猫/淘宝扣点、商家广告推广花费 |
| **软性用户价值** | 用户体验、商品性价比、店铺服务质量 |

> **核心：给平台创造的商业化价值越高，获得的流量与补贴越多。**
> 这也解释了为什么"费比"和"价格力"会被绑在一起看（见 ch05）。

### 配套的三条硬门槛（与价格力同属 2026 四大规则）

| 评分 | 阈值 | 后果 |
|---|---|---|
| 店铺体验分 | < 4.6 分 | 失去搜索权重、**无法报名大促** |
| 商品体验分 PXI | < 70 分 | 流量负向影响 |
| 商品体验分 PXI | < 60 分 | **彻底断流** |

（来源：`爆款三板斧-平台规则` §3）

> ⚠️ **口径冲突，需复核**：KB 盘点报告同时记录 `店铺评分红线-stub` 写的是"**<4.2 分无法报名官方活动**"，与上面的 4.6 不一致。保守做法：**按 4.6 卡**，并核对当期平台公告。

### 价格力的操作抓手

| 抓手 | 内容 |
|---|---|
| 超级单品标 | 最高等级标签 ★★★★★；申请条件：店铺层级 H4 以上、近 30 天 GMV 达类目 TOP10、动态体验分 ≥4.8、好评率 ≥98% |
| 平台自检标 | 有工厂或稳定供应链、商品通过平台质量检测、配合平台小二实地考察 |
| 爆品裂变 · 价格力 | 属八大裂变方法之一（主图人群裂变/类目布局/SKU拆分/**价格力**/组合套餐/空间配套/地域优化/用户调研） |

（来源：`爆款叠标打法全解` §6、KB 盘点报告转录 `爆品裂变八大方法`）

## 四、报名前的价格自检四问

1. 活动价是否 ≤ 近 30 天最低价？
2. 这次让利用的手段，是否**全部落在"不计入最低价"清单**里？（要真降价才用计入清单的手段）
3. 拉低最低价之后，**全网同款/相似款**比价还能过吗？——活动报名时平台自动比，**不达标直接被踢**。
4. 活动后原价恢复是否合理、是否设了价格保护期？（避免被比价平台抓取）
