## 一、费比：定义与强制规则

**费比 = 推广花费占成交金额的比例。**（MTD 费比 = 月度累计口径）

来源：`爆款三板斧-平台规则` §2「投入侧：商业化保费比强制要求」

| 要点 | 说明 |
|---|---|
| **费比强制要求** | **广告花费占比不低于去年同期** |
| **费比不达标后果** | 消费券从"**平台全资**"降为"**商家混资/全资**" |
| **⚠️ 淘客无效** | **淘客佣金不计入商业化权重**，无法提升店铺权重 |
| 天猫权重 > 淘宝 | 扣点更高，权重天然更高 |

### 三条推论

1. **费比是一条"地板线"，不是"天花板"**。去年花了 10 万，今年至少也得花 10 万的量级，否则平台补贴降级。**低价不是免费的。**
2. **淘客佣金不能替代广告费**。它只计入短期成交冲量，**不进入商业化权重**，用它去"凑费比"是无效的；**凑费比只能用真实广告花费**。
3. **费比与价格力是一对**：平台按"营销投入 + 价格力 + 体验分"划分消费券等级。投入侧塌了（费比低），价格侧再好也可能被降档。

### ⚠️ MTD 费比口径未验证

知识库中 `MTD费比` 是**低密度概念笔记**，素材未给出完整定义、分子分母口径与统计周期 → **未验证**。本 skill 的"费比 = 推广花费占成交金额的比例"是从各笔记用法（"广告花费占比""整体推广费用占比""系列费比"）归纳的通用口径。

## 二、费比参考区间

### 行业与推广模式

| 场景 | 费比 | 来源 |
|---|---|---|
| 行业均值（2025 口径） | 约 **5%**，上下浮动约 1% | `CMP-2025平台规则变化下的突围1` |
| 万相台无界 · 矩阵模式（多店多平台大商家） | 3%-5% | `万相台无界核心概念` |
| 万相台无界 · 动销模式（有人群资产的老店） | 5%-8% | 同上 |
| 万相台无界 · 爆款模式（无人群资产的新店） | 8%-10% | 同上 |
| 直通车 · 营销托管（非标新品） | 约 20-25% | `直通车计划搭建` |
| 直通车 · 老品走全站 | 可达 5-10 倍营销托管 | 同上 |
| 实操案例：全店 ROI 2.8 → 3.7 | 费比 12% | KB 盘点报告转录 `P2-推广计划组合分工` |
| 实操案例：全店 ROI 1.8、人群资产 +250% | 费比 11% | KB 盘点报告转录 `P3-推广计划搭建策略` |
| 实操案例：全店 ROI 2.8、人群资产 +180% | 费比 13% | 同上 |

> 2025 平台规则口径补充：行业均值推广费比约 5%，**"拉升推广费比势在必行，早日提价，早日拉升推广花费占比的企业会享受到红利"**。2026 的强制规则是这条趋势的延续（见 ch04）。

### 红绿灯判费比

来源：`P4-多端数据融合调研`

| 条件 | 灯 | 动作 |
|---|---|---|
| 投产 ≥ 目标 ROI 且 费比 ≤ 目标费比 | 🟢🟢 双绿灯 | 优秀；持续监控边际效应，新增预算后投产下滑到黄灯即停加预算 |
| 投产绿灯 + 费比红灯 | 单绿单红 | 待优化：退款率过高 → 减预算 30%-50%；间接成交占比过高 → 看系列费比，系列费比绿灯则保留预算 |
| 投产红灯 + 费比绿灯 | 单红单绿 | 待观察：必要时增加收割预算 |
| 双红灯 | 🔴🔴 | 较差：优化为主，不盲目增加预算 |

**费比单独判灯的阈值**：

| 条件 | 灯 |
|---|---|
| 实际费比 ≤ 目标费比 | 🟢 |
| 目标费比 < 实际 ≤ 目标费比 × 1.2 | 🟡 |
| 实际 > 目标费比 × 1.2 | 🔴 |

### 产品分级 × 费比

来源：`爆款三板斧-产品分级`

| 等级 | 定义 | 推广费占比 | 计划数量 |
|---|---|---|---|
| **S 级** | 镇店爆款，销售额前几名 | **20-25%** | 8-10 个 |
| **A 级** | 动销款，稳定销售 | 逐步递减 | 4-6 个 |
| **B 级** | 平销款 | 更少 | 2-3 个 |
| **C/D 级** | 尾部链接 | **0-5%** | 1-2 个 |

**执行原则**：推广投产低于店铺均值 → **禁止盲目增加预算**；S 级爆款 → 多计划配合，整体盈亏平衡；C/D 级尾部 → 用低价计划筛选。

**保底利润率阶梯**（三阶引擎，来源：KB 盘点报告转录 `三阶引擎工具表-说明`）：**S 品 10% / A 品 15% / B 品 20% / C 品 25%**；超额利润 = 实际 − 保底；全店可投费用池 = 所有产品超额利润汇总；每 30 天调级。

## 三、算账四公式

### 1. 盈亏平衡投产比

```
盈亏平衡投产比 = 1 ÷ (毛利率 × (1−退款率))
```
（来源：`爆款三板斧-七维选品` 七维产品布局的价格维度）

> 这是**定价与投放的共同约束**：价格定的毛利率要能撑住退款率，投放的 ROI 要能撑住退款率后的真实口径。

### 2. 盈亏平衡 ROI

```
盈亏平衡 ROI = 1 ÷ 毛利率
```
（来源：`淘系运营核心公式` 公式 8）

示例：毛利率 60% → 盈亏平衡 ROI = 1.67，ROI > 1.67 才盈利。

### 3. 斩杀线

```
斩杀线 = 固定成本 ÷ (毛利率 − 推广费用占比)
```
（来源：`淘系运营核心公式` 公式 9、`2026淘系电商斩杀线破局`）

| 月销 vs 斩杀线 | 经营状态 | 风险等级 |
|---|---|---|
| 月销 < 斩杀线 | 持续亏损 | 🔴 红 |
| 月销 ≈ 斩杀线 | 盈亏脆弱 | 🟡 黄 |
| 月销 > 1.5 倍斩杀线 | 健康经营 | 🟢 绿 |

**破法**：控制固定成本 / 提升毛利率 / 优化推广费用占比。

### 4. 真实投产（投产去伪）

```
真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交
```
（来源：KB 盘点报告转录 `2026-07-27` 每日学习批次）

**案例**：投产 6.8 × 15% 退款率 = 真实投产 1，费比 100%。

> 投产 6.8 看着很健康，扣掉退款后真实投产只有 1 —— **不除退款率的投产都是假的**。

### 配套：推广投产 vs 总投产

| 指标 | 统计范围 | 意义 |
|---|---|---|
| 推广投产 | 仅付费流量成交 | 参考价值有限 |
| 总投产 | 免费 + 付费流量 | 真实效率 |

**差值越大 = 单品免费流量占比越高**（产品竞争力越强）。

### 配套：顺逆差

```
顺逆差 = 单品成交金额占比 − 单品推广花费占比
```

| 结果 | 含义 | 行动 |
|---|---|---|
| 正向顺差 | 花小钱办大事 | 预算倾斜 |
| 负向顺差 | 花钱多产出少 | 优化或淘汰 |
| 零顺差 | 收支平衡 | 维持观察 |

## 四、费比与利润的联合判据（自建四象限）

把"费比"和"真实投产"两个轴放一起，能直接得出动作：

| | 真实投产 ≥ 盈亏平衡投产比 | 真实投产 < 盈亏平衡投产比 |
|---|---|---|
| **费比 ≤ 目标** | 🟢 **加预算**（双绿灯，每次增幅 ≤50%） | 🟡 **优化转化/退款**，不加预算 |
| **费比 > 目标 ×1.2** | 🟡 **查间接成交占比**——投产绿灯费比红灯多半是"收割"或"退款高"，减预算 30%-50% | 🔴 **止损**：降推广费比或砍链接 |

> 这张表是本 skill 的**核心决策产物**：它把"加不加预算"从感觉变成判据。注意"增幅 ≤50%"这条来自 `[[skill-ecommercial]]` 的推广原则。
