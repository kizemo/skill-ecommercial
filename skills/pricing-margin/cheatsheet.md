> 所有数字均为知识库原文快照（2026 上半年口径）。平台规则会变，落地前核对当期公告。

## 1. 定价倒推表（成本 100 元）

**公式**：`定价 = 成本 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1−扣佣比例)`

| 毛利率（角色） | 底价 | 扣佣 5%<br>(秒杀 3-8%) | 扣佣 10%<br>(百亿补贴/首单礼金低档) | 扣佣 20%<br>(首单礼金) | 扣佣 25%<br>(首单礼金高档) |
|---|---|---|---|---|---|
| **30%**（利润款 ≥30%） | 130 | 190 | 200 | 226 | 240 |
| **40%**（形象款 ≥40%） | 140 | 194 | 205 | 233 | 248 |
| **80%**（科学定价档） | 180 | 263 | 277 | 312 | 333 |

**自检锚点**（素材原文案例）：成本 40 元、毛利率 80%、扣佣 25% → 定价 **133 元**（40 × 1.8 × 1.2 × 1.05 × 1.1 ÷ 0.75 = 133.05）。

> ⚠️ **别把两个公式混用**：
> - **预留空间公式**（上表）额外把跨店满减/购物金/淘金币/扣佣叠进去 → 用于**对外定价**
> - **科学定价倍率** = 1 ÷ (1−定价毛利率)，只摊费用率 → 用于**判断这个品有没有利润空间**（50 元成本 × 2.78 = 139 元）

## 3. 报活动前检查清单

- [ ] 活动价 **≤ 近 30 天最低价**
- [ ] 角色毛利率达标（利润款 ≥30% / 引流款 15-20% / 形象款 ≥40%）
- [ ] 已用预留空间公式倒推过底价，且已预留扣佣空间
- [ ] 让利手段是否全部落在"不计入最低价"清单（要真降价才用计入清单的手段）
- [ ] 全网同款/相似款比价能过（**不达标直接被踢出活动**）
- [ ] 店铺体验分 ≥ **4.6**（⚠️ 素材另有 4.2 口径，保守按 4.6 卡）
- [ ] 商品体验分 PXI ≥ **70**（<70 流量负向，**<60 彻底断流**）
- [ ] 佣金已按目标活动取档（秒杀 3-8% / 首单礼金 10-30%）
- [ ] 库存够：预热期备 **100% 销量目标**库存
- [ ] 设了价格保护期，活动后逐步恢复原价（⚠️ 避免被比价平台抓取）
- [ ] 算出这次活动的 `盈亏平衡投产比 = 1 ÷ (毛利率 × (1−退款率))` 与 `真实投产`
- [ ] 费比不低于去年同期（否则消费券从平台全资降为商家混资/全资）
- [ ] **合规检查已过**（医疗器械类目另见 `[[compliance-medical]]`）

## 4. 阈值表

### 费比

| 场景 | 费比 |
|---|---|
| 行业均值（2025 口径） | 约 5%（±1%） |
| 万相台 · 矩阵模式 | 3%-5% |
| 万相台 · 动销模式 | 5%-8% |
| 万相台 · 爆款模式 | 8%-10% |
| 直通车 · 营销托管（非标新品） | 约 20-25% |
| 老品走全站 | 可达营销托管的 5-10 倍 |
| 产品分级 S 级 | 20-25%｜C/D 级 0-5% |
| **强制线** | **不低于去年同期** |

**红绿灯**：≤目标 🟢｜目标<实际≤目标×1.2 🟡｜>目标×1.2 🔴

### 算账

| 公式 | 表达式 |
|---|---|
| 盈亏平衡投产比 | `1 ÷ (毛利率 × (1−退款率))` |
| 盈亏平衡 ROI | `1 ÷ 毛利率`（毛利 60% → 1.67） |
| 斩杀线 | `固定成本 ÷ (毛利率 − 推广费用占比)` |
| 真实投产 | `投产 × (1−退款率) × (1−间接成交占比) × 拉新成交` |
| 顺逆差 | `单品成交金额占比 − 单品推广花费占比` |

**斩杀线判据**：月销 < 斩杀线 🔴 持续亏损｜≈ 斩杀线 🟡 盈亏脆弱｜> 1.5 倍斩杀线 🟢 健康经营

### 利润目标

| 指标 | 目标 |
|---|---|
| 净毛利率 / 净利率 | ≥20% / ≥10% |
| 全店动销率 | ≥60% |
| 客单价 | 高于类目均值 20%+ |
| 复购率 | ≥15% |
| 链接数 / 季度增长 | ≥100 / ≥30% |
| 保底利润率阶梯 | S 10%｜A 15%｜B 20%｜C 25% |

### 成本结构参考

物流 7-10%｜广告 12-20%｜平台扣点 5.5%｜税金 4-11%｜库存死货 10%

## 5. 决策树

```
要报活动吗
├─ 店铺体验分 < 4.6 → 报不了，先修评分
├─ 商品体验分 PXI < 60 → 彻底断流，先修
├─ 算不出活动价 ≤ 近30天最低价 → 日常价盘没铺，先做日常优惠券
├─ 全网比价预估过不了 → 比不动就别报，改用不计入最低价的手段做活动
└─ 能报 → 算 盈亏平衡投产比 + 真实投产 再决定报哪个

该用什么优惠手段
├─ 想保最低价 → 首单礼金/购物金/淘金币/超级立减/营销托管（不计入）
├─ 想拿秒杀流量 → 秒杀（计入最低价，需真降价）
├─ 想拿百亿补贴流量 → 百亿补贴（与秒杀互斥）
└─ 想两个都要 → 只能选一个，另一个留给下一轮

要加预算吗
├─ 真实投产 ≥ 盈亏平衡投产比 且 费比 ≤ 目标 → 🟢 加（增幅 ≤50%）
├─ 真实投产 ≥ 盈亏平衡投产比 但 费比 > 目标×1.2 → 🟡 查间接成交占比，减预算 30%-50%
├─ 真实投产 < 盈亏平衡投产比 且 费比 ≤ 目标 → 🟡 优化转化/退款，不加
└─ 双差 → 🔴 止损：降费比或砍链接

利润不够，从哪挤
├─ 提价 → 涨价三步法（科学定价，倍率 ≥2.78）+ 平台补贴抵消消费者端
├─ 降本 → 成本八大维度（物流/广告/扣点/税金/死货）
├─ 换带 → 投产胜率定价法 + 利润规模定价法
└─ 换结构 → 利润款/引流款/形象款/清仓款毛利率重排
```

## 6. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 漏留扣佣空间 | 活动期实收低于预期 | 佣金按**定价**扣不按实付扣，按最高档留 |
| 用 `×(1+扣佣)` 而非 `÷(1−扣佣)` | 定价偏低、活动亏损 | 按 §1 锚点复算：40 元成本 → 133 元 |
| 以为最低价会保护你 | 活动报名比价不过被踢 | 活动价必须 ≤ 近 30 天最低价，日常价盘提前铺 |
| 秒杀与百亿补贴同时报 | 浪费一次机会 | 二选一 |
| 用淘客佣金凑费比 | 不计入商业化权重，白花钱 | 只能用真实广告花费 |
| 降佣不重算定价 | 毛利掉一块，且报不了下一个活动 | 每降一档按新佣金重跑公式 |
| 只看投产不看真实投产 | 投产 6.8 实际真实投产 1 | 除以退款率与间接成交占比 |
| 定销售目标不设利润目标 | 未完成时降价猛投广告 | 定利润目标；分红挂净利率 |
| 只盯低利润价格带 | 80% 竞争对手扎堆，打不动 | 投产胜率法先选打得赢的带 |
| 活动后原价猛拉 | 被比价平台抓取 | 设价格保护期，逐步恢复 |
| 忽略体验分门槛 | <4.6 报不了大促，<60 断流 | 报名前查分 |
| 只做毛利率不算费用率 | 看似赚钱实则亏损 | 用科学定价：固定+可变+目标净利 |
