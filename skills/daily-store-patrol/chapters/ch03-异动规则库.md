# 第 3 章 · 异动规则库

> **症状 → 先查什么 → 大概率原因 → 动作**。
> 每条规则的阈值要么来自知识库（标注出处），要么来自"与自身 7 日均值对比"（相对判定）。
> 本表是巡店发现异常后的**标准处置路径**，避免每天临时判断。

---

## 一、店铺大盘层

### R1 · 支付金额跌，访客没跌

| | |
|---|---|
| **先查** | `支付转化率` `跳失率` `客单价` `加购人数` `收藏人数` |
| **大概率原因** | 承接端问题：主图/详情页/评价/SKU/价格；或平台流量结构调整 |
| **动作** | `conversion-optimization`（按决策链：SKU → 主图 → 买家秀 → 详情页） |
| **不要做** | 别一上来就加推广预算 —— 转化没修好，加的钱会被吃掉 |

### R2 · 支付金额跌，访客也跌

| | |
|---|---|
| **先查** | `shop_traffic_source_2026` 按二级来源对比，找出跌得最多的 3 个来源 |
| **大概率原因** | 某个流量来源萎缩（限流/降权/活动结束/竞品抢量） |
| **动作** | 掉在免费来源 → 查商品权重与标签；掉在付费来源 → `wanxiangtai-wujie` 查计划状态 |

### R3 · 支付金额涨，访客没涨

| | |
|---|---|
| **先查** | `客单价` `支付买家数` `支付件数` |
| **大概率原因** | 客单价提升（涨价/凑单/高端款占比上升）；**也可能是退款滞后未体现** |
| **动作** | 查 ERP 同期的 `退货金额`，确认不是"卖得多退得也多"的假象 |

### R4 · 费比上涨，但金额没涨

| | |
|---|---|
| **先查** | `真实投产`（投产 × (1−退款率) × (1−间接成交占比) × 拉新成交）→ `profit-model` |
| **大概率原因** | 投产是假的：间接成交占主导（收割）、或退款率高、或全是老客成交 |
| **动作** | 先降无效计划的预算（`wanxiangtai-wujie` 红绿灯），**不要直接砍全店预算** |

### R5 · 费比下降，但金额也降

| | |
|---|---|
| **先查** | 推广花费分项（`全站推广花费`/`关键词推广花费`/`精准人群推广花费`）哪个降了 |
| **大概率原因** | 砍了拉新预算，剩下的全是收割型投放 |
| **动作** | 补拉新（`customer-asset-ops` + `wanxiangtai-wujie`），否则 1-2 周后大盘会塌 |

### R6 · 跳失率上升

| | |
|---|---|
| **先查** | `商品访客数` 与 `支付买家数` 的比；`加购人数` 是否同步掉 |
| **大概率原因** | 主图/标题对不上人群预期（新增流量不精准）；或详情页首屏失效 |
| **动作** | `conversion-optimization`；同时查流量结构（是不是新加了一类不精准的来源） |

> 跳失率是知识库「转化漏斗四环节」里的**认知环节**指标 —— 跳失率高就改主图/标题（`conversion-optimization`）。

### R7 · 评分（三项）下滑

| | |
|---|---|
| **先查** | `描述相符评分` / `服务态度评分` / `物流服务评分` 哪一项掉了 |
| **红线** | 店铺体验分 **< 4.6** → 失去搜索权重 + 无法报名大促（`compliance-medical`） |
| **动作** | 描述相符 → 详情页与实物一致性（可能踩禁用词）；服务态度 → 客服话术与响应；物流 → 发货时效与快递（看 `发货包裹数`/`揽收包裹数`/`平均支付_签收时长(秒)`） |

## 二、流量结构层

### R8 · 最后一次访问来源的「效果广告」占比 ≫ 第一次访问来源

| | |
|---|---|
| **判据** | 「效果广告」在**最后一次**的支付买家占比 ÷ 在**第一次**的支付买家占比 ≥ 2 |
| **含义** | **在跑收割型定向** —— 花钱买的是本来就要买的人（知识库：间接成交 = 直接成交 2 倍 ⇒ 投放完全无效） |
| **动作** | `store-diagnosis` 归因切换法 → 停收割型定向，改拉新 |

### R9 · 某来源访客涨、支付金额不涨

| | |
|---|---|
| **先查** | 该来源的 `支付转化率` 与店铺均值的差 |
| **大概率原因** | 流量不精准 / 承接跟不上 / 该来源本身是低质来源 |
| **动作** | 看该来源是否值得加投；不精准就降预算并查定向 |

### R10 · 某来源转化率显著高于店铺均值

| | |
|---|---|
| **含义** | **机会项** —— 该来源被低估了 |
| **动作** | 加预算（`keyword-promo` / `wanxiangtai-wujie`），**增幅 ≤50%**（知识库铁律） |

### R11 · 免费搜索流量骤降

| | |
|---|---|
| **先查** | 搜索是否被压制：对比「全站推广」与「搜索」两个来源的访客变化 |
| **口径提示** | 知识库对"全站是否压制搜索"有**互相矛盾的三种说法**（不抢／压制／压缩），**需复核** |
| **动作** | 查标签与权重（`hit-product-lifecycle` 叠标），再查搜索卡位（`keyword-promo`） |

### R12 · 大促会场 / 百亿补贴频道来源有流量无成交

| | |
|---|---|
| **判据** | 该来源 `支付金额 = 0` 或转化率极低 |
| **含义** | 进了活动会场但没接住 —— 可能是价格不占优（活动价 vs 日常价） |
| **动作** | `pricing-margin` 查最低价管控；`campaign-playbook` 查报名与价盘 |

## 三、客户资产层

### R13 · 潜在客户数大、已购客户数小

| | |
|---|---|
| **含义** | 大量到店未成交 —— 承接或人群问题，不是流量问题 |
| **动作** | `customer-asset-ops` 人群校正 + `conversion-optimization` 承接 |

### R14 · 沉睡粉丝 ≫ 活跃粉丝

| | |
|---|---|
| **含义** | **私域没激活 —— 这是最容易兑现的增量** |
| **动作** | 今日排召回（`customer-asset-ops`），配合 `campaign-playbook` 的券/触达 |

### R15 · 复购率低 + 老客金额占比低

| | |
|---|---|
| **含义** | 只能靠新客维持 → 拉新成本会持续上升 |
| **动作** | `customer-asset-ops` 召回与复购；检查商品是否只适合首购（复购型选品） |

### R16 · 新客占比低（<50%）

| | |
|---|---|
| **对应知识库** | 领先率四档：≥80% 合格｜70-80% 可接受｜50-70% 资源浪费在收割｜<50% 主要跑收割｜<30% 拉新链路已断 |
| **动作** | `customer-asset-ops` 预算圈层 + `wanxiangtai-wujie` 开拉新计划 |

### R17 · 资产表与大盘表的新客占比打架

| | |
|---|---|
| **含义** | 两个口径不同源，**不是异常，是口径差** |
| **动作** | 标「口径冲突，需复核」，**不要据此下结论**，回原报表核对定义 |

## 四、推广计划层

### R18 · 有花费、无直接成交

| | |
|---|---|
| **判据** | `花费 > 0` 且 `直接成交金额 = 0` |
| **动作** | 降预算 50% → 观察 3 天 → 仍无成交则停（`wanxiangtai-wujie`） |

### R19 · 间接成交 ≥ 2 倍直接成交

| | |
|---|---|
| **来源** | 知识库红线：**该品投放完全无效** |
| **动作** | 停该计划；查是不是在用收割型定向（`store-diagnosis`） |

### R20 · 投产达标但新客数为 0

| | |
|---|---|
| **含义** | 只收割不拉新 —— 短期赚钱，长期资产变薄 |
| **动作** | 保留预算但加一条拉新计划（`wanxiangtai-wujie` 计划组合分工） |

### R21 · 点击率 < 1%

| | |
|---|---|
| **含义** | 素材问题，不是投放问题 |
| **动作** | `visual-material`（主图四要素 / FABE / AI 主图四法 / 素材八大入口）；**不要**先降价降出价 |

### R22 · 展现量高、点击量低、点击率低且花不出去

| | |
|---|---|
| **含义** | 出价太低跑不出去（`平均点击花费` 远低于同类） |
| **动作** | `wanxiangtai-wujie` 查竞价与红绿灯；**放量增幅 ≤50%** |

### R23 · 加购高、成交低

| | |
|---|---|
| **含义** | 转化漏斗卡在「兴趣 → 购买」环节 |
| **动作** | `conversion-optimization`：SKU 五要素、评价、价格锚定（知识库四环节：兴趣→卖点/营销，购买→SKU/评价） |

## 五、商品层

### R24 · 成本倒挂（销售成本 > 商家实收）

| | |
|---|---|
| **级别** | **🔴 最高优先级，止损** |
| **动作** | 立刻停投该品 → 查定价（`pricing-margin`）→ 查是否有降价活动（`campaign-playbook` 价盘管控） |
| **不要做** | 不要靠加销量摊薄成本 —— 卖一单亏一单，量越大亏越多 |

### R25 · 退货率 ≥ 20%

| | |
|---|---|
| **先查** | ERP `shouhou_2026` 的售后类型分布；同商品是否"次日达/预售"造成的口径差 |
| **大概率原因** | 质量、描述不符、尺码/规格预期差、发货时效 |
| **动作** | 医械类目同时过 `compliance-medical`（禁用词与功效暗示）；否则走 `conversion-optimization` |

### R26 · 销量骤降 > 50%

| | |
|---|---|
| **先查** | 库存（`jst_fact_inout_summary` 的 `end_qty`/`turnover_days`）、是否下架、是否被平台处罚、价格是否变动 |
| **动作** | 知识库案例：热销 SKU 低库存预警后第一时间补货，避免 **7 天销量下滑超 20%** 的损失 |

### R27 · 次品数量 > 0

| | |
|---|---|
| **动作** | 进售后流程；同批次库存全部排查；医械类目同步 `compliance-medical` |

### R28 · 有销量无推广

| | |
|---|---|
| **含义** | **潜力品** —— 自然能卖但没投 |
| **动作** | `sabc-product-tiering` 定级（升 B/A），`wanxiangtai-wujie` 加投 |

## 六、跨层：一致性自检

巡店收尾时跑一遍，任一条不成立就说明有数据问题或口径混用：

| # | 自检 | 不成立说明什么 |
|---|---|---|
| 1 | 大盘支付金额与 ERP 同期的商家实收能对上（允许时滞与口径差） | 两个源的日期没对齐 |
| 2 | 流量表的「每一次访问来源」访客总数 ≈ 大盘访客数 | 流量表漏了某些来源 |
| 3 | 三种归属原则的访客数相等 | 归属原则被混用了 |
| 4 | 推广花费分项合计与商家后台当日推广花费一致 | 字段口径或源文件切换 |
| 5 | 红绿灯基线窗口内没有跨越源文件切换日 | 比率单位被切换污染（ch01 坑 1） |
