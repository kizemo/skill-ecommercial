# 人群资产运营

**来源**：`taobao-operation` 知识库（GBRain source `taobao-operation`，2013 页）｜**版本**：2026.10｜**层级**：L1 专项

2026 年电商竞争的核心是人群资产的竞争，**预算决定流量圈层，人群资产是付费推广的前提**。人群运营不是发短信，是从认知到忠诚的全链路管理。

本 skill 回答四件事：

1. 人群资产现在长什么样？（AIPL 盘点 + RFM 分层）
2. 下一笔钱该投给谁？（O 机会人群 + 预算圈层）
3. 人群不准怎么修？（人群校正五方法）
4. 效果算不算好？（效果评估四条）

---

## 一、AIPL 模型：四阶段

| 阶段 | 定义 | 运营目标 | 核心指标 |
|---|---|---|---|
| **Awareness 认知** | 潜在消费者看到品牌 | 曝光触达 | 曝光量、CTR |
| **Interest 兴趣** | 消费者对品牌产生兴趣 | 种草培育 | 收藏量、加购量 |
| **Purchase 购买** | 消费者完成首次购买 | 首购转化 | 转化率、客单价 |
| **Loyalty 忠诚** | 消费者形成复购习惯 | 复购维护 | 复购率、会员 LTV |

**平台侧的时间窗口与权重**（做盘点时按这个口径取数）：

| 人群 | 定义 | 时间窗口 | 权重层级 |
|---|---|---|---|
| A（浏览人群） | 浏览过店内商品 | 15 天 | ★☆☆☆☆ |
| I（收藏加购人群） | 收藏/加购过店内商品 | 90 天 | ★★★☆☆ |
| P（单次购买人群） | 有 1 天购买过店内商品 | 365 天 | ★★★★☆ |
| L（多次购买人群） | 有 2 天及以上购买过店内商品 | 365 天 | ★★★★★ |

优先展现权权重：**L > P > I > A**。消费者与店铺建立人群资产关系的唯一核心条件就是**点击店铺广告**。

## 二、O-AIPL：把机会人群单独拎出来

AIPL 只管已触达的人，O-AIPL 在前面加一个 **O（Opportunity 机会人群）**。

| 项 | 内容 |
|---|---|
| O 定义 | 高潜购买力 + 尚未触达的人群 |
| O 来源 | 达摩盘 lookalike + 行业大盘 |
| O 价值 | 拉新效率比普通拉新**高 50%+** |
| 与 AIPL 区别 | AIPL = 已有触达后的人群；O-AIPL 把机会人群独立出来 |

**O 阶段 KPI**：

| 指标 | 目标值 |
|---|---|
| O 阶段人群规模 | > 100w |
| O → A 转化率 | > 15% |
| 大促蓄水量（O + A） | > 200w |
| 建计划时点 | 大促前 30 天 |
| O 阶段预算占比 | 30%+ |

**O-AIPL 实操五步**：① 每次大促前 30 天建 O-AIPL 计划 → ② O 阶段预算占 30%+ → ③ 达摩盘导出 O 阶段人群包 → ④ 万相台无界拉新 + 直通车精准组合 → ⑤ 每天看 O→A 转化率（健康值 > 15%）。

**适用场景**：大促前蓄水期（重点投入 O 阶段拉新）｜新店冷启动（O 先于 A）｜老店人群破圈（O 阶段相似人群扩量）｜高潜客户挖掘（行业大盘 + 竞品相似）。

## 三、客户分层：三条轴

### 客户生命周期五阶段

| 阶段 | 特征 | 运营策略 |
|---|---|---|
| 引入期 | 新客户获取 | 精准拉新、首单优惠 |
| 成长期 | 客户活跃度提升 | 收藏加购引导、会员升级 |
| 成熟期 | 客户贡献稳定 | 复购激励、交叉销售 |
| 休眠期 | 客户活跃度下降 | 唤醒策略、专属优惠 |
| 流失期 | 客户即将流失 | 挽留措施、流失预警 |

### 四类人群

| 人群类型 | 定义 | 运营策略 |
|---|---|---|
| 新客 | 首次购买客户 | 首购体验优化、会员引导 |
| 老客 | 有复购记录客户 | 复购激励、专属权益 |
| 潜客 | 加购/收藏但未购买 | 精准推送、限时优惠 |
| 流失客 | 长期无互动客户 | 唤醒活动、专属钩子 |

**潜客是转化率最高的一群人**，加购人群转化率最高 —— 拉新之外最便宜的成交来自这里。

### RFM 分层

RFM 是与 AIPL 并行的另一条轴：AIPL 看**行为深度**，RFM 看**交易价值**。

知识库索引层记录：RFM **八分类**，其中**重要价值用户占 5% 人数、贡献 40% 价值**（源：2026淘宝AI时代运营全攻略核心提炼，经知识库索引转述）。RFM 三轴定义与八分类阈值在本次取回的正文中未展开，**未验证，需回原库复核**。

## 四、人群精准运营三方法

| 方法 | 四步 |
|---|---|
| **人群资产盘点与规划** | ① 达摩盘分析 AIPL 各层级人群量 → ② 按 GMV 目标倒推各层级人群需求 → ③ 制定拉新/激活/复购/忠诚分阶段策略 → ④ 每日监控人群资产变化 |
| **新老客分层运营** | ① 新客获取（万相台精准拉新，人群定向到兴趣人群）→ ② 新客转化（首单优惠 + 优质客服体验）→ ③ 老客激活（个性化推荐 + 会员积分体系）→ ④ 老客复购（定期会员专享价 + 新品预告） |
| **客户流转表设计** | ① 确定关键指标（拉新数、转化率、复购率、LTV）→ ② 设定流转节点（曝光→点击→加购→首购→复购→忠诚）→ ③ 监控各节点数据，及时发现流转断点 → ④ 针对性优化断点环节 |

客户流转表是运营团队的核心工具。它把"人群运营"变成一张**可监控的节点表**，断点即行动点。

## 五、预算决定流量圈层

| 日预算 | 主要人群 | 潜客占比 |
|---|---|---|
| 50 元以下 | 店铺老客 | < 50% |
| 200-500 元 | 老客 + 少量相似 | 50-60% |
| 1000-2000 元 | 广泛相似 + 行业 | 60-70% |
| 5000 元+ | 全行业泛人群 | > 70% |

**预算是最核心的变量**：日预算 50 元只能买到老客。想扩圈层只能加预算，调定向调不出圈层。

## 六、人群校正五方法

| 方法 | 操作 | 适用场景 |
|---|---|---|
| 直通车手动高溢价 | 核心人群溢价 100%+ | 基础校正 |
| 人群拓展 | 70% 均价 + 100% 拓展溢价 | 扩大流量 |
| 地域拆分 | 一二线 / 三四线分开计划 | 消费分层 |
| 引力魔方屏蔽 | 直接排除 L1-L2 | 精准屏蔽 |
| 主图优化 | 更换风格调整人群 | 源头调整 |

**校正顺序**：先做基础校正（手动高溢价）→ 再扩量（人群拓展）→ 再分层（地域拆分）→ 再屏蔽（引力魔方）→ 最后才动主图（源头调整，代价最大）。

## 七、效果评估四条

| 指标 | 目标 |
|---|---|
| 目标人群占比 | ≥ 70% |
| 推广 ROI | 稳步上升 |
| 转化率 | 逐步提升 |
| 客单价 | 高端人群占比提升 |

四条要**同时看**：只看 ROI 会被收割型投放刷高，只看目标人群占比会掩盖成交下降。

## 八、四大误区

| 误区 | 真相 |
|---|---|
| 只关注新客获取 | 新客成本是老客的 **5-7 倍** |
| 人群运营 = 发短信 | 人群运营是全链路管理 |
| 忽视潜客培育 | 加购人群转化率最高 |
| 不做人群资产盘点 | 人群资产决定付费推广效率 |

## 使用说明

1. **先盘点再动手**：没有 AIPL 现状数据就不要动人群预算，方法一（盘点与规划）是其余方法的前置。
2. **人群问题优先于推广问题**。领先率低于合格线时，先看人群资产够不够，再动出价 —— 资产不足时高预算也是浪费。
3. **O 阶段在大促前 30 天建**，平时按 AIPL 四阶段跑日常运营，不要把 O 当日常。
4. **校正顺序不要跳级**：主图优化是源头调整，代价最大，先把前四个方法做完再考虑。
5. **效果评估四条同时看**，单看 ROI 会把收割当增长。
