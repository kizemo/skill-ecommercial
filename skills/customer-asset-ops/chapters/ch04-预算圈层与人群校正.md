# 预算圈层与人群校正

**来源笔记**：《2026淘宝运营完整知识体系》《人群运营策略》《客户运营体系》

---

## 一、预算决定流量圈层

| 日预算 | 主要人群 | 潜客占比 |
|---|---|---|
| 50 元以下 | 店铺老客 | < 50% |
| 200-500 元 | 老客 + 少量相似 | 50-60% |
| 1000-2000 元 | 广泛相似 + 行业 | 60-70% |
| 5000 元+ | 全行业泛人群 | > 70% |

**读法**：

- 日预算 50 元只能买到**店铺老客** —— 潜客占比 < 50%，几乎没有新客进来
- 预算从 50 元提到 200-500 元，才开始有"少量相似人群"，潜客占比过半
- 1000-2000 元买到"广泛相似 + 行业"人群
- 5000 元以上变成全行业泛人群，潜客占比 > 70%

**预算是最核心的变量**。想让圈层变宽只有两条路：加预算，或**先把人群资产做厚**（资产厚了，同样预算能触达更广的人）。调定向调不出圈层。

**与超级短视频的指标对齐**：超级短视频的核心指标是**潜客占比（目标 60%-80%）+ 盈利性**，投放策略是"超短拉新 → 全站收割"。潜客占比不到 60% 时，短视频也在给老客抬轿。

**与效果评估对齐**：人群校正做完，**目标人群占比要 ≥ 70%**。达不到就说明圈层还没打开，预算或资产还得加。

## 二、人群校正五方法

| 方法 | 操作 | 适用场景 | 代价 |
|---|---|---|---|
| **直通车手动高溢价** | 核心人群溢价 100%+ | 基础校正 | 只影响已有计划内的点击成本，改动最轻 |
| **人群拓展** | 70% 均价 + 100% 拓展溢价 | 扩大流量 | 扩量必然拉低精准度，需盯转化率 |
| **地域拆分** | 一二线 / 三四线分开计划 | 消费分层 | 计划数量翻倍，拆之前先确认地域差异真实存在 |
| **引力魔方屏蔽** | 直接排除 L1-L2 | 精准屏蔽 | 排除掉的量是真没了，要先确认 L1-L2 不是主成交人群 |
| **主图优化** | 更换风格调整人群 | 源头调整 | 换主图 = 重开测图，影响面最大，放最后做 |

### 校正顺序

```
基础校正（手动高溢价）
   ↓ 仍不够准
屏蔽 + 分层（引力魔方屏蔽 L1-L2、地域拆分）
   ↓ 需要更大流量
扩量（人群拓展 70% 均价 + 100% 拓展溢价）
   ↓ 人群本身吸引错
源头调整（换主图风格）
```

**不要跳级**：主图优化是源头调整，代价最大（换图 = 重开测图），前四个方法做完还解决不了才动它。

**配套溢价参考**（直通车人群溢价）：核心人群溢价 100%+、行为人群（浏览未购买）溢价 150%+、相似店铺人群溢价 80%+。

**引力魔方的三套计划**：手动计划（拉 L3-L5 高端人群，自定义屏蔽 L1-L2）｜控 ROI 计划（收割高意向人群，屏蔽非自定义人群）｜竞争人群渗透（针对看过竞品但未购买的人群，高客单核心玩法）。**人群校正主要作用在手动计划上**。

## 三、效果评估四条

| 指标 | 目标 | 怎么测 |
|---|---|---|
| **目标人群占比** | ≥ 70% | 推广报表按人群维度拆，成交人群落在目标人群包内的比例 |
| **推广 ROI** | 稳步上升 | 看趋势而不是单点，单次高 ROI 可能是收割 |
| **转化率** | 逐步提升 | 校正后不该掉；掉了说明扩量扩猛了或主图/详情没跟上 |
| **客单价** | 高端人群占比提升 | 人群升级的标志，说明圈层真的往上走了 |

**四条必须同时看**：

- 只看 ROI → 收割型投放能把 ROI 刷高，人群精准度反而下降
- 只看目标人群占比 → 掩盖成交总量下降
- 只看转化率 → 忽略客单价，UV 价值上不去
- 只看客单价 → 忽略新客占比，资产断代

**判断顺序**：目标人群占比是否 ≥ 70%（圈层对不对）→ 转化率是否逐步提升（承接对不对）→ ROI 是否稳步上升（效率对不对）→ 客单价高端人群占比是否提升（质量对不对）。

## 四、人群运营日历

### 日常

| 时间 | 动作 |
|---|---|
| 每日 | 查看人群数据报告 |
| 每日 | 调整人群溢价 |
| 每周 | 分析人群变化趋势 |
| 每月 | 更新人群策略 |

### 大促节点

| 阶段 | 人群策略 |
|---|---|
| 预热期 | 精准人群种草，老客召回 |
| 爆发期 | 全站放量，转化收割 |
| 余热期 | 库存清理，新客沉淀 |
| 日常期 | 人群资产维护 |

**预热期就是 O 阶段**：大促前 30 天建 O-AIPL 计划，O 阶段预算占 30%+，蓄水量（O+A）> 200w（见 `ch01-AIPL与O-AIPL.md`）。

## 六、常见问题

**Q：UV 价值和 ROI 有什么区别？**
A：UV 价值衡量每个访客的产出，ROI 衡量付费推广的效率。UV 价值是结果，ROI 是手段。

**Q：人群放量和精准是矛盾的吗？**
A：不是矛盾，是阶段不同。打标期重精准，爆发期重规模，稳定期找平衡。

**Q：私域人群如何运营？**
A：淘宝群定期发福利，会员中心设置专属权益，客服主动触达高意向用户。

**Q：人群不准，第一步做什么？**
A：先切生意参谋归因方式（第一次 / 最后一次访问来源）确认是不是口径问题，再动校正五方法。口径没查清就改人群，等于蒙眼调参。判定细节见 [[store-diagnosis]]。
