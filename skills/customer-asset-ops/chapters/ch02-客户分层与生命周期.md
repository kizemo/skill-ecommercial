# 客户分层与生命周期

**来源笔记**：《客户运营体系》《人群运营策略》《淘系运营核心公式》《O-AIPL》

---

## 一、客户生命周期五阶段

| 阶段 | 特征 | 运营策略 |
|---|---|---|
| 引入期 | 新客户获取 | 精准拉新、首单优惠 |
| 成长期 | 客户活跃度提升 | 收藏加购引导、会员升级 |
| 成熟期 | 客户贡献稳定 | 复购激励、交叉销售 |
| 休眠期 | 客户活跃度下降 | 唤醒策略、专属优惠 |
| 流失期 | 客户即将流失 | 挽留措施、流失预警 |

**阶段是客户的，不是店铺的**。同一个人会在五阶段之间移动，所以召回的本质是**把人拉回前一个阶段**，而不是发一发就完。

| 当前阶段 | 拉回目标 | 主用手段 |
|---|---|---|
| 流失期 | 回到成熟期 | 挽留措施、流失预警 |
| 休眠期 | 回到成熟期 | 唤醒策略、专属优惠 |
| 成熟期 | 停留在成熟期 | 复购激励、交叉销售 |
| 成长期 | 推进到成熟期 | 收藏加购引导、会员升级 |
| 引入期 | 活到成长期 | 精准拉新、首单优惠 |

## 二、四类人群

| 人群类型 | 定义 | 运营策略 |
|---|---|---|
| 新客 | 首次购买客户 | 首购体验优化、会员引导 |
| 老客 | 有复购记录客户 | 复购激励、专属权益 |
| 潜客 | 加购/收藏但未购买 | 精准推送、限时优惠 |
| 流失客 | 长期无互动客户 | 唤醒活动、专属钩子 |

**潜客是转化率最高的一群人**：加购人群转化率最高。这是全店最便宜的一块成交 —— 他们的意图已经发生了，只差一次推送。

**新客成本是老客的 5-7 倍**：只关注新客获取会把预算全烧在最贵的流量上。

## 三、RFM 分层

RFM 是与 AIPL 并行的另一条轴：**AIPL 看行为深度，RFM 看交易价值**。

知识库索引层记录的 RFM 结论：

| 项 | 结论 |
|---|---|
| 分类方式 | **八分类** |
| 头部分布 | **重要价值用户占 5% 人数，贡献 40% 价值** |

**未验证**：RFM 三轴（R 最近一次消费 / F 消费频次 / M 消费金额）的具体定义、每轴分档阈值、八分类的完整名单，在本次取回的素材正文中均未展开。**落地前必须回原库复核**（相关原笔记：`50-客户与私域/RFM分层.md`、`每日学习/历史/01-全域用户召回策略：RFM分层与A1-A3动态意图系统`）。

**当前可以安全用的结论**：**5% 的人贡献 40% 的价值** —— 意味着高价值客户的识别和单独运营是最高杠杆的动作，其余客户用低成本手段承接（自动推荐、会员权益）。

## 四、新老客比例

```
健康店铺新老客比例 = 新客 50% : 老客 50%
```

**老客复购是利润的主要来源**。优化方向：新客成本高 → 提高新客转化效率；老客价值高 → 建立会员体系提升复购。

> 口径注（**口径冲突，需复核**）：《人群运营策略》的"人群运营数据指标"表里另有一条"新客占比 合格线 30-50% / 优秀线 40-60%"，未注明是**人数占比**还是**成交占比**。它与"健康新老客比例 50:50"、与领先率（前比）"新客成交 ÷ 总成交 ≥ 80%"三者口径不同，**不能混用**。本 skill 用领先率判断"拉新 vs 收割"，用新老客比例判断"结构是否失衡"。

## 五、UV 价值

```
UV价值 = GMV / UV数 = 平均每个访客带来的成交金额
```

**UV 价值 vs ROI**：UV 价值衡量每个访客的产出，ROI 衡量付费推广的效率。**UV 价值是结果，ROI 是手段。**

### UV 价值提升四维法

| 维度 | 方法 |
|---|---|
| **客单价提升** | 凑单引导（如满 300 减 30）、详情页推荐关联产品；套餐组合（加量装/套装、捆绑优惠）；升级引导（展示高客单价产品对比、强调性价比） |
| **转化率提升** | 优化详情页（卖点前置、信任背书完善、评价管理）；营销刺激（限时优惠、赠品策略、会员价）；服务保障（运费险、快速发货、售后承诺） |
| **复购率提升** | 会员体系（积分制度、会员专享价、生日福利）；复购触达（老客专属优惠、换季提醒、库存预警）；产品矩阵（多产品覆盖同一用户需求、推出迭代产品） |
| **人群精准度提升** | 标签优化（通过叠标精准触达、排除无效人群）；内容精准（精准人群看到精准内容，减少无效曝光） |

**人群精准度提升是唯一能同时改善 UV 价值和付费效率的一维** —— 另外三维是"把已有流量榨得更狠"，这一维是"换更好的流量"。

## 六、人群运营数据指标（合格线 / 优秀线）

| 指标 | 合格线 | 优秀线 | 优化方向 |
|---|---|---|---|
| UV 价值 | ≥ 行业均值 | ≥ 行业 1.5 倍 | 客单价、转化率、复购 |
| 人群资产总量 | 访客数的 50% | 访客数的 80% | 拉新投入 |
| 新客占比 | 30-50% | 40-60% | 拉新与老客平衡 |
| 老客复购率 | ≥ 10% | ≥ 20% | 会员体系、触达 |

**人群资产总量是付费推广效率的地基**：总量不到访客数 50%，说明流量进来留不下，高 ROI 撑不了多久。

**老客复购率 10% → 20%** 这一格是人群运营最直接的收益来源 —— 见 [[profit-model]] 算 LTV 的账。

## 七、客户 LTV 与获客成本上限

```
LTV = 平均客单价 × 平均购买次数 × 平均生命周期
```

**LTV 决定获客成本上限**：当新客获取成本低于 LTV 才成立。结合"新客成本是老客的 5-7 倍"，推论是：**老客侧的投入回报率结构性高于新客侧**，预算不能全压在拉新。

（类目参考值见 [[taobao-ops-playbook]] 核心公式手册，医疗器械类目 LTV 1200-7500 元为该类目专属，不可套用。）
