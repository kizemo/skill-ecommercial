# 可复用方法 · customer-asset-ops

---

## 人群资产盘点与规划法

**何时用**：每月一次；大促前 60 天启动；新店冷启动；投放 ROI 连续下滑且加预算无效时。

**怎么做**：
1. 打开达摩盘，按 A（15 天浏览）/ I（90 天收藏加购）/ P（365 天 1 天购买）/ L（365 天 ≥2 天购买）四层取数。
2. 算人群资产总量占访客数的比例，< 50% 说明资产不足。
3. 按 GMV 目标**倒推**各层级人群需求，而不是先定流量再倒推 GMV。
4. 给每层配一条策略：拉新 / 激活 / 复购 / 忠诚。
5. 每日监控各层级人数变化，写进日报。

**代价/风险**：倒推依赖 GMV 目标准确，目标虚高会推导出过量的预算需求；A/I/P/L 的时间窗口必须用平台口径，自己的口径和平台对不上时"盘点"没有可比性。

## O-AIPL 大促蓄水法

**何时用**：大促前 30 天；新店冷启动（O 先于 A）；老店人群破圈；挖高潜客户。

**怎么做**：
1. 大促前 **30 天**建 O-AIPL 计划。
2. O 阶段预算占 **30%+**。
3. 达摩盘导出 O 阶段人群包（达摩盘 lookalike + 行业大盘）。
4. 万相台无界拉新 + 直通车精准组合跑 O 阶段。
5. 每天看 O→A 转化率，健康值 **> 15%**；人群规模目标 **> 100w**，蓄水量（O+A）**> 200w**。

**代价/风险**：O 阶段的产出不是即时成交，是蓄水，**当月看不到 GSV 属于正常**，用短期 ROI 考核 O 阶段会直接把它砍掉。人群规模不足 100w 时 O→A 转化率再高也没有意义，先补规模。

## 新老客分层运营法

**何时用**：日常；大促期间；老客复购率低于 10% 时。

**怎么做**：
1. **新客获取**：万相台精准拉新，人群定向到兴趣人群。
2. **新客转化**：首单优惠 + 优质客服体验（首购体验决定后续所有阶段）。
3. **老客激活**：个性化推荐 + 会员积分体系。
4. **老客复购**：定期会员专享价 + 新品预告。
5. 配触达工具：淘宝群发福利、会员中心设专属权益、客服收藏夹标记高意向用户。

**代价/风险**：步骤顺序不能跳 —— 新客体验做砸，后面的复购与忠诚全部落空。私域触达过度会变成骚扰，触达频次要与客户的购买周期匹配。

## 客户流转表断点排查法

**何时用**：转化率突然下滑；不知道该改哪个环节；做单品的客户结构体检。

**怎么做**：
1. 明确关键指标：拉新数、转化率、复购率、LTV。
2. 搭节点表：曝光 → 点击 → 加购 → 首购 → 复购 → 忠诚，逐节点算转化率。
3. 找**转化率最低的那一跳**（断点），只修断点，不通铺。
4. 按断点类型选动作：
   - 曝光→点击：测图、卖点前置
   - 点击→加购：详情页、买家秀、问大家
   - 加购→首购：限时优惠、会员价、运费险、首单礼金
   - 首购→复购：会员体系、复购触达
   - 复购→忠诚：专属权益、交叉销售
5. 修完复算节点转化率，确认断点已过。

**代价/风险**：流转表的价值在断点，**整条链都看等于没看**。节点口径必须同源，尤其"曝光"与"点击"要来自同一套报表。

## 预算圈层换算法

**何时用**：给拉新定预算；判断计划是不是在买老客；预算砍了以后判断会丢什么人。

**怎么做**：
1. 查当前日预算，落到圈层档位：

   | 日预算 | 主要人群 | 潜客占比 |
   |---|---|---|
   | 50 元以下 | 店铺老客 | < 50% |
   | 200-500 元 | 老客 + 少量相似 | 50-60% |
   | 1000-2000 元 | 广泛相似 + 行业 | 60-70% |
   | 5000 元+ | 全行业泛人群 | > 70% |

2. 用实际潜客占比对照档位，偏低说明预算与圈层不匹配。
3. 要提高圈层只有两条路：加预算，或先把人群资产做厚（资产厚了同预算能触达更广的人）。
4. 改完复测潜客占比与目标人群占比。

**代价/风险**：预算是最核心的变量，**调定向调不出圈层**。加预算换来的泛人群会拉低转化率，要盯转化率是否逐步提升。

## 人群校正五步法

**何时用**：目标人群占比 < 70%；转化率低于行业；同类竞品能拿到更高质量流量。

**怎么做**：
1. **先查口径**：切生意参谋归因方式（第一次 / 最后一次访问来源），确认不是报表问题（见 [[store-diagnosis]]）。
2. **基础校正**：直通车手动高溢价，核心人群溢价 100%+（可配行为人群 150%+、相似店铺 80%+）。
3. **屏蔽与分层**：引力魔方手动计划直接排除 L1-L2；一二线 / 三四线分开计划。
4. **扩量**：人群拓展 70% 均价 + 100% 拓展溢价。
5. **源头调整**（前四步做完仍不准才做）：换主图风格调人群。

**代价/风险**：主图优化换的是流量入口，影响面最大、放最后。屏蔽掉的量是真没了，排除前先确认 L1-L2 不是主成交人群。人群拓展必然拉低精准度，盯转化率别掉出可接受范围。

## 效果评估四条核验法

**何时用**：每次人群策略调整后；月度复盘；向老板汇报人群运营成果。

**怎么做**：
1. **目标人群占比 ≥ 70%** —— 圈层对不对。
2. **转化率逐步提升** —— 承接对不对。
3. **推广 ROI 稳步上升** —— 效率对不对。
4. **客单价高端人群占比提升** —— 质量对不对。
5. 四条同时满足才算通过；任一条不满足就定位到对应环节重做。

**代价/风险**：单看 ROI 会被收割型投放刷高；单看目标人群占比会掩盖成交下降；单看客单价会忽略新客占比导致资产断代。

## 爆款放量三步法

**何时用**：链接进入起量期之后；人群包已积累到一定量级。

**怎么做**：
1. **精准蓄水**：直通车精准拉新 + 超级短视频种草 + 小红书内容种草。判断标准：人群包规模达到一定量级、标签准确度高。
2. **标签放大**：逐步降低人群精准度、扩展相似人群、增加推荐流量。判断标准：人群规模增长，**转化率下降不超过 20%**。
3. **全站放量**：全站推广介入 + 活动配合 + 内容联动。判断标准：ROI 达到预期目标、GSV 持续增长。

**代价/风险**：转化率下降超过 20% 是红线，退回蓄水重新做。放量要循序渐进，每次增幅 ≤ 50%。全站推广压制自然流量，新品期慎用。

## 老客召回法

**何时用**：休眠期 / 流失期客户占比上升；大促预热期；老客复购率低于 10%。

**怎么做**：
1. 从达摩盘/私域工具圈出休眠与流失客，按消费分层（人群校正里的地域拆分思路）分批。
2. 差异化钩子：老客专属优惠、换季提醒、库存预警、新品预告、会员专享价。
3. 走淘宝群 + 会员中心 + 客服收藏夹三个触点，不群发一条了事。
4. 复盘召回率与召回后的复购率，决定下一轮钩子。

**代价/风险**：无差别群发会拉低店铺体验分与客户信任。召回成本要低于该客户的 LTV，否则召回越多亏越多（见 [[profit-model]]）。
