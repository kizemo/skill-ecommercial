## 1. 阈值表

| 指标 | 目标 / 健康线 | 低于此线的后果 |
|---|---|---|
| 目标人群占比 | ≥ 70% | 圈层没打开，校正没做够 |
| O 阶段人群规模 | > 100w | O→A 转化率再高也无意义 |
| O → A 转化率 | > 15% | 蓄水效率不足 |
| 大促蓄水量（O + A） | > 200w | 大促爆发力不足 |
| O-AIPL 计划建立时点 | 大促前 30 天 | 蓄水来不及 |
| O 阶段预算占比 | 30%+ | 蓄水投入不足 |
| O 拉新效率 | 比普通拉新高 50%+ | O 阶段失去意义 |
| 人群资产总量 | 访客数的 50%（优秀 80%） | 付费推广 ROI 会持续下滑 |
| 老客复购率 | ≥ 10%（优秀 ≥ 20%） | 老客价值没兑现 |
| UV 价值 | ≥ 行业均值（优秀 ≥ 行业 1.5 倍） | 承接效率不足 |
| 新老客比例 | 新客 50% : 老客 50% | 结构失衡 |
| 超级短视频潜客占比 | 目标 60%-80% | 短视频在给老客抬轿 |
| 兴趣点访客（店铺资产） | 基础 ≥ 2-5 万；成熟店 > 5 万 + 新客 ≥ 20 万 | 无样本，AI 场景只推泛流量 |
| 直通车人群溢价 | 核心 100%+ / 行为 150%+ / 相似店铺 80%+ | 精准人群拿不到量 |

## 2. 预算 → 圈层 → 潜客占比

| 日预算 | 主要人群 | 潜客占比 |
|---|---|---|
| 50 元以下 | 店铺老客 | < 50% |
| 200-500 元 | 老客 + 少量相似 | 50-60% |
| 1000-2000 元 | 广泛相似 + 行业 | 60-70% |
| 5000 元+ | 全行业泛人群 | > 70% |

**想扩圈层只有两条路：加预算，或先把人群资产做厚。调定向调不出圈层。**

## 3. 决策规则（当 X 时做 Y，因为 Z）

| 当 | 做 | 因为 |
|---|---|---|
| 领先率低于合格线 | 先查人群资产总量，再动出价 | 资产不足时高预算也是浪费（[[store-diagnosis]]） |
| 预算 < 50 元且想拉新 | 加预算或先做 O 阶段蓄水 | 这个预算只能买到店铺老客 |
| 潜客占比 < 60% | 拉预算档位或加 O 阶段投入 | 现在的钱主要在给老客抬轿 |
| 目标人群占比 < 70% | 走人群校正五步法 | 圈层没打开 |
| O→A 转化率 < 15% | 先查人群包质量与素材，再加钱 | 人群不对时加钱只会更差 |
| O 阶段人群规模 < 100w | 先补规模再谈转化率 | 池子太小撑不起大促 |
| 转化率下降超过 20%（放量时） | 退回精准蓄水 | 放量红线，人群扩太泛 |
| 老客复购率 < 10% | 做会员体系 + 复购触达 | 老客是最便宜的增长 |
| 效果差但 ROI 好看 | 查目标人群占比与成交人群来源 | 收割能把 ROI 刷高 |
| 客户流转表某跳转化率最低 | 只修这一跳 | 断点即行动点，通铺无效 |
| 主图风格与目标人群不符 | 换主图（源头调整） | 人群是靠入口内容筛出来的 |
| L1-L2 为主成交人群 | 不要屏蔽 | 屏蔽掉的量是真没了 |
| 新客成本是老客的 5-7 倍 | 预算不能全压拉新 | 老客侧回报结构性更高 |
| RFM 重要价值客户只占 5% 人数 | 单独运营这批人 | 他们贡献 40% 价值 |

## 4. 决策树

```
要做人群运营
├─ 有 AIPL 现状盘点吗？
│  └─ 没有 → 先盘点（达摩盘取 A/I/P/L 四层 + 资产总量占比）→ 再谈动作
├─ 是大促前 30 天内？
│  ├─ 是 → 建 O-AIPL 计划，O 预算占 30%+，蓄水 > 200w，每天看 O→A > 15%
│  └─ 否 → 走日常 AIPL 四阶段运营
└─ 效果不达预期
   ├─ 目标人群占比 < 70%？
│  ├─ 是 → 人群校正五步法（手动高溢价 → 屏蔽/分层 → 拓展 → 换主图）
   │  └─ 仍不达标 → 查报表归因口径是不是错（[[store-diagnosis]]）
   └─ 否 → 看成交人群来源：老客为主 = 收割型投放 → 停收割计划

召回流失客
├─ 客户价值高（RFM 重要价值 / 消费频次高）→ 人工触达 + 专属钩子
├─ 一般老客 → 淘宝群 + 会员专享价 + 新品预告
└─ 成本核算：召回成本 < 该客户 LTV 否则不召（[[profit-model]]）
```

## 5. 人群校正五方法（按顺序做）

| 顺序 | 方法 | 操作 | 适用场景 |
|---|---|---|---|
| 1 | 直通车手动高溢价 | 核心人群溢价 100%+ | 基础校正 |
| 2 | 引力魔方屏蔽 | 直接排除 L1-L2 | 精准屏蔽 |
| 3 | 地域拆分 | 一二线 / 三四线分开计划 | 消费分层 |
| 4 | 人群拓展 | 70% 均价 + 100% 拓展溢价 | 扩大流量 |
| 5 | 主图优化 | 更换风格调整人群 | 源头调整（代价最大，放最后） |

## 6. 效果评估四条

| 指标 | 目标 | 单独看会骗人 |
|---|---|---|
| 目标人群占比 | ≥ 70% | 掩盖成交总量下降 |
| 推广 ROI | 稳步上升 | 收割型投放能刷高 |
| 转化率 | 逐步提升 | 忽略客单价，UV 价值上不去 |
| 客单价 | 高端人群占比提升 | 忽略新客占比，资产断代 |

**四条同时看才算通过。** 判定顺序：圈层 → 承接 → 效率 → 质量。

## 7. 客户流转表节点

| 节点 | 断点原因 | 修复方向 |
|---|---|---|
| 曝光 → 点击 | 主图/素材不吸引 | 测图、卖点前置（[[visual-material]]） |
| 点击 → 加购 | 详情页说服力不足 | 详情页、买家秀、问大家（[[conversion-optimization]]） |
| 加购 → 首购 | 价格/运费/时效顾虑 | 限时优惠、会员价、运费险、首单礼金 |
| 首购 → 复购 | 体验差、无召回 | 会员体系、复购触达、新品预告 |
| 复购 → 忠诚 | 只买折扣款 | 专属权益、交叉销售、囤货装 |

关键指标：拉新数、转化率、复购率、LTV。

## 9. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 只关注新客获取 | 新客成本是老客的 5-7 倍，预算烧在最贵流量上 | 新老客分层运营，老客复购率 ≥ 10% 是底线 |
| 人群运营 = 发短信 | 触达只是最后一步，前面全是空的 | 走 AIPL 全链路 + 流转表断点 |
| 忽视潜客培育 | 放掉转化率最高的一群人 | 潜客单独盯，限时优惠 + 精准推送 |
| 不做人群资产盘点 | 资产决定付费推广效率，没盘点就是蒙投 | 每月盘点 + 每日监控 |
| 用默认归因判断人群准不准 | 口径失真，改人群等于蒙眼调参 | 先切第一次 / 最后一次访问来源（[[store-diagnosis]]） |
| 先换主图再改人群 | 换图 = 重开测图，影响面最大 | 前四个校正方法做完再动主图 |
| 预算不够却怪人群不准 | 50 元预算只能买到老客 | 先看预算档位与潜客占比 |
| 拿 O 阶段当月考核 ROI | 蓄水看不到当期成交，直接被砍 | O 阶段看 O→A 与蓄水量 |
| 把"目标人群占比 ≥ 70%"当"会员 GMV 占比 ≥ 70%" | 两个指标混用 | 分开记，前者是人群校正验收，后者是会员资产 |
| 混用"新客占比 30-50%"与领先率 ≥ 80% | 口径不同（人数 vs 成交） | 领先率判断拉新/收割，新老客比例判断结构 |
| 计划跑久了效果变差就加价 | 精准人群池被自己吃完 | 重建（换人群包/创意/定向），不加价 |
| 无差别群发召回 | 拉低体验分与客户信任 | 按客户价值分层触达 |
