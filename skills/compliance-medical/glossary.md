# 术语表 · compliance-medical

> 每条格式：**术语** — 定义（来源：<笔记名>）

---

**医疗器械合规** — 医疗器械在天猫/淘宝上架、宣传、销售必须遵守的法规和平台规则总称，涵盖资质 / 广告法 / 标签 / 经营许可 / 电商平台规则多个维度；是医疗器械电商的生死线（来源：医疗器械合规.md）

**一类医疗器械** — 资质为**备案凭证**（地市级药监局）；举例：创可贴、纱布、医用冷敷贴、棉签；平台要求：营业执照 + 商标注册证（来源：医疗器械合规.md）

**二类医疗器械** — 资质为**注册证**（省级药监局）+ 备案；举例：血糖仪、血压计、家用雾化器、轮椅、护腰带；平台要求：医疗器械经营备案凭证 + 注册证 + 营业执照（来源：医疗器械合规.md）

**三类医疗器械** — 资质为**注册证**（国家药监局）+ **经营许可**；举例：制氧机、医用敷料（部分）、植入器械；平台要求：医疗器械经营许可证 + 注册证 + 营业执照（来源：医疗器械合规.md）

**备案凭证** — 一类医疗器械的法定资质，由地市级药监局核发（来源：医疗器械合规.md）

**注册证** — 二类由省级药监局核发、三类由国家药监局核发的医疗器械法定资质（来源：医疗器械合规.md）

**经营许可 / 经营备案凭证** — 医疗器械经营环节的资质要求；三类需经营许可，二类需经营备案凭证（来源：医疗器械合规.md）

**商标注册证** — 天猫平台资质之一，R 标 / TM 标（来源：医疗器械合规.md）

**绝对化用语** — 禁用词第 1 组（原文标 10 个）：最 / 最佳 / 最好 / 第一 / 唯一 / 顶级 / 顶尖 / 极致 / 国家级 / 世界级；100% 违规（来源：医疗器械合规.md）

**医疗效果承诺** — 禁用词第 2 组（原文标 15 个、实列 14 条）：治愈率 / 根治 / 彻底治愈 / 永不复发 / 有效率 100% / 立即见效 / 药到病除 / 100% 起效 / 无效退款（医疗类）/ 替代药物治疗 / 替代手术 / 替代医生诊断 / 经临床验证（无依据时）/ 医院同款（无授权时）；100% 违规，触发 C 类处罚（来源：医疗器械合规.md）

**功效夸大** — 禁用词第 3 组（原文标 15 个、实列 14 条）：治疗 / 预防 / 根治 / 治愈（仅二类可声称"辅助治疗"）/ 减肥 / 增高 / 丰胸 / 美容（医疗器械禁忌）/ 抗衰老 / 延寿 / 提高免疫力 / 增强体质（无依据时）/ 改善睡眠 / 缓解疼痛（医疗器械需明确适应症）；100% 违规（来源：医疗器械合规.md）

**安全性虚假承诺** — 禁用词第 4 组（原文标 10+ 个）：无副作用 / 绝对安全 / 100% 安全 / 零风险 / 零刺激 / 纯天然 / 0 添加 / 0 防腐剂（无依据时）/ 不含任何有害物质（无检测报告时）/ 通过 FDA / CE / 权威认证（无授权时）；100% 违规（来源：医疗器械合规.md）

**其他禁用词** — 禁用词第 5 组（原文标 10+ 个）：祖传 / 秘方 / 神器 / 神效 / 立竿见影 / 专家推荐 / 院士研发 / 博士团队（无身份证明）/ 包治百病 / 一次断根 / 永不复发 / 销量第一 / 好评率第一 / 复购率第一（无数据证明）（来源：医疗器械合规.md）

**禁忌症** — 标签强制标注第 4 项，必须列；缺一项即违规；客服咨询禁忌症需 100% 准确（来源：医疗器械合规.md）

**不良反应** — 标签强制标注第 5 项，必须列；缺一项即违规（来源：医疗器械合规.md）

**标签强制标注** — 医疗器械必须逐项标注的 7 项：注册证编号/备案编号、生产企业名称+地址、产品名称+规格、禁忌症、不良反应、使用说明/储存条件、生产日期/有效期；缺一项 = 违规（来源：医疗器械合规.md）

**医疗器械旗舰店 / 专卖店** — 天猫医疗器械类目要求的店铺类型（来源：医疗器械合规.md）

**私下交易** — 天猫禁止的行为；**引导加微信 / 转线下 = 严重违规**（来源：医疗器械合规.md）

**A 类违规** — 单条违规词 → 商品下架 + 扣 2-6 分（来源：医疗器械合规.md）

**B 类违规** — 多次违规 / 严重词 → 扣 6-12 分 + 罚款 5-20 万（来源：医疗器械合规.md）

**C 类违规** — 医疗效果承诺 / 多次 B 类 → 封店 + 罚款 20-100 万（来源：医疗器械合规.md）

**D 类违规** — 重大医疗事故 → 刑事责任 + 永久禁业（来源：医疗器械合规.md）

**医疗效果承诺 = 立即封店** — 案例 1（血糖仪「治愈糖尿病」）的原文教训：扣 12 分 + 封店（来源：医疗器械合规.md）

**直播话术比详情页更严** — 案例 5（雾化器直播「医生推荐」）的原文教训：扣 12 分 + 直播封禁（来源：医疗器械合规.md）

**合规 review 会议** — 每周三的合规例会，参会方为运营 + 客服 + 主播（来源：医疗器械合规.md）

**AI 巡店（全店诊断）** — 千牛 AI 生意管家的巡检功能，1 分钟完成店铺全维度巡检，含订单 / 商品 / 推广 / 店铺四大模块，可排查标题违规词、库存、质量分、体验分、违规记录（来源：b17-千牛ai生意管家运营实战指南.md）

**价格力** — 2026 淘系平台规则第一权重，取代五星价格力；活动报名自动对比全网同款/相似款价格，不达标直接被踢出活动（来源：30-爆款三板斧-平台规则.md）

**商业化保费比** — 2026 平台对广告花费占比的强制要求：不低于去年同期，否则消费券从"平台全资"降为"商家混资/全资"；淘客佣金不计入商业化权重（来源：30-爆款三板斧-平台规则.md）

**真实体验分** — 2026 平台的一票否决项：店铺体验分 < 4.6 失搜索权重 + 无法报名大促；商品体验分 PXI < 70 流量负向、< 60 彻底断流（来源：30-爆款三板斧-平台规则.md）

**强活动化** — 2026 平台活动侧规则：618 预计 5 月上旬、双十一提前至 10 月上旬、活动周期拉长至 1.5 个月、淘宝秒杀/超级立减/品牌新享常态化（来源：30-爆款三板斧-平台规则.md）

**店铺评分红线（4.2 口径）** — 另一处店铺体验分口径：< 4.2 分无法报名官方活动；与 4.6 口径并存，**口径冲突，需复核**（来源：运营方法论 stub「店铺评分红线」）

**推荐流量获取基础规则（4.3 口径）** — 千牛 AI「行业洞察小助手」列出的门槛：店铺体验分 ≥ 4.3、商品质量分 ≥ 60、价格力三星以上、主图 ≥ 4 张近 30 天有动销、支持七天无理由/包邮；与 4.6 / 4.2 属不同维度，一并登记复核（来源：b17-千牛ai生意管家运营实战指南.md）
