# 可复用方法 · compliance-medical

> 每条格式：`## 方法名` + **何时用** + **怎么做** + **代价/风险**

---

## 六载体全量扫描法

**何时用**：每周一全店巡检；大促前 7 天全店审查；换新一批详情页/主图之后。

**怎么做**：
1. 列载体清单，六类并列：详情页文案、主图/副图文字、SKU 标题、客服话术、直播话术、评价内容。
2. 把 `cheatsheet.md` 的五组词表整段粘进扫描工具（Excel 查找或脚本正则），逐组扫一遍。
3. **第 2 组（医疗效果承诺）单独人工过一遍**——它不靠字符串，靠语义，机器扫不出来。
4. 命中分三种处置：明确违规 → 立即改；条件性词（经临床验证 / 医院同款 / 纯天然 / 销量第一）→ 查档后决定；技术参数假阳性（最大功率 / 最小噪音）→ 人工确认后登记为假阳性。
5. 输出《禁用词扫描报告》：载体 / 命中词 / 所属组 / 处置结论 / 责任人。

**代价/风险**：漏一个载体就等于漏一个雷区（案例 5 出在直播）。机器扫会把"最大功率"这类参数误报，误报多了一线就不看报告了——所以要定期维护假阳性白名单。

## 条件性词证据留档法

**何时用**：文案里有"经临床验证""医院同款""纯天然""无添加""销量第一""专家推荐"这类需要凭据的词时。

**怎么做**：
1. 建《条件性词证据台账》：词 → 出现在哪个链接/哪段文案 → 凭据类型（授权书 / 检测报告 / 平台数据截图 / 身份证明）→ 凭据文件位置 → 有效期。
2. 凭据齐全 → 放行，登记；凭据缺失或过期 → 立即改文案。
3. 涉及数据证明的（销量第一 / 好评率第一 / 复购率第一）必须留存**截图 + 时间 + 统计口径**——平台认的是"当时那个口径下的数据"，无口径的截图无效。
4. 台账每月随资质台账一起复核。

**代价/风险**：证据会过期——授权到期、检测报告换版、数据被后来者超过。**凭据过期 = 自动变成违规词**，所以台账必须带有效期字段并设提醒，不能只存文件。

## 客服禁忌症话术库管控

**何时用**：新客服入职；产品或注册证信息变更；每周三 review 会议。

**怎么做**：
1. 按产品建话术条目，每个产品至少三段定稿：适用人群 / 禁忌症 / 不良反应与处理建议。
2. **答案必须 100% 准确**——直接引用注册证与说明书原文，不做口语化改写。
3. 话术库**专人维护**、版本号管理；客服只能从库里复制，不得自由发挥。
4. 遇到库里没有的问题 → 统一回复"需要核实后回复"并转专员，**不许猜**。
5. 每周三 review 会议抽查真实会话记录。

**代价/风险**：话术库会有"覆盖不全"的问题——库外的咨询最容易变成自由发挥。**所以必须配套"库外问题上报"通道**，否则库外的咨询就等于没有合规答案。

## 直播话术双控

**何时用**：每场直播前、直播中、直播后。

**怎么做**：
1. **场前**：给主播一份禁说词卡（至少包含 100% / 立即见效 / 医生推荐 / 根治 / 无副作用），当场过一遍。
2. **场中**：安排专人实时盯屏/盯弹幕关键词，出现即提醒；重大表述当场叫停。
3. **场后**：复盘回放，查是否出现平台处罚警告、用户截图投诉。
4. 直播中**不承诺疗效、不借专业身份背书**；有真实合作医生或专家的，只能在授权范围内表述并出示身份证明。

**代价/风险**：直播的不可控性是结构性的——主播临场反应比脚本快。**实时监控只能降低概率，不能消除**，所以直播话术要比详情页更保守，而不是更灵活。

## 资质有效期台账

**何时用**：每月 1 号例行核对；新链接上架前；大促报名前。

**怎么做**：
1. 建台账，一证一行：证件类型 / 编号 / 核发机构 / 有效期至 / 剩余天数 / 续期负责人 / 提醒日。
2. **剩余 30 天触发续期**——30 天是启动窗口，不是截止日（经营许可换证周期比注册证长，更要早排期）。
3. 每次上架前查台账：证件齐全 + 在有效期 + 营业执照经营范围含医疗器械 + 店铺类型为医疗器械旗舰店/专卖店，四项全过才能上架。
4. 每年工商变更后复查经营范围。

**代价/风险**：证件本身有效但**类别对不上**（拿二类证卖三类品）是最隐蔽的错，台账要记"覆盖产品范围"一列，不只记有效期。

## 大促前全店审查

**何时用**：大促前 7 天；任何新活动会场素材上线前。

**怎么做**：
1. **范围**：全店在架链接 + 活动会场页 + 活动主图 + 直播脚本 + 客服快捷回复 + 赠品说明。
2. **顺序**：先资质与标签（能不能卖），再文案词表（怎么写），最后话术（谁在说）。
3. 会场素材最容易漏——它是临时的、活动专属的，常常绕过日常文案流程。**会场素材必须走同一份词表**。
4. 2026 活动周期拉长至 1.5 个月、双十一提前至 10 月上旬、618 预计 5 月上旬 → **审查窗口覆盖整个活动期**，不是只审上架当天。

**代价/风险**：大促期间文案改得最频繁（追热点、改卖点、加活动话术），**改一次就要复扫一次**，不能只在开卖前扫一遍。

## 24 小时违规响应

**何时用**：收到平台违规通知、被投诉、或自查发现已发布违规内容的当下。

**怎么做**：
1. **先下架**（争议内容先止损，风险敞口不挂着）。
2. **再申辩**（有凭据的用凭据，无凭据的不硬扛）。
3. **再整改**（全店同类排查，不是只改这一处）。
4. **记录**：下架时间 / 申辩提交时间 / 整改内容 / 涉及链接清单。
5. 24 小时内完成三件事，超时本身就是二次违规。

**代价/风险**：下架会影响在售与发货——**下单量大的商品要同时准备库存与履约预案**。C 类（封店）情形下，24 小时内还要准备发货中断的应对方案。

## 未验证条目登记法

**何时用**：素材有缺口、或规则出现多个口径时。

**怎么做**：
1. 单开一节"⚠️ 口径冲突，需复核"，把各版本的数字、后果、出处并排列出，**不选边**。
2. 素材完全没覆盖的（如某些新规则），标注"素材未覆盖"并写清检索范围。
3. 落地前以**当期平台公告**为唯一定案口径；内部管理按**最严口径**设内控线。
4. 补齐后回填出处与生效时间，并把登记项从"待复核"转为"已确认"。

**代价/风险**：登记项长期挂着会被当成结论用。**内部管理一律按最严线执行**（如体验分按 4.6 卡），这样无论最终哪条口径成立都不会翻车。
