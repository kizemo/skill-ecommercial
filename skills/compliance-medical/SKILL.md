# 医疗器械合规红线

**来源**：`taobao-operation` 知识库（GBRain source `taobao-operation`，2013 页）｜**版本**：2026.10｜**层级**：L2 域层

**一句话**：医疗器械在天猫/淘宝上架、宣传、销售必须遵守的法规和平台规则总称，涵盖资质 / 广告法 / 标签 / 经营许可 / 电商平台规则多个维度。**是医疗器械电商的生死线。**

本 skill 回答四件事：**① 我家店该拿什么证？② 哪些词一个字都不能写？③ 会被罚到什么程度？④ 每周/大促前怎么巡检？**

> **最重要的一句话**：合规是生死线——**任何动作前先过合规审查**。文案、主图、客服话术、直播话术四类载体，一个都不豁免。

---

## 一、资质三类分级（先确定你的产品在哪个类目）

| 类目 | 资质要求 | 举例 | 平台要求 |
|---|---|---|---|
| **一类** | **备案凭证**（地市级药监局） | 创可贴、纱布、医用冷敷贴、棉签 | 营业执照 + 商标注册证 |
| **二类** | **注册证**（省级药监局）+ **备案** | 血糖仪、血压计、家用雾化器、轮椅、护腰带 | 医疗器械经营备案凭证 + 注册证 + 营业执照 |
| **三类** | **注册证**（国家药监局）+ **经营许可** | 制氧机、医用敷料（部分）、植入器械 | 医疗器械经营许可证 + 注册证 + 营业执照 |

**天猫平台资质（三项，缺一不可）**：

1. **医疗器械经营许可证 / 备案凭证**
2. **营业执照**（**经营范围含医疗器械**）
3. **商标注册证**（R 标 / TM 标）

> 一类只需备案凭证、不用注册证；三类必须持经营许可证才能上架。**上错类目比文案违规更致命**——证不够，链接直接上不了。

## 二、禁用词 50+ 分 5 组（**完整词表见 cheatsheet.md**）

广告法禁用词按五组管理，**扫描文案时逐组过，不要只查"绝对化"那一组**——实际事故里最贵的往往是第 2、3 组。

| 组 | 条目数 | 性质 | 代表词 |
|---|---|---|---|
| **一、绝对化用语** | 10 | 100% 违规 | 最 / 最佳 / 最好 / 第一 / 唯一 / 顶级 / 顶尖 / 极致 / 国家级 / 世界级 |
| **二、医疗效果承诺** | 标 15、实列 14 | 100% 违规 | 治愈率 / 根治 / 彻底治愈 / 永不复发 / 有效率 100% / 立即见效 / 药到病除 / 100% 起效 / 无效退款（医疗类）/ 替代药物治疗 / 替代手术 / 替代医生诊断 / 经临床验证（无依据时）/ 医院同款（无授权时） |
| **三、功效夸大** | 标 15、实列 14 | 100% 违规 | 治疗 / 预防 / 根治 / 治愈（仅二类可称"辅助治疗"）/ 减肥 / 增高 / 丰胸 / 美容 / 抗衰老 / 延寿 / 提高免疫力 / 增强体质 / 改善睡眠 / 缓解疼痛（需明确适应症） |
| **四、安全性虚假承诺** | 标 10+、实列 12 | 100% 违规 | 无副作用 / 绝对安全 / 100% 安全 / 零风险 / 零刺激 / 纯天然 / 0 添加 / 0 防腐剂 / 不含任何有害物质 / 通过 FDA / CE / 权威认证（无授权时） |
| **五、其他** | 标 10+、实列 14 | 违规 | 祖传 / 秘方 / 神器 / 神效 / 立竿见影 / 专家推荐 / 院士研发 / 博士团队 / 包治百病 / 一次断根 / 永不复发 / 销量第一 / 好评率第一 / 复购率第一（无数据证明） |

**按原文逐条清点合计 64 个条目**（"根治""治愈""永不复发"跨组重复，去重后 **61** 个；原文标题写"50+ 词长表"）。第 1-4 组标 100% 违规，第 5 组标违规。

**扫描用**：把 `cheatsheet.md` 的禁用词全表（含可复制的纯文本段）整段粘进扫描工具，逐条扫**详情页文案 + 主图文字 + SKU 标题 + 客服话术 + 直播话术 + 评价内容**。

> 三组原文内部计数有出入：第 2、3 组标"15 个"实列 14 条。**以词条本身为准**，不要按组标题数字裁剪词表。

## 三、标签强制标注 7 项（**缺一项即违规**）

```
1. 注册证编号 / 备案编号
2. 生产企业名称 + 地址
3. 产品名称 + 规格
4. 禁忌症（必须列）
5. 不良反应（必须列）
6. 使用说明 / 储存条件
7. 生产日期 / 有效期
```

**第 4、5 项是医械区别于普通电器的核心**：普通商品详情页可以不写这两项，医械写了才算合规；反过来，**客服答不出禁忌症与不良反应，就是违规**（见 §四）。

---

## 四、天猫医疗器械类目规则（4 条）

1. 店铺需为「**医疗器械旗舰店**」或「**专卖店**」
2. **详情页必须展示「医疗器械注册证」**
3. **客服咨询禁忌症/副作用需 100% 准确**
4. **不允许私下交易**（**引导加微信 / 转线下 = 严重违规**）

> 第 4 条最容易被当成"小事"：一句"加个微信发说明书"就是严重违规。第 3 条是**客服 100% 准确率**要求，不是"尽量准确"。

## 五、违规处罚 4 级

| 级别 | 触发条件 | 后果 |
|---|---|---|
| **A 类（轻）** | 单条违规词 | **商品下架 + 扣 2-6 分** |
| **B 类（中）** | 多次违规 / 严重词 | **扣 6-12 分 + 罚款 5-20 万** |
| **C 类（重）** | 医疗效果承诺 / 多次 B 类 | **封店 + 罚款 20-100 万** |
| **D 类（重罪）** | 重大医疗事故 | **刑事责任 + 永久禁业** |

**风险提示**：医疗器械违规处罚 = 扣分 6-12 分 / 封店 / 罚款 5-20 万 / 刑事责任（视情节）。

**分级的实用读法**：**单词 = 下架扣分**（可承受）；**反复 = 罚款**（不可承受）；**碰到医疗效果承诺 = 直接封店**（C 类）。所以第 2 组"医疗效果承诺"是绝对红线，**一次都不能碰**。

## 六、5 个真实违规案例

| 案例 | 违规内容 | 处罚 | 教训 |
|---|---|---|---|
| **案例 1：血糖仪「治愈糖尿病」** | 绝对化用语 + 医疗效果承诺 | **扣 12 分 + 封店** | 医疗承诺 = 立即封店 |
| **案例 2：制氧机「100% 安全无副作用」** | 安全性虚假承诺 | **扣 6 分 + 罚款 5 万** | 「100%」「无副作用」是雷区 |
| **案例 3：轮椅「医院同款」** | 无授权的品牌词 | **扣 6 分 + 商品下架** | 「医院同款」需授权 |
| **案例 4：医用敷料「无添加纯天然」** | 虚假宣传 | **扣 6 分 + 商品下架** | 「纯天然」「无添加」需检测报告 |
| **案例 5：雾化器直播「医生推荐」** | 虚假宣传 + 医疗承诺 | **扣 12 分 + 直播封禁** | **直播话术比详情页更严** |

**从案例能读出的三条规律**：

- 案例 1 和案例 5 都落在第 2 组（医疗效果承诺）→ 罚得最重，一个封店一个直播封禁。
- 案例 2、3、4 各只是**一个词**（「100% 安全」「医院同款」「无添加纯天然」）→ 就已经是扣 6 分 + 罚款/下架。**别以为一个词没事。**
- 案例 5 在直播里 → **直播是独立载体，直播封禁不影响详情页但照样扣 12 分**，不能因为"详情页没问题"就放过直播话术。

## 七、每周巡检 5 步 SOP

```
1. 每周一      专人 / AI 扫描全店文案（详情页 + 主图 + 客服话术）
2. 每周三      合规 review 会议（运营 + 客服 + 主播）
3. 每月 1 号   核对资质有效期（提前 30 天续期）
4. 大促前 7 天 全店文案合规审查
5. 重大违规 24h 响应：发现立即下架 + 申辩 + 整改
```

**每周扫描 Checklist（8 项）**：

- [ ] 资质：注册证 / 备案 / 经营许可证 在有效期
- [ ] 标签：注册证编号 + 生产企业 + 禁忌 + 不良反应
- [ ] 详情页：无「最 / 第一 / 唯一」等绝对化词
- [ ] 详情页：无「治愈 / 根治 / 无副作用」等违规词
- [ ] 主图：未放绝对化词 / 医疗效果承诺
- [ ] 客服话术：禁忌症 / 副作用问题答案 100% 准确
- [ ] 直播话术：禁说「100%」「立即见效」「医生推荐」
- [ ] 评价管理：定期 review，已出现的违规词引导客户删除

**第 5 步是硬时限**：24 小时内完成"下架 + 申辩 + 整改"三件事。**先下架再申辩**——挂着商品等申诉结果，风险敞口一直开着。

## 八、3 大高频踩雷点

1. **详情页绝对化词**（最 / 第一 / 唯一）—— 每周扫描
2. **客服禁忌症答错**（医疗器械 100% 准确）—— 话术库专人维护
3. **直播话术医疗承诺**（100% 起效 / 立即见效）—— 直播实时监控

**这三个的共性**：都是**载体级**问题——不是资质问题、不是价格问题，而是"话写在哪、谁在说"。所以巡检对象必须是**载体清单**（详情页 / 主图 / SKU 标题 / 客服 / 直播 / 评价），不是"店铺"。

## 九、2026 淘系四大规则变化（对医械店的影响）

| 侧 | 规则 | 医械店怎么受影响 |
|---|---|---|
| **价格侧** | **价格力 = 第一权重**（取代五星价格力）；活动报名自动对比全网同款/相似款价格，不达标直接踢 | 医械同款比价严重（血压计、血糖仪），价格力不达标 = 大促报名被踢 |
| **投入侧** | **商业化保费比强制**：广告花费占比不低于去年同期，否则消费券从"平台全资"降为"商家混资/全资"；**淘客佣金不计入商业化权重** | 医械投流成本高，医械店不能用淘客凑权重 |
| **评分侧** | **真实体验分一票否决**：店铺体验分 < 4.6 失搜索权重 + 无法报名大促；商品体验分 PXI < 70 流量负向、< 60 彻底断流 | 医械的退换货/售后体验直接影响评分，扣分与合规扣分叠加 |
| **活动侧** | **强活动化**：618 预计 5 月上旬，双十一提前至 10 月上旬，活动周期拉长至 1.5 个月；淘宝秒杀、超级立减、品牌新享常态化 | 活动窗口变长 → **合规审查窗口也变长**，不能只审大促当天 |

> ⚠️ **口径冲突（体验分阈值），需复核**：店铺体验分门槛在素材里有**两个口径**——
> - **口径 A（爆款三板斧-平台规则）**：店铺体验分 **< 4.6** → 失去搜索权重、无法报名大促；
> - **口径 B（运营方法论 stub「店铺评分红线」）**：店铺体验分 **< 4.2** → 无法报名官方活动。
>
> 两者**不是同一件事的口径重述，而是两条不同规则**（一条管搜索权重+大促，一条管官方活动报名），数值也不一致。**本 skill 不替用户选边，只登记**，落地前以当期平台公告为准。
>
> 另有一处相关但不同的数字：千牛 AI「行业洞察小助手」列出的推荐流量获取基础规则里写**店铺体验分 ≥ 4.3**（商品质量分 ≥ 60、价格力三星以上、主图 ≥ 4 张近 30 天有动销、支持七天无理由/包邮）。这是"拿推荐流量的门槛"，与上面两条规则不同维度，**一并登记复核**。

## 十二、使用说明

1. **先定类目，再谈文案**：三类可用表述范围不同（"辅助治疗"只有二类可称），类目定错后面全错。
2. **扫描是逐组过，不是查关键词**：第 2 组（医疗效果承诺）单独加一道人工过——它不靠字符串，靠语义。
3. **载体清单化管理**：详情页 / 主图 / SKU 标题 / 客服话术 / 直播话术 / 评价内容，六类载体各登记责任人。
4. **有依据的词才留**：第 3、4、5 组带"（无授权时）""（无检测报告时）""（无数据证明）"的词，有凭据就能用——所以要留档。
5. **输出物**：《禁用词扫描报告》＋《资质有效期台账》＋《客服禁忌症话术库》。

## Scope & Limits

- 本 skill **只适用于医疗器械类目**；消字号、化妆品、保健食品另有规则，不在覆盖范围。
- 禁用词表是知识库《医疗器械合规》笔记快照（2026-06），**不是《广告法》原文**；平台与监管口径会变，**引用前核对当期法规与平台类目规则**。
