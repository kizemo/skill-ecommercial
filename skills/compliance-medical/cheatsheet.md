## 2. 资质速查表

| 类目 | 监管层级 | 核心证件 | 举例 | 平台证件 |
|---|---|---|---|---|
| **一类** | 地市级药监局 | **备案凭证** | 创可贴、纱布、医用冷敷贴、棉签 | 营业执照 + 商标注册证 |
| **二类** | 省级药监局 | **注册证 + 备案** | 血糖仪、血压计、家用雾化器、轮椅、护腰带 | 经营备案凭证 + 注册证 + 营业执照 |
| **三类** | 国家药监局 | **注册证 + 经营许可** | 制氧机、医用敷料（部分）、植入器械 | 经营许可证 + 注册证 + 营业执照 |

**天猫三项平台资质**：① 医疗器械经营许可证 / 备案凭证　② 营业执照（**经营范围含医疗器械**）　③ 商标注册证（R 标 / TM 标）

**店铺类型**：必须是「医疗器械旗舰店」或「专卖店」。

## 3. 标签强制标注 7 项（缺一项即违规）

```
1. 注册证编号 / 备案编号

3. 产品名称 + 规格
4. 禁忌症（必须列）
5. 不良反应（必须列）
6. 使用说明 / 储存条件
7. 生产日期 / 有效期
```

## 4. 天猫类目规则 4 条

1. 店铺需为「医疗器械旗舰店」或「专卖店」
2. 详情页必须展示「医疗器械注册证」
3. **客服咨询禁忌症/副作用需 100% 准确**
4. **不允许私下交易（引导加微信 / 转线下 = 严重违规）**

## 5. 处罚 4 级

| 级别 | 触发条件 | 后果 |
|---|---|---|
| **A 类（轻）** | 单条违规词 | 商品下架 + 扣 2-6 分 |
| **B 类（中）** | 多次违规 / 严重词 | 扣 6-12 分 + 罚款 5-20 万 |
| **C 类（重）** | 医疗效果承诺 / 多次 B 类 | 封店 + 罚款 20-100 万 |
| **D 类（重罪）** | 重大医疗事故 | 刑事责任 + 永久禁业 |

**风险提示**：扣分 6-12 分 / 封店 / 罚款 5-20 万 / 刑事责任（视情节）。

| 案例 | 违规内容 | 处罚 | 教训 |

## 7. 每周巡检清单（8 项）

- [ ] 资质：注册证 / 备案 / 经营许可证 在有效期
- [ ] 标签：注册证编号 + 生产企业 + 禁忌 + 不良反应
- [ ] 详情页：无「最 / 第一 / 唯一」绝对化词
- [ ] 详情页：无「治愈 / 根治 / 无副作用」违规词
- [ ] 主图：未放绝对化词 / 医疗效果承诺
- [ ] 客服话术：禁忌症 / 副作用问题答案 100% 准确
- [ ] 直播话术：禁说「100%」「立即见效」「医生推荐」
- [ ] 评价管理：定期 review，已出现的违规词引导客户删除

**扫描载体（六类，别只扫详情页）**：详情页文案 ｜ 主图/副图文字 ｜ SKU 标题 ｜ 客服话术 ｜ 直播话术 ｜ 评价内容

## 10. 2026 四大规则变化速查

| 侧 | 规则 | 关键数字 / 后果 |
|---|---|---|
| **价格侧** | 价格力 = 第一权重（取代五星价格力）；活动报名自动对比全网同款/相似款价格 | 不达标直接被踢出活动 |
| **投入侧** | 商业化保费比强制 | 费比**不低于去年同期**，否则消费券从平台全资降为商家混资/全资；**淘客佣金不计入商业化权重** |
| **评分侧** | 真实体验分一票否决 | 店铺体验分 **< 4.6** 失搜索权重 + 无法报名大促；PXI **< 70** 流量负向、**< 60** 彻底断流 |
| **活动侧** | 强活动化 | 618 预计 5 月上旬；双十一提前至 10 月上旬；活动周期拉长至 **1.5 个月**；淘宝秒杀/超级立减/品牌新享常态化 |

## 11. ⚠️ 口径冲突登记（需复核，本表不选边）

| # | 冲突点 | 版本 A | 版本 B | 版本 C |
|---|---|---|---|---|
| 1 | **店铺体验分阈值** | **< 4.6** → 失搜索权重 + 无法报名大促（爆款三板斧-平台规则） | **< 4.2** → 无法报名官方活动（运营方法论 stub「店铺评分红线」） | **≥ 4.3** → 推荐流量获取基础规则门槛（千牛 AI 行业洞察） |

| 3 | 第 3 组词条数 | 组标题标 15 个 | 实列 14 条 | 以词条为准 |

**说明**：第 1 条的三处数字**不是同一规则的重述**——A 管搜索权重与大促报名、B 管官方活动报名、C 是拿推荐流量的门槛，属不同维度。

**处理原则**：以**当期平台公告**为唯一定案口径；内部管理**一律按最严线（4.6）设内控**，无论最终哪条口径成立都不翻车。
