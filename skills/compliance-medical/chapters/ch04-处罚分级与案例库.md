# 处罚分级与案例库

> 来源：医疗器械合规.md。

---

## 一、违规处罚 4 级

| 级别 | 触发条件 | 后果 |
|---|---|---|
| **A 类（轻）** | 单条违规词 | **商品下架 + 扣 2-6 分** |
| **B 类（中）** | 多次违规 / 严重词 | **扣 6-12 分 + 罚款 5-20 万** |
| **C 类（重）** | 医疗效果承诺 / 多次 B 类 | **封店 + 罚款 20-100 万** |
| **D 类（重罪）** | 重大医疗事故 | **刑事责任 + 永久禁业** |

**风险提示（原文）**：医疗器械违规处罚 = 扣分 6-12 分 / 封店 / 罚款 5-20 万 / 刑事责任（视情节）。

---

## 二、分级的三条读法

### 读法 1：单词 ≠ 没事

A 类是"单条违规词 → 下架 + 扣 2-6 分"，看起来轻。但案例 2、3、4 都只**一个词**：

- 制氧机「100% 安全无副作用」→ 扣 6 分 + **罚款 5 万**
- 轮椅「医院同款」→ 扣 6 分 + 商品下架
- 医用敷料「无添加纯天然」→ 扣 6 分 + 商品下架

**"一个词"和"多次"在后果上是量变到质变**：单词进 A 类，反复进 B 类（罚款）。

### 读法 2：医疗效果承诺 = 直接跳级

C 类的触发条件里有两条，**第一条就是"医疗效果承诺"**——它不要求"多次"。案例 1 血糖仪「治愈糖尿病」一句就 **扣 12 分 + 封店**。

**所以第 2 组（医疗效果承诺）必须单独立一条红线**：一次都不能碰，扫描时人工过。

### 读法 3：D 类不是"平台处罚"，是法律责任

D 类的触发条件是「**重大医疗事故**」→ 后果是**刑事责任 + 永久禁业**。

**这条的真正含义**：医械文案违规在情节严重时不止是平台内罚，而是可能触及法律责任。**售后纠纷处理不当 → 事故 → D 类**，这条链上运营也有责任，不只是文案的事。

## 三、5 个真实违规案例逐案拆解

### 案例 1：血糖仪「治愈糖尿病」

| 项 | 内容 |
|---|---|
| **违规内容** | 绝对化用语 + 医疗效果承诺 |
| **处罚** | **扣 12 分 + 封店** |
| **原文教训** | 医疗承诺 = 立即封店 |
| **落到哪一组** | 第 1 组 + 第 2 组（治愈） |
| **替代写法** | 血糖仪是**家用监测设备**，可以说"帮你记录血糖变化""数据可导出给医生参考"——**说设备做什么，不说它治什么** |

### 案例 2：制氧机「100% 安全无副作用」

| 项 | 内容 |
|---|---|
| **违规内容** | 安全性虚假承诺 |
| **处罚** | **扣 6 分 + 罚款 5 万** |
| **原文教训** | 「100%」「无副作用」是雷区 |
| **落到哪一组** | 第 4 组（无副作用 / 绝对安全 / 100% 安全） |
| **替代写法** | 按注册证载明的信息写适用范围与使用条件；**有检测报告支撑的部分才能写，且要留档** |

### 案例 3：轮椅「医院同款」

| 项 | 内容 |
|---|---|
| **违规内容** | 无授权的品牌词 |
| **处罚** | **扣 6 分 + 商品下架** |
| **原文教训** | 「医院同款」需授权 |
| **落到哪一组** | 第 2 组（医院同款：无授权时） |
| **替代写法** | 有授权就写授权主体与授权文件；没有就换成自家可证的属性（结构、材质、承重、认证） |

### 案例 4：医用敷料「无添加纯天然」

| 项 | 内容 |
|---|---|
| **违规内容** | 虚假宣传 |
| **处罚** | **扣 6 分 + 商品下架** |
| **原文教训** | 「纯天然」「无添加」需检测报告 |
| **落到哪一组** | 第 4 组（纯天然 / 0 添加） |
| **替代写法** | 成分与工艺按检测报告与注册证写；没有报告就不写"纯天然""无添加"这类总体性断言 |

### 案例 5：雾化器直播「医生推荐」

| 项 | 内容 |
|---|---|
| **违规内容** | 虚假宣传 + 医疗承诺 |
| **处罚** | **扣 12 分 + 直播封禁** |
| **原文教训** | **直播话术比详情页更严** |
| **落到哪一组** | 第 5 组（专家推荐 / 医生推荐：无身份证明）+ 第 2 组 |
| **替代写法** | 有真实合作医生身份证明时可表述并留档；否则不得借专业身份背书 |

## 四、5 个案例的横向规律

| 规律 | 证据 |
|---|---|
| **落第 2 组的罚最重** | 案例 1（封店）、案例 5（直播封禁 + 扣 12 分）都同时命中第 2 组 |
| **只写一个词也会出事** | 案例 2、3、4 各只是一个词 → 扣 6 分 + 罚款/下架 |
| **载体决定后果形态** | 详情页/商品 → 商品下架；直播 → 直播封禁；医疗承诺 → 整店封店 |
| **"同款/推荐/纯天然"都要凭据** | 案例 3（授权）、案例 4（检测报告）、案例 5（身份证明）——**无凭据即虚假宣传** |
| **合规与体验分叠加** | 扣分同时压店铺体验分（< 4.6 失搜索权重 + 无法报名大促），**合规问题会连带打掉流量与大促资格** |

---

## 五、代价换算（做决策用）

以 B 类区间为例：**扣 6-12 分 + 罚款 5-20 万**。对一个医械店：

- 罚款 5 万 ≈ 数个链接一月的净利；
- 扣 6-12 分 → 店铺体验分掉到 4.6 以下 → **失搜索权重 + 无法报名大促** → 流量与大促资格一起没。

**因此经济账的结论是**：一次 B 类违规的成本 ≫ 一次全店文案巡检的成本。**巡检不是成本中心，是止损措施。**

## 六、处置动作清单（按级别）

| 级别 | 立刻要做的 |
|---|---|
| A 类 | 下架该商品 → 改文案 → 复检 → 记录 |
| B 类 | 下架 + 全店同类词排查 + 准备申辩材料 + 罚款预案 |
| C 类 | 立即下架 + 24h 内响应（申辩 + 整改）＋ 店存与现金流预案（**封店意味着发货中断**） |
| D 类 | 立即下架 + 停止相关宣传 + 依法配合 + 保留全部证据 |

> 处置细节与 24h 响应流程见 ch05-巡检SOP与规则变化.md。
