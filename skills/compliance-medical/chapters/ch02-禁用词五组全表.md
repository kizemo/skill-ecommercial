# 禁用词五组全表

> 来源：医疗器械合规.md（源：Phase 4 P4-2 stub，2026-06-08）。
> **本 skill 的 cheatsheet.md 里有可直接复制去扫描的完整词表**；本章讲清每组词的性质、边界条件和扫法。

---

## 一、为什么分五组

禁用词不是一张无差别的黑名单，而是**按违法性质分组**的：

| 组 | 性质 | 违反的是 | 罚则倾向 |
|---|---|---|---|
| 一、绝对化用语 | 100% 违规 | 广告法绝对化用语 | A 类（下架 + 扣 2-6 分） |
| 二、医疗效果承诺 | 100% 违规 | 医疗器械不得承诺疗效 | **C 类（封店）** |
| 三、功效夸大 | 100% 违规 | 超出注册证载明适用范围 | A → B 类 |
| 四、安全性虚假承诺 | 100% 违规 | 安全性绝对化 | B 类（罚款 5-20 万） |
| 五、其他 | 违规 | 虚假宣传、无依据背书 | A → B 类 |

**分组的实用价值**：第 2 组是**绝对红线**（案例 1 血糖仪"治愈糖尿病"→ 扣 12 分 + 封店），要单独加一道人工过；第 3、4、5 组里带"（无依据时）""（无授权时）""（无数据证明）"的词属于**有条件可用**——条件成立就能用，所以要留档。

## 二、逐组拆解

### 第 1 组 · 绝对化用语（原文标 10 个）

```
最 / 最佳 / 最好 / 第一 / 唯一 / 顶级 / 顶尖 / 极致 / 国家级 / 世界级
```

**边界**：

- "最"是**单字命中**，扫描时要注意"最大功率""最新款"这类技术描述也会命中——**"最大功率"是合法的参数表述，"行业最大功率"不是**。所以第 1 组不能只做字符串替换，要人工过一遍上下文。
- "第一"同理："本店 3000-4000 元价位成交额第一名"（带定语限定）属于**有依据的限定性表述**，但"全网第一"直接违规。

### 第 2 组 · 医疗效果承诺（原文标 15 个，实列 14 条）

```
治愈率 / 根治 / 彻底治愈 / 永不复发 / 有效率 100% / 立即见效 / 药到病除
100% 起效 / 无效退款（医疗类）/ 替代药物治疗 / 替代手术 / 替代医生诊断
经临床验证（无依据时）/ 医院同款（无授权时）
```

**逐条说明**：

| 词 | 说明 |
|---|---|
| 治愈率 / 根治 / 彻底治愈 | 直接承诺疗效，医械一律禁用 |
| 永不复发 | 既是疗效承诺也是绝对化，两个雷区叠加 |
| 有效率 100% / 100% 起效 | "100%" 单独就是第 4 组雷区 |
| 立即见效 | 直播话术第 3 大踩雷点之一 |
| 药到病除 | 药品语境的词，医械用同样违规 |
| 无效退款（医疗类） | 指向医疗效果的服务承诺 |
| 替代药物治疗 / 替代手术 / 替代医生诊断 | 越权宣称，性质最重 |
| 经临床验证（无依据时） | **有临床数据就能用**，无依据即违规 |
| 医院同款（无授权时） | **有医院/机构授权就能用**；案例 3 轮椅"医院同款"无授权 → 扣 6 分 + 下架 |

### 第 3 组 · 功效夸大（原文标 15 个，实列 14 条）

```
治疗 / 预防 / 根治 / 治愈（仅二类可声称"辅助治疗"）
减肥 / 增高 / 丰胸 / 美容（医疗器械禁忌）
抗衰老 / 延寿 / 提高免疫力 / 增强体质（无依据时）
改善睡眠 / 缓解疼痛（医疗器械需明确适应症）
```

**边界**：

- **二类**可以声称"**辅助治疗**"，但不能声称"治疗"本身。一类、三类没有这项例外。
- 减肥 / 增高 / 丰胸 / 美容 是**医疗器械禁忌领域**——即使产品有相关物理结构也不能提。
- 改善睡眠 / 缓解疼痛：必须落在**注册证载明的适应症**范围内，写进详情页前先翻注册证。

### 第 4 组 · 安全性虚假承诺（原文标 10+ 个）

```
无副作用 / 绝对安全 / 100% 安全 / 零风险 / 零刺激
纯天然 / 0 添加 / 0 防腐剂（无依据时）
不含任何有害物质（无检测报告时）
通过 FDA / CE / 权威认证（无授权时）
```

**说明**：

- 案例 2（制氧机「100% 安全无副作用」）——两个词都在这组 → **扣 6 分 + 罚款 5 万**。
- 案例 4（医用敷料「无添加纯天然」）→ **扣 6 分 + 商品下架**，原文教训是"「纯天然」「无添加」需检测报告"。
- "通过 FDA / CE / 权威认证"：**有授权就能写**，没有就是虚假宣传。医疗器械领域这一组特别容易被同行蹭品牌词。

### 第 5 组 · 其他（原文标 10+ 个）

```
祖传 / 秘方 / 神器 / 神效 / 立竿见影
专家推荐 / 院士研发 / 博士团队（无身份证明）
包治百病 / 一次断根 / 永不复发
销量第一 / 好评率第一 / 复购率第一（无数据证明）
```

**说明**：

- "祖传 / 秘方 / 神器 / 神效"是**伪科学背书**，直接违规。
- "专家推荐 / 院士研发 / 博士团队"需**身份证明**；案例 5 雾化器直播"医生推荐"无据 → **扣 12 分 + 直播封禁**。
- "销量第一 / 好评率第一 / 复购率第一"需**数据证明**。**数据必须留档**（截图 + 时间 + 口径），否则等于没证明。

## 四、扫描执行

### 4.1 扫描对象（六类载体）

| 载体 | 谁负责 | 频率 |
|---|---|---|
| 详情页文案 | 运营 | 每周 |
| 主图 / 副图文字 | 运营 / 设计 | 每周 |
| SKU 标题 | 运营 | 每周 |
| 客服话术 | 客服 | 每周 + 话术库版本管控 |
| 直播话术 | 主播 | 实时监控 + 每场后复盘 |
| 评价内容 | 运营 | 定期 review |

> **载体漏了最贵的**：案例 5 出在直播里，案例 3/4 出在商品标题/详情页。**六个载体要并列管理，不能只扫详情页。**

### 4.2 三种命中情形的处置

| 情形 | 处置 |
|---|---|
| 明确违规（最 / 第一 / 治愈 / 根治 / 无副作用 / 100%） | **立即改**，不等复盘 |
| 条件性词（经临床验证 / 医院同款 / 纯天然 / 销量第一） | 查档：有依据 → 留档放行；无依据 → 立即改 |
| 技术参数命中（最大功率 / 最小噪音） | **人工过上下文**，确认为参数描述的放行，登记为"假阳性" |

### 4.3 扫描顺序

```
1. 第 2 组 单独人工过一遍（医疗效果承诺 = 封店级）
2. 第 1、4 组机器扫 + 人工过（绝对化与安全性，最容易出现在主图和标题里）
3. 第 3 组 机器扫 + 对照注册证适应症人工过
4. 第 5 组 机器扫 + 查档（专家/院士/销量第一类）
```
