## 一、三类医疗器械的资质对照

医疗器械按风险程度分三类，**类目决定你手里必须有什么证**。上错类目比文案违规更致命——证不够，链接直接上不了。

### 1. 一类医疗器械

- **资质**：**备案凭证**（**地市级药监局**）
- **举例**：创可贴、纱布、医用冷敷贴、棉签
- **平台要求**：**营业执照 + 商标注册证**

> 一类**不需要注册证**，只有备案凭证。这是三类里门槛最低的，但也意味着一类商家最容易误用"治疗/预防"这类词——因为产品本身确实跟"医用"沾边，越想强调医疗属性越容易踩第 3 组。

### 2. 二类医疗器械

- **资质**：**注册证**（**省级药监局**）+ **备案**
- **举例**：血糖仪、血压计、家用雾化器、轮椅、护腰带
- **平台要求**：**医疗器械经营备案凭证 + 注册证 + 营业执照**

> 二类是医械电商的**主力类目**（血压计、血糖仪、雾化器、轮椅全在这一类）。二类有一条特殊表述许可：**可以声称"辅助治疗"**，但不能声称"治疗"本身。

### 3. 三类医疗器械

- **资质**：**注册证**（**国家药监局**）+ **经营许可**
- **举例**：制氧机、医用敷料（**部分**）、植入器械
- **平台要求**：**医疗器械经营许可证 + 注册证 + 营业执照**

> 三类多一道**经营许可**（不是备案）。制氧机这一品类同时命中案例 2（「100% 安全无副作用」）和案例 5（雾化器直播「医生推荐」，雾化器为二类）——**三类品的合规风险集中在"安全性承诺"和"医疗承诺"两处**。

## 二、对比表（直接照着核对）

| | 一类 | 二类 | 三类 |
|---|---|---|---|
| **监管层级** | 地市级药监局 | 省级药监局 | 国家药监局 |
| **核心证件** | 备案凭证 | 注册证 + 备案 | 注册证 + 经营许可 |
| **举例** | 创可贴、纱布、医用冷敷贴、棉签 | 血糖仪、血压计、家用雾化器、轮椅、护腰带 | 制氧机、医用敷料（部分）、植入器械 |
| **平台证件** | 营业执照 + 商标注册证 | 经营备案凭证 + 注册证 + 营业执照 | 经营许可证 + 注册证 + 营业执照 |
| **可用表述注意** | 不得声称治疗/预防 | **可称"辅助治疗"** | 不得声称治疗/预防 |

## 三、天猫平台资质（三项，缺一不可）

- **医疗器械经营许可证 / 备案凭证**
- **营业执照**（**经营范围含医疗器械**）
- **商标注册证**（**R 标 / TM 标**）

> "经营范围含医疗器械"是最容易被忽略的一条：营业执照有公司，但经营范围里没写医疗器械，平台一样不给过。**每年工商变更后要复查经营范围**。

---

## 四、天猫店铺类型要求

- 店铺需为「**医疗器械旗舰店**」或「**专卖店**」

推论：

- **不要用普通专卖/专营店上架医械**，店铺类型本身就是准入项；
- 多店经营时，医械资质要**按店铺主体对应**，不能全店通用一个证；
- **类型错了，改文案也救不了**。

## 五、资质有效期管理

### 月度动作（每月 1 号）

```
核对资质有效期 → 提前 30 天续期
```

**三个必须核的日期**：

| 证件 | 关注点 |
|---|---|
| **注册证 / 备案凭证** | 有效期届满前 30 天启动续期（重新注册/备案） |
| **医疗器械经营许可证 / 备案凭证** | 同上；经营许可换证周期比注册证长，要更早排期 |
| **商标注册证** | R 标有效期届满前续展（TM 标无此问题） |

### 证件挂靠与原件

- 详情页必须展示「**医疗器械注册证**」→ 注册证编号要能对上实物
- 标签第 1 项就是「注册证编号 / 备案编号」，第 2 项是「**生产企业名称 + 地址**」——**注册证上的生产企业名与实际发货方必须一致**，不一致就是"货不对版"，会同时吃到退款率和合规两头的风险

## 六、为什么资质是第一优先级

```
资质不足 → 链接上不了 / 下架
        → 流量与活动资格同时归零
文案违规 → 扣分 → 扣分累积到一定程度 → 封店
```

两条路的终点一样（店开不下去），但**资质问题可以在上架前就发现，文案问题常常在流量起来之后才爆发**——那时已经投了钱、压了货。

**实践结论**：上架前把资质核完（类目对、证件齐、在有效期、经营范围含医疗器械、店铺类型对），再开始做主图和详情页。顺序反了，文案做得再好也上不了架。
