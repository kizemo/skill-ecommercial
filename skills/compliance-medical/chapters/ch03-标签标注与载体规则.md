## 一、标签强制标注 7 项（缺一项即违规）

医疗器械不是"贴个图就完了"，它的标签义务是**逐项强制**的：

| # | 标注项 | 说明 |
|---|---|---|
| 1 | **注册证编号 / 备案编号** | 一类写备案编号，二三类写注册证编号 |
| 2 | **生产企业名称 + 地址** | 与注册证上的生产企业一致 |
| 3 | **产品名称 + 规格** | 名称与规格型号要能被注册证对上 |
| 4 | **禁忌症**（必须列） | 缺失即违规 |
| 5 | **不良反应**（必须列） | 缺失即违规 |
| 6 | **使用说明 / 储存条件** | 使用方法 + 存放条件 |
| 7 | **生产日期 / 有效期** | 批次与效期 |

**为什么第 4、5 项是重点**：普通商品详情页可以不写这两项；**医械写了才算合规**。这一条在实操里是双向的——

- 详情页漏写禁忌症/不良反应 → 标签违规；
- 客服答不出这两项 → 触发"客服咨询禁忌症/副作用需 100% 准确"的类目规则违规。

**第 2、3 项与退款率联动**：注册证上的生产企业/规格与实际发货不一致 = "货不对版"，会同时吃到退款率上升和合规风险（案例 3、4 讲的都是"实际与宣称对不上"这一类）。

## 二、六类载体的具体规则

### 2.1 详情页

| 要求 | 原文依据 |
|---|---|
| **必须展示「医疗器械注册证」** | 天猫医疗器械类目规则 |
| 7 项标签齐全 | 标签强制标注 |
| **无绝对化词**（最 / 第一 / 唯一） | 每周扫描 Checklist |
| **无违规词**（治愈 / 根治 / 无副作用） | 每周扫描 Checklist |
| 功效表述不得超出注册证载明适应症 | 功效夸大组边界 |

**详情页还要做的一件事**：把注册证编号、生产企业名称、禁忌症、不良反应、使用说明/储存条件、生产日期/有效期**做成图或表放在用户会看到的位置**，而不是塞在第 20 屏。"标注了"不等于"标注到位"。

### 2.2 主图 / 副图

- **不得放绝对化词 / 医疗效果承诺**（原文 Checklist 明确列出）
- 主图是审核与用户第一眼信息，**风险高于详情页**——详情页可以靠长尾流量慢慢被看到，主图一挂上就被扫

### 2.3 SKU 标题

- SKU 标题属于商品信息，受同一套广告法约束
- 与详情页不同的点：SKU 标题常常是运营批量生成/复制来的，**一次违规会同时污染多个 SKU**——改的时候要整条链接一起改

### 2.4 客服话术

- **咨询禁忌症/副作用需 100% 准确**——不是"尽量准确"，是 100%
- 需要**专人维护话术库**：禁忌症与不良反应的标准答法定稿，客服不得自由发挥
- **不允许私下交易**：**引导加微信 / 转线下 = 严重违规**

**"转线下"的高频伪装形式**（都要拦）：

- "加个微信我发详细说明书给你"
- "私聊更便宜 / 微信下单有优惠"
- "我这边有个链接，不是平台的"

这三类话术的共同点是把交易或关键信息**移出平台监管范围**。一旦成立就是严重违规，不是扣分级别。

### 2.5 直播话术

- 禁止「100%」「立即见效」「医生推荐」等表述（原文 Checklist）
- **直播话术比详情页更严**（案例 5 教训原文）
- 实时性要求：主播临场发挥是最大漏洞，**需要实时监控 + 每场后复盘**

### 2.6 评价内容

- 定期 review
- **已出现的违规词引导客户删除**（原文 Checklist）
- 注意：评价里的违规词同样进平台扫描，**不处理会持续计分**

## 三、每周扫描 Checklist（8 项，原文）

- [ ] 资质：注册证 / 备案 / 经营许可证 在有效期
- [ ] 标签：注册证编号 + 生产企业 + 禁忌 + 不良反应
- [ ] 详情页：无「最 / 第一 / 唯一」绝对化词
- [ ] 详情页：无「治愈 / 根治 / 无副作用」违规词
- [ ] 主图：未放绝对化词 / 医疗效果承诺
- [ ] 客服话术：禁忌症 / 副作用问题答案 100% 准确
- [ ] 直播话术：禁说「100%」「立即见效」「医生推荐」
- ] 评价管理：定期 review，已出现的违规词引导客户删除

> 这 8 项是**载体 × 检查点**的交叉表——前 3 项是"底座"（资质与标签），中间 3 项是"文案载体"，后 2 项是"人"（客服、直播）。**人是最难标准化的一环，也是最容易出事的**（案例 5 就出在直播）。

## 四、AI 巡店能顶哪一段

千牛 AI 生意管家的 **AI 巡店（全店诊断）** 四大巡检模块：

| 模块 | 功能 | 与合规的关系 |
|---|---|---|
| 订单巡检 | 排查发货超时、物流异常 | 支撑动态体验分 |
| **商品巡检** | **排查标题违规词、库存、质量分** | **直接对应文案合规** |
| 推广巡检 | 对标同行推广数据 | — |
| **店铺巡检** | **排查体验分、违规记录** | **直接对应资质与处罚记录** |

**操作入口**：千牛 AI 版模式 → 全店诊断 → 执行巡检任务。

**使用节奏**：每日必巡（早上 5 分钟完成全店异常处理）｜大促期间每 4 小时巡检 1 次｜对 TOP3 爆款单独做专项巡检。

**边界（重要）**：AI 巡店能查**标题违规词**，但查不了：

- 第 2 组医疗效果承诺的**语义变体**（"让血糖稳下来"这种没有违禁字面的表述）
- 客服与直播的**实时话术**
- 有授权/检测报告的**条件性词**是否站得住

**所以 AI 巡店是第 1 道，不能是唯一一道。** 语义层与话术层仍需人工（详见 ch05）。
