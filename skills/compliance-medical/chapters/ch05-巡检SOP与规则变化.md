# 巡检 SOP 与 2026 规则变化

> 来源：医疗器械合规.md、b17-千牛ai生意管家运营实战指南.md、30-爆款三板斧-平台规则.md、CMP-2025平台规则变化下的突围1。

---

## 一、实操 SOP 5 步

```
1. 每周一      专人 / AI 扫描全店文案（详情页 + 主图 + 客服话术）
2. 每周三      合规 review 会议（运营 + 客服 + 主播）
3. 每月 1 号   核对资质有效期（提前 30 天续期）
4. 大促前 7 天 全店文案合规审查
5. 重大违规 24h 响应：发现立即下架 + 申辩 + 整改
```

### 逐步说明

**第 1 步 · 每周一全店扫描**

- 对象：详情页 + 主图 + 客服话术（原文列举的三处）；实践中要扩到 **SKU 标题、直播话术、评价内容**
- 方式：专人 / AI（千牛 AI 巡店的"商品巡检"可查标题违规词）
- **AI 能顶标题层，顶不了语义层与话术层**——第 2 组（医疗效果承诺）必须人工过一遍

**第 2 步 · 每周三合规 review 会议**

- 参会：运营 + 客服 + 主播（原文）
- 议题：本周扫描命中清单 + 处置结果 + 话术库更新 + 直播复盘
- **这 5 步里唯一能改"人"的一步**：客服与主播是活口，词表管得住文案，管不住嘴

**第 3 步 · 每月 1 号核资质有效期**

- 三个必核：注册证 / 备案 / 经营许可证
- **提前 30 天续期**——续期不是当天能办完的事，30 天是启动窗口

**第 4 步 · 大促前 7 天全店文案审查**

- 大促前是**新文案、新活动话术、新主图**集中上线的时候
- 配合 2026"强活动化"（活动周期拉长至 1.5 个月、双十一提前至 10 月上旬、618 预计 5 月上旬），**审查窗口也要覆盖整个活动期**，不能只审上架那天

**第 5 步 · 重大违规 24h 响应**

```
发现 → 立即下架 + 申辩 + 整改
```

**顺序不能换**：先下架，再申辩。挂着商品等申诉结果，风险敞口一直开着——而且"仍在展示"本身会继续被计入违规。

## 二、每周扫描 Checklist（8 项）

- [ ] 资质：注册证 / 备案 / 经营许可证 在有效期
- [ ] 标签：注册证编号 + 生产企业 + 禁忌 + 不良反应
- [ ] 详情页：无「最 / 第一 / 唯一」绝对化词
- [ ] 详情页：无「治愈 / 根治 / 无副作用」违规词
- [ ] 主图：未放绝对化词 / 医疗效果承诺
- [ ] 客服话术：禁忌症 / 副作用问题答案 100% 准确
- [ ] 直播话术：禁说「100%」「立即见效」「医生推荐」
- [ ] 评价管理：定期 review，已出现的违规词引导客户删除

> 原文另有"段总 4 家天猫店合规 Checklist（每周扫描）"这一标题——**这是多店医械经营者的版本**，说明巡检对象是"店"不是"链接"。

## 三、AI 巡店：能顶什么、顶不了什么

千牛 AI 生意管家 **AI 巡店** 四大模块与使用节奏：

| 模块 | 功能 | 合规相关性 |
|---|---|---|
| 订单巡检 | 发货超时、物流异常 | 支撑动态体验分 |
| **商品巡检** | **标题违规词、库存、质量分** | **直接对应文案合规** |
| 推广巡检 | 对标同行推广数据 | — |
| **店铺巡检** | **体验分、违规记录** | **直接对应处罚记录** |

**入口**：千牛 AI 版模式 → 全店诊断 → 执行巡检任务。

**节奏**：每日必巡（5 分钟）｜大促期间每 4 小时 1 次｜TOP3 爆款单独专项巡检。

**能顶**：标题层的字符串命中（绝对化词、明显违规词）。

**顶不了**：

| 场景 | 为什么 AI 顶不了 |
|---|---|
| 语义变体（"让血糖稳下来"不含违禁字面） | 需要理解语境 |
| 客服 / 直播实时话术 | 不在商品信息里 |
| 条件性词是否有授权/检测报告 | 这是**档案问题**，不是文本问题 |
| 禁忌症/不良反应答案是否 100% 准确 | 靠话术库版本管控，不靠扫描 |

**结论**：AI 巡店是**第 1 道**，每周 SOP 里的**第 2 步 review 会议与话术库**才是第 2 道。少一道就漏。

## 四、3 大高频踩雷点

1. **详情页绝对化词**（最 / 第一 / 唯一）—— 每周扫描
2. **客服禁忌症答错**（医疗器械 100% 准确）—— 话术库专人维护
3. **直播话术医疗承诺**（100% 起效 / 立即见效）—— 直播实时监控

**三个踩雷点的共性**：都是**载体级**问题。资质、价格、活动都不出错，但载体上的一句话就能把前面的努力清零。

| 踩雷点 | 防线 | 责任人 |
|---|---|---|
| 详情页绝对化词 | 机器扫 + 人工过 | 运营（每周一） |
| 客服禁忌症答错 | 话术库专人维护 + 版本管控 | 客服（每周三 review） |
| 直播话术医疗承诺 | 实时监控 + 每场复盘 | 主播（每周三 review） |

## 五、2026 淘系四大规则变化

> 来源：30-爆款三板斧-平台规则.md。2026 年淘系平台规则围绕**价格力、商业化、用户体验、活动化**四大维度重构。

### 5.1 价格侧：价格力 = 第一权重

| 变化 | 说明 |
|---|---|
| 取代五星价格力 | 成为平台流量分配核心指标 |
| 比价机制 | 活动报名自动对比全网同款 / 相似款价格 |
| 消费券分级 | 根据营销投入、价格力、体验分划分 |

**后果**：价格不达标直接被踢出活动。

**对医械店**：血压计、血糖仪、雾化器是**同款比价最激烈**的类目。价格力不达标 = 大促报名被踢；而医械店的自然流量又高度依赖大促（活动周期 1.5 个月），**被踢一次等于整个活动期没有活动流量**。

### 5.2 投入侧：商业化保费比强制要求

| 要点 | 说明 |
|---|---|
| 天猫权重 > 淘宝 | 扣点更高，权重天然更高 |
| **费比强制要求** | **广告花费占比不低于去年同期** |
| 费比不达标后果 | 消费券从"平台全资"降为"商家混资/全资" |

**⚠️ 淘客无效**：**淘客佣金不计入商业化权重**，无法提升店铺权重。

**对医械店**：医械类目竞争加剧、推广费用上升（来自斩杀线笔记对医械的判断）。想靠淘客凑费比是行不通的——淘客佣金不进商业化权重。

### 5.3 评分侧：真实体验分 = 一票否决权

| 评分 | 阈值 | 后果 |
|---|---|---|
| 店铺体验分 | < 4.6 分 | 失去搜索权重、无法报名大促 |
| 商品体验分 PXI | < 70 分 | 流量负向影响 |
| 商品体验分 PXI | < 60 分 | **彻底断流** |

**对医械店**：合规违规扣分 + 售后体验差 = **双重压分**。合规问题不只是罚款，还会连带打掉搜索权重和大促资格。

### 5.4 活动侧：强活动化

| 变化 | 说明 |
|---|---|
| 大促前置 | **618 预计 5 月上旬，双十一提前至 10 月上旬** |
| 活动周期 | **拉长至 1.5 个月** |
| 日常活动 | 淘宝秒杀、超级立减、品牌新享常态化 |

**运营逻辑**：全年以"活动备战"为核心。

**对医械店**：**合规审查窗口必须跟着活动周期一起拉长**。活动期 1.5 个月，期间所有新增文案、直播话术、活动会场素材都要进入巡检范围。

## 六、⚠️ 口径冲突登记：店铺体验分阈值

素材中店铺体验分门槛有**三个不同的数字**，分别来自不同规则：

| # | 阈值 | 后果 | 出处 |
|---|---|---|---|
| **A** | **< 4.6** | 失搜索权重 + 无法报名大促 | 30-爆款三板斧-平台规则.md |
| **B** | **< 4.2** | 无法报名官方活动 | 运营方法论 stub「店铺评分红线」 |
| **C** | **≥ 4.3** | 达不到则不满足推荐流量获取基础规则（另需商品质量分 ≥ 60、价格力三星以上、主图 ≥ 4 张近 30 天有动销、支持七天无理由/包邮） | b17-千牛ai生意管家运营实战指南.md（行业洞察小助手） |

**判断**：A 与 B **不是同一规则的口径重述**——A 管的是"搜索权重 + 大促报名"，B 管的是"官方活动报名"；C 是"拿推荐流量的门槛"，又是第三个维度。三条规则的适用面不同，数值也不一致。

**处理原则**：

- **口径冲突，需复核**，本 skill 不替用户选边；
- 落地时**以当期平台公告为准**（这是唯一能定案的口径）；
- 内部管理可按**最严口径（4.6）**设内控线——用最高标准卡自己，永远不会因为选了另一条规则而翻车。
