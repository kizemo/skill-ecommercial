# 可复用方法 · profit-model

> 每条格式：`## 方法名` + `**何时用**` + `**怎么做**` + `**代价/风险**`

---

## 口径对齐法（算账第一步）

**何时用**：任何一次算账之前；尤其是"我看到的数和老板看到的不一样"的时候。

**怎么做**：
1. 确认 **投产** 是推广投产还是总投产。
2. 确认 **销售额** 含不含退款（用"去退销售额"还是"支付金额"）。
3. 确认时间窗（近 30 天还是近 7 天）、是否同一批次活动。
4. 确认 **毛利率** 是账面毛利率还是扣完平台扣点后的净毛利率。
5. 把这四条写在报表表头，所有人按同一口径看。

**代价/风险**：多花十分钟，但省掉的是"结论反转"。知识库里"投产假好"的多数案例，根因就是口径没对齐。

## 三层去伪法

**何时用**：投产好看但销售不涨、越投越贵、老板问"这个品到底赚不赚钱"。

**怎么做**：
```
第一层  推广投产 vs 总投产 → 差值大 = 免费流量占比高 = 产品力强
第二层  真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交
第三层  顺逆差 = 成交金额占比 − 推广花费占比；领先率 = 新客成交 ÷ 总成交
```
**判据**：真实投产 < 盈亏平衡 ROI → 不加预算；间接 = 直接 × 2 → 投放完全无效；领先率 < 50% → 在跑收割。

**代价/风险**："拉新成交"这个因子知识库只给了定义与案例，**没有给分档阈值**——落地必须自定口径（如"新客成交占总成交比例"，取与领先率同一数值），并写进口径表。

## 链接级利润表法

**何时用**：做月度复盘、决定一个链接的生死、回答"这条链接贡献了多少净利"。

**怎么做**：
1. 销售额（含退款/去退，两个数都留）
2. 减：成本 → 毛利 = 销售额 × 毛利率
3. 减：运营成本（人工/仓储物流/平台扣点/退款退货/办公杂费）
4. 减：推广费用 → 推广费用占比
5. 算三个基准：盈亏平衡 ROI、斩杀线、真实投产
6. 算两个效率：顺逆差、领先率
7. 写结论：加预算 / 维持 / 优化投放 / 降级 / 停投 / 清仓

**代价/风险**：人工成本和仓储物流通常只能算到店铺级，摊到单链接会有误差。**店铺级和链接级要分开算，别把店铺成本硬摊到单链接上然后据此停掉一条链接**——这是最危险的误判。

## 止损树（真实投产不达标时的动作）

**何时用**：一个链接连续两个周期真实投产不达标。

**怎么做**：
```
1. 是新品上线前两周吗？ → 是，正常，不止损
2. 间接成交 = 直接成交 × 2 吗？ → 是，投放完全无效，停投
3. 领先率 < 50% 吗？ → 是，停收割型定向（智能推荐/全站）后重测
4. 8 维度得分 < 6 吗？ → 是，产品层问题，先修产品
5. 都过了但真实投产仍不达标 → 降级（见 [[sabc-product-tiering]]）
```

**代价/风险**：顺序不能乱。先停投再查原因会失去诊断数据。**先做 3、4 步的诊断（只读不改），拿到结论再动预算。**

## 费用池算法（回答"这周能投多少"）

**何时用**：要定总推广预算时；或者老板要求"按利润分配预算"时。

**怎么做**：
1. 保底利润率阶梯：S 品 10% / A 品 15% / B 品 20% / C 品 25%
2. 超额利润 = 实际利润 − 保底利润
3. 全店可投费用池 = 所有产品超额利润汇总
4. 按等级预算比例切给各级

**代价/风险**：前提是保底阶梯与实际毛利结构匹配。耗材占比高的店（器械类目）S 品 10% 的保底偏松，费用池会虚高。**这套算法只覆盖 S/A/B 三级，没有 C 级保底口径。**

## 净利率分红法（团队激励设计）

**何时用**：定薪酬方案、解决"团队只会冲 GMV 不管利润"。

**怎么做**：
1. 分红基数定为**店铺净利率**（不是销售额、不是 GMV）。
2. 阶梯：< 10% 无分红；10-20% 分红 5%；20-30% 分红 10%；> 30% 分红 15-20%。
3. 岗位权重参考：运营店长 底薪 30% / 绩效 30% / 分红 40%（导向店铺净利率）；运营助理 50/30/20（链接动销率）；视觉设计 50/30/20（点击率提升）；客服 60/30/10（转化率+满意度）。

**代价/风险**：净利率低的任务做数据会有"洗澡"风险（压低投放、拉长账期）。**必须同时盯净利率绝对值和规模增长**，否则团队会走向另一个极端（不花钱也不赚钱）。3384 的三大目标顺序是：利润是底线、规模是路径、品牌是终局——不要只挂净利率。

---

## 五梯队矩阵设计法

**何时用**：从单爆款依赖要转成矩阵协同时；链接数少于 100、规模卡住时。

**怎么做**：
1. 按五梯队规划链接数：第一梯队 5-10、第二梯队 30-50、第三梯队 100-200、第四梯队 5-10、第五梯队 10-20。
2. 预算：40% / 30% / 30% / 不付费 / 不付费。
3. 每个角色定毛利率：利润款 ≥ 30%、引流款 15-20%、形象款 ≥ 40%、清仓款可低。
4. 配四源流量结构：付费 50-60% / 免费 20-30% / 内容 10-15% / 私域 5-10%。
5. 90 天三阶段推进：1-30 诊断标准化 → 31-60 跑 1-2 个核心爆款试跑 → 61-90 推广至全店。

**代价/风险**：第一梯队要求"利润与规模并重、ROI ≥ 4、单链接月销 ≥ 10 万"，链接数 5-10 个——**这是有体量门槛的，小店照抄会全盘卡在第一梯队**。链接数不足 100 时规模目标也要下调。

## 视觉调性统一法（提客单 + 降退货）

**何时用**：客单价上不去、退货率高、复购低时。

**怎么做**：
1. **主图统一**：第一张主图突出核心卖点，不是好看，是有效。
2. **详情统一**：前 3 屏解决"我是谁 / 我能给你什么 / 为什么选我"。
3. **店铺统一**：首页/分类页/活动页调性一致。
4. 测图配套：至少 3 张主图同测、2-3 天出结果、点击率 > 行业均值 1.2 倍为合格；每个创意至少 50 个点击；先看整体达标再选最优。

**代价/风险**：统一调性会牺牲部分链接的差异化表达。用"全店统一调性 + 单链接差异化"组合，而不是全店一模一样。**参考收益：客单价高 25-40%、退货率低 5-10%、复购率高 3-5 倍。**

---

## 定价倍数校准法

**何时用**：定新品定价、或要涨价/降价时。

**怎么做**：
1. 算定价倍数 = 售价 ÷ 成本。
2. 目标落在 **2-2.5 倍**（2 倍毛利 35%）。
3. 再叠加活动预留：最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1−扣佣比例)。
4. 核对最低价口径：百亿补贴/秒杀/跨店满减/直降计入；首单礼金/店铺优惠券/购物金/淘金币/超级立减/会员专享不计入。

**代价/风险**：3 倍时毛利只到 36.6%（比 2 倍只多 1.6 个点），但转化和人群会明显掉——**毛利率的提升在这个区间已经吃不到便宜了**。超过 2.5 倍要靠价值定价（品质、服务、视觉）而不是靠价。

## 真实投产去伪法（给老板做汇报）

**何时用**：对外/对上汇报业绩时；防止"报表很好看，年底一算亏钱"。

**怎么做**：
1. 拿看板投产，按 `真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交` 逐层扣。
2. 对比盈亏平衡 ROI（建议用扣退款率的严版）。
3. 把"看板口径"和"真实口径"两条线并列展示。
4. 给出真实投产低于盈亏平衡的链接清单与止损动作。

**代价/风险**：汇报口径一变，团队的历史 KPI 全部失效，可能引起抵触。**做法是加一条线而不是换一条线**：原有口径继续留，真实口径并排加，直到整个团队适应后再替换。

---

## 借壳复制法（换品复制成功结构）

**何时用**：要开新计划没把握；测试新品能否复制老品成功结构。

**怎么做**：
1. 挑历史跑得好的拉新/追投/收割计划各 3-5 个。
2. 复制换品，保持场景/出价/人群/创意不变。
3. 启动后观察 3-7 天。

**代价/风险**：历史计划是在旧价格、旧素材、旧人群下跑出来的。**观察期内不要提前下结论**，也不要在 3-7 天内改出价——改了就不是"复制"了，实验失去对照。
