# 盈利体系与算账

**来源**：`taobao-operation` 知识库（GBRain source `taobao-operation`）｜**版本**：2026.10｜**层级**：L1 体系层

本 skill 回答四件事：**① 这个链接/这个店到底赚不赚钱？② 投产漂亮是真的吗？③ 该投多少？④ 什么时候该停？**

**一切结论从三个公式起步**：
```
利润          = 销售额 × 毛利率 − 运营成本 − 推广费用
盈亏平衡 ROI  = 1 ÷ 毛利率
斩杀线        = 固定成本 ÷ (毛利率 − 推广费用占比)
```

货盘怎么分级看 [[sabc-product-tiering]]；钱花在哪没生效看 [[store-diagnosis]]；总纲看 [[taobao-ops-playbook]]。

## 一、利润基本公式：算账先扣哪些项

```
利润 = 销售额 × 毛利率 − 运营成本 − 推广费用
```

**运营成本必须包含**（漏一项利润就是虚的）：人工成本、仓储物流、平台扣点、退款退货、办公杂费。

**利润是终极目标，不是销售额。** 看到"销售额涨了"不能结束分析——要看这个涨是用多少推广费、多少退货换来的。

**两个不直接看 ROI 的配套公式**：
```
付费效率    = 人群资产增量 ÷ 付费消耗      （看人群资产沉淀，不看单次 ROI）
新品成功率  = 测款通过率 × 爆款转化率      （99% 的问题在选品测款）
```

---

## 二、盈亏平衡 ROI：低于这条线就是亏

```
盈亏平衡 ROI = 1 ÷ 毛利率
```

| 毛利率 | 盈亏平衡 ROI | 含义 |
|---|---|---|
| 60% | **1.67** | ROI > 1.67 才盈利（示例来自医疗器械类目） |
| 30% | **3.33** | ROI 必须过 3.33 |

**另一版本（更严）**：
```
盈亏平衡投产比 = 1 ÷ [毛利率 × (1 − 退款率)]
```
**口径冲突，需复核**：是否扣退款率，知识库两处写法不同。做实盘决策**用更严的那版**，因为它贴近"钱到底有没有回来"。

**推论**：全站推广设 ROI 目标时按毛利率反推——毛利率 30% → ROI 目标 ≥ 1:3（素材示例）。**注意 1:3 低于理论盈亏平衡 3.33**，差额来自没计运营成本，**口径冲突，需复核**：要不要把固定成本摊进去，取决于这家店的人工与仓储占比。

---

## 三、斩杀线：低于此线亏得撑不住

```
斩杀线 = 固定成本 ÷ (毛利率 − 推广费用占比)
```

**含义**：这是"每卖一单至少要达到的 ROI"。低于斩杀线，亏的不是毛利，是**固定成本收不回来**。

**三个改善方向**（知识库给的三条，方向互斥不可混用）：
1. 控制固定成本
2. 提升毛利率
3. 优化推广费用占比

> 知识库中"斩杀线"存在多个版本（汇总报告记录「斩杀线多版本」），本 skill 采用的是《淘系运营核心公式》公式9 的版本，**其余版本未验证**。

## 四、投产去伪：看板漂亮 ≠ 赚钱

### 4.1 第一层：推广投产 vs 总投产

| 指标 | 统计范围 | 意义 |
|---|---|---|
| **推广投产** | 仅付费流量成交 | 参考价值有限 |
| **总投产** | 免费 + 付费流量 | **真实效率** |

**差值意义**：差值越大，单品免费流量占比越高（产品竞争力越强）。

**这就是"投产假好"的第一层**：一个链接的推广投产很高、总投产很低，说明付费在花钱买本来就会来的流量。

### 4.2 第二层：真实投产（4.0 利润思维的去伪公式）

```
真实投产 = 投产 × (1 − 退款率) × (1 − 间接成交占比) × 拉新成交
```

四个因子各扣一层水分：
- **退款率** — 钱退回来了，不算收入
- **间接成交占比** — 用户点广告进来、又通过别的渠道成交，这单不该算广告的功劳
- **拉新成交** — 只认拉新成交，老客成交不是广告的增量

**真实案例**：投产 **6.8**、退款率 **15%** → 真实投产 **1**、费比 **100%**。看板上 6.8 的投产，实际是一笔不赚钱甚至倒亏的生意。

**配套判据（来自店铺诊断四层分析法）**：
- **间接成交 = 直接成交的 2 倍 → 该品投放完全无效**
- **领先率 = 新客成交 ÷ 总成交**：普通店 ≥ 80%、头部 KA ≥ 70%；**< 50% = 主要在跑收割、资源浪费**；**< 30% = 几乎全是老客在买**

**真实案例（诊断四层）**：某商品月花费 **8000 元**，投产"看起来很好"，但直接成交 **13 笔**、间接成交 **24 笔** → 财务反馈实际亏钱 → 结论：**该品不值得投放任何广告**。

### 4.3 第三层：顺逆差

```
顺逆差 = 单品成交金额占比 − 单品推广花费占比
```

| 结果 | 含义 | 行动 |
|---|---|---|
| **正向顺差** | 花小钱办大事 | **预算倾斜** |
| **负向顺差** | 花钱多产出少 | 优化或淘汰 |
| **零顺差** | 收支平衡 | 维持观察 |

**投产判断原则**（与顺逆差配合用）：
- 推广投产 **< 店铺均值** → **禁止盲目增加预算**
- 推广投产 **> 店铺均值** → 可适当增加预算
- 总投产持续下滑 → 检查产品竞争力

## 五、3384 利润公式：从爆款短命到品牌长青

**结构**："3"个核心目标 + "3"大核心能力 + "8"个核心模块 + "4"个核心保障 = **3384 利润公式**。

**核心原则**：利润是底线、规模是路径、品牌是终局。**三者顺序不能颠倒。**

### 5.1 三大核心目标（"3"）

| 目标 | 核心定义 | 关键指标 |
|---|---|---|
| **利润目标** | 摆脱高销量低利润的伪增长 | 净毛利率 **≥ 20%**，净利率 **≥ 10%** |
| **规模目标** | 摆脱单店单爆款的天花板 | 链接数 **≥ 100**，季度销售额增长率 **≥ 30%** |
| **品牌目标** | 摆脱"白牌无溢价"的标签 | 复购率 **≥ 15%**，品牌词搜索量增长 |

### 5.2 三大核心能力（"3"）

| 能力 | 核心定义 | 落地表现 |
|---|---|---|
| **全域获客能力** | 突破单一流量来源（直通车） | 付费 + 免费 + 内容 + 私域**四源齐发** |
| **全店动销能力** | 摆脱 20% 链接贡献 80% 销售额 | 全店动销率 **≥ 60%** |
| **品牌溢价能力** | 摆脱同质化价格战 | 客单价高于类目均价 **20%+** |

### 5.3 八个核心模块（"8"）

| # | 模块 | 核心动作 |
|---|---|---|
| 1 | **视觉体系** | 主图/详情/视频统一调性 |
| 2 | **客群体系** | RFM 分层 + 标签精准 |
| 3 | **产品体系** | 爆款群矩阵（核心/潜力/动销/形象）+ 5 梯队模型 |
| 4 | **流量体系** | 全域流量分配（付费/免费/内容/私域） |
| 5 | **转化体系** | 详情页逻辑 + SKU 排序 + 评价引导 |
| 6 | **服务体验** | 售前售后全链路标准化 |
| 7 | **团队激励** | 利润分红 + 爆款奖励 + 梯队培养 |
| 8 | **数据复盘** | 日/周/月复盘 + 看板监控 |

**落地工具与每模块动作细节**见 ch03。

### 5.4 四大核心保障（"4"）

1. **供应链保障**：爆款补货 7 天到位、动销品不断货、形象品精致化
2. **财务保障**：单链接/全店成本核算，**毛利与净利分开算**
3. **组织保障**：运营 + 视觉 + 客服三大岗位 SOP、店长责任制
4. **风险保障**：梯队动态调整、**低利润链接及时止损**

**落地建议**：先从 8 模块里选最弱的 2 个突破（如视觉 + 产品体系），跑通后再扩展。

## 六、爆款群矩阵：五梯队 × 四角色

### 6.1 五大梯队

| 梯队 | 定位 | 链接数 | 预算占比 | 核心指标 |
|---|---|---|---|---|
| **第一梯队** | 核心爆款 | 5-10 | **40%** | ROI ≥ 4，单链接月销 ≥ 10 万 |
| **第二梯队** | 潜力爆款 | 30-50 | **30%** | 上升期，30 天增长 30%+ |
| **第三梯队** | 动销款 | 100-200 | **30%** | 低费比引流，提升全店动销 |
| **第四梯队** | 形象款 | 5-10 | **不做付费** | 拉高店铺调性，提升客单价 |
| **第五梯队** | 清仓款 | 10-20 | **不做付费** | 清理库存，回收现金流 |

**两条硬原则**：
- 第一梯队要"**利润与规模并重**"，不能只追规模放弃利润。
- 第三梯队是"**全店动销率**"的核心贡献者，不能放弃。

### 6.2 四大角色毛利率

| 角色 | 毛利率 | 职责 |
|---|---|---|
| **利润款** | **≥ 30%** | 店铺利润核心 |
| **引流款** | **15-20%** | 带流量为主 |
| **形象款** | **≥ 40%** | 拉高店铺调性 |
| **清仓款** | 毛利率可低 | 回款为主 |

### 6.3 四源流量结构与分配

| 流量来源 | 占比目标 | 核心工具 | 成本 |
|---|---|---|---|
| **付费推广** | 50-60% | 直通车 + 万象台 + 全站推广 | 高 |
| **免费流量** | 20-30% | 搜索 + 首页 + 微详情 | 低 |
| **内容流量** | 10-15% | 逛逛 + 短视频 + 直播 | 中 |
| **私域流量** | 5-10% | 企微 + 社群 + 会员 | 极低 |

**核心公式**：**流量价值 = 流量精准度 × 转化率 × 客单价 × 复购率**，而不是"流量越大越好"。

各梯队（核心/潜力/动销/形象）具体流量结构见 ch03。

## 七、团队激励：利润分红的阶梯

**店铺净利率分红**：

| 店铺净利率 | 分红比例 |
|---|---|
| **< 10%** | **无分红** |
| 10-20% | **5%** |
| 20-30% | **10%** |
| **> 30%** | **15-20%** |

> 关键：分红必须基于**净利率**而非销售额，否则团队会盲目冲量不顾利润。
> 岗位权重参考（运营店长 分红 40%、运营助理 20%、视觉设计 20%、客服 10%）见 ch03。

## 八、什么时候该停（决策规则）

| 触发条件 | 动作 |
|---|---|
| **真实投产 < 盈亏平衡 ROI** | 不加预算；连续不达标则停投重测 |
| **间接成交 = 直接成交的 2 倍** | 该品投放完全无效 → **停投** |
| **领先率 < 50%** | 暂停该品或重新测试（< 30% = 几乎全是老客在买） |
| **顺逆差为负** | 优化或淘汰，不加预算 |
| **推广投产 < 店铺均值** | **禁止盲目增加预算**（不是必须停，是禁止加） |
| **总投产持续下滑** | 检查产品竞争力，不是先加钱 |
| **ROI 目标达不到且连续 2 个周期** | 转止损（风险保障：低利润链接及时止损） |
| **新品上线前两周投产 < 1** | **正常，不止损**——新品期投产本来就不到 1 |

**放量的纪律**：放量要循序渐进，**每次增幅 ≤ 50%**。超级短视频建议占整体推广预算的 **10-20%**，持续投放。

**该投多少**：级别决定总盘子（见 [[sabc-product-tiering]] 的预算占比表），链接内部按梯队流量结构分配，**预算决定流量圈层**——日预算 50 元只能买到老客，5000 元+ 才能买到全行业泛人群。

## 九、口径冲突登记（先看，再决策）

| # | 冲突点 | 版本 A | 版本 B |
|---|---|---|---|
| 1 | **盈亏平衡 ROI** | `1 ÷ 毛利率`（淘系运营核心公式） | `1 ÷ [毛利率 × (1−退款率)]`（七维产品布局） |
| 2 | **全站推广 ROI 目标示例** | 毛利率 30% → ROI ≥ 1:3（付费推广组合选择逻辑） | 理论盈亏平衡 1/0.3 = 3.33，未计运营成本 |
| 3 | **斩杀线** | `固定成本 ÷ (毛利率 − 推广费用占比)`（核心公式手册） | 知识库存在多版本，其余**未验证** |
| 4 | **3384 毛利率目标** | 通用：净毛利率 ≥ 20% | 医疗器械：25-35% |
| 5 | **推广 ROI 参考区间** | 直通车：标品 1:3~1:8、非标品 1:2~1:5 | 3384 第一梯队：ROI ≥ 4 |

**处理原则**：做实盘决策取**更严**的一版；引用数字时写明出自哪套口径。

## 十二、使用说明

1. **先确认口径**：`投产` 是推广投产还是总投产？`销售额` 是含退款还是去退？口径不清，算出来的数都是废的。
2. **四层去伪按顺序走**：推广投产 vs 总投产 → 真实投产 → 顺逆差 → 领先率。任何一层不过就别往下加预算。
3. **算账不替决策**：算账只给"超过/低于某条线"，决策还要看该链接是不是 S 级（战略品允许亏）。
4. **输出物**：一份《链接利润表》+ 一份《止损清单》。
5. **3384 是体系不是公式**：单店不用一次上齐 8 模块，素材自己建议"先挑最弱的 2 个突破"。

## Scope & Limits

- 本 skill 覆盖淘系（淘宝/天猫）店铺与链接的盈利核算。**京东/拼多多/抖音的算账口径不在知识库范围内**。
- 所有阈值来自知识库原文快照（2026 上半年口径）。**平台费比、类目均价、退款率会变，引用具体数字前先核对当期数据**。
- §9 列出的 5 项口径冲突**尚未在知识库内解决**，本 skill 不替用户选边。
- 「真实投产」公式中的**拉新成交**因子，知识库只给了定义与案例，**没有给分档阈值**，落地需自定口径。
- 「斩杀线」其余版本**未验证**（汇总报告记录知识库内存在多版本，本次素材只取到一版）。
- 单品怎么打爆看 [[hit-product-lifecycle]]；流量怎么买看 [[wanxiangtai-wujie]]；货盘怎么分看 [[sabc-product-tiering]]。
