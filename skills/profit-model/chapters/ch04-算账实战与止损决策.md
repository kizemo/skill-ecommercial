# ch04 · 算账实战与止损决策

> 用途：把前面的公式落到"这个链接今天该加钱、该停、还是该改价"。

---

## 一、真实案例数字（可直接当标杆背下来）

### 案例 1：投产 6.8，实际费比 100%

| 项 | 数值 |
|---|---|
| 看板投产 | **6.8** |
| 退款率 | **15%** |
| 真实投产 | **1** |
| 费比 | **100%** |

**结论**：看板上最漂亮的投产，去伪之后是倒挂。**费比 100% = 每卖一单，钱刚好打平，一分不赚。**

（来源：4.0 利润思维，2026-07-27 体系）

### 案例 2：月花费 8000 元的"好品"其实在亏

| 项 | 数值 |
|---|---|
| 月花费 | **8000 元** |
| 直接成交 | **13 笔** |
| 间接成交 | **24 笔** |

**结论**：间接 ≈ 直接的 2 倍 → 该品投放完全无效 → **不值得投放任何广告**。

（来源：店铺诊断四层分析法）

### 案例 3：砍掉两个收割型定向

| 项 | 数值 |
|---|---|
| 原有定向 | **4 个** |
| 停掉的收割型定向 | **2 个** |
| 每月节省广告费 | **4 万元** |
| 销售变化 | **无变化** |

**结论**：省下的广告费 = 直接的利润增加；不影响销售（本来就在收割老客）。

（来源：店铺诊断四层分析法）

### 案例 4：S 级引流的量化收益

| 项 | 数值 |
|---|---|
| S 级爆款日访客 | **10000** |
| 浏览其他产品比例 | **20%** |
| 后续收割转化 | **5%** |
| 整体转化率 | **2% → 3%** |
| 销售额提升 | **50%** |

**结论**：S 级的产出不在这条链接的利润上，在**全店转化率**上。

（来源：产品分级与全店矩阵运营）

### 案例 5：视觉调性统一的收益

| 项 | 数值 |
|---|---|
| 平均客单价 | **高 25-40%** |
| 退货率 | **低 5-10%** |
| 复购率 | **高 3-5 倍** |

（来源：电商功守道：3384 利润公式）

## 二、止损决策树

```
这个链接的投产好看，但我在犹豫要不要继续投
│
├─ ① 口径先对齐
│   ├─ 投产是推广投产还是总投产？
│   └─ 销售额含不含退款？
│
├─ ② 算真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交
│   ├─ 真实投产 ≥ 盈亏平衡 ROI → 进 ③
│   └─ 真实投产 < 盈亏平衡 ROI
│       ├─ 新品上线前两周？→ 正常，不止损
│       └─ 否 → 停投重测 / 降级（见 [[sabc-product-tiering]]）
│
├─ ③ 算顺逆差
│   ├─ 正向 → 加预算 / 升级候选
│   ├─ 零 → 维持观察
│   └─ 负向 → 优化投放结构或淘汰
│
├─ ④ 查领先率
│   ├─ ≥ 80% → 拉新正常，继续
│   ├─ 50-80% → 查定向与出价
│   └─ < 50% → 停掉收割型定向（智能推荐/全站）
│
├─ ⑤ 查直接/间接成交比
│   ├─ 间接 = 直接 × 2 → 投放完全无效 → 停
│   └─ 正常 → 进 ⑥
│
└─ ⑥ 看推广投产 vs 店铺均值
    ├─ < 店铺均值 → 禁止盲目增加预算
    └─ > 店铺均值 → 可适当增加预算（每次增幅 ≤ 50%）
```

## 三、该投多少

### 3.1 层级：预算决定流量圈层

| 日预算 | 主要人群 | 潜客占比 |
|---|---|---|
| **< 50 元** | 店铺老客 | < 50% |
| 200-500 元 | 老客 + 少量相似 | 50-60% |
| 1000-2000 元 | 广泛相似 + 行业 | 60-70% |
| **5000 元+** | 全行业泛人群 | > 70% |

**推论**：预算决定流量圈层，**预算是最核心的变量**。日预算 50 元只能买到老客——这时候追"拉新"是徒劳的，先加预算或先扩人群资产。

### 3.2 店铺内分配

全店预算按等级切（S/A/B/C），见 [[sabc-product-tiering]] 的预算占比表与三种口径冲突登记。

### 3.3 链接内分配：按梯队流量结构

核心爆款 付费 50% / 内容 30% / 私域 20%；潜力爆款 付费 60% / 免费 20% / 内容 20%；动销款 付费 40% / 免费 40% / 私域 20%；形象款 内容 50% / 私域 50%。

### 3.4 工具内的预算纪律

- **超级短视频**：占整体推广预算的 **10-20%**，持续投放；唯一有效出价是**最大化转化出价**；测试期多素材（5-10 条）、放量期单素材（1-2 条）集中；核心指标**潜客占比 60%-80% + 盈利性**。
- **全站推广**：**不要一次性全压**，分批次测试效果；实时监控 GSV 产出，超成本立即调整；新品期慎用。
- **放量节奏**：每次增幅 **≤ 50%**。

## 四、链接日销分层与 6 阶段投放

### 4.1 链接日销分层

| 层 | 日销 |
|---|---|
| 低层 | **0 - 1k** |
| 中层 | **1k - 1w** |
| 高层 | **1w+** |

不同日销层的链接配不同的计划结构与预算，不能用同一套模板打全部链接。

### 4.2 6 阶段投放体系

```
基础收割 → 标签收割 → 精准拉新 → 广泛拉新 → 广泛拉潜客 → 超级广泛拉潜客
```

这是 4.0 利润思维（2026-07-27）的投放阶段划分，与 [[wanxiangtai-wujie]] 的全域场域视角配合使用。

### 4.3 水滴计划 5 理论

| # | 理论 | 要点 |
|---|---|---|
| 1 | **通道原理** | 先确定流量通道，再谈人群与出价 |
| 2 | **多引擎原理** | 多种推广引擎协同而非单引擎硬扛 |
| 3 | **人群池容量** | 人群池有容量上限，耗尽要重建 |
| 4 | **链接矩阵** | 用链接矩阵承接流量，不靠单链接 |
| 5 | **时间拉长** | 连养 **7 日 / 14 日 / 30 日** |

### 4.4 标品 PPC 校准

| 客单价 | 盯什么 |
|---|---|
| **< 100 元** | 盯 **PPC**（客单低，投产指标不敏感） |
| **> 300 元** | 盯**投产**（客单高，投产是主信号） |

## 五、定价倍数的账

```
定价倍数 = 售价 ÷ 成本
```

| 倍数 | 毛利率 | 判断 |
|---|---|---|
| **2 倍** | **35%** | 最优区间起点 |
| **2.5 倍** | — | 最优区间上沿 |
| **3 倍** | **36.6%** | 毛利只多 1.6 个点，但转化损失大，不划算 |

**结论：定价倍数 2-2.5 倍最优。** 再往上抬价格，毛利增幅极小，而转化率和人群会明显掉——这正是"客单价高 25-40% 但退货率也高"的另一面。

## 六、定价预留空间

```
最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1 − 扣佣比例)
```

**最低价管控**：

| 计入最低价 | 不计入最低价 |
|---|---|
| 百亿补贴 / 秒杀 / 跨店满减 / 直降 | 首单礼金 / 新品礼金 / 店铺优惠券 / 购物金 / 淘金币 / 超级立减 / 会员专享 |

**为什么必须预留**：活动期降价、满减叠加会把实际成交价压到毛利线以下。**没预留活动空间的定价，大促一来就是亏本冲量。**

## 八、算账的三个陷阱

1. **把 S 级当利润款算** — S 级允许亏，它的产出是人群资产。给 S 级套盈亏平衡 ROI 会得出"该停"的错误结论。**S 级用"领先率 + 达摩盘回流"评估，不用 ROI 评估。**
2. **用店铺整体投产判断单品** — 整体漂亮但单品在亏。必须按花费排序看商品报表，逐品算。
3. **用默认归因算投产** — 每一次访问来源会重复计算，投产被高估。**必须切到第一次/最后一次访问来源验证。**
