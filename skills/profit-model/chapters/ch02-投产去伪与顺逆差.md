# ch02 · 投产去伪与顺逆差

> 用途：处理"投产很好看，但销售不涨 / 越投越贵"这一类问题。核心是把看板上的数一层层剥掉水分。

---

## 一、三层去伪

```
看板投产
  ↓ 第一层：分清推广投产 / 总投产
  ↓ 第二层：真实投产（扣退款率、间接成交、只认拉新）
  ↓ 第三层：顺逆差 + 领先率（判断在拉新还是在收割）
真实经营效率
```

---

## 二、第一层：推广投产 vs 总投产

| 指标 | 统计范围 | 意义 |
|---|---|---|
| **推广投产** | 仅付费流量成交 | 参考价值有限 |
| **总投产** | 免费 + 付费流量 | **真实效率** |

**差值意义**：差值越大，单品免费流量占比越高（产品竞争力越强）。

**为什么差值重要**：推广投产高、总投产低 = 花钱买来了本来也会来的流量。这种链接真正的问题不是 ROI 数字低，是**没有免费流量**——处理方式是修产品竞争力（视觉、SKU、评价），不是改出价。

**"投产好但销售下滑"的正解**：店铺整体数据漂亮掩盖了单品异常；按花费排序看商品报表，找投产好的品，再看它的直接/间接成交比。

---

## 三、第二层：真实投产（4.0 利润思维）

```
真实投产 = 投产 × (1 − 退款率) × (1 − 间接成交占比) × 拉新成交
```

**四个因子各扣一层**：

| 因子 | 扣掉的是什么 |
|---|---|
| **(1 − 退款率)** | 退回来的钱不算收入 |
| **(1 − 间接成交占比)** | 点广告进来又走别的渠道成交的单，不算广告功劳 |
| **拉新成交** | 只认拉新成交；老客成交不是广告的增量 |

### 3.1 真实案例

**投产 6.8、退款率 15% → 真实投产 1、费比 100%。**

**读法**：看板上 6.8 的投产（远超任何盈亏平衡 ROI），去伪之后只剩 1，费比 100%——**每卖一单倒贴**。这个链接看起来是"全店最赚钱的品"，实际上是"全店最亏钱的品"。

### 3.2 配套判据：直接成交 vs 间接成交

| 指标 | 含义 |
|---|---|
| **直接成交** | 用户通过广告直接点击后成交 |
| **间接成交** | 用户点击广告后，又通过其他渠道（如搜索）成交 |

| 判据 | 结论 |
|---|---|
| 间接成交 >> 直接成交 | 广告基本在跑收割，拉新无效 |
| **间接成交 = 直接成交的 2 倍** | **该品投放完全无效** |

**真实案例**：某商品月花费 **8000 元**，投产"看起来很好"，但直接成交 **13 笔**、间接成交 **24 笔** → 财务反馈该品实际亏钱 → 结论：**该品不值得投放任何广告**。

### 3.3 领先率（前比）

```
领先率 = 新客成交 ÷ 总成交
```

| 领先率 | 判定 | 动作 |
|---|---|---|
| **≥ 80%** | 普通店铺合格线 | 正常推进 |
| **70-80%** | 头部 KA 可接受区间（高基数难拉高） | 继续积累 |
| **50-70%** | 资源浪费在收割 | 查定向与出价 |
| **< 50%** | 主要在跑收割 | 停掉收割型定向 |
| **< 30%** | 几乎全是老客在买 | 拉新链路已断 |

**典型问题表现**：某商品花费排名前 5，但领先率只有 50% → 这个品主要在收割，不是在拉新 → 花的广告费只是让老客重复购买。

### 3.4 归因方式必须切

| 归因方式 | 用途 |
|---|---|
| 每一次访问来源（默认） | 容易重复计算，**不推荐** |
| **第一次访问来源** | 看拉新渠道：转化率高 = 主要拉新渠道 |
| **最后一次访问来源** | 看收割渠道：转化率高 = 主要在收割 |

```
第一次访问转化率 > 最后一次访问转化率 → 广告在跑拉新 ✓
最后一次访问转化率更高               → 广告主要在跑收割 ✗
```

## 四、第三层：顺逆差效率模型

```
顺逆差 = 单品成交金额占比 − 单品推广花费占比
```

| 结果 | 含义 | 行动 |
|---|---|---|
| **正向顺差** | 花小钱办大事 | **预算倾斜**（这是加预算的核心依据） |
| **负向顺差** | 花钱多产出少 | 优化或淘汰 |
| **零顺差** | 收支平衡 | 维持观察 |

### 4.1 执行步骤（五步）

1. **数据收集**：统计各单品成交金额、推广花费
2. **占比计算**：单品成交占比 vs 单品推广占比
3. **顺逆差分析**：判断效率方向
4. **预算调整**：倾斜正向顺差产品
5. **持续监控**：每周复盘数据

### 4.2 投产判断原则（与顺逆差并用）

| 情况 | 行动 |
|---|---|
| 推广投产 **< 店铺均值** | **禁止盲目增加预算** |
| 推广投产 **> 店铺均值** | 可适当增加预算 |
| 总投产持续下滑 | 检查产品竞争力 |

### 4.3 效率分析维度：新品看加购，老品看转化

| 维度 | 新品重点 | 老品重点 |
|---|---|---|
| 加购数据 | ✅ 高 | 参考 |
| 转化率 | 参考 | ✅ 高 |

---

## 五、把三层去伪和顺逆差拼成决策矩阵

| | 真实投产达标 | 真实投产不达标 |
|---|---|---|
| **顺逆差正向** | ✅ **加预算 / 升级候选** | ⚠️ 可能是免费流量在扛，查品类竞争力与产品力 |
| **顺逆差负向** | ⚠️ 投放结构有问题，先重构计划组合 | ⛔ **降级 / 停投** |
| **领先率 < 50%** | ⛔ 在收割老客，先清收割型定向 | ⛔ 停投 |
| **间接 = 直接 × 2** | ⛔ 投放完全无效，停 | ⛔ 停 |

---

## 六、顺逆差模型的三个限制

1. **顺逆差是相对指标**：只看单店内部对比。一家店所有链接顺逆差都为正，说明全店相对高效，但绝对值可能仍然亏——必须配合盈亏平衡 ROI。
2. **顺逆差不看时间**：一个品本月顺差、下月负差，月度平均会掩盖问题。做周度监控。
3. **占比的分母会变**：全店推广花费变化会改变所有链接的花费占比，导致"什么都没做，所有链接顺逆差都变了"。**比较时要固定口径（同一时间窗、同一去退规则）**。
