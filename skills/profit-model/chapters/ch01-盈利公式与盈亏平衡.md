# ch01 · 盈利公式与盈亏平衡

> 用途：把"这个链接赚不赚钱"拆成可计算的项，并定出 ROI 底线。

---

## 一、利润基本公式

```
利润 = 销售额 × 毛利率 − 运营成本 − 推广费用
```

**说明**：利润是终极目标，不是销售额。

**运营成本必须包含**（漏一项利润就是虚的）：

| 项 | 备注 |
|---|---|
| 人工成本 | 运营、客服、视觉 |
| 仓储物流 | 发货、快递、仓储 |
| 平台扣点 | 佣金 + 支付手续费 |
| 退款退货 | 退货产生的货损与运费 |
| 办公杂费 | 耗材、水电、软件订阅 |

**用法**：把每个链接的销售额、毛利率、运营成本、推广费用填进去，得出的才是这个链接的净贡献。**店铺级和链接级要分开算**（对应 3384 的财务保障：单链接/全店成本核算、毛利与净利分开算）。

---

## 二、盈亏平衡 ROI

```
盈亏平衡 ROI = 1 ÷ 毛利率
```

**说明**：ROI 高于盈亏平衡 ROI 才盈利。

| 毛利率 | 盈亏平衡 ROI |
|---|---|
| 60% | **1.67**（素材示例：医疗器械毛利率 60%） |
| 30% | **3.33** |

### 2.1 更严的一版：扣掉退款率

```
盈亏平衡投产比 = 1 ÷ [毛利率 × (1 − 退款率)]
```

**来源**：七维产品布局（词人图价货场营）的「价」维度。

**口径冲突，需复核**：知识库两处写法不同——核心公式手册的公式8 不扣退款率，七维产品布局扣退款率。

**裁决建议**：做实盘决策**用扣退款率的那版**，因为它对应"钱到底有没有回来"。但引用时必须写明是哪一版，别把两个数混着用。

### 2.2 全站推广的 ROI 目标反推

```
ROI 目标 = 根据毛利率反推可接受 ROI
```
**素材示例**：毛利率 30% → ROI 目标 ≥ **1:3**。

**口径冲突，需复核**：1:3 = 3.0，低于理论盈亏平衡 1/0.3 = **3.33**。差额来自**没把固定成本（人工、仓储、办公）摊进去**。这家人是不是该按 3.33 设目标，取决于固定成本占比。设 ROI 目标时必须明确"这是含运营成本的净 ROI 目标，还是只覆盖毛利"。

### 2.3 各工具的 ROI 参考区间

| 工具 | 品类 | ROI 参考 |
|---|---|---|
| **直通车** | 标品 | **1:3 ~ 1:8** |
| **直通车** | 非标品 | **1:2 ~ 1:5** |
| **全站推广** | 通用 | 按毛利率反推（示例：毛利率 30% → ≥1:3） |
| **超级短视频** | 所有品类 | 不看 ROI，看潜客占比（目标 60%-80%）+ 盈利性 |

**用法**：ROI 参考区间是**设目标时的起点**，不是考核线。真考核线永远是你自己的盈亏平衡 ROI。

## 三、斩杀线

```
斩杀线 = 固定成本 ÷ (毛利率 − 推广费用占比)
```

**说明**：低于斩杀线则亏损难以为继。

**含义拆解**：这是"每笔推广费至少要换回多少成交额"的底线。
- 分子是**固定成本**（人工、仓储、办公这些不随销量变的钱）
- 分母是**毛利率减去推广费用占比**——剩下的才是每单真正能拿去覆盖固定成本的部分
- 分母趋近 0 时斩杀线趋于无穷大 → **这类品投多少广告都是亏的，只能靠调价或提毛利救**

**三个改善方向**：
1. **控制固定成本** — 分母不变时，分子变小，斩杀线下降
2. **提升毛利率** — 分母变大，斩杀线下降
3. **优化推广费用占比** — 分母变大，斩杀线下降

> **未验证**：汇总报告记录知识库内"斩杀线"存在**多版本**，本次素材只取到《淘系运营核心公式》公式9 这一版。其余版本口径未核实，引用时注明。

## 四、定价侧的预留公式

利润的上游是定价，定价留不出空间，后面所有推广都是在放大亏损。

```
最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1 − 扣佣比例)
```

**最低价管控规则**：

| 计入最低价 | 不计入最低价 |
|---|---|
| 百亿补贴 | 首单礼金 |
| 秒杀 | 新品礼金 |
| 跨店满减 | 店铺优惠券 |
| 直降 | 购物金、淘金币 |
| | 超级立减、会员专享 |

**定价方法三种**：

| 方法 | 公式 |
|---|---|
| 成本定价 | 成本 × (1 + 毛利要求) |
| 竞品定价 | 基于竞品价格带 |
| 价值定价 | 基于客户感知价值 |

**定价倍数参考**（4.0 利润思维，2026-07-27）：**2-2.5 倍最优**——2 倍对应毛利 35%，3 倍对应毛利 36.6%。倍数继续往上抬，毛利增幅很小但转化损失大。

## 五、配套公式：两个"不直接看 ROI"的指标

### 付费效率

```
付费效率 = 人群资产增量 ÷ 付费消耗
```

**不是看单次 ROI，是看人群资产沉淀。**
- 人群资产不足时 → 优先积累人群
- 人群资产充足时 → 追求 ROI 收割

**这条是 S 级存在的理由**：S 级本身 ROI 可能不好看，但它换回来的人群资产会让 A 级变好赚。

### 新品成功率

```
新品成功率 = 测款通过率 × 爆款转化率
```

**说明**：99% 的问题在选品测款。
- 提升测款标准（宁缺毋滥）
- 优化测款效率（缩短周期）

### LTV 与获客成本上限

```
LTV = 平均客单价 × 平均购买次数 × 平均生命周期
```
**LTV 决定获客成本上限。** 医疗器械类目参考值：平均客单价 200-500 元、平均购买次数 2-3 次/年、平均生命周期 3-5 年 → LTV 1200-7500 元。

### 新老客比例

```
健康店铺新老客比例 = 新客 50% : 老客 50%
```
**老客复购是利润的主要来源。**

## 六、算账动作清单

做一次完整的链接级算账，按这个顺序：

```
1. 口径对齐   销售额含不含退款？投产是推广投产还是总投产？
2. 算毛利     销售额 × 毛利率
3. 扣运营成本 人工 / 仓储物流 / 平台扣点 / 退款退货 / 办公杂费
4. 扣推广费   推广费 ÷ 销售额 = 推广费用占比
5. 算盈亏平衡 1 ÷ 毛利率（对照 1 ÷ [毛利率 × (1−退款率)]）
6. 算斩杀线   固定成本 ÷ (毛利率 − 推广费用占比)
7. 算真实投产 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交
8. 算顺逆差   成交金额占比 − 推广花费占比
9. 算领先率   新客成交 ÷ 总成交
10. 判结论    真实投产 vs 盈亏平衡 / 顺逆差正负 / 领先率档位
```

**第 1 步不做，后面 9 步全是废算。** 知识库里多数"投产假好"案例，根因都在口径没对齐。
