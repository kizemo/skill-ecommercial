# 速查表 · profit-model

> 所有阈值均为知识库原文快照（2026 上半年口径）。平台费比、类目均价、退款率会变，落地前核对当期数据。

---

## 1. 公式速查

```
利润          = 销售额 × 毛利率 − 运营成本 − 推广费用
盈亏平衡 ROI  = 1 ÷ 毛利率
盈亏平衡投产比 = 1 ÷ [毛利率 × (1 − 退款率)]        ← 更严，做实盘用这版
斩杀线        = 固定成本 ÷ (毛利率 − 推广费用占比)
真实投产      = 投产 × (1 − 退款率) × (1 − 间接成交占比) × 拉新成交
顺逆差        = 单品成交金额占比 − 单品推广花费占比
领先率        = 新客成交 ÷ 总成交
付费效率      = 人群资产增量 ÷ 付费消耗
新品成功率    = 测款通过率 × 爆款转化率
LTV           = 平均客单价 × 平均购买次数 × 平均生命周期
流量价值      = 流量精准度 × 转化率 × 客单价 × 复购率
最终定价      = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1−扣佣比例)
```

**运营成本五项**：人工、仓储物流、平台扣点、退款退货、办公杂费。

---

## 2. 盈亏平衡 ROI 对照表

| 毛利率 | 盈亏平衡 ROI | 严格版（假设 15% 退款率） |
|---|---|---|
| 60% | **1.67** | 1.96 |
| 40% | 2.50 | 2.94 |
| 30% | **3.33** | 3.92 |
| 20% | 5.00 | 5.88 |

> 严格版 = 1 ÷ [毛利率 × (1−15%)]。**15% 取自素材案例值**，非通用退款率——用自己店的实际退款率替换。

## 3. 阈值速查

| 指标 | 阈值 | 含义 |
|---|---|---|
| **领先率** | 普通店 ≥ 80% / 头部 KA ≥ 70% | 拉新正常 |
| 领先率 | < 50% | 主要跑收割，资源浪费 |
| 领先率 | < 30% | 几乎全是老客在买 |
| **间接/直接成交比** | = 2 倍 | 该品投放完全无效 → 停 |
| **推广投产 vs 店铺均值** | < 均值 | 禁止盲目增加预算 |
| **真实投产 vs 盈亏平衡 ROI** | < 基准 | 不加预算，连续不达标则降级/停投 |
| **8 维度得分** | < 6 分 | 先修产品，不升不降 |
| **顺逆差** | 正向 / 零 / 负向 | 倾斜 / 观察 / 优化或淘汰 |
| **净毛利率** | < 10% | 无分红；10-20% 分 5%；20-30% 分 10%；> 30% 分 15-20% |
| **店铺净利率** | ≥ 10% | 3384 利润目标底线 |
| **全店动销率** | ≥ 60% | 3384 全店动销能力指标 |
| **客单价 vs 类目均价** | 高 20%+ | 3384 品牌溢价能力指标 |
| **复购率** | ≥ 15% | 3384 品牌目标指标 |
| **链接数** | ≥ 100 | 3384 规模目标指标 |
| **季度销售额增长率** | ≥ 30% | 3384 规模目标指标 |
| **测图点击率** | > 行业均值 1.2 倍 | 合格线 |
| **测图/测款** | 每创意 ≥ 50 点击 | 低于此不下结论 |
| **测款预算** | 50-100 元/天，3-5 天跑完 50 点击 | 效率要求 |
| **ROI 参考（直通车）** | 标品 1:3~1:8 / 非标品 1:2~1:5 | 设目标起点，非考核线 |
| **全站推广 ROI 目标** | 毛利率 30% → ≥ 1:3 | ⚠️ 低于理论 3.33，口径冲突 |
| **放量增幅** | ≤ 50% | 每次 |
| **超级短视频预算** | 占整体推广预算 10-20% | 持续投放 |
| **潜客占比** | 目标 60%-80% | 超级短视频核心指标 |
| **人群校正目标** | 目标人群占比 ≥ 70% | 效果评估 |
| **新品成功率** | 测款通过率 × 爆款转化率 | 99% 问题在选品测款 |
| **定价倍数** | 2-2.5 倍最优（2 倍毛利 35%、3 倍 36.6%） | 再往上抬不划算 |
| **健康新老客比** | 50:50 | 老客复购是利润主来源 |

## 4. 止损决策树

```
投产好看，要不要继续投？
│
├─ 新品上线前两周？→ 是：正常，不止损
├─ 真实投产 < 盈亏平衡 ROI？
│   ├─ 间接成交 = 直接成交 × 2 → 停投（投放完全无效）
│   ├─ 领先率 < 50% → 停收割型定向后重测
│   ├─ 8 维度 < 6 分 → 先修产品
│   └─ 以上都过 → 降级（见 [[sabc-product-tiering]]）
├─ 真实投产 ≥ 盈亏平衡 ROI
│   ├─ 顺逆差正向 → 加预算 / 升级候选
│   ├─ 顺逆差零 → 维持观察
│   └─ 顺逆差负向 → 优化投放结构或淘汰
└─ 加预算前：推广投产 > 店铺均值？否 → 禁止盲目增加预算
```

## 5. 该投多少

| 层级 | 口径 |
|---|---|
| **全店→等级** | S/A/B/C 预算占比（见 [[sabc-product-tiering]]，三套口径冲突） |
| **链接→流量源** | 核心爆款 付费50/内容30/私域20；潜力爆款 付费60/免费20/内容20；动销款 付费40/免费40/私域20；形象款 内容50/私域50 |
| **全店→四源** | 付费 50-60% / 免费 20-30% / 内容 10-15% / 私域 5-10% |
| **工具内** | 超级短视频占 10-20%；全站推广分批次压不一次全压；放量增幅 ≤ 50% |
| **链接日销分层** | 0-1k / 1k-1w / 1w+，各层配不同计划结构 |
| **预算→人群圈层** | <50 元=老客；200-500=老客+少量相似；1000-2000=广泛相似+行业；5000+=全行业泛人群 |

## 6. 3384 结构速查

| 块 | 内容 |
|---|---|
| **3 目标** | 利润（净毛利率≥20%、净利率≥10%）／规模（链接数≥100、季度增长≥30%）／品牌（复购率≥15%、品牌词增长） |
| **3 能力** | 全域获客（四源齐发）／全店动销（动销率≥60%）／品牌溢价（客单价高于类目均价 20%+） |
| **8 模块** | 视觉体系／客群体系／产品体系／流量体系／转化体系／服务体验／团队激励／数据复盘 |
| **4 保障** | 供应链（补货 7 天到位）／财务（毛利净利分开算）／组织（三岗 SOP、店长责任制）／风险（动态调整、及时止损） |
| **5 梯队** | 核心爆款 5-10/40%/ROI≥4/单链接月销≥10万；潜力爆款 30-50/30%/30天+30%；动销款 100-200/30%；形象款 5-10/不付费；清仓款 10-20/不付费 |
| **4 角色毛利** | 利润款 ≥30%／引流款 15-20%／形象款 ≥40%／清仓款 可低 |
| **测图** | ≥3 张同测／2-3 天出结果／点击率 > 行业 1.2 倍 |
| **分红** | 净利率 <10% 无／10-20% 5%／20-30% 10%／>30% 15-20% |
| **90 天** | 1-30 诊断标准化／31-60 跑 1-2 个核心爆款试跑／61-90 推广全店 |

## 7. 案例数字

| 案例 | 数字 | 结论 |
|---|---|---|
| 高投产假象 | 投产 6.8、退款率 15% → 真实投产 1、费比 100% | 看板最漂亮的品实际倒挂 |
| 收割型投放 | 月花 8000 元，直接成交 13 笔、间接 24 笔 | 投放完全无效，不值得投任何广告 |
| 定向清理 | 4 个定向停 2 个，每月省 4 万元，销售无变化 | 省下的广告费=直接利润增加 |
| S 级引流 | 日访客 10000，20% 浏览其他品，5% 收割成交，转化率 2%→3%，销售额 +50% | S 级的产出在全店不在自己 |
| 视觉统一 | 客单价 +25-40%，退货率 -5-10%，复购率 ×3-5 倍 | 视觉是最便宜的利润杠杆 |

## 8. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 只看店铺整体投产 | 整体漂亮但单品在亏 | 按花费排序看商品报表，逐品算 |
| 用默认归因 | 重复计算，投产虚高 | 切"第一次/最后一次访问来源" |
| 只看推广投产 | 掩盖免费流量缺失 | 对比推广投产 vs 总投产，差值=免费流量占比 |
| 不扣退款率 | 把退回来的钱算成收入 | 用严格版盈亏平衡投产比 |
| 把老客成交算进广告功劳 | 真实投产被高估 | 真实投产只认拉新成交 |
| 用 ROI 评估 S 级 | 得出"S 级该停"的错误结论 | S 级用领先率 + 达摩盘回流评估 |
| 分红挂销售额 | 团队盲目冲量不顾利润 | 分红基数换成净利率 |
| 定价不留活动空间 | 大促一来亏本冲量 | 用定价预留空间公式 |
| 只扣毛利不扣固定成本 | 忽略运营成本 | 算斩杀线 |
| 店铺成本硬摊到单链接 | 误停健康链接 | 店铺级与链接级分开算 |
| 未满 50 点击就判测图结果 | 结论不成立 | 每创意 ≥ 50 点击 |
| 放大 ROI 目标时漏掉运营成本 | 目标定得过松 | 明确"含不含固定成本" |
| 一个月换一次口径 | 所有环比作废 | 口径锁定一个季度 |

## 9. 口径冲突登记

| # | 冲突点 | 版本 A | 版本 B |
|---|---|---|---|
| 1 | 盈亏平衡 ROI | `1 ÷ 毛利率` | `1 ÷ [毛利率 × (1−退款率)]` |
| 2 | 全站 ROI 目标示例 | 毛利率 30% → ≥ 1:3 | 理论盈亏平衡 3.33（未计运营成本） |
| 3 | 斩杀线 | `固定成本 ÷ (毛利率 − 推广费用占比)` | 知识库存在多版本，其余**未验证** |
| 4 | 3384 毛利率目标 | 通用净毛利率 ≥ 20% | 医疗器械 25-35% |
| 5 | 推广 ROI 参考 | 直通车标品 1:3~1:8、非标品 1:2~1:5 | 3384 第一梯队 ROI ≥ 4 |
| 6 | 流量结构 | 3384 付费 50-60%/免费 20-30% | 健康店 免费 60%/付费 30%/内容 10% |
| 7 | 分级口径 | SABC（S=低利润/流量发动机） | 3384 五梯队（第一梯队利润与规模并重、ROI ≥ 4） |

**裁决**：做实盘取更严的一版；流量结构按店铺阶段选（进攻型用 3384，防守型用健康店结构），不要混用。

## 10. 未验证点

- 「真实投产」公式中**拉新成交**因子的分档阈值——素材只给定义与案例。
- 「斩杀线」的**其余版本**口径——素材只取到一版。
- 「拉新 / 追投 / 收割」计划里的**盈亏比**定义——素材只给了阈值，没给算式。
