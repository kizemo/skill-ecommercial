# 万相台无界 · 全域投放体系

**来源**：`taobao-operation` 知识库（万相台无界课程总览 / P1-P4 / 万相台无界核心概念）｜**版本**：2026.10｜**层级**：L1

回答一个具体问题：**同样的钱，怎么换回更多成交**。答案不是压价，是把"曝光逻辑"换成"资产逻辑"——先攒人群资产，再让资产在多品多域里被放大。

**① 成交机会够不够？② 计划该搭哪几种？③ 每个计划怎么建？④ 数据出来加不加钱？**

---

## 一、两大核心公式

第一条管天花板，第二条管兑现率。**承接力不够就铺多品多域，变现力不够就修流转效率和人群浓度。**

```
成交机会 = 优先展现权激活人数 × 货品曝光场域数量 × 匹配商品数量   ← 承接力
成交规模 = AI→P 流转效率 × 人群资产总规模 × TA 人群浓度             ← 变现力
```

| 因子 | 可控性 | 怎么提 |
|---|---|---|
| 优先展现权激活人数 | ✅ 核心可控 | 点击广告即激活；多打精准的类目熟客 |
| 货品曝光场域数量 | ✅ | 多场域布局，全域承接流量 |
| 匹配商品数量 | ✅ | 多宝贝运营，**裂变而非铺货** |
| fx（算法权重） | ❌ | 平台黑箱，不必猜 |
| 流转效率 / 人群资产规模 / TA 人群浓度 | ✅ | 打标精准度与承接页 / 拉新净产出 / 人群溢价与竞品定向 |

> 成交机会出自万相台无界课程总览；成交规模出自《万相台无界双公式（流量承接力/变现力）》。

## 二、从"曝光逻辑"到"资产逻辑"

**改范式，不是改技巧。**

| 维度 | 传统曝光逻辑 | 人群资产逻辑 |
|---|---|---|
| 核心目标 | 追求"更多人看到" | 追求"更对的人看到" |
| 运营重点 | 优化标题、主图、点击率 | 建立人群资产、激活优先展现权 |
| 货品与场域策略 | 少而精，聚焦搜索/推荐 | 多而优（裂变增加匹配数），全场域布局多点承接 |
| 推广逻辑 | 拉新为主，盲目扩大流量池 | 拉新+收割结合，精准激活临门一脚人群 |
| 投产比 | 低（1.0-2.0） | 高（3.0-5.0+） |

**自检**：动作全是"改主图改标题"→ 还在曝光逻辑；出现"激活多少人、覆盖几个场域、裂变几个子链接"→ 已在资产逻辑。

## 三、核心打法：多品多域

多品多域 = 把成交机会公式的三个可控因子拉满。

| 维度 | 做法 | 数量/优先级 |
|---|---|---|
| **多品·标品** | 场景裂变做独立子链接；主图/货号/详情页/标题必须差异化（重复铺货会被处罚） | **5-8 个**核心场景（上限 15 个） |
| **多品·非标品** | 高频上新，以款式丰富度取胜 | **每类 10-15 款**；每周 3-5 款、每月 15+ 款；在线 50-100 款 |
| **多域** | 搜索 ★★★★★、百亿补贴 ★★★★★、推荐 ★★★★☆、淘宝秒杀 ★★★★☆、小黑盒 ★★★☆☆、88VIP ★★★☆☆ | 布局预算：搜索+推荐 50% → 补贴+秒杀 30% → 直播+小黑盒 15% → 金币+88VIP 5% |

**三大核心优势**：突破同店打散原则（人群资产消费者可看到店铺多个商品，传统仅 2 个）→ 曝光 **+230%**｜全场景优先展现 → 复购意愿 **+14%**｜跨叶子类目展现 → 客单价 **+15%**。场域参与条件与避坑见 ch02。

## 四、OAIPL 链路与三大计划类型

万相台的本质是**从流量采买到人群资产经营**的升级。

| OAIPL | 含义 | 万相台工具 |
|---|---|---|
| **O**owns | 认知触达 | 拉新快 |
| **A**ctivate | 兴趣激发 | 人群方舟 |
| **P**urchase | 购买转化 | 收割计划 |
| **I**oyalty | 复购留存 | 水滴计划 |

三大计划类型：**拉新计划**（低价+广泛人群，扩大资产）｜**收割计划**（高价+精准人群，提高 ROI）｜**全店动销**（水滴计划+多链接）。

出价：安全出价 = 系统建议价 × 0.7；手动出价"低出高溢"；付免联动 = 付费带动免费流量。

## 五、三大推广模式与计划类型定义

| 模式 | 适配店铺 | 核心目标 | 核心计划 | 费比 |
|---|---|---|---|---|
| **动销模式** | 有人群资产的老店 | 多打标、高回搜 | 好货快投+趋势明星 | 5%-8% |
| **爆款模式** | 无人群资产的新店 | 高权重、高转化 | 智能单品+标准计划 | 8%-10% |
| **矩阵模式** | 多店多平台大商家 | 规模复制 | 标准+全店智能 | 3%-5% |

**动销模式 5 计划**：好货快投（出价行业均价 30%-50%，禁最大化出价，日预算 100-200 元）｜趋势明星（主题词包手动，出价行业 PPC 的 50%，初期 5-50 个计划）｜智能测款（测完关闭）｜全店智能低价计划（PPC ≤ 行业均值 50%）｜全店标准低价计划（智能计划的人工替代版）。

**爆款模式 2 计划**：智能单品计划（前期开后期关，单日 500 元以内，点击率达行业均值 1.5 倍以上是爆款信号，日销 1000 元以上+自然搜索占比 30% 以上时关闭）｜标准计划（成长期=权重计划，成熟期=拉新计划，大促期=收割计划）。

> ⚠️ **术语易混**：万相台的"**全店智能/全店标准**计划" ≠ 独立工具"**全站推广**"。

## 六、P1-P4 操作框架

| 模块 | 要点 | 详见 |
|---|---|---|
| **P1 人群资产** | 优先展现权两规则、同店打散、AIPL、类目新客 vs 熟客 | ch03 |
| **P2 组合分工** | 收割 4 类型 + 拉新 4 策略、竞品定向三要素、有效人群比例 | ch04 |
| **P3 计划搭建** | 拉新 3 + 收割 4 + 追投 3 | ch05 |
| **P4 数据融合** | 生意参谋+万相台融合、红绿灯监控、预算加减 | ch06 |

- **P1**：权重随时间递减（1月3日浏览 > 1月1日浏览）；层级 **L > P > I > A**；有资产可展现 3-6 个甚至更多宝贝，无资产最多 2 个。
- **P2**：收割优先因为①直接产粮保障 ROI，②成交有时效性——被收割触达人群成交转化率 **6.26%**，未被触达的纯免费流量人群仅 **1.66%**，差 **3.7 倍**。**拉新不看 ROI，看有效人群比例**（≥60% 优秀 / 40%-60% 良好 / <40% 较差）；竞品定向优先线：规模≥5万、浓度≥30%、未渗透≥60%。
- **P3**：追投只对转化周期 >15 天。**P4**：预算调整铁律，每次幅度 ≤ **30%**。

## 七、适用场景 → 推荐策略

| 场景 | 拉新 | 收割 |
|---|---|---|
| **中高客单价 ≥300元** | 关键词手动低出高溢 + 精准竞争航线 | 全站（控投产）+ 关键词（品牌词）+ 老客复购 |
| **中低客单价 <300元** | 关键词智能控点击成本 + 相似品跟投 | 全站（最大化）+ 关键词（行业词）+ 流量金卡 |
| **短周期 ≤7天** | 智能控成本 + 相似品跟投 | 全站（控投产）+ 关键词 + 流量金卡（无需追投） |
| **长周期 >15天** | 手动低出高溢 + 竞争航线 + 达摩盘 | 全站（控投产+多目标）+ 人群资产转化（加追投） |
| **标品（非搜不买）** | 关键词手动低出高溢 + 相似品跟投 | 关键词（行业+品牌）+ 全站 + 流量金卡 |
| **非标品（搜推均成交）** | 关键词智能控成本 + 精准竞争航线 | 全站（控投产+多目标）+ 人群资产转化 + 人群超市 |

新店铺起步期：先聚焦搜索+推荐积累基础人群资产。标品（除甲醛/家电/日用品）：重点布局 搜索+推荐+百亿补贴+秒杀。非标品（服装/鞋帽）：重点布局 搜索+推荐+直播+小黑盒。

## 八、窗口期判断

多品多域不是永久红利，**同行普遍采用后优势衰减**。三条特征需同时成立：

```
同行多链接占比 < 30%   且   多场域参与率 < 20%   且   行业 ROI > 4.0
```

任意一条不成立，就该重新评估多品多域的性价比。

## 十、使用说明

1. **先定位再优化**：用成交机会判断是承接力问题还是变现力问题。
2. **按顺序落地**：P1 → P2 → P3 → P4。跳到 P3 先建计划，没有资产承接。
3. **拉新与收割分开看指标**：收割看 ROI，拉新看有效人群比例。
4. **每次只调一个变量**：预算、人群、出价、场域，一次只动一个，否则归因不了。
5. **阈值来自知识库原文快照**（2026 上半年口径）。平台每月迭代，新功能先用 30-50 元最低预算试。

## Scope & Limits

- 覆盖**万相台（无界版）**投放体系；直通车/引力魔方/超级短视频对比见 `chapters/ch05-计划搭建与场景分流.md`。
- 案例数据来自课程案例（霍尼韦尔除甲醛、高端空气净化器、零食、高端定制家具、棉服类目），**是单店样本，不是行业均值**。
- **口径冲突（需复核）**：① 费比——三大推广模式建议值 3%-10%，实战案例实际 11%-13%，建议值偏保守，实际按品类与毛利率校准。② 全站推广在课程总览中列为"收割计划四类型"之一，在万相台核心概念中"全店智能/全店标准"又是万相台内部计划——两套工具并行时先按 `cheatsheet.md` 决策树分流。
- 阈值来自 2026 上半年知识库快照。平台规则与后台功能会变，**落地前核对当期平台公告**。
