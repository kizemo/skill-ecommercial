# 速查表 · wanxiangtai-wujie

> 所有阈值均为知识库原文快照（2026 上半年口径）。平台规则每月迭代，落地前核对当期公告。

---

## 1. 两大公式与诊断入口

```
成交机会 = 优先展现权激活人数 × 货品曝光场域数量 × 匹配商品数量   ← 承接力（天花板）
成交规模 = AI→P 流转效率 × 人群资产总规模 × TA 人群浓度             ← 变现力（兑现率）
```

| 症状 | 诊断 | 去哪改 |
|---|---|---|
| 曝光不够、看到的人少 | 成交机会低 | 多品多域（ch02） |
| 有曝光不成交、成交规模低 | 变现力低 | 流转效率/人群浓度/承接页（ch04/ch05） |
| 子链接少、只在搜索露 | 匹配商品数低 | 标品场景裂变 5-8 个 / 非标每类 10-15 款 |
| 场域只做了搜索推荐 | 曝光场域数低 | 按优先级扩场域（ch02） |

## 2. 阈值表：核心数字

### 2.1 成交机会与场域

| 项 | 阈值 |
|---|---|
| 标品场景裂变子链接 | **5-8 个**核心场景（上限 15 个） |
| 非标每类款式 | **10-15 款**；每周上新 3-5 款、每月至少 15 款 |
| 非标在线商品数 | **50-100 款** |
| 场域预算分配 | 搜索+推荐 50% / 补贴+秒杀 30% / 直播+小黑盒 15% / 金币+88VIP 5% |
| 窗口期 | 同行多链接占比 <30% **且** 多场域参与率 <20% **且** 行业 ROI >4.0 |

### 2.2 人群与溢价

| 项 | 阈值 |
|---|---|
| AIPL 时间窗 | A 15 天 / I 90 天 / P 365 天 / L 365 天 |
| 权重层级 | L > P > I > A |
| 同店打散 | 有资产 3-6 个甚至更多 / 无资产 最多 2 个 |
| 类目新客浏览量 | 5-10 个 |
| 类目熟客浏览量 | 50 个以上，反复看 3-5 个 |
| L4/L5 人群溢价 | 200%（常规）→ 500%（成熟账户） |
| L1/L2 人群溢价 | 5% |
| 人群清洗周期 | 30 天暂停 L1；90 天替换混乱标签 |
| 地域出价 | 投产≥2 均价 / 1.5-2 均价 80% / <1.5 均价 50% |
| 安全出价 | 系统建议价 × 0.7 |

### 2.3 竞品定向

| 项 | 优先选择 | 规避 |
|---|---|---|
| TA 人群规模 | ≥ 5 万 | < 3 万 |
| TA 人群浓度 | ≥ 30% | < 20% |
| TA 未渗透率 | ≥ 60% | < 40% |

### 2.4 拉新与收割

| 项 | 阈值 |
|---|---|
| 有效人群比例 | ≥60% 优秀 / 40%-60% 良好 / <40% 较差（暂停） |
| 收割 vs 被收割转化率 | 6.26% vs 1.66%（3.7 倍） |
| 全站边际效应 | 上升 ≥目标ROI×1元 / 放缓 目标ROI×0.6~1 / 下滑 <目标ROI×0.6 |
| 全站下滑阶段动作 | 减 30%-50% 预算转拉新 |
| 品牌词占收割预算 | 20%-30% |
| 精准人群占收割预算 | 15%-20% |
| 流量金卡占收割预算 | 10%-15% |
| 垃圾词占比 | >30% 关闭流量智选词包改手动 |
| 关键词手动拉新出价 | 行业均值 60%-70% |
| 关键词手动拉新溢价 | 100%-150%（建议不超 200%） |
| 相似品跟投 | 出价 70%-80% + 溢价 80%-100% |
| 达摩盘拉新 CPC | 高于行业均值 20%-30% |
| 低效词剔除 | 点击率 <1% 或 转化率 <0.5% |

### 2.5 红绿灯与预算

| 指标 | 🟢 绿 | 🟡 黄 | 🔴 红 |
|---|---|---|---|
| 投产 ROI | ≥ 目标 ROI | ≥ 目标×0.8 且 < 目标 | < 目标×0.8 |
| 费比 | ≤ 目标费比 | 目标 < 实际 ≤ 目标×1.2 | > 目标×1.2 |

| 动作 | 触发条件 | 幅度 |
|---|---|---|
| **加预算** | 双绿 + 连续 3 天稳定 + 新增预算 ROI ≥ 原有 80% + TA 未渗透 ≥50% | 单品 +20%-30%，系列总 ≤+30% |
| **减预算** | 双红，或连续 3 天黄灯无改善，或退款率 >30%，或间接成交 >70% 且系列费比红 | 双红 -50%-80%（或暂停）；费比红投绿 -30%-50% |
| **观望** | 黄灯波动大 / 日预算 <500 元 / 推广 <7 天 | 不增不减，监控 7-10 天 |

**铁律**：每次调整预算幅度 **≤ 30%**。

### 2.6 大促三阶段

| 阶段 | 预算占比 | 关键动作 |
|---|---|---|
| 预热期 | 拉新 60%-70% | 拉新有效人群 ≥60% 则加 30%-50% 预算 |
| 爆发期 | 收割 70%-80% | 最大化拿量+防停投，投产达标自动加预算 |
| 返场期 | 收割 ≤30% | 出价目标切"净成交金额" |

### 2.7 万相台计划参数

| 计划 | 关键参数 |
|---|---|
| 好货快投 | 出价 30%-50% 均价；禁最大化出价；日预算 100-200 元；按最低客单价均值出价 |
| 趋势明星 | 出价 50% 行业 PPC；初期 5-50 个计划；仅"增加点击量"和"相似品跟投" |
| 全店智能低价 | PPC ≤ 行业均值 50% |
| 智能单品 | 单日 ≤500 元；点击率达行业均值 1.5 倍 = 爆款信号；日销>1000 元 + 自然搜索占比>30% 则关 |
| 标准计划·权重期 | CTR/CVR 达行业均值 2 倍以上；出价公式 `关键词出价 × 分时折扣 × (1+人群溢价)`；出价不低于行业 30% |
| 标准计划·拉新期 | 30 天内手淘搜索少的词降至 0.05 元；不开新客营销/一键起量/搜索卡位 |
| 标准计划·收割期 | 优先事件营销、条件营销；不参加满减活动 |

### 2.8 三大推广模式费比

| 模式 | 适配 | 核心计划 | 费比控制 |
|---|---|---|---|
| 动销模式 | 有人群资产的老店 | 好货快投+趋势明星 | 5%-8% |
| 爆款模式 | 无人群资产的新店 | 智能单品+标准计划 | 8%-10% |
| 矩阵模式 | 多店多平台大商家 | 标准+全店智能 | 3%-5% |

> ⚠️ 案例实际费比为 11%-13%（霍尼韦尔 12%、高端空净 13%、零食 11%），高于模式建议值——**口径冲突，需复核**。按品类毛利率校准。

## 4. 决策树

```
成交机会不够
├─ 匹配商品数少
│  ├─ 标品 → 场景裂变 5-8 个子链接（主图/货号/详情页/标题必须差异化）
│  └─ 非标 → 每类 10-15 款，每周 3-5 款、每月 15+ 款
└─ 曝光场域少 → 按 搜索+推荐 50% / 补贴+秒杀 30% / 直播+小黑盒 15% / 金币+88VIP 5% 推进

拉新计划看不到 ROI
├─ 有效人群比例 ≥60% → 正常，继续投（拉新看资产不看 ROI）
├─ 40%-60% → 优化人群标签和出价溢价
└─ <40% → 暂停，重筛竞品/关键词/人群标签
   └─ 排查：匹配方式是否广泛 / 竞品浓度是否<20% / 素材是否引来低消费力 / 缺 L4L5 标签

拉新计划花不出钱
├─ 关键词出价是否低于行业均值 50% → 逐步提高
├─ 人群溢价是否未设置 → 补上
├─ 竞品 TA 规模是否 <3 万 → 换竞品
└─ 都不是 → 开"一键起量"冷启动

全站推广全是推荐流量
├─ 暂停全站 → 启动关键词收割（仅搜索端）1-2 周
├─ 检查搜索端主图
└─ 拉新计划侧重搜索端

全站投产下滑
├─ 上升阶段（≥目标ROI×1元）→ 继续加
├─ 放缓阶段（目标ROI×0.6~1）→ 停止加预算，观察 3-5 天
└─ 下滑阶段（<目标ROI×0.6）→ 减 30%-50% 转拉新
   └─ 若连续 3 天下滑且 < 目标ROI×70% → 立即停止加预算

投产/费比双红
├─ 减 50%-80% 或暂停
├─ 查人群精准度 / 宝贝竞争力 / 计划搭配
└─ 暂停的单品 1-2 周后小预算测试，仍红则长期暂停

选工具：全站 vs 无界
├─ 新品测图测款 → 先用无界（2-4 周）
├─ 数据稳定 → 转全站放大
├─ 利润薄产品 → 慎用全站，用无界
├─ 大促期 / KA 商家 → 全站+无界配合
└─ 完全没数据的新品 → 不要直接放全站
```

## 5. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 用 ROI 判拉新计划 | 长期正确的拉新被误杀 | 看有效人群比例 + 30 天转化 |
| 只收割不拉新 | 人群池耗尽，投产 3-5 天后下滑 | 收割/拉新双计划并行 |
| 盲目加预算 | 投产跌破目标 ROI×70% | 盯边际效应三阶段，增幅 ≤30% |
| 只做搜索一个场域 | 成交机会卡在天花板 | 搜索+推荐先占 50% 预算 |
| 标品重复铺货 | 平台处罚 | 主图/货号/详情页/标题全差异化 |
| 非标上新只看数量 | 流量分散、款式同质化 | 上新前做款式差异化检测 |
| 盲目参与所有场域 | 曝光高转化低 | 场域与商品价格带/客群匹配 |
| 低价标品报 88VIP | 点击率低 | 88VIP 要 ≥9.5 折且客单价匹配 |
| 大促只看总成交 | 凑单退款吃掉利润 | 切"净成交金额"出价目标 |
| 间接成交跨系列汇总 | ROI 虚高 | 按"系列"汇总，共享人群资产统一评估 |
| 粘贴时改了公式单元格 | 模板公式失效 | 只"选择性粘贴→值" |
| 万相台下载时营销场景没全选 | 漏掉部分计划数据 | 营销场景必须全选 |
| 把"全店智能/全店标准计划"当"全站推广" | 工具选错 | 前者是万相台内部计划，后者是独立工具 |
| 大促返场期沿用爆发期预算结构 | 收割超过 30% 浪费 | 返场收割 ≤30% |

## 6. 关键原则清单

1. 成交机会决定天花板，成交规模决定兑现率——**先看承接力，再看变现力**。
2. 精准人群资产是一切付费推广的前提（[[customer-asset-ops]]）。
3. 收割有时效性：6.26% vs 1.66%，错过即无。
4. 拉新看有效人群比例，收割看 ROI，**两把尺子不能混**。
5. 预算每次调整 ≤30%，优先调单品而不是整个系列。
6. 新功能先用 30-50 元最低预算测，红利期短暂但盲目上量更贵。
7. 推广的问题要在单品中找答案（[[store-diagnosis]]）。
8. 算账、盈亏平衡、投产去伪见 [[profit-model]]；全局公式与路由见 [[skill-ecommercial]]；链接阶段判定见 [[hit-product-lifecycle]]。
