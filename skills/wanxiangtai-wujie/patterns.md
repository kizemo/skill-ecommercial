# 可复用方法 · wanxiangtai-wujie

> 每条方法给出**何时用 / 怎么做 / 代价与风险**。数字均来自知识库原文快照。

---

## 1. 标品场景裂变

**何时用**
标品、款式单一、上新无法增加匹配商品数量，但需要承接优先展现权、想在多个场域铺开时。典型场景：除甲醛、家电、日用品。

**怎么做**
1. 列出 5-8 个真实消费场景（如除甲醛品类：母婴优选 / 新车除醛 / 新房急住 / 长效净化 / 冰箱除味）。
2. 每个场景做一个独立子链接，**主图、货号、详情页、标题全部差异化**。
3. 子链接总数不超过 15 个。
4. 不同子链接分配到不同场域（引流款走百亿补贴/秒杀，品质款走小黑盒/88VIP），同时解决全站推广与效果广告的互斥问题。
5. 只让主链接做拉新积累人群资产，场景链接等主链接的资产自然承接。

**代价/风险**
- 重复铺货会被平台处罚——差异化不彻底等于没做。
- 场景虚假化会被查（"母婴款"要提供安全检测报告）。
- 5-8 个子链接意味着库存、客服、评价都要跟上，运营复杂度成倍上升。
- 参考效果（霍尼韦尔单店样本）：核心裂变链接支付金额 +450.63%，支付件数 +396.25%——**单店案例，不是行业均值**。

## 2. 非标品高频上新

**何时用**
非标品（服装/鞋帽）、款式是竞争力、搜索热度变化快的品类。

**怎么做**
1. 每周上新 3-5 款，每月至少 15 款，每类保持 10-15 款差异化商品。
2. 选"搜索热度高、竞争度低"的细分款式——童装店发现"防蚊裤"夏季搜索量激增就快速上新 3 款。
3. 上新时同步做关联搭配链接（"夹克+打底衫+休闲裤"），提升连带率。
4. 在线商品总数控制在 50-100 款。

**代价/风险**
- **忌"数量＞质量"**：款式同质化会分散流量。上新前先做款式差异化检测。
- 上新节奏压过了测款能力，会把预算花在没验证过的款上。
- 新品上得越多，越需要新品运营中心和低预算测试机制配合（见 [[hit-product-lifecycle]]）。

## 3. 场域布局分期推进

**何时用**
店铺从起步期进入成长期/成熟期，需要把曝光从单场域铺到全场域时。

**怎么做**
按优先级分四步推进，预算跟着阶段走：

| 阶段 | 场域组合 | 预算分配 |
|---|---|---|
| 起步期 | 搜索 + 推荐 | 50% |
| 成长期 | 百亿补贴 + 秒杀 | 30% |
| 成熟期 | 直播 + 小黑盒 | 15% |
| 稳定期 | 淘金币 + 88VIP | 5% |

**代价/风险**
- **忌盲目参与所有场域**：非标小众款参加百亿补贴，曝光高但转化低。
- **忌场域与商品不匹配**：低价标品参加 88VIP，客单价不符合 88VIP 用户需求，点击率低。
- 每个场域有硬性参与条件（百亿补贴要求价低于行业 10%+、售后率≤5%；秒杀要求价低于日常 20%+、库存≥1000），不达标就报不上名。
- 场域越多，需要盯的坑位越多——先用"搜索+推荐"跑通模型再扩。

## 4. 收割优先、精准拉新

**何时用**
店铺已有一定人群资产，需要先把投产拉起来、再慢慢扩规模时。

**怎么做**
1. **先开收割**：全站推广（控投产）+ 关键词收割（品牌词/行业词）+ 精准人群收割（店铺种子人群）+ 套餐包（流量金卡/人群超市）。
2. 收割结构：本店人群资产 → 全站 60% + 精准人群 40%；竞对人群资产 → 竞争航线 70% + 关键词 30%。
3. **同步开拉新**：按客单价分流——中高客单（≥300元）用关键词手动+达摩盘，中低客单（<300元）用相似品跟投+竞争航线。
4. 收割用 ROI 判，拉新用**有效人群比例**判。

**代价/风险**
- 只收割不拉新 → 人群池耗尽，3-5 天后投产开始下滑。
- 只拉新不收割 → 现金流断档，推广费无处可摊。
- 收割有**时效性**：成交转化率 6.26% vs 纯免费流量 1.66%，错过即无——被竞品先触达就抢不回来。
- 用 ROI 去判断拉新计划是**用错尺子**，会让长期正确的拉新计划被误杀。

## 5. 竞品定向三要素筛选

**何时用**
需要精准抢夺竞品人群（拉新计划或竞对人群收割）时。

**怎么做**
1. 达摩盘 →"同行宝贝行为人群"→选择竞品宝贝 ID→30 天浏览→取中位数，得到 **TA 人群规模**。
2. 竞品 TA 人群 ∩ 我方目标画像 → 有效人数 ÷ TA 规模 = **TA 人群浓度**。
3. 竞品 TA 人群 ∩ 店铺 30 天未浏览人群 → 占比 = **TA 未渗透率**。
4. **优先选**：规模 ≥5 万 + 浓度 ≥30% + 未渗透 ≥60%。**规避**：规模 <3 万、浓度 <20%、未渗透 <40%。

**代价/风险**
- 三要素全高但不可达时慎用——竞品 TA 规模巨大不代表我方能切进去。
- 达摩盘取数是 30 天窗口，竞品节奏变化快时数据滞后。
- 竞争航线出价建议设为行业均值的 120%-150%，**CPC 会明显高于同类计划**，预算要预留。

## 6. 有效人群比例监控

**何时用**
拉新计划上线后，**不要用即时 ROI 判它生死**。每 7-10 天做一次。

**怎么做**
1. 万相台 → 洞察 → 人群 → 选择拉新计划 → 导出人群 ID。
2. 达摩盘 → 自定义人群 → 添加"拉新计划人群 ID" ∩ "目标画像标签"。
3. 有效人群比例 = 有效人群数 ÷ 拉新计划总人群数 × 100%。
4. 判读：≥60% 加预算并可扩大定向范围；40%-60% 优化人群标签和出价溢价；<40% 暂停并重筛竞品/关键词/人群标签。

**代价/风险**
- <40% 时不要先加钱——先修竞品选择、匹配方式和人群标签。
- 有效人群比例 ≥40% 就**坚持投**，即使当期 ROI 不好看（拉新价值是长期人群资产）。
- 该指标只在 30 天口径下有意义，短期波动别当结论。

## 7. 长周期品类的追投三型

**何时用**
转化周期 >15 天的高端家电、定制家具、高客单价滋补品。**≤7 天短周期不要建追投计划。**

**怎么做**
| 型 | 定向 | 出价参考 |
|---|---|---|
| 种子人群追投 | 店播/收加人群（30 天互动） | 3 元 |
| 低浏览人群激活 | 30 天浏览 1 次 + 未收加 | 2.8 元 |
| 预流失人群挽回 | 浏览 ≥2 次 + 15 天未访 | 3.2 元 |

统一用"促进点击"优化目标。

**代价/风险**
- 追投本质是**维持关系**，不是收割，别拿它的 ROI 去跟收割计划横向比。
- 追投人群池小，扩量空间有限，不能替代拉新。
- 参考效果（单店样本）：CPC 2.9 元、浏览频次提升率 45%、30 天转化率 6.2%、ROI 3.1。

## 8. 数据融合 + 红绿灯调预算

**何时用**
每周例行复盘，或大促期间需要精确调预算时。**单看万相台 ROI 会误判**（它不剔退款）。

**怎么做**
1. **下载**：生意参谋（商品分析→商品明细，务必勾选"退款金额"）+ 万相台（报表中心→商品报表，营销场景必须全选）。
2. **粘贴**：用"选择性粘贴→值"，不要动表头和公式单元格。
3. **汇总**：万相台侧同一宝贝多条记录（不同计划）先按"宝贝 ID+日期"汇总再粘贴。
4. **标注**：按"共享人群资产"原则给宝贝标类目/系列，用 Excel 筛选批量标注。
5. **校验**：核对总成交金额和总推广花费两边一致。
6. **判灯**：投产绿 ≥ 目标 ROI；费比绿 ≤ 目标费比。
7. **调预算**：双绿加（单品 +20%-30%，系列总 +≤30%）/ 双红减（-50%-80% 甚至暂停）/ 黄灯观望（不增不减，监控 7-10 天）。

**代价/风险**
- **每次调整幅度不超过 30%**，这是铁律。
- 预算调整应**优先调单品而非整个系列**。
- 大促期间凑单退款多，返场期要切"净成交金额"出价目标。
- 间接成交跨系列重复计算会虚高 ROI——务必按系列汇总。
- 数据样本不足（日预算 <500 元或推广天数 <7 天）时不要下结论，走观望策略。

## 9. 全站推广与万相台无界配合

**何时用**
选付费工具时，尤其是新品冷启动阶段。

**怎么做**
```
无界测图测款（2-4 周） → 数据稳定 → 全站放大收割 → 效果下滑 → 再转无界维护
```
- 利润薄的产品慎用全站，用无界。
- 大促期、KA 商家：全站 + 无界配合。
- 万相台迭代非常快（每月都有新功能），新功能第一时间用 **30-50 元**最低预算测试——红利期短暂。

**代价/风险**
- **完全没有数据的新品不要直接放全站**。
- 全站投产比高不代表真正盈利——**退货率要核算**。
- 全站计算包含免费流量，top 店铺天然有优势；全站效果不好的根因往往是产品力（点击率、转化率）不够。
- 冷启动突破：选"最大化投放+一键起量"3-5 天后切"控投产投放"。

## 10. 新功能小额快测

**何时用**
万相台每月都有新功能上线时。

**怎么做**
1. 看到新功能，先用 **30-50 元**最低预算开一个测试计划。
2. 观察 3-5 天，拿到点击/成交样本再决定是否上量。

**代价/风险**
- 红利期短暂，观望等于放弃。
- 但盲目上量更贵——先测再放量是唯一安全姿势。
