# ch06 · 多端数据融合与红绿灯监控（P4）

> 来源：P4-多端数据融合调研（智篆商业·老草老师讲座-P4）

P4 解决"数据出来之后加不加钱"。**万相台看 ROI 是毛的，生意参谋看成交是漏的**，两边不融合就做不出决策。

---

## 一、数据来源与核心痛点

### 1.1 两大核心数据平台对比

| 数据平台 | 核心数据类型 | 优势 | 不足 |
|---|---|---|---|
| 📊 生意参谋 | 成交金额、退款金额、净成交、访客数、转化率、客单价 | 财务闭环、精细类目、长效追溯 | 颗粒度粗、归因断裂、ROI 缺失 |
| 🚀 万相台无界 | 推广花费、直接成交、间接成交、ROI、宝贝推广明细 | 链路归因、投产直观、推广透视 | 非净值数据、类目缺失、数据延迟 |

### 1.2 数据融合的三大痛点

1. **数据分散**：成交、退款在生意参谋，推广花费、ROI 在万相台，无法直接关联
2. **颗粒度不足**：生意参谋缺推广维度细分，万相台缺类目级别汇总
3. **归因缺失**：生意参谋无法匹配推广归因周期，万相台无法剔除退款影响

### 1.3 数据融合的核心目标

- 统一数据口径：计算"净成交费比""系列 ROI"等核心指标
- 评估单品与系列价值：分析单个宝贝和同一人群资产下多个宝贝的整体价值
- 建立监控体系：通过红绿灯规则快速识别推广效果优劣
- 支撑目标拆解：将销售额、流量、花费目标转化为可落地的推广动作

## 二、数据融合实操：Excel 模板全流程

### 2.1 准备工作

**融合范围**：
- **时间范围**：建议按天融合，每日更新前一天数据
- **宝贝范围**：按"**系列**"进行分类融合（如同一类目、同一系列），**共享人群资产的宝贝需统一评估**

**核心指标**：

| 平台 | 核心指标 |
|---|---|
| 生意参谋 | 日期、宝贝 ID、宝贝名称、总成交金额、退款金额、净成交金额、访客数、转化率、客单价 |
| 万相台无界 | 宝贝 ID、推广花费、直接成交、间接成交、ROI |

### 2.2 实操六步骤

**步骤 1：下载生意参谋数据**
1. 登录生意参谋 → 商品分析 → 商品明细
2. 选择时间范围 → 勾选核心指标 → 点击"下载报表"
3. **关键注意**：必须勾选"退款金额"，日期格式统一为"YYYY/MM/DD"

**步骤 2：下载万相台无界数据**
1. 登录万相台无界 → 报表中心 → 商品报表
2. 选择时间范围 → **营销场景"全选"** → 维度选择"商品明细" → 勾选核心指标
3. **关键注意**：营销场景必须全选（取消所有勾选），否则会遗漏部分推广计划数据

**步骤 3：粘贴生意参谋数据到模板**
1. 打开模板"生参数据"工作表 → 选中 A2 单元格
2. 选择性粘贴 → 仅粘贴**值**，排除格式与超链接
3. 调整日期格式为"YYYY/MM/DD"

**步骤 4：粘贴万相台无界数据到模板**
1. 切换到模板"无界数据"工作表 → 选中 A2 单元格
2. 选择性粘贴 → 仅粘贴值
3. **关键注意**：同一宝贝在无界数据中存在多条记录（如不同推广计划），需先按"**宝贝 ID + 日期**"汇总后再粘贴

**步骤 5：宝贝类目分类标注**
1. 切换到"宝贝类目清单"工作表
2. 从"生参数据"复制所有宝贝 ID 与宝贝名称 → 粘贴到 A 列和 B 列
3. 按"**共享人群资产**"原则，给宝贝标注类目/系列 → 填写到 C 列
4. **批量标注技巧**：使用 Excel"筛选"功能按关键词批量标注

**步骤 6：模板自动计算与数据校验**
1. 切换到"系列总红绿灯"工作表 → 选择时间范围和类目
2. 模板自动计算：总成交金额、总退款金额、净成交金额、总推广花费、总直接成交、总间接成交、系列 ROI、系列费比、退款率
3. **数据校验**：核对生参数据与模板汇总的总成交金额是否一致；核对无界数据与模板汇总的总推广花费是否一致

## 三、红绿灯监控体系

### 3.1 红绿灯判定规则

| 指标 | 🟢 绿灯条件 | 🟡 黄灯条件 | 🔴 红灯条件 |
|---|---|---|---|
| 投产（ROI） | ≥ 目标 ROI | ≥ 目标 ROI × 0.8 且 < 目标 ROI | < 目标 ROI × 0.8 |
| 费比 | ≤ 目标费比 | 目标费比 < 实际 ≤ 目标费比 × 1.2 | > 目标费比 × 1.2 |

### 3.2 四大核心场景解读

#### 场景 1：投产绿灯 + 费比绿灯（双绿灯）— 优秀

**特征**：推广效果优秀，投入产出比与成本控制均符合预期
**决策**：**增加预算**，扩大推广规模

- 优先给 ROI 最高的宝贝增加 **20%-30%** 预算
- 若系列整体表现优秀，可新增拉新计划
- 持续监控边际效应，若新增预算后投产下滑至黄灯，停止加预算

#### 场景 2：投产绿灯 + 费比红灯（单绿单红）— 待优化

**特征**：推广转化效果好，但成本超标

**原因分析**：
1. 退款率过高（净成交偏低）→ 减少 **30%-50%** 预算，优化宝贝质量/服务
2. 间接成交占比过高 → 看系列费比，若系列费比为绿灯则保留预算

**决策**：优化为主，不盲目增加预算

#### 场景 3：投产红灯 + 费比绿灯（单红单绿）— 待观察

**特征**：成本控制到位，但转化效果差

**原因分析**：
1. 免费流量占比高，推广流量转化差
2. 推广预算过少，数据样本不足
3. 拉新计划占比过高，收割计划不足

**决策**：观察优化，必要时增加收割预算

#### 场景 4：投产红灯 + 费比红灯（双红灯）— 较差

**特征**：转化效果差且成本超标
**原因**：人群精准度低、宝贝竞争力弱、推广计划搭建不合理
**决策**：**立即减少预算 50%-80%**，甚至暂停推广，全面优化后再重启

## 四、预算调整策略

### 4.1 核心原则

- **数据驱动**：所有调整基于融合数据的红绿灯状态，不依赖主观判断
- **循序渐进**：每次调整预算幅度**不超过 30%**
- **聚焦核心**：优先调整表现优秀/较差的单品，而非整个系列
- **动态优化**：调整后持续监控数据，效果未改善则及时二次调整
- **结合场景**：日常推广与大促推广的调整逻辑不同

### 4.2 加预算策略（双绿灯场景）

**适用条件**：
- 系列/单品双绿灯，且连续 **3 天**数据稳定
- 边际效应未显现（新增预算 ROI ≥ 原有 ROI 的 **80%**）
- 人群资产充足（TA 人群未渗透率 ≥ **50%**）

**操作步骤**：
1. 筛选核心对象：双绿灯且 ROI 最高的 **3-5 个**单品
2. 确定调整幅度：每个核心单品增加 **20%-30%** 预算，系列总预算增加不超过 **30%**
3. 监控边际效应：若 ROI 仍保持绿灯继续加，若降至黄灯则停止

### 4.3 减预算策略（红灯场景）

**适用条件**：
- 系列/单品双红灯，或连续 **3 天**黄灯无改善
- 退款率持续 **>30%** 且无法快速优化
- 间接成交占比 **>70%** 且系列费比红灯

**操作步骤**：
1. 双红灯单品：减少 **50%-80%** 预算，或暂停推广
2. 费比红灯但投产绿灯的单品：减少 **30%-50%** 预算
3. 将减少的预算转移至双绿灯单品，或增加收割计划预算
4. 暂停的单品 **1-2 周**后小预算测试，若仍为红灯则长期暂停

### 4.4 观望优化策略（黄灯场景）

**适用条件**：
- 系列/单品黄灯，且数据波动较大
- 数据样本不足（推广日预算 < **500 元**，或推广天数 < **7 天**）
- 外部因素影响（如季节变化、平台活动）

**操作步骤**：
1. 维持预算规模：不增不减
2. 优化细节：收割计划优化关键词、调整控投产目标；拉新计划更换 1-2 个竞品、调整人群溢价
3. 积累数据样本：持续监控 **7-10 天**
4. 后续决策：若转为绿灯则加预算，若转为红灯则减预算

## 五、大促预算调整特殊策略

| 阶段 | 重点 | 预算占比 | 关键动作 |
|---|---|---|---|
| 预热期 | 积累人群资产 | 拉新 **60%-70%** | 若拉新有效人群 ≥60%，增加 30%-50% 预算 |
| 爆发期 | 抢占流量高峰 | 收割 **70%-80%** | 开启"最大化拿量+防停投"，投产达标时自动加预算 |
| 返场期 | 收割剩余人群资产 | 收割 **≤30%** | 切换无界数据出价目标为"净成交金额" |

## 六、实战案例：棉服类目数据融合与调优

**案例背景**：
- 核心类目：棉服（40 个宝贝）
- 推广目标：系列 ROI ≥ **8**，费比 ≤ **25%**，月净成交 ≥ **15 万元**
- 初始：日推广预算 1500 元，收割 60%，拉新 40%

**数据融合结果（12月1日-4日）**：

| 核心指标 | 数值 |
|---|---|
| 总成交金额 | 11000 元 |
| 总退款金额 | 6100 元 |
| 净成交金额 | 5600 元 |
| 总推广花费 | 1500 元 |
| 系列 ROI | (6800+9200)÷1500 = **10** |
| 系列费比 | 1500÷5600 ≈ **26.79%** |
| 退款率 | 6100÷11000 ≈ **55.45%** |

**红绿灯判定**：
- 系列 ROI = 10 ≥ 目标 ROI = 8 → **绿灯**
- 系列费比 = 26.79% > 目标 25%，但 ≤ 25%×1.2 = 30% → **黄灯**
- 最终判定：**系列黄灯**（投产绿灯 + 费比黄灯）

**问题分析**：
1. 退款率 **55.45%** 远高于行业均值 30%，导致净成交偏低，费比超标
2. 间接成交占比 **57.5%** 高，说明引流与成交宝贝协同效果好
3. 转化率 **1.19%** 低于行业均值 1.8%，宝贝基础优化有提升空间

**三阶段调优**：

| 阶段 | 核心动作 | 效果 |
|---|---|---|
| 第一阶段 | 优化详情页；切换出价目标为"净成交金额" | ROI=9.2 绿灯，费比=22.8% 绿灯 → **双绿灯** |
| 第二阶段 | 增加总预算 30%（+500 元 → 竞争航线） | 14 天净成交 9.2 万元 |
| 第三阶段 | 预算增至 2500 元/天，拉新占比 50% | 月净成交 **41.85 万元**，超额完成目标 |

## 七、避坑指南

| # | 坑 | 破法 |
|---|---|---|
| 1 | 模板公式失效 | 粘贴时必须"选择性粘贴→值"，不修改表头和公式单元格 |
| 2 | 数据不一致 | 以生意参谋的宝贝 ID 为准，统一无界数据的宝贝 ID |
| 3 | 间接成交重复计算 | 按"系列"汇总数据，避免跨系列重复计算 |
| 4 | 退款率异常 | 大促期间凑单退款多，需在目标拆解时提高预估退款率 |
