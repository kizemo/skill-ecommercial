## 一、两大核心公式

### 1.1 成交机会（流量承接力）

```
成交机会 = f(优先展现权激活人数 × 货品曝光场域数量 × 匹配商品数量)
```

| 因子 | 商家可控性 | 说明 |
|---|---|---|
| 优先展现权激活人数 | ✅ 核心可控 | 消费者点击广告即激活，人群越精准价值越高 |
| 货品曝光场域数量 | ✅ 可控 | 多场域布局，全域承接流量 |
| 匹配商品数量 | ✅ 可控 | 多宝贝运营（裂变而非铺货） |
| fx（算法权重） | ❌ 不可控 | 平台算法黑箱，商家无需猜测 |

**运营核心思路**：在无法改变平台算法的前提下，通过优化三大可控因子的数值，实现成交机会最大化。

**关键理解**：这是一个**乘法公式**——任何一项为 0，整体为 0。只有 5-8 个子链接、却只投搜索一个场域，成交机会依然上不去；反过来铺了 6 个场域但只激活了 50 个精准人群，也撑不起盘子。

### 1.2 成交规模（变现力）

```
成交规模 = AI→P 流转效率 × 人群资产总规模 × TA 人群浓度
```

| 因子 | 含义 | 提升手段 |
|---|---|---|
| AI→P 流转效率 | AIPL 各环节（认知→兴趣→购买→复购）的转化率 | 打标精准度、详情页/主图承接 |
| 人群资产总规模 | 沉淀下来的可触达人群总量 | 拉新计划持续投入 |
| TA 人群浓度 | 触达人群中目标画像的占比 | 人群溢价、竞品定向、达摩盘标签组合 |

> 知识库中"AI→P"指 AIPL 链路的兴趣激发到购买转化这一段；公式整体对应 O-AIPL 全链路的流转效率。

### 1.3 两条公式怎么用

- **成交机会是"天花板"**：决定你能接到多少流量。
- **成交规模是"兑现率"**：决定接到的流量能变成多少成交。

**诊断顺序**：先看成交机会（承接力），再看成交规模（变现力）。
承接力不够 → 铺多品多域；变现力不够 → 修流转效率、人群浓度、承接页。

## 二、从"曝光逻辑"到"资产逻辑"

| 维度 | 传统曝光逻辑 | 现有人群资产逻辑 |
|---|---|---|
| 核心目标 | 追求"更多人看到" | 追求"更对的人看到" |
| 运营重点 | 优化标题、主图、提升点击率 | 建立人群资产、激活优先展现权 |
| 商品策略 | 少而精（控制在线商品数量） | 多而优（裂变增加有效匹配数量） |
| 场域策略 | 聚焦搜索/推荐单一渠道 | 全场域布局，多点承接 |
| 推广逻辑 | 拉新为主，盲目扩大流量池 | 拉新+收割结合，精准激活临门一脚人群 |
| 投产比 | 低（1.0-2.0） | 高（3.0-5.0+） |

**范式切换的自检问题**：
- 你上个月的动作清单里，有几条是"改链接内容"的？→ 曝光逻辑。
- 有几条是"这个月激活多少人群资产、覆盖几个场域、裂变几个子链接"的？→ 资产逻辑。

## 三、窗口期判断

多品多域仍有窗口期。**当同行普遍采用时优势会减弱**，需抓住窗口期快速布局。

窗口期特征（需同时成立）：

| 特征 | 阈值 |
|---|---|
| 同行多链接占比 | **< 30%** |
| 多场域参与率 | **< 20%** |
| 行业 ROI | **> 4.0** |

**反向用法**：如果同行多链接占比已经 >50%、多场域参与率 >40%，说明红利期过了，继续铺链接只会摊薄人群资产和预算，**该转向单链接效率**（打标、承接、复购）。

## 四、人群资产与免费流量闭环

### 4.1 闭环逻辑

```
付费推广 → 精准打标新客户（L4/L5 为主） → 积累人群资产
人群资产放大 → 平台分配纯新流量、回收流量、动销流量
免费流量成交 → 降低推广依赖 → 实现稳定盈利
```

### 4.2 三类免费流量

| 类型 | 定义 | 与推广关联 |
|---|---|---|
| 纯新流量 | 直接通过搜索/推荐进入 | 无直接关联，由产品级别决定 |
| 回收流量 | 先点击付费广告，后自然搜索回访 | 推广打标的直接结果 |
| 动销流量 | 点击 A 产品后搜索购买 B 产品 | 推广打标+全店动销布局 |

### 4.3 人群资产的核心价值

- **规模决定推广难度**：人群资产越大，推广越容易。
- **上新即有流量**：人群资产充足的店铺，新品可直接获得动销流量。
- **抗风险能力强**：规则调整时仍能稳定获取免费流量。

### 4.4 付费不可替代免费，但免费已计入付费

部分品类免费成交占 82%+，说明人群资产的厚度决定免费流量的分配。这也是为什么"成交机会"公式把**激活人数**放在第一位——它是后面两个因子的前置条件。

## 五、万相台无界的本质

万相台 = **从流量采买到人群资产经营的升级**。核心不再是"买多少流量"，而是"沉淀多少可触达的人群资产"。

**人群资产三要素**（与成交规模公式一一对应）：
1. 匹配商品数 —— 商品与人群越匹配，人群资产越多
2. 流转效率 —— O→A→P→I 各环节转化率
3. 人群浓度 —— 触达人群中目标人群占比

**出价决策**：
- 安全出价 = 系统建议价 × 0.7
- 手动出价 = 低出高溢（拉新低出、收割高出）
- 付免联动 = 付费带动免费流量
