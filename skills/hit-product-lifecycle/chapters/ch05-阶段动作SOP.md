## 二、四大付费工具的四阶段配比

| 阶段 | 直通车 | 引力魔方 | 全站推广 | 超级短视频 |
|---|---|---|---|---|
| 打标期 | ★★★★★ | ★★☆☆☆ | ☆☆☆☆☆ | ★★☆☆☆ |
| 起量期 | ★★★★☆ | ★★★★☆ | ★★☆☆☆ | ★★★☆☆ |
| 爆发期 | ★★★☆☆ | ★★★☆☆ | ★★★★★ | ★★★★☆ |
| 稳定期 | ★★☆☆☆ | ★★☆☆☆ | ★★★★☆ | ★★★☆☆ |

**工具定位**：

| 工具 | 核心定位 | PPC | 人群精准度 | 适用场景 |
|---|---|---|---|---|
| **全站推广** | 放量+收割 | 中 | 中 | 搜索少的店铺、动销款 |
| **直通车** | 拉新+关键词 | 高 | 高 | 标品、高客单 |
| **引力魔方** | 高端人群拉新 | 低 | 极高 | 高客单、竞争渗透 |
| **超级短视频** | 种草+拉新 | **最低** | 中 | 所有品类 |

**工具级操作要点**：

- **直通车**：打标期用精准长尾词（5-10 个），起量期加入核心热词，稳定期维护行业大词排名。人群溢价：核心人群 100%+，行为人群（浏览未购买）150%+，相似店铺人群 80%+。出价：初期高出价低日限额，中期稳定出价，后期降低出价维持排名。ROI 参考：标品 1:3~1:8，非标品 1:2~1:5。
- **引力魔方**：人群选择（智能定向 / 自定义人群 / 达摩盘人群）；资源位选择（手淘首页猜你喜欢=最大流量位，购后推荐位=竞争小，购中推荐位=转化率高）；出价低出价高溢价 + 重点资源位单独溢价。
- **全站推广**：ROI 目标按毛利率反推（毛利率 30% → ROI 目标 ≥1:3）；预算不要一次性全压，分批次测试；实时监控 GSV 产出，超成本立即调整。**打标期和起量期不建议用。**
- **超级短视频**：15-30 秒黄金时长，9:16 竖版；真人出镜效果更好；达人合作+自播结合；收推素材（将小红书/抖音内容二次投放淘宝）降低制作成本。**唯一有效出价：最大化转化出价**（不用自定义/控投产）。测试期触点级出价 + 多素材（5-10 条）；放量期长效转化最大化 + 单素材（1-2 条）集中。核心指标：潜客占比（目标 60%-80%）+ 盈利性。预算占整体推广预算 10%-20%。

## 四、三大营销场景的联动（阶段推进的底层逻辑）

当前淘系流量分发依托三大营销场景，所有运营动作、付费计划、流量获取都围绕三大场景展开，且**必须实现场景联动、购物意图统一**。

| 场景 | 核心 | 定位 | 作用 | 对应阶段 |
|---|---|---|---|---|
| **搜索场景** | 关键词推广 | 最能直接体现用户实时购物意图，是店铺流量种子 | 锁定精准购物意图、积累初始样本 | **打标期** |
| **推荐场景** | 人群推广 | 基于搜索沉淀的样本，召回相似人群、放大流量 | 二次/多次触达，提升转化与复购 | **起量期** |
| **AI 智能场景** | 智能计划/全站推广 | 依托大模型自动分配流量、智能出价 | 放大资产 | **爆发期** |

### 铁律：无样本不碰 AI 智能场景

- 无样本时，AI 无法识别店铺精准人群，只会推送泛流量
- 正确逻辑：**先通过搜索+推荐建样本、积资产，再用 AI 放大**

**联动要求**：搜索场景的关键词 = 推荐场景的兴趣点 = AI 场景的样本数据。若场景割裂，店铺样本会散乱，系统无法识别成交方向。

**这就是"打标期不上全站推广"的根本原因**——不是全站不好，是**没样本的时候上全站等于花钱买泛流量**。

## 五、人群放量三步法

配合阶段切换使用。

### 第一步：精准蓄水

**目标**：积累精准人群资产
**动作**：直通车精准拉新 + 超级短视频种草 + 小红书内容种草
**判断标准**：人群包规模达到一定量级；标签准确度高

### 第二步：标签放大

**目标**：扩大精准人群规模
**动作**：逐步降低人群精准度；扩展相似人群；增加推荐流量
**判断标准**：人群规模增长；**转化率下降不超过 20%**

### 第三步：全站放量

**目标**：最大化 GMV 产出
**动作**：全站推广介入 + 活动配合 + 内容联动
**判断标准**：ROI 达到预期目标；GSV 持续增长

**"转化率下降不超过 20%"是关键红线**——放量必然降转化，但降幅超 20% 说明放太宽了，该收回来。

## 六、阶段动作明细

### 6.1 打标期

**目标**：让产品获得精准人群标签，获得平台初始流量池的认可

| 动作 | 说明 | 执行要点 |
|---|---|---|
| 基础权重建立 | 完成破零销量 | 10-30 单真实成交 |
| 人群精准化 | 吸引目标客群 | 精准搜索词、精准人群溢价 |
| 标签积累 | 积累产品初始标签 | 直通车精准匹配 + 浏览行为引导 |
| 基础评价 | 基础评价和买家秀 | 引导真实购买用户评价 |

**标签策略**：精准长尾词不用大词；人群溢价 ≥70%；地域和时间段精准投放；参考指标收藏加购率 ≥10%。

**避坑**：
- ❌ 标签未明确时大量投放（浪费预算）
- ❌ 用低价 SKU 引流的非目标人群
- ❌ 找鱼塘做非标签流量

### 6.2 起量期

**目标**：在打标期标签基础上，逐步放大流量规模

| 动作 | 说明 | 执行要点 |
|---|---|---|
| 词路扩展 | 从长尾词扩展到核心词 | 转化率稳定后再扩展 |
| 人群放大 | 从精准人群到宽泛人群 | 逐步降低人群溢价比例 |
| 流量渠道扩展 | 增加推荐流量 | 超级短视频种草 |
| 付费推广加码 | 直通车/引力魔方增量 | 全站推广辅助起量 |

**判断标准**：搜索流量每天增长 10%+；转化率稳定在行业均值以上；收藏加购率维持 8%+；动态体验分稳定。

### 6.3 爆发期

**目标**：通过叠标玩法和放量策略，实现流量和成交的集中爆发

| 动作 | 说明 | 执行要点 |
|---|---|---|
| 叠标放大 | 多标签叠加扩大人群 | 爆标 + 潜力标签组合 |
| 全站推广介入 | 最大化流量获取 | 设置合理 ROI 目标 |
| 活动参与 | 借助平台活动势能 | 聚划算/天天特卖/百亿补贴 |
| 内容联动 | 短视频+直播组合 | 打造内容成交峰值 |

**放量公式**：`爆发量 = UV价值 × 人群规模 × 标签匹配度`

**注意**：爆发期需要充足的库存和客服支撑；不要因为流量爆发降低服务体验；实时监控动态体验分。

### 6.4 稳定期

**目标**：维持爆款生命周期，推爆下一个链接

| 动作 | 说明 | 执行要点 |
|---|---|---|
| 持续维护 | 维持搜索排名 | 保持基础销量和评价 |
| 迭代优化 | 优化主图/详情页 | 通过数据反馈迭代 |
| 爆款延伸 | 布局下一个爆款 | 同类型产品矩阵 |
| 清仓处理 | 库存清理 | 临期/过季产品特价 |

**核心指标**：月销量稳定在一定量级；退款率控制在合理范围；动态体验分持续稳定。

## 七、阶段速查：当 X 时做 Y

| 情况 | 动作 |
|---|---|
| 刚上新、还没有基础销量 | 直通车打标 + 超级短视频种草；不碰全站推广 |
| 有销量但没有精准人群 | 直通车拉新 + 引力魔方测试；开始建搜索样本 |
| 搜索流量自然增长、转化率稳定 | 进入起量期：开超级短视频、提首单礼金到 20%-30%、报秒杀 |
| 基础销量达 50 单 | 立即报名秒杀 |
| 日均销量达 100 单 | 自动获得热销爆品标；进入爆发期：叠标 + 全站放量 |
| 日均销量达 100 单以上且自然搜索占比 30%+ | 智能单品计划可关闭 |
| 付费 ROI 达到预期、人群规模足够大 | 进入爆发期，加全站推广放量 |
| 冲进类目前五 | 自动获得超级单品标；进入稳定期：降付费占比 |
| 销量增速放缓、接近天花板 | 进入稳定期：降首单礼金直到取消、秒杀换百亿补贴、推下一个链接 |
| 退款率上升、体验分掉 | 立即停放量，先修物流和服务（<4.6 会失去搜索权重，<60 会彻底断流） |
| 爆了但没赚到钱 | 算 CQ：<0.5 是昙花一现，别加长期预算 |
| 品类周期是低客单标品（5 个月） | 耐心等，别在第 8 天判死刑；看 LQ 是否仍 >0.6 |
| 转化周期 >15 天 | 必须加追投计划（见 [[wanxiangtai-wujie]]） |

## 八、常见误区

| 误区 | 事实 |
|---|---|
| ❌ 开了全站推广就会有流量 | 前提是产品本身在搜索流量池有竞争力；**无样本不碰 AI 场景** |
| ❌ 全站推广会吃掉搜索流量 | 付费成交提升权重，反而增加自然搜索 |
| ❌ 推广问题在推广中解决 | **推广的问题要在单品中找答案** |
| ❌ 爆款能直接赚钱 | 爆款 = 引流工具 + 层级工具；利润靠 A 级承接 + 私域复购 |
| ❌ 标签越多越好 | 标签权重是加法但阶段错配会打架；打标期要**单一精准**，不是更多 |
| ❌ 打标期就要报百亿补贴 | 打标期要的是精准标签（新品标+首单礼金+超级立减）；百亿补贴是成熟期活动且计入最低价 |
| ❌ 爆了就得长期加预算 | CQ <0.5 是昙花一现；费比不达标还会降级消费券补贴 |
