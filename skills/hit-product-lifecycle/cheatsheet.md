# 速查表 · hit-product-lifecycle

> 所有阈值均为知识库原文快照（2026 上半年口径）。标签规则、类目门槛、活动政策会变，报名前核对当期平台公告。

---

## 1. 四阶段速查

| 阶段 | 时间 | 目标 | 核心动作 | 标签组合 | 主投工具 |
|---|---|---|---|---|---|
| 打标期 | 1-7 天 | 新品标签初始化 | 多渠道打标+基础销量+素材 | 新品标+首单礼金+超级立减 | 直通车 ★★★★★ |
| 起量期 | 8-15 天 | 进类目前 20 | 超级短视频+首单礼金+秒杀 | 新品标+首单礼金+秒杀 | 引力魔方 ★★★★☆、超短 ★★★☆☆ |
| 爆发期 | 16-30 天 | 进类目前五 | 全站放量+叠标+竞品截流 | 热销爆品标+秒杀+首单礼金+购物金+淘金币 | 全站推广 ★★★★★ |
| 稳定期 | 31 天+ | 整体盈利 | 降付费占比+多链接+私域 | 超级单品标+百亿补贴+购物金+淘金币 | 全站推广 ★★★★☆ |

> ⚠️ **口径冲突，需复核**：`爆款打造四阶段运营SOP` 记为 1-14 / 15-30 / 31-60 / 60天+。本表采用 1-7 / 8-15 / 16-30 / 31天+（与 [[taobao-ops-playbook]] 一致）。

### 阶段切换信号

| 切换 | 信号 |
|---|---|
| 打标 → 起量 | 搜索流量开始自然增长，转化率稳定 |
| 起量 → 爆发 | 付费 ROI 达到预期，人群规模足够大 |
| 爆发 → 稳定 | 销量增长放缓，接近天花板 |

## 2. 阶段硬指标

| 指标 | 打标期 | 起量期 | 爆发期 | 稳定期 |
|---|---|---|---|---|
| 基础销量 | 10-30 单真实成交 | 50 单后报秒杀 | 日均 100 单 | 维持基础销量与评价 |
| 收藏加购率 | ≥ 10% | 维持 8%+ | — | — |
| 搜索流量 | 自然增长 | 每天增长 10%+ | — | 维持搜索排名 |
| 转化率 | — | 稳定在行业均值以上 | 提升 | — |
| 人群溢价 | ≥ 70% | 逐步降低 | 溢价放大 | 精准化 |
| 关键词 | 精准长尾词，不用大词 | 扩展到核心词 | 竞品截流 | 维护行业大词 |
| 标签数量 | 单一精准 | 扩展 | 多标签叠加 | 优化替换 |
| 活动 | 超级立减 | 秒杀 | 聚划算/天天特卖/百亿补贴 | 降付费占比 |

## 3. 三公式判定表

| 公式 | 构成 | 阈值 |
|---|---|---|
| **LQ**（要不要投） | 收藏加购率×40% + 关键词质量×30% + 价格力×30% | >0.6 有潜力 / <0.4 放弃 |
| **BQ**（能不能爆） | 坑产超越系数×45% + 增长率×35% + 转化率×20% | >1.2 进爆款通道 / >1.5 爆款确认 |
| **CQ**（值不值） | 利润率×40% + 复购率×30% + 客户满意度×30% | >0.8 可持续 / <0.5 昙花一现 |

**顺序**：LQ 不过不投 → BQ 不过不爆 → CQ 不过不长期投。

## 5. 标签申请门槛

| 标签 | 条件 |
|---|---|
| 超级单品标 | 店铺层级 H4 以上 + 近 30 天 GMV 达类目 TOP10 + 动态体验分 ≥4.8 + 好评率 ≥98% |
| 平台自检标 | 有自己的工厂或稳定供应链 + 商品通过平台质量检测 + 配合平台小二实地考察 |
| 热销爆品标 | 日均销量达 100 单后自动获得 |
| 新品标 | 上新后立即申请 |

## 6. 品类周期（时间轴等比缩放）

| 品类 | 全周期 | 特点 | 打法 |
|---|---|---|---|
| 非标品（服饰） | 15-20 天 | 决策快、复购低 | 布局战、测款战 |
| 中客单标品（家居） | 约 3 个月 | 决策周期中等 | 阵地战、价格战 |
| 低客单标品 | 约 5 个月 | 竞争激烈、规模效应 | 阵地战、价格战 |
| 高客单（1000元+） | 45 天+ | 竞争小、利润高、决策长 | 阵地战 + 必须上追投 |

**爆款三型**：标品=销量主导（阵地战+价格战）｜非标品=款式主导（布局战+测款战）｜半标品=混合型（偏标/偏非标差异化）。

## 7. 平台硬门槛

| 项 | 阈值 | 后果 |
|---|---|---|
| 店铺体验分 | < 4.6 | 失去搜索权重、无法报名大促 |
| 商品体验分 PXI | < 70 | 流量负向影响 |
| 商品体验分 PXI | < 60 | **彻底断流** |
| 费比 | 低于去年同期 | 消费券从平台全资降为商家混资/全资 |
| 价格力 | 不过线 | **直接被踢出活动** |
| 淘客佣金 | — | **不计入商业化权重**，拉不动权重 |
| 特定 ROI 坑位 | — | 只有一个坑位，竞品降 ROI 会抢走流量 |

## 8. 定价与扣佣

```
最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) × (1+扣佣比例)
```

> ⚠️ **口径冲突，需复核**：另一版为 `... ÷ (1−扣佣比例)`（[[taobao-ops-playbook]] 采用）。扣佣 20% 时两版差 40% 以上，**定价前确认当期口径**。

**案例**：成本 40 元 → 定价 133 元（预留 25% 扣佣空间）→ 20% 首单礼金 → 消费者实付 106 元 → 扣佣 26.6 元 → 实际收入 79.4 元 → **每单毛利 39.4 元**。

**不计入最低价**：首单礼金/新品礼金/店铺优惠券/购物金/淘金币/超级立减/会员专享
**计入最低价**：百亿补贴/秒杀/跨店满减/直降

## 9. 决策树：这个链接怎么处理

```
新链接/新品
├─ 算 LQ
│  ├─ <0.4 → 放弃，腾出预算
│  └─ >0.6 → 继续
├─ 打标期（单标签：新品标+首单礼金+超级立减）
│  ├─ 基础销量 10-30 单真实成交
│  ├─ 收藏加购率 ≥10%，人群溢价 ≥70%
│  └─ 基础销量达 50 单 → 报秒杀，礼金提到 20%-30% → 进起量期
├─ 起量期（超级短视频放大，搜索流量每天 +10%）
│  ├─ 日均销量达 100 单 → 获热销爆品标 → 进爆发期
│  └─ 付费 ROI 达预期 + 人群规模够大 → 进爆发期
├─ 爆发期（叠标 + 全站放量）
│  ├─ 冲进类目前五 → 获超级单品标 → 进稳定期
│  └─ 算 BQ：>1.2 进爆款通道 / >1.5 爆款确认
└─ 稳定期
   ├─ 算 CQ：>0.8 可持续 / <0.5 昙花一现 → 冲量后收手
   ├─ 降付费占比、秒杀换百亿补贴、礼金降到取消
   └─ 布局下一个爆款（多链接矩阵 + 私域）

需要临时扩量
├─ 精准蓄水（直通车+超短+小红书种草）
├─ 标签放大（转化率下降不超过 20%）
└─ 全站放量（ROI 达标 + GSV 增长）
   └─ 顺序不能反：搜索建样本 → 推荐放大 → AI 收割

点击率/转化率不达标
├─ 先查 SKU（★★★★★）和主图（★★★★☆）
├─ 再查买家秀、短标题、问大家
├─ 最后才动详情页（★★☆☆☆）
└─ 别忘了查体验分（<70 流量负向，<60 断流）和价格力

想报新活动
├─ 算价格力（比价全网）→ 过不了线直接被踢
├─ 算最低价（哪些计入、哪些不计入）
├─ 查店铺体验分 ≥4.6、商品 PXI ≥70
├─ 查费比不低于去年同期
└─ 查互斥（秒杀/百亿补贴/国家补贴 三选一）
```

## 10. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 打标期就上全站推广 | 无样本 → 买泛流量 | 无样本不碰 AI 智能场景；先搜索建样本 |
| 打标期报百亿补贴 | 成熟期活动+计入最低价，比价过不了 | 打标期用新品标+首单礼金+超级立减 |
| 标签乱叠（不按阶段） | 权重被稀释、扣佣吃掉利润 | 按四阶段组合表走 |
| 秒杀和百亿补贴一起报 | 报名失败 | 三选一 |
| 以为爆了就该长期加预算 | CQ<0.5 是昙花一现 | 三公式全过才长期投 |
| 用转化率评判新品 | 新品转化率天然低 | 新品看加购数据（LQ 权重 40%） |
| 第 8 天就判"这个品没起来" | 低客单标品周期 5 个月 | 按品类周期等比缩放，看 LQ |
| 爆发期不管库存客服 | 体验分掉 → 断流 | 库存和客服跟上，实时监控体验分 |
| 稳定期不减付费占比 | 费比不达标 → 消费券补贴降级 | 稳定期降付费 + 换标签 |
| 先改详情页 | 转化优先级最低，浪费 | SKU → 主图 → 买家秀 → 详情页 |
| 用低价 SKU 引流 | 引来非目标人群 | 引流 SKU 慎用，确认人群 |
| 指望淘客拉权重 | 淘客不计入商业化权重 | 别投 |
| 只看推广投产 | 高估付费效率 | 推广投产 vs 总投产，差值=免费流量占比 |
| 爆款当利润来源 | 利润被冲量吃掉 | S级引流 → A级利润 → 私域复购 |

## 11. 关键原则清单

1. **爆款是验证出来的，不是打造出来的**（`销售额 = 展现量 × 点击率 × 转化率 × 客单价`）。
2. **爆款基因 = 产品力 × 时机力 × 价格力**，缺一不可；价格力是 2026 第一权重。
3. **爆款 = 引流工具 + 层级工具，不是盈利工具**。
4. **阶段动作不可跨**；打标→起量看流量转化，起量→爆发看 ROI 和人群规模，爆发→稳定看增速。
5. **标签顺序不可反**：先打标（打准）→ 再叠标（堆权重）。
6. **人群放量的红线是转化率下降不超过 20%**。
7. **无样本不碰 AI 智能场景**。
