# 可复用方法 · hit-product-lifecycle

> 每条方法给出**何时用 / 怎么做 / 代价与风险**。数字均来自知识库原文快照。

---

## 1. 三公式准入闸门

**何时用**
任何新品准备投入、任何爆款准备加长期预算之前。**这是最省钱的一道闸门。**

**怎么做**
按顺序算三步，前一步不过就不用算后一步：

1. **LQ（要不要投）** = 收藏加购率×40% + 关键词质量×30% + 价格力×30%
   - >0.6 → 继续；<0.4 → 放弃，腾出预算和人群位置
2. **BQ（能不能爆）** = 坑产超越系数×45% + 增长率×35% + 转化率×20%
   - >1.2 → 进爆款通道；>1.5 → 爆款确认
3. **CQ（值不值）** = 利润率×40% + 复购率×30% + 客户满意度×30%
   - >0.8 → 可持续，值得长期投；<0.5 → 昙花一现，冲量后收手

**代价/风险**
- 三个因子的取值口径知识库未给统一定义，**先固定自己店铺的取值方式再横向比较**，否则公式不可复用。
- LQ 偏低的品即使 BQ 好看也难起量——**收藏加购率权重 40%，是硬门槛**。
- CQ 低但 BQ 高的品最容易让人误判：它已经爆了，数据很好看，但加长期预算会亏。**爆了不等于该继续投。**

## 2. 阶段判定与动作锁定

**何时用**
每次准备给链接加预算、改价格、报新活动之前。先确认它在哪个阶段。

**怎么做**
按信号判阶段，不按日期判：

| 阶段 | 切换信号 | 锁定动作 | 锁定标签 |
|---|---|---|---|
| 打标期 | 搜索流量开始自然增长、转化率稳定 | 多渠道打标、基础销量、素材 | 新品标+首单礼金+超级立减 |
| 起量期 | 付费 ROI 达到预期、人群规模足够大 | 超级短视频、礼金提到 20%-30%、报秒杀 | 新品标+首单礼金+秒杀 |
| 爆发期 | 销量增长放缓、接近天花板 | 全站放量、叠标、竞品截流 | 热销爆品标+秒杀+首单礼金+购物金+淘金币 |
| 稳定期 | — | 降付费占比、多链接矩阵、私域复购 | 超级单品标+百亿补贴+购物金+淘金币 |

**代价/风险**
- **跨阶段动作是纯浪费**：打标期报百亿补贴（成熟期活动且计入最低价），起量期上全站推广（无样本 = 买泛流量），稳定期还堆标签（叠标红利已过，只增加扣佣）。
- 时间轴要按品类等比缩放——**低客单标品整条链路 5 个月，别在第 8 天判死刑**。
- 阶段判定依赖数据窗口，**数据滞后时宁可保守**（留在上一阶段），不要激进跳阶段。

## 3. 叠标四段递进

**何时用**
打标期开始，到稳定期结束，贯穿整个生命周期。

**怎么做**
```
打标期：单一精准标签  → 新品标 + 首单礼金 + 超级立减
起量期：扩展          → 新品标 + 首单礼金 + 秒杀
爆发期：多标签叠加    → 热销爆品标 + 秒杀 + 首单礼金 + 购物金 + 淘金币
稳定期：优化          → 超级单品标 + 百亿补贴 + 购物金 + 淘金币
```

各阶段参数：
- 打标期：首单礼金 10%-20%，报名超级立减，完成 50-100 单基础销量和评价
- 起量期：基础销量达 50 单立即报秒杀，首单礼金提到 20%-30%，日均销量目标 100 单
- 爆发期：日均 100 单自动得热销爆品标，持续报秒杀，开购物金和淘金币
- 稳定期：冲进类目前五自动得超级单品标，礼金逐步降到取消，**秒杀换百亿补贴**

**代价/风险**
- **秒杀 ↔ 百亿补贴 ↔ 国家补贴 三选一**，不能同时报。
- 报活动前先算比价（价格力是第一权重），**价格不达标直接被踢出活动**。
- 稳定期换标签不是白换：百亿补贴和秒杀**计入最低价**，首单礼金/超级立减不计入——换之前要重新核最低价是否还能过线。
- 叠标是放大器，**基础权重（销量、评价、体验分）不够，叠多少标也起不来**。

## 4. 场景裂变（标品专属）

**何时用**
标品需要增加匹配商品数量、承接优先展现权、或想在多个场域铺开时。

**怎么做**
1. 列出 5-8 个真实消费场景，每个做一个独立子链接。
2. 主图、货号、详情页、标题全部差异化。
3. 子链接总数 ≤15 个。
4. 不同子链接分配到不同场域（引流款走百亿补贴/秒杀，品质款走小黑盒/88VIP）。
5. 只让主链接做拉新积累人群资产，场景链接等主链接的资产自然承接。

**代价/风险**
- 重复铺货会被平台处罚——差异化不彻底等于没做。
- 场景虚假化会被查（"母婴款"要提供安全检测报告）。
- 库存、客服、评价压力成倍上升。
- 参考（霍尼韦尔单店样本）：核心裂变链接支付金额 +450.63%、支付件数 +396.25%——**单店案例，不是行业均值**。

## 5. 高频上新淘汰（非标品专属）

**何时用**
非标品、款式是竞争力、搜索热度变化快的品类。

**怎么做**
1. 每周上新 3-5 款、每月至少 15 款，每类保持 10-15 款。
2. 选搜索热度高、竞争度低的细分款式。
3. 上新时同步做关联搭配链接。
4. 在线商品总数控制在 50-100 款。
5. 测款淘汰：靠 LQ（收藏加购率）筛，不靠转化率筛。

**代价/风险**
- 忌"数量＞质量"：款式同质化会分散流量，上新前先做款式差异化检测。
- 新品淘汰要快——**打标期 10-30 单真实成交就该看出信号**。
- 非标品整条生命周期只有 15-20 天，**上新节奏慢了就出局**。

## 6. 人群放量三步法

**何时用**
起量期到爆发期的过渡，以及需要临时扩量时。

**怎么做**
1. **精准蓄水**：直通车精准拉新 + 超级短视频种草 + 小红书种草。判断标准：人群包规模达标、标签准确度高。
2. **标签放大**：逐步降低人群精准度、扩展相似人群、增加推荐流量。判断标准：人群规模增长，**转化率下降不超过 20%**。
3. **全站放量**：全站推广介入 + 活动配合 + 内容联动。判断标准：ROI 达到预期、GSV 持续增长。

**代价/风险**
- **转化率降幅超 20% 就是放太宽了**，收回来。
- AI 智能场景必须放最后——**无样本不碰 AI 智能场景**，顺序错了等于花钱买泛流量。
- 放量的前提是搜索样本和推荐兴趣点已经统一；场景割裂时系统识别不出成交方向。

---

## 7. 场景联动（搜索→推荐→AI）

**何时用**
规划一个链接的流量结构时，以及解释"为什么打标期不能上全站"。

**怎么做**
1. 搜索场景（关键词推广）建样本：锁定精准购物意图、积累初始样本。
2. 推荐场景（人群推广）放大：基于搜索样本召回相似人群。
3. AI 智能场景（智能计划/全站推广）收割：依托大模型自动分配流量。

**联动铁律**：搜索场景的关键词 = 推荐场景的兴趣点 = AI 场景的样本数据。

**代价/风险**
- 场景割裂 → 样本散乱 → 系统识别不出成交方向 → 三头都不灵。
- 跳过搜索直接上全站 = 花钱买泛流量。**这是打标期最贵的错误。**
- 搜索流量本身在持续下滑（30 元以上商品免费搜索流量 <5%），搜索建样本要**快**。

## 8. 稳定期收手与复制

**何时用**
爆款进入稳定期，或爆款 CQ <0.5 需要判断是否继续。

**怎么做**
1. 算 CQ：>0.8 才值得长期投；<0.5 则冲量后收手，不加长期预算。
2. 降付费占比：降低全站推广预算，提高 ROI；降首单礼金比例直到取消。
3. 换标签：报名百亿补贴替代秒杀，冲进类目前五后拿超级单品标。
4. 做矩阵：同类型产品矩阵布局下一个爆款；爆款延伸 + 私域复购。
5. 清库存：临期/过季产品特价处理。
6. 持续维护：保持基础销量和评价，维持搜索排名；迭代主图/详情页。

**代价/风险**
- **费比不达标不只是利润问题**——商业化保费比强制要求广告花费占比不低于去年同期，不达标消费券从平台全资降为商家混资/全资。**爆款期高付费可以，长期挂着会降补贴资格。**
- 爆款是引流工具+层级工具，不是利润来源。**利润靠 A 级承接 + 私域复购**（见 [[profit-model]]、[[customer-asset-ops]]）。
- 稳定期不布局下一个爆款，等窗口关闭时手里没有牌。

## 9. 产品力体检（七维度）

**何时用**
打标期点击率或转化率不达标时；爆款 BQ 卡在 1.2 上不去时。

**怎么做**
按七维度逐项查：

| 维度 | 查什么 |
|---|---|
| 词维度 | 核心词放两端、长尾词放中间；类目词→属性词→长尾词 |
| 图维度 | 卖点突出、差异化、场景化、信任背书 |
| SKU 维度 | 引流 SKU/利润 SKU/锚定 SKU 结构 |
| 详情维度 | 痛点→解决方案→证据链→促销信息 |
| 视频维度 | 短视频权重（内容流量占 30%-40%） |
| 评价维度 | 口碑管理、信任背书 |
| 价格维度 | 成本/竞品/价值三种定价法 |

**代价/风险**
- 详情页优化优先级在转化链路里**最低**（SKU ★★★★★ > 主图 ★★★★☆ > 买家秀 ★★★★☆ > 短标题 ★★★☆☆ > 问大家 ★★★☆☆ > 详情页 ★★☆☆☆）。**先修 SKU 和主图，别先改详情页。**
- 词图匹配只是基本要求，**词图人匹配**才是高境界——只做到前者，转化会卡在行业均值。
- 引流 SKU 会带来非目标人群，**打标期用之前先确认人群对不对**。

## 10. 底价与活动资格自检

**何时用**
每次准备报名新活动之前。

**怎么做**
1. 算价格力：活动报名会自动比价全网同款/相似款，**过不了线直接被踢出**。
2. 算最低价：百亿补贴/秒杀/跨店满减/直降**计入**；首单礼金/新品礼金/店铺优惠券/购物金/淘金币/超级立减/会员专享**不计入**。
3. 查体验分：店铺 ≥4.6、商品 PXI ≥70（<60 彻底断流）。
4. 查费比：广告花费占比不低于去年同期，否则消费券补贴降级。
5. 查价力符合后再定标签组合。

**代价/风险**
- 体验分是**一票否决权**，不是扣分项：店铺 <4.6 直接失去搜索权重、无法报名大促。
- 稳定期把秒杀换成百亿补贴后，**必须重算最低价**——两个都计入最低价，但活动价不同。
- 淘客佣金**不计入商业化权重**，别指望用淘客拉权重。

## 11. 定价预留空间

**何时用**
新品定价、报活动前算到手价和毛利时。

**怎么做**
```
最终定价 = 成本价 × (1 + 毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) × (1 + 扣佣比例)
```
参考案例：成本 40 元，定价 133 元（预留 25% 扣佣空间），设 20% 首单礼金，消费者实付 106 元，扣佣金 26.6 元，实际收入 79.4 元，**每单仍有 39.4 元毛利**。

**代价/风险**
- ⚠️ **口径冲突，需复核**：知识库中该公式有两个版本——`爆款叠标打法全解` 用 **×(1+扣佣比例)**，`2026淘宝运营完整知识体系` 用 **÷(1−扣佣比例)**（[[skill-ecommercial]] 采用后者）。扣佣 20% 时两版结果差 40% 以上，**定价前必须确认平台当期口径**。
- 扣佣空间是**定价时预留的**，不是事后从利润里挤的。先定标签组合 → 再算扣佣比例 → 最后定定价。
