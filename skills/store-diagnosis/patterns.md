# 可复用方法 · store-diagnosis

---

## 领先率筛查法

**何时用**：任何一次"这个链接/这个店到底行不行"的判断之前；每月复盘；投放加预算之前。

**怎么做**：
1. 在生意参谋商品报表里取"新客成交"与"总成交"两个数，算 领先率 = 新客成交 ÷ 总成交。
2. 对照档位：≥ 80% 合格 / 70-80% KA 可接受 / 50-70% 资源浪费在收割 / < 50% 主要跑收割 / < 30% 几乎全是老客。
3. 店铺层算一遍，花销 Top5 品各算一遍，两个结果都要有。
4. 店铺层低但单品层正常 → 是货盘结构问题，交 [[sabc-product-tiering]]；单品层低 → 继续往下跑四层。

**代价/风险**：领先率只看新客成交占比，**分母里如果有大量低价或退款订单，会把领先率做低**；分子新客的判定口径（是否含 90 天内回头客）各家不同，先固定口径再连看多期。不同来源的档位表述存在差异（50-70% 档口径冲突，需复核）。

## 四层分析法（店铺体检）

**何时用**：投产数据异常、销售下滑、费率突然升高、准备做投放结构调整之前。

**怎么做**：
1. **第 1 层 营销产品报表**：看整体费率，找费率异常高的品、找"投产特别好但销售没增长"的品，产出异常品清单。
2. **第 2 层 商品报表**：按推广花费排序，对每个品算 间接成交 ÷ 直接成交。≈ 2 倍即判该品投放完全无效。
3. **第 3 层 单品视角**：对第 1、2 层命中的品算领先率，判定拉新还是收割。
4. **第 4 层 定向分析**：用归因切换找到收割型定向，出待停清单和预计月省金额。
5. 诊断阶段**只出结论和清单**，不调出价、不加预算、不改分级。

**代价/风险**：四层是漏斗，跳层会砍错品（只跑第 4 层会停掉正在拉新的计划）。耗时集中在第 2 层的商品报表排序，数据量大时限制在"花销前 5 品"。

## 直接 / 间接成交比排查法

**何时用**：某个品投产好看但财务反馈亏钱；怀疑广告在抢自然成交。

**怎么做**：
1. 商品报表按推广花费排序，取该品的直接成交数与间接成交数。
2. 间接 ≈ 2× 直接 → 该品投放完全无效，停投该品全部广告。
3. 间接远大于直接但不到 2 倍 → 广告基本在跑收割，改定向（关键词手动为主）、加强拉新。
4. 间接 < 直接 → 拉新链路有效，问题不在投放，转查转化链路。

**代价/风险**：直接/间接成交依赖生意参谋的归因字段，切换归因方式数值会变，**跨期比较必须用同一归因方式**。

## 归因切换验证法

**何时用**：投产"假好"；要停一个定向但不确定它在拉新还是在收割；复核任何广告效果的结论。

**怎么做**：
1. 报表归因方式从"每一次访问来源"切到**第一次访问来源**，记录各定向转化率。
2. 再切到**最后一次访问来源**，记录同一批定向的转化率。
3. 第一次访问转化率更高 → 拉新；最后一次更高 → 收割，进待停清单。
4. 结论写进诊断记录表：定向名、两次转化率、判定、预计月省金额。

**代价/风险**：默认归因会把同一次成交在多渠道重复计入，投产虚高。切换后短期内报表数值会与之前不可比，需要重新建立基线。

## 收割定向清理法

**何时用**：领先率低于合格线且已确认有收割型定向；月度费比异常高；需要立刻降费但不砍销售。

**怎么做**：
1. 从定向清单里挑出倾向收割的（智能推荐、全站优先）。
2. 逐个验证：转化主要落在"最后一次访问来源"，且间接成交显著高于直接成交。
3. 算收益：省下的广告费 = 被停定向的日均消耗 × 停投天数。
4. 按收益从大到小停，能停 1 个就不停 2 个。
5. 停后核对销售：案例基准是"销售没有任何变化"，有下滑就回滚。

**代价/风险**：停收割定向会短期减少总成交额（老客重复购买），数字上"销售没变"才成立，**任何下滑都要回滚**。别在不了解定向配置的情况下整包关引力魔方，它是拉新+收割混合。

## 顺逆差预算倾斜法

**何时用**：全店预算分配；单品之间争预算；月度推广复盘。

**怎么做**：
1. 统计各单品成交金额与推广花费，算各自占比。
2. 顺逆差 = 成交金额占比 − 推广花费占比。
3. 正向顺差 → 预算倾斜；负向顺差 → 优化或淘汰；零顺差 → 维持观察。
4. 推广投产 < 店铺均值的单品，**禁止盲目增加预算**；> 均值才可适当增加。
5. 每周复盘一次。

**代价/风险**：顺逆差是相对占比指标，**新品天然是负向顺差**（没成交占比却有花费占比），不能按老品标准砍。配合投产诊断的"新品看加购、老品看转化率"来用。

## 真实投产去伪法

**何时用**：向老板/合作方汇报投产时；判断一个链接是不是真的在赚钱；决定是否加预算。

**怎么做**：
1. 取三个折扣因子：退款率、间接成交占比、拉新成交占比。
2. 真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交。
3. 同时对比推广投产与总投产，差值即免费流量占比信号。
4. 真实投产与盈亏平衡 ROI（1 ÷ 毛利率）比，低于即亏损，交给 [[profit-model]]。

**代价/风险**：四个因子的口径必须同源同窗，尤其"拉新成交"要用与领先率一致的新客定义。公式化简后对单项误差很敏感，退款率与间接成交占比偏高会把结果压得过低。

## 红绿灯固化法

**何时用**：诊断出结论之后，防止下次重复犯错；需要把诊断指标交给团队每天执行。

**怎么做**：
1. 只选不超过 3 个关键指标（如店铺领先率、花销 Top5 品间接/直接比、月度费比）。
2. 每个指标定目标值（参考历史数据与行业均值，跳一跳够得着）。
3. 做表：指标名称 | 目标值 | 实际值 | 完成率 | 颜色 | 改进措施。
4. 绿=保持，黄=分析原因调整，红=重点关注并定改进计划；每月复盘一次。
5. 指标变成常态后换新的重点。

**代价/风险**：红绿灯不与绩效挂钩，一旦挂钩就变成打分游戏，团队会挑好看的指标上报。每部门不超过 3 个指标这条纪律破了，表格就没人看。
