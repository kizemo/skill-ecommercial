# 领先率与四层分析法

**来源笔记**：《店铺诊断四层分析法》（源：2025 年 6 月子尤老师精细化运营培训，status: verified）｜**层级**：L1 诊断主干

---

## 一、为什么是领先率（前比）

```
领先率 = 新客成交 / 总成交
```

领先率把"这个店/这个品是在拉新，还是在收割老客"压成一个数字。它不需要额外报表，不需要新建口径，翻开商品报表就能算。

**它同时回答两个问题**：

- 新客进没进来（分母里有没有新客）
- 钱是不是花在了收割老客上（总成交里老客占比越高，说明付费流量越可能在给老客抬轿）

**判定分档**：

| 领先率 | 店铺类型 | 判定 | 动作 |
|---|---|---|---|
| ≥ 80% | 普通店铺 | 合格线 | 拉新正常 |
| ≥ 70% | 头部 KA 卖家 | 合格线（高基数下难以拉高） | 继续积累 |
| < 50% | 任意 | 主要在跑收割，资源大量浪费 | 停收割型定向 |
| < 30% | 任意 | 几乎全是老客在买 | 拉新链路已断 |

> 口径注（**口径冲突，需复核**）：《店铺诊断四层分析法》原文只给三档（80 / 50 / 30）加"头部 KA ≥ 70%"。"50-70% = 资源浪费在收割"这一中间档出自 [[taobao-ops-playbook]]，其 `SKILL.md` 与 `cheatsheet.md` 对 "< 50%" 的措辞也不一致（前者写"主要在跑收割"，后者写"资源浪费在收割"）。用数字前先定口径。

**店铺层与单品层要分开看**：店铺领先率低，可能是某几个大品拖累；单品领先率低，说明这一个品的广告费在给老客抬轿。两者的处理动作完全不同：店铺级 → 查货盘结构；单品级 → 查该品的定向。

## 二、四层分析法：逐层操作

四层是**漏斗**。上层负责圈定范围，下层负责定位责任对象。跳层是诊断出错的主要原因。

```
第 1 层 营销产品报表（店铺报表）   → 圈出异常品
第 2 层 商品报表（按推广花费排序） → 判定该品投放是否有效
第 3 层 单品视角（领先率）        → 确认拉新 / 收割属性
第 4 层 定向分析                  → 定位到具体计划，停掉它
```

### 第 1 层：营销产品报表（店铺报表）

**目的**：看整体费率，发现异常品。

两个必答问题：

- 哪些品费率异常高？
- 哪些品投产特别好但销售没增长？

**不合格表现（典型掩盖场景）**：

```
店铺整体数据"很漂亮"（投产高）
   ↓
但每月销售持续下滑
   ↓
→ 问题被整体数据掩盖了
```

整体投产是**加权和**，某个高投产的大品可以把几个亏钱品的投产拉起来。所以第一层的产出不是结论，而是**一份需要单独复核的异常品清单**。

### 第 2 层：商品报表（按推广花费排序）

**操作**：按推广花费排序，逐个品看直接成交 / 间接成交比。

| 指标 | 含义 |
|---|---|
| 直接成交 | 用户通过广告直接点击后成交 |
| 间接成交 | 用户点击广告后，又通过其他渠道（如搜索）成交 |

**判断标准**：

| 表现 | 含义 | 动作 |
|---|---|---|
| 间接成交 >> 直接成交 | 广告基本在跑收割，拉新无效 | 优化定向，加强拉新 |
| 间接成交 = 直接成交的 2 倍 | 该品投放完全无效 | 停投该品全部广告 |
| 间接成交 < 直接成交 | 拉新链路在起作用 | 转查转化链路 |

**真实案例**：

> 某商品月花费 8000 元，投产"看起来很好"，但直接成交 13 笔、间接成交 24 笔。
> → 财务数据反馈：该品实际亏钱
> → 结论：该品不值得投放任何广告

这条案例的要点不在数字，而在**投产口径骗人**：广告把本来会走搜索成交的人先截了一遍，报表记成"广告带来的间接成交"，投产算的是广告费，而销售是本来就会发生的。这类品越投越亏。

### 第 3 层：单品视角（领先率）

**核心指标**：领先率（前比）。逐品算，与第 2 层得到的异常品清单交叉。

```
领先率 = 新客成交 / 总成交

领先率 ≥ 80% → 拉新正常
领先率 < 50%  → 主要跑收割，资源浪费
领先率 < 30%  → 几乎全是老客在买
```

**典型问题表现**：

- 某商品花费排名前 5
- 但领先率只有 50%
- → 这个品主要在收割，不是在拉新
- → 花的广告费只是让老客重复购买

第 3 层的作用是给第 2 层的异常品**定性**：是"效率低"还是"根本不该投"。

### 第 4 层：定向分析

**目的**：找到具体哪些定向在跑收割。

**判断方法**：哪些定向的转化主要发生在"最后一次访问来源"？这些定向就是在跑收割。

**优化动作**：

1. 找出跑收割的定向 → 直接暂停或关闭
2. 省下的广告费 = 直接的利润增加
3. 不影响销售（因为本来就在收割老客）

**真实案例**：

> 某同学店铺有 4 个定向
> 其中 2 个定向明显跑收割（智能推荐等）
> 去掉这 2 个定向后，每月省下 4 万元广告费
> 销售没有任何变化

"销售没有任何变化"是这个动作的**验收条件**。停定向前必须确认被砍的成交确实来自老客的重复购买，否则省下的广告费会变成流失的销售额。验证方法见 `ch02-报表与归因切换.md` 的归因切换法。

## 三、四层跑完之后的分流

| 结论组合 | 说明 | 去向 |
|---|---|---|
| 第 1 层异常 + 第 2 层间接 ≈ 2× 直接 + 第 3 层领先率 < 50% | 明确的无效投放 | 停该品广告 → [[sabc-product-tiering]] 调级 |
| 第 1 层正常 + 第 4 层存在收割定向 | 结构没问题，是定向配错了 | 停收割定向 → [[wanxiangtai-wujie]] 调计划 |
| 第 3 层领先率 < 30% | 拉新链路已断 | 补人群资产 → [[customer-asset-ops]] |
| 第 1 层销售下滑但各层都正常 | 不是投放问题 | 查产品竞争力与利润 → [[profit-model]] |
