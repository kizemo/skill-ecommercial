# 速查表 · store-diagnosis

> 所有阈值来自知识库原文快照（《店铺诊断四层分析法》等，2025-2026 口径）。平台报表口径会变，落地前核对当期生意参谋字段。

---

## 1. 阈值表

| 指标 | 健康线 | 低于此线的后果 |
|---|---|---|
| 领先率（前比）· 普通店 | ≥ 80% | <50% 主要跑收割；<30% 拉新链路已断 |
| 领先率（前比）· 头部 KA | ≥ 70% | 高基数下难拉高，别拿普通店标准考核 |
| 间接成交 ÷ 直接成交 | < 1 正常 | ≈ 2 倍 → 该品投放完全无效（停投） |
| 单品领先率 | ≥ 80% | <50% 该品在收割；<30% 几乎全是老客 |
| 推广投产 vs 店铺均值 | ≥ 均值才可加预算 | < 均值 → 禁止盲目增加预算 |
| 顺逆差 | > 0 预算倾斜 | < 0 优化或淘汰；= 0 维持观察 |
| 全站推广 ROI 目标 | 由毛利率反推（毛利率 30% → ≥1:3） | 设错即亏 |
| 直通车 ROI 参考 | 标品 1:3~1:8；非标 1:2~1:5 | 低于参考值先查定向再查出价 |

## 2. 决策规则（当 X 时做 Y，因为 Z）

| 当 | 做 | 因为 |
|---|---|---|
| 领先率 < 30% | 停收割型定向 + 转 [[customer-asset-ops]] 补人群 | 几乎全是老客在买，拉新链路已断 |
| 领先率 50-70% | 查定向与出价，不加预算 | 资源浪费在收割，先定位再谈增长 |
| 间接成交 ≈ 2× 直接 | 停投该品全部广告 | 该品投放完全无效（案例：月花 8000 元、直接成交 13 笔 / 间接 24 笔，实际亏钱） |
| 某品花费排名前 5 但领先率 < 50% | 暂停该品或重新测试 | 花的广告费只是让老客重复购买 |
| 店铺整体投产高但销售持续下滑 | 拆到单品层查费率 | 整体数据掩盖了个别异常品 |
| 投产"假好" | 切换到第一次 / 最后一次访问来源验证 | 默认归因重复计算 |
| 第一次访问转化率 > 最后一次 | 保留该定向 | 广告在跑拉新 |
| 最后一次访问转化率更高 | 该定向进待停清单 | 广告主要在跑收割 |
| 停定向后月省 4 万、销售无变化 | 继续清理其余无效定向 | 本来就在收割（案例：4 个定向停 2 个） |
| 推广投产 < 店铺均值 | 禁止盲目加预算 | 单品效率低于店铺水平 |
| 总投产持续下滑 | 检查产品竞争力 | 不是投放能解决的 |
| 顺逆差为负 | 优化或淘汰该品 | 花钱多产出少 |
| 出价模式与阶段不匹配 | 换出价模式再调价 | 错误的出价模式直接抬高成本 |

## 3. 决策树

```
投产好看 / 销售下滑
├─ 切归因方式（第一次 vs 最后一次访问来源）
│  ├─ 最后一次转化率更高 → 收割型定向 → 停该定向（验证间接>直接再停）
│  └─ 第一次转化率更高 → 在拉新 → 继续往下查
├─ 按推广花费排序看商品报表
│  ├─ 间接 ≈ 2× 直接 → 该品投放完全无效 → 停投该品
│  ├─ 间接 >> 直接 → 收割为主 → 改定向（关键词手动为主）
│  └─ 间接 < 直接 → 转查转化链路（[[conversion-optimization]]）
└─ 查领先率（前比）
   ├─ ≥ 80% → 拉新正常 → 转查流量规模与人群浓度（[[customer-asset-ops]]）
   ├─ 70-80% → KA 区间 → 继续积累
   ├─ 50-70% → 资源浪费在收割 → 查定向与出价
   ├─ < 50% → 主要跑收割 → 停收割型定向
   └─ < 30% → 几乎全是老客 → 拉新链路已断 → 补人群资产

新链接没流量
├─ 搜索端有词但没点击 → 主图点击率不达标 → 测图（[[keyword-promo]]）
├─ 搜索端根本没词 → 补词路选款（[[selection-testing]]）
└─ 有展现无转化 → SKU / 主图 / 评价链路（[[conversion-optimization]]）

要停一个定向
├─ 倾向收割型（全站 / 智能推荐）？ ──否→ 不停，先查配置
├─ 转化主要落在最后一次访问来源？ ──否→ 不停，它在拉新
├─ 间接成交显著高于直接成交？ ──否→ 只观察，不停
└─ 是 → 算月省金额 → 按收益从大到小停 → 核对销售，下滑即回滚
```

## 4. 定向分类速查

| 定向类型 | 倾向 | 说明 |
|---|---|---|
| 关键词（手动） | 拉新为主 | 精准锁定搜索人群 |
| 引力魔方（半智能） | 拉新+收割混合 | 看具体配置 |
| 全站 | 收割为主 | 基于店铺人群资产快速收割 |
| 智能推荐 | 收割为主 | 系统探索，不可控 |
| 货品加速 | 渠道扩充 | 不具备人群放大作用 |

## 5. 日常节奏

| 频率 | 动作 | 看什么 |
|---|---|---|
| 每天 | 营销产品报表 | 整体费率是否异常 |
| 每天 | 商品报表 | 花销前 5 品间接成交比是否过高 |
| 每天 | 单品领先率 | 是否 < 80% |
| 每周 | 定向分析 | 清理跑收割的定向 |
| 每周 | 竞品监控 | 调整出价策略（先确认自己跑拉新还是收割） |
| 每月 | 诊断记录复盘 | 上一轮清单的命中率 |

## 6. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 只看店铺整体投产 | 整体漂亮但单品在亏 | 按花费排序看商品报表 |
| 用默认归因（每一次访问来源） | 重复计算，投产虚高 | 切第一次 / 最后一次访问来源 |
| 看推广投产不看总投产 | 高估付费效率 | 对比两者，差值 = 免费流量占比信号 |
| 把间接成交当增量 | 投产好看，实际没带来新客 | 间接 ≈ 2× 直接即停投 |
| 领先率档位口径混用 | 同一数据判出两种结论 | 先定档位口径（50-70% 档口径冲突，需复核） |
| 诊断阶段就改出价加预算 | 同一份数据被反复动 | 诊断只出清单，变更交对应 skill |
| 整包关引力魔方 | 拉新位被一起砍掉 | 引力魔方是混合型，按具体配置拆 |
| 把新品按顺逆差砍掉 | 新品天然负向顺差 | 新品看加购、老品看转化率 |
| 停收割定向不复核销售 | 销售额掉了才发现 | 案例基准是"销售无变化"，有下滑即回滚 |
| 拿竞品数据直接改出价 | 跟着别人的坑位跑 | 先判自己跑拉新还是收割 |
