# 可复用方法 · conversion-optimization

> 每条格式：**何时用** / **怎么做** / **代价与风险**。
> 这些是可重复动作，不是知识点的复述。

---

## 1. 流失点定位法（30 秒决定改哪里）

**何时用**：任何"有流量没成交"的报修；每周例行体检。

**怎么做**：
1. 按决策链路逐段问："用户在哪一步走的？"——搜索结果页 / 商品页 / 评价区 / 加购 / 详情页；
2. 对照优先级表定动手顺序：**SKU → 主图 → 买家秀 → 短标题 → 问大家 → 详情页**；
3. 只挑**一个**环节先改，改完留出观察期；
4. 改完再跑一遍定位，看流失点是否下移。

**代价与风险**：**"详情页最不重要"是指投入产出比，不是"可以不写"**——详情页承接能力对应 8 维度里的"停留时长"。用链路表定位、用优先级表排序，两张表混用会改错地方。

---

## 2. 主推 SKU 锁定法（配合"推荐最适合的 SKU"）

**何时用**：一个品有多个 SKU；搜索推荐不推你的品；不知道该把资源压在哪一档。

**怎么做**：
1. 明确**一个**主推 SKU，其余是引流档 / 利润档 / 锚定档；
2. 把标签、服务项、氛围元素、库存全部压到主推 SKU；
3. 主推 SKU 的价格放在用户比价时最常停留的档位（通常是中间档）；
4. 主推 SKU 的销量会反过来推高整个链接的推荐权重 —— 所以主推 SKU 卖不动，先查 SKU 设计（价格/命名/标签），**不要先改详情页**。

**代价与风险**：所有 SKU 平均用力 = 没有任何 SKU 被推荐。**多 SKU 不等于每档都推。**

---

## 3. SKU 五要素补全法（逐项打勾）

**何时用**：转化率低但有加购；新上 SKU；竞品同款明显更敢买。

**怎么做**：
1. **短标题**：写成"高级哑光黑-亲肤材质"，不是"黑色"；
2. **标签**：热销爆款 / 店长推荐 / 新品上市；
3. **服务项**：7 天无理由退换、顺丰包邮、终身质保；
4. **价格**：清晰展示（配合锚定法）；
5. **氛围元素**：火焰、爆炸、箭头营造热销氛围；
6. **补一句从众引导**："70% 的人选择""99% 的买家推荐"。

**代价与风险**：五要素齐了但**主图与 SKU 图说的不是一回事**，会同时掉点击率和转化率。改 SKU 要和主图联动。

---

## 4. SKU 搜索图三步升级

**何时用**：搜索结果页点击率低（主图改了也没用）；任何一次改版。

**怎么做**：
1. 进商品编辑页 → **SKU 搜索图**；
2. **按主图标准**做：卖点 + 价格 + 服务项清晰可见；
3. 删掉简单白底图版本。

**代价与风险**：**搜索页展示的是 SKU 搜索图，不是主图**。只改主图不改 SKU 搜索图，等于搜索端什么都没变——这是"改了很多但搜索点击率没动"的最常见原因。

---

## 5. SKU 标题词布局法（用 SKU 拿免费长尾流量）

**何时用**：主标题已排满；想做长尾词覆盖；AI 万能搜匹配不到词。

**怎么做**：
1. 列出主标题已占的词（核心词、属性词）；
2. 把**长尾词、人群词、场景词**写进 SKU 标题（如"家用 老人 静音 臂式"）；
3. 用用户常用自然语言描述（参考 AI 万能搜的问法："能放进书包的保温杯"）。

**代价与风险**：SKU 标题堆词会影响可读性，**每条 SKU 标题保持 1-2 个补充词**。堆太多反而拉低点击。

---

## 6. FABE 补 Evidence 法（修主图说服力）

**何时用**：主图有点击无转化；详情页跳失高；差评集中在"不信"。

**怎么做**：
1. 先写清 F（特征）→ A（优点）→ B（利益）；
2. **E（证据）从零补**：服务承诺（90 天免费试用 / 7 天无理由）→ 量化背书（10 万+好评、销量、复购率）→ 资质检测 → 第三方评价（榜单截图、达人推荐、复购截图）；
3. **一份证据复用四处**：评价区、主图第二张、SKU 图、详情页证据链；
4. 验证：主图第二张的职责是"背书"，第三张的职责是"收益"。

**代价与风险**：证据必须**真实**。虚构销量、虚假榜单、虚假冠军标属虚假宣传，医疗器械类目另有禁用词表（[[compliance-medical]]）。**补 Evidence 的前提是先有真的 Evidence。**

---

## 7. 榜单/证据三处同步法

**何时用**：新品刚上一笔成交；活动拿到名次；获评优质内容。

**怎么做**：
1. 上榜（新品最容易上**幸运榜**，一笔成交就可能第一名）→ **立即截图**；
2. 截图加到**副图、SKU 图、店铺装修**三处；
3. 同步写进详情页**证据链**段。

**代价与风险**：榜单会变，**过期截图是负资产**（用户点进来发现榜单早没了）。定期核对并更新。

---

## 8. 问大家覆盖补齐法（低成本信任）

**何时用**：问大家区空白或问题太少；客服/差评里反复出现同一疑问。

**怎么做**：
1. 汇总三个来源：客服高频问题、差评里的疑问、详情页证据链没答上的点；
2. 每条疑问写成"消费者会怎么问"；
3. 回答写成"真实 + 详细 + 有使用体验"，末尾带明确解决方案，可加核心卖点、适当引导下单。

**代价与风险**：素材里的"多账号批量覆盖"是**灰色手法**，风险高。**用真实账号做真实回答**成本并不高，且能长期累积。

---

## 9. 买家秀生产与追评节奏（合规优先）

**何时用**：需要评价区撑起信任；新品期缺评价。

**怎么做**：
1. 优先走**真实买家**与**官方工具**（新品直销：扫码加购 → 退出 → 搜索半标题或品牌词下单，计入搜索权重；一个账号**最多 6 单**）；
2. 需要提效率时用**单人多单法**（6-10 个 SKU 各发一条，评完删除多余 SKU）+ **匿名评价**；
3. **追评不早于收货后 7-15 天**，内容真实可信；
4. 素材另记了"适量负面评价显得真实"的做法——**本 skill 不建议采用**。

**代价与风险**：批量操作有被风控识别的风险，2026 年虚假交易处罚主要是**删除销量和评价**（不扣分不封店），但会直接打掉你刚补的信任资产。**先评估店铺体量能否承受。**

---

## 10. 详情页四段重排法

**何时用**：详情页跳失高；新做详情页；促销信息前置导致跳失。

**怎么做**：
1. 按 **痛点挖掘 → 解决方案 → 证据链 → 促销信息** 重排；
2. 核心信息**前置到前 3 屏**；
3. 用模板或 AI 工具生成，**图文结合、少文字**；
4. 排完再补防跳失三招：**九宫格后置 → 长白底图法（"已经到底了"）→ 底部关联**。

**代价与风险**：**促销信息提到最前 = 跳失更快**。防跳失三招是收尾工程，**不解决"第一眼有没有被抓住"**——顺序不能反。

---

## 11. 价格锚定 + 三角色 SKU 法（提客单价）

**何时用**：客单价长期不涨；只有一个 SKU；想提客单又怕掉转化。

**怎么做**：
1. 拆三档：**引流 SKU（低价占位）/ 利润 SKU（正常定价，主推）/ 锚定 SKU（高价对比）**；
2. 档位差要让用户觉得"多买更划算"；
3. 主推档放中间偏下；
4. 锚定档必须有**真实增量价值**（多送一件 / 规格更大）；
5. 上线前同时核对定价是否留够活动空间。

**代价与风险**：锚定档没有真实增量 → 用户看穿 → **退款率上升**（退款率超行业均值 2 倍会直接限制流量，见 [[data-metrics]]）。只做客单动作不补信任（Evidence / 买家秀 / 证据链），转化率会塌。

---

## 12. 一次只改一处（归因纪律）

**何时用**：每次改主图、改 SKU、改详情页之后。

**怎么做**：
1. 一次只动一个环节、一个变量；
2. 改完留固定观察期（≥3 天）；
3. 记录"改了什么 / 为什么 / 数据怎么变"。

**代价与风险**：同时换主图 + 改 SKU + 动详情页，数据变好也说不清是谁的功劳；变差也不知道该回退哪个。
