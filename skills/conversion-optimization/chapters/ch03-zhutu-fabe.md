## 一、FABE 主图法则

| 要素 | 含义 | 示例 |
|---|---|---|
| **F**eature 特征 | 产品基本属性 | 纯棉材质、防水设计 |
| **A**dvantage 优点 | 特征带来的优势 | 透气舒适、不怕雨淋 |
| **B**enefit 利益 | 给消费者的好处 | 穿着舒服、雨天不用愁 |
| **E**vidence 证据 | 证明的证据 | 90 天免费试用、10 万+好评 |

> **大多数商家只做到特征和优点，缺少最重要的证据部分。**

**为什么 Evidence 缺位最致命**：F/A/B 是**自述**，E 是**他证**。用户不关心你说自己多好，只关心凭什么信你。证据缺位 = 用户没有被说服 = 跳失。

**证据从哪来**（按可信度排序）：
1. **服务承诺**：90 天免费试用、7 天无理由、终身质保；
2. **量化背书**：10 万+ 好评、销量 N 件、复购率；
3. **资质检测**：行业认证、检测报告（医疗器械类目另有红线，见 [[compliance-medical]]）；
4. **第三方评价**：榜单截图、达人推荐、老客复购截图。

## 二、主图四要素与前三张排布

**主图四要素**：

| 要素 | 说明 |
|---|---|
| **卖点突出** | 第一眼看到核心卖点 |
| **差异化** | 与竞品形成区隔 |
| **场景化** | 使用场景代入 |
| **信任背书** | 资质 / 销量 / 评价 |

**前三张主图的排布逻辑（可复用三段式）**：**卖点 → 背书 → 收益**

| 张数 | 承担 | 内容 |
|---|---|---|
| 第 1 张 | **卖点** | 把核心卖点说清楚 |
| 第 2 张 | **背书** | 资质 / 销量 / 评价做证据 |
| 第 3 张 | **收益** | 落到消费者能拿到的好处 |

**三张各承担一件事，不要第一张就把所有信息塞满。**用户只给第一张一次注意力。

**词图匹配**：搜索什么展示什么（基本要求）；更高境界是**词图人匹配**——了解买的人的内心向往。

## 三、主图打标三种方法

### 3.1 系统热销标模拟

制作带**热销标签的 PNG 白底图**上传到**鹿班中心**作为背景图 → 所有主图显示热销标签。

### 3.2 冠军标打造

利用"**定语足够多什么都能是第一**"原理：
- "本店大黑牛沙发 3000-4000 元价位成交额第一名"
- "2026 年 3 月北京地区客厅吊灯销量冠军"

**注意**：这类表述必须有真实数据支撑。**虚构的销量/排名宣称属于虚假宣传**，医疗器械类目另有严格禁用词表（见 [[compliance-medical]]）。

### 3.3 榜单效应

- 新品最容易上**幸运榜**，**只要有一笔成交就可能登上幸运榜第一名**；
- 上榜后**立即**将榜单截图添加到**副图、SKU 图、店铺装修**中。

**为什么立刻做**：榜单截图是免费的 Evidence，且有时效性——榜单会变，截图过期后就是负资产（用户点进详情发现榜单早就不在了）。

## 四、导购标题优化（副标题/卖点前缀）

| 类型 | 示例 |
|---|---|
| **数字型** | "热销 10000 件""99% 好评" |
| **名人型** | "佳琪推荐""老爸评测" |
| **热点型** | "小红书爆款""抖音同款" |
| **特殊符号型** | "㊣正品保证""★★★★★五星好评" |

**点击率提升参考**：

| 常规标题 | 高点击率标题 | 点击率提升 |
|---|---|---|
| 纯棉T恤夏季新款 | 小红书爆款纯棉T恤夏季新款 | **25%** |
| 家居收纳盒抽屉式 | 佳琪推荐抽屉式收纳盒大容量 | **35%** |
| 蓝牙耳机无线 | 热销 10 万+无线蓝牙耳机超长续航 | **40%** |

**读法**：**加前缀不改主体**——前缀只解决"凭什么点你"，点进来还得靠主图与 SKU 承接。

## 五、素材层：主图不是孤立的一张图

2026 淘宝进入**素材时代**：**同一个产品，用不同素材，可获得完全不同的人群和流量规模**。

**皮带案例**：素材"男士真皮皮带，商务休闲必备" → 流量是 25-35 岁男性，转化率 3%；改为"父亲节礼物，送给最爱的爸爸" → 流量变成 20-30 岁女性，**转化率提升到 6%，流量规模扩大 3 倍**。

**对主图的含义**：**换素材 = 换人群**，不只是换点击率。主图改版前先想清楚要吸谁。

**搜推素材规则**（2026 投入最多的素材形式）：同时在搜索结果页、推荐页、活动页展示；人群匹配精度比传统素材高 **30%+**；流量池是光合平台素材 **2 倍以上**；只需一张主图 + 一段文案。被标"精选"可获 **10 倍以上流量**，**30 天没有成为精选素材立即替换**；**不要使用 AI 生成视频**。详见 [[visual-material]]。

## 六、主图修改纪律

1. **一次只改一个变量**：主图构图 / 卖点 / 人群定位 / 标题前缀，四者分开测；
2. **主图与短标题、SKU 图联动**：改了主图卖点，SKU 五要素里的短标题要跟上，否则用户点进来发现"说的不是一回事"；
3. **改完看点击率，不看转化率**：主图负责把人拉进来，转化归 SKU 与详情页；
4. **测图走 [[keyword-promo]] ch03 的 SOP**：≥3 张图、每图 ≥100 点击、点击率 ≥ 行业 1.5 倍才保留。
