# 术语表 · conversion-optimization

> 每条标注来源笔记。定义取知识库原文口径。

**FABE 主图法则** — 主图内容的四段式：F（Feature 特征，产品基本属性）→ A（Advantage 优点，特征带来的优势）→ B（Benefit 利益，给消费者的好处）→ E（Evidence 证据，真实数据支持）。**大多数商家只做到特征和优点，缺少最重要的证据部分。**（来源：`转化率全链路优化`、`2026淘宝运营完整知识体系`）

**消费者决策链路** — 搜索结果页（主图、短标题、销量、价格、标签 → 点击率）→ 进入商品页（五张主图 → 兴趣激发）→ 评价区（买家秀、问大家 → 信任建立）→ 加购环节（SKU 设置 → 转化决策）→ 详情页（详细介绍、品牌信息 → 补充说服）。（来源：`转化率全链路优化`）

**推荐最适合的 SKU** — 搜索推荐逻辑已从"推荐最适合的商品"转变为"推荐最适合的 SKU"，哪个 SKU 卖得好系统就推荐哪个 SKU。这是 SKU 被列为转化优化第一优先级的根因。（来源：`转化率全链路优化`、`2026淘宝运营完整知识体系`）

**SKU 优化五要素** — 短标题（核心卖点）、标签（热销爆款/店长推荐）、服务项（7 天无理由/顺丰包邮）、价格、氛围元素（火焰/爆炸/箭头）。（来源：`2026淘宝运营完整知识体系`、`转化率全链路优化`）

**SKU 搜索图** — 商品编辑页面的独立图片位，展示在搜索结果页。按主图标准制作、清晰展示卖点/价格/服务，避免简单白底图。素材标注为"紧急优化：立即更新所有产品的 SKU 搜索图"。（来源：`转化率全链路优化`）

**SKU 标题词布局** — 把主标题放不下的长尾词、人群词、场景词写进 SKU 标题，可被搜索检索到获得额外流量。（来源：`转化率全链路优化`）

**引流 SKU / 利润 SKU / 锚定 SKU** — SKU 三种角色：引流 SKU 吸引点击、低价占位；利润 SKU 主要盈利、正常定价；锚定 SKU 衬托主款、高价对比。（来源：`b12-爆款三板斧-产品布局`）

**价格锚定法** — 设置多档装（"1 瓶装 29 元""2 瓶装 49 元""3 瓶装 69 元"）引导购买高客单价，用高价档做对比锚点。（来源：`转化率全链路优化`）

**主图四要素** — 卖点突出、差异化、场景化、信任背书。前三张主图排布逻辑为"卖点 → 背书 → 收益"。（来源：`b12-爆款三板斧-产品布局`）

**主图打标三法** — ① 系统热销标模拟（带热销标签的 PNG 白底图上传鹿班中心作背景图）；② 冠军标打造（"定语足够多什么都能是第一"）；③ 榜单效应（新品容易上幸运榜，上榜后立即把截图加到副图、SKU 图、店铺装修）。（来源：`转化率全链路优化`）

**词图匹配 / 词图人匹配** — 词图匹配是"搜索什么展示什么"（基本要求）；词图人匹配是"了解买的人的内心向往"（更高境界）。（来源：`b12-爆款三板斧-产品布局`）

**导购标题** — 主图上的卖点前缀，按类型分数字型（"热销 10000 件"）、名人型（"佳琪推荐"）、热点型（"小红书爆款"）、特殊符号型（"㊣正品保证"）。（来源：`素材革命与八大流量入口`）

**买家秀优化五法** — 点赞数 P 图法、AI 视频生成法、榜单 P 图法、复购截图法 +（第 5 条口径冲突）广告位 P 图法 / 明星同款合成。（来源：`转化率全链路优化`、`2026淘宝运营完整知识体系`）

**单人多单法** — 一个买家账号同时购买 6-10 个不同 SKU，每个 SKU 发布一条带图或带视频评价，完成后删除多余 SKU 只留主卖 SKU；一个账号可产 6-10 条买家秀。（来源：`安全补单与买家秀实操`）

**匿名评价法** — 所有评价设置为匿名，避免同一头像的多个评价显得虚假。（来源：`安全补单与买家秀实操`）

**追评节奏** — 收到货后不要立即追评，至少间隔 7-15 天；追评内容真实可信。（来源：`安全补单与买家秀实操`）

**新品直销** — 官方合规的权重单工具：买家扫码加购 → 退出二维码页 → 通过搜索半标题或品牌词下单，计入搜索权重；一个买家账号最多 6 单。（来源：`安全补单与买家秀实操`）

**补单三大合法场景** — 活动门槛达标（★★★★★）、基础销量积累（★★★★☆）、数据优化（★★★☆☆）。核心结论：不要为了刷搜索权重而补单。（来源：`安全补单与买家秀实操`）

**问大家自问自答** — 站在消费者角度设计问题 → 真实详细有说服力的回答（可加个人使用体验）→ 回答中融入核心卖点、给明确解决方案、结尾适当引导下单。（来源：`转化率全链路优化`）

**高转化详情页结构** — 痛点挖掘（引起共鸣）→ 解决方案（建立信任）→ 证据链（消除顾虑）→ 促销信息（促进下单）；口诀"痛点 → 卖点 → 信任 → 行动"。（来源：`b12-爆款三板斧-产品布局`）

**防跳失三招** — 九宫格后置、长白底图法（写"已经到底了"）、底部关联。三招属于收尾工程，不解决第一眼有没有被抓住。（来源：`转化率全链路优化`）

**证据链** — 详情页第三段，内容为资质 / 检测 / 用户评价，作用是消除顾虑。与主图 FABE 的 E（Evidence）是同一类素材的不同位置复用。（来源：`b12-爆款三板斧-产品布局`、`转化率全链路优化`）

**跳失率 / 停留时长** — 三阶引擎 8 维度考核中的一对镜像：停留时长看"人愿意看多久"，跳失率看"人立刻走了多少"。只修一个通常无效。（来源：`data-metrics`）

**素材时代** — 2026 淘宝进入素材时代：同一个产品用不同素材，可获得完全不同的人群和流量规模。（来源：`素材革命与八大流量入口`）
