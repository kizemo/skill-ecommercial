## 4. 决策树：有流量没成交

```
有流量没转化
├─ 搜索结果页就跳走（没点击）
│  └─ 主图点击率问题 → 转 [[keyword-promo]] 测图 SOP
├─ 点了进商品页就跳走
│  ├─ 五张主图没接住 → 改主图（FABE 补 Evidence）
│  └─ SKU 搜索图是白底 → 立刻重做 SKU 搜索图
├─ 看了评价区不下单
│  └─ 信任不足 → 买家秀 + 问大家 + 详情页证据链
├─ 加购了不下单
│  ├─ SKU 只有 1 档 → 拆引流/利润/锚定三档
│  ├─ SKU 名只有颜色词 → 名称精细化 + 从众引导
│  └─ 缺标签/服务项/氛围元素 → 补五要素
├─ 下单但客单价低
│  └─ 上价格锚定法（先补证据，否则转化会塌）
└─ 下单后退款多
   └─ 预期管理 / 描述一致性 → 转 [[data-metrics]]

全店转化率都低
└─ 不是单品问题 → 转 [[store-diagnosis]]
```

## 7. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 只改主图不改 SKU 搜索图 | 搜索端什么都没变 | 搜索页展示的是 SKU 搜索图 |
| 把"详情页不重要"当"可以不写" | 停留时长掉，跳失率升 | 优先级是投入产出比，不是取舍 |
| 在全不达标的图里挑"最不差的" | 转化与信任双输 | 先确认整体达标，再选最优 |
| 多 SKU 平均用力 | 没有 SKU 被推荐 | 锁定一个主推 SKU |
| 锚定档没有真实增量 | 用户看穿 → 退款率上升 | 锚定档必须真加量 |
| 只做客单动作不补信任 | 客单上去转化塌 | 客单路径与信任路径同步 |
| 促销信息放详情页最前 | 跳失更快 | 痛点 → 卖点 → 信任 → 行动 |
| 详情页第一屏就塞满所有信息 | 用户找不到重点 | 重点前置但只留 1-2 个卖点 |
| 过期榜单截图 | 变成负资产 | 定期核对更新 |
| 虚构销量/冠军标/好评数 | 虚假宣传 + 类目红线 | Evidence 必须真实 → [[compliance-medical]] |
| 把"P 图""多账号自问自答"当标准 SOP | 风控升级，评价资产归零 | 先读 ch04 合规边界 |
| 同时改主图 + SKU + 详情页 | 归因不了 | 一次只改一处，留 ≥3 天观察期 |

## 8. 合规红线

| 做法 | 判定 |
|---|---|
| 真实买家秀 + 真实使用体验 | ✅ 正常运营 |
| 新品直销（官方工具） | ✅ 官方合规路径 |
| 点赞 P 图 / 榜单 P 图 / 广告位 P 图 / 明星同款合成 | ⚠️ 灰色手法，风险中高 |
| 多账号问大家自问自答 | ⚠️ 灰色手法，风险中高 |
| 全额退款折叠差评 | ⚠️ 灰色手法，风险中高 |
| 追评加"适当负面评价显得真实" | ⚠️ 灰色手法，风险中高 |
| 绝对化词 / 医疗承诺 / 虚假资质宣称 | ❌ 红线，见 [[compliance-medical]] |

**原则**：本 skill 记录素材原文，**不提供任何规避平台检测的方法**。被处罚后的处理路径见 ch04 §4.3。

## 9. 口径冲突（需复核，落地前先定一个）

1. **决策链路顺序**：链路表 SKU 第 4 / 结论句与优先级表 SKU 第 1 / "转化原则"第 4 条写成"主图→买家秀→SKU→详情页"。**三处不一致**；行动以"SKU 优先级最高"为准。
2. **买家秀五法第 5 条**：广告位 P 图法（转化率全链路优化）vs 明星同款合成（2026淘宝运营完整知识体系）。**实为 6 种手法。**
3. **测图点击门槛**（与 [[keyword-promo]] 同一冲突）：每图 ≥100 / 每创意 ≥50 / 累计 500+。
