# 术语表 · selection-testing

> 每条标注来源笔记。定义取知识库原文口径。

**运营四字诀** — 选 → 测 → 打 → 手。选（选对产品，★★★★★）、测（测准产品，★★★★★）、打（打爆款，★★★）、手（做私域/复购，★★）。原则：强化前两个环节，弱化后两个环节。（来源：`选品测款标准流程`）

**七维选品法** — 市场容量、竞争度、毛利空间、供应链、合规性、时效性、差异化。选品决定 70% 的运营效果。（来源：`爆款三板斧-七维选品`）

**词路选品** — 用搜索侧确定性需求反推选品。门槛：搜索人气 15 万+、增速 100%+、转化 10%+。（来源：`煜东老师-爆款三板斧`）

**虚假爆款** — 三类：数据异常款（有人为操作）、衰退期款（品类已过峰）、资源堆款（靠堆资源堆销量，非产品力）。（来源：`煜东老师-爆款三板斧`）

**首购新客成本** — 高复购品类必须改用的观测指标。只看总成交成本会导致所有计划跑向收割。（来源：`选品测款标准流程`）

**测图** — 测主图/创意是否有点击力。核心指标点击率，前置条件是产品已有基础销量和评价，每创意 ≥50 点击。（来源：`选品测款标准流程`）

**测款** — 测产品是否值得投入。核心指标加购率（标品加转化率），每款 ≥50 点击，建议 3-5 天/款。（来源：`选品测款标准流程`）

**老品测新品图** — 用价格与关键词成交来源一致、且词权重好的老款验证新主图。上传 4-8 张新图，每创意 50 点击。（来源：`选品测款标准流程`）

**加购率** — 新品预判的核心指标。不受价格波动与活动节奏干扰，大促蓄水与爆发变现都靠它。（来源：`爆款三板斧-七维选品`）

**流量分级** — 按产品阶段选工具：新品冷启动→引力魔方半智能；潜力款爬坡→关键词手动低出高价；S 级爆款放量→全站+关键词双驱动；尾货动销→全站低价。（来源：`选品测款标准流程`）

**词图匹配** — 搜索什么展示什么，是基本要求。（来源：`爆款三板斧-产品布局`）

**词图人匹配** — 了解买的人的内心向往，比词图匹配更高境界。（来源：`爆款三板斧-产品布局`）

**引流 SKU / 利润 SKU / 锚定 SKU** — SKU 三种角色：引流 SKU 吸引点击（低价占位）、利润 SKU 主要盈利（正常定价）、锚定 SKU 衬托主款（高价对比）。（来源：`爆款三板斧-产品布局`）

**标准化 SOP** — 选品 → 上新 → 测图测款 → 爆款孵化 → 数据优化 → 爆款维护。价值：替代个人经验、团队可复制、持续迭代。（来源：`爆款三板斧-标准化SOP`）

**九大标准化运营表格** — 类目洞察表、类目趋势分析表、新品老品效率对比表、效率对比表、费比核算表、补贴核算表、顺逆差分析表、产品分级表、测图测款记录表。（来源：`爆款三板斧-标准化SOP`）

**顺逆差** — 单品成交金额占比 − 单品推广花费占比。正向=花小钱办大事=预算倾斜依据；负向=优化或淘汰。（来源：`爆款三板斧-投产诊断`）

**新品成功率** — 测款通过率 × 爆款转化率。99% 的问题出在选品测款。（来源：`淘系运营核心公式`）
