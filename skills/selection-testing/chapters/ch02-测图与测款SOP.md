# 第 2 章 · 测图与测款 SOP

> 来源笔记：`选品测款标准流程`（子尤老师精细化运营培训 2025-06）、`爆款三板斧-标准化SOP`

---

## 一、测评环节的最大难点：用错指标

**新品测试用"投产"评估是最不科学的。**

| 误区 | 正确认知 |
|---|---|
| "新品投产 = 1，感觉不好" | 新品期前两周投产本来就不到 1，**正常** |
| "投产差就该换品" | 投产差不一定是品的问题，可能是**指标选错了** |

**为什么不能用投产判新品**：投产 = ROI，它同时包含了转化率、客单价、退款率、间接成交占比等一堆后期变量。新品期这些变量都还没稳定，用它做决策等于用一把会变的尺子量东西。

---

## 二、按品类选对测试指标

| 品类类型 | 测试指标 | 注意 |
|---|---|---|
| 低客单标品 | 点击率 + 转化率 | 成交周期 ≈ 1 天 |
| 高客单标品 | 点击率 + 转化率 + **人群精准度** | 人群容易跑偏，重点关注 L1/L2 比例 |
| 非标品 | **加购率** | 购买周期 ≠ 1 天时用 |
| 高复购品类 | **首购新客成本**（不是总成交成本） | 只看总成交成本，所有计划会跑向收割 |
| toB / 定制类 | **咨询率** | 不看加购，看咨询量和咨询成本 |

### 高复购品类的死循环与破法

```
只看成交成本 → 所有计划跑向收割 → 老客占比越高、成交成本越低
              → 更没人愿意拉新 → 老客吃光 → 死循环
```

**破法**：
- 观测指标改为「**首购新客成本**」
- 关注**每个计划的拉新效率**，而不是整体投产

## 三、测图标准流程

### 前提条件（不满足就别测）
- 产品**已有基础销量和评价** —— 否则测图数据不准
- 无基础销量的新品**不测图**，先做基础优化（基础销量 + 评价积累起来再测）

### 四步
```
Step 1: 建立手动测图计划（非智能计划）
Step 2: 每个创意至少 50 个点击
Step 3: 点击率对比行业均值
Step 4: 差图及时删除（智能计划）/ 保留权重（手动计划）
```

> **为什么要手动计划**：智能计划会自动淘汰差图，等它筛完你拿不到"这张图到底行不行"的确定答案。手动计划让你自己控变量。

### 判断逻辑（最容易做错的一步）

**先确认整体，再选最优：**

1. 先看整体数据是否达标（对比行业均值）
2. 在**达标**图片中选点击率最高的一张
3. **不要在全部不达标的图片中选"最不差的"**

第 3 条是重点：在一堆 1% 点击率的图里挑出 1.8% 那张，得到的结论是"这张图能跑"，但真实情况是"这个品在这个位置拿不到流量"。**整体不达标时，正确动作是重做图，不是选图。**

### 老品测新品图（低成本验证主图）

这是最值得复用的测图变体 —— 用老品的数据验证新品的主图。

**条件**：
- 找一个**价格和关键词成交来源一致**的老款
- 该老款有历史关键词投放数据、**词权重好**

**流程**：
1. 建立手动测图计划
2. 上传 **4-8 张**新图
3. 每个创意 **50 个点击**
4. 选最优图替换主图

## 四、测款标准流程

### 核心原则
1. 测款是测**产品**是否值得投入，不是测**图片**
2. 测款用**加购率**作为核心指标（标品也参考转化率）

### 四步
```
Step 1: 建立测款计划（手动 + 低出高价）
Step 2: 每个款至少 50 个点击
Step 3: 加购率达到类目均值以上
Step 4: 转化率达标后可进入下一阶段（打品）
```

### 测款计划配置

| 配置项 | 建议 | 为什么 |
|---|---|---|
| 出价方式 | 手动，低出高价 | 智能出价会自动跑向收割人群，测出来的人群不是你要的 |
| 定向 | 半智能 / 关键词相关人群 | 保证测的是"对的人"，不是"随便的人" |
| 预算 | 能保证 **3-5 天**内跑完 50 个点击 | 拖太久会浪费钱，也拖慢迭代 |
| 地域 | 关闭偏远地区 | 避免无效点击稀释数据 |

## 五、测款效率提升

### 三个常见错误
| 错误 | 后果 | 正确做法 |
|---|---|---|
| 数据量不足就下结论 | 25 个点击就判死刑或加冕 | 必须 **50 个点击** |
| 测试周期拉太长 | 一款测两周，资金被锁死 | **3-5 天/款** |
| 用新号测款 | 标签不准，数据失真 | 用有历史成交的老号 |

### 两个效率工具
- **达摩盘** —— 查看人群标签，辅助判断品类匹配度
- **声量（原生意参谋）** —— 多维度对比行业均值

## 六、测款 → 测图的顺序问题

两个环节经常被搞混。**判据很简单：测的是"图"还是"品"？**

| | 测图 | 测款 |
|---|---|---|
| 测什么 | 主图/创意是否有点击力 | 产品是否值得投 |
| 核心指标 | 点击率 | 加购率（标品加转化率） |
| 前置条件 | 已有基础销量和评价 | 无（新品也测） |
| 计划类型 | 手动测图计划 | 手动 + 低出高价 |
| 样本量 | 每创意 ≥50 点击 | 每款 ≥50 点击 |
| 结论 | 换哪张主图 | 这个品打不打 |

**新品没有基础销量时：先测款（测产品），等有了基础销量和评价再测图。** 顺序反了会得到"图不好"的错误结论 —— 实际是品没验证。
