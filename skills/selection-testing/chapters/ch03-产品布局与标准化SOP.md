# 第 3 章 · 产品布局与标准化 SOP

> 来源笔记：`爆款三板斧-产品布局`、`爆款三板斧-标准化SOP`、`选品测款标准流程`

---

## 一、什么是产品布局

**产品布局是"打造吸引买家的优质饵料"。** 七个维度全实操：词、图、SKU、详情、视频、评价、价格。

| 维度 | 核心内容 | 目的 |
|---|---|---|
| **词维度** | 标题权重、关键词布局 | 搜索流量 |
| **图维度** | 主图点击率优化 | 获取点击 |
| **SKU 维度** | 规格定价策略 | 提升客单价 |
| **详情维度** | 转化率优化 | 促进成交 |
| **视频维度** | 短视频权重 | 内容流量 |
| **评价维度** | 口碑管理 | 信任背书 |
| **价格维度** | 定价策略 | 利润与转化 |

---

## 二、词维度

### 标题权重规则
- **核心词放两端**（权重最高）
- **长尾词布局中间**

### 关键词布局顺序
```
类目词放前 → 属性词次之 → 长尾词兜底
```

---

## 三、图维度

**点击率越高 → 流量获取成本越低 → 推广效果越好。**

### 高点击率主图四要素
| 要素 | 说明 |
|---|---|
| **卖点突出** | 第一眼看到核心卖点 |
| **差异化** | 与竞品形成区隔 |
| **场景化** | 使用场景代入 |
| **信任背书** | 资质 / 销量 / 评价 |

### 词图匹配 vs 词图人匹配
- **词图匹配** —— 搜索什么展示什么（**基本要求**）
- **词图人匹配** —— 了解买的人的内心向往（**更高境界**）

素材案例：皮带主图从「男士真皮皮带」改成「父亲节礼物」→ 流量从 20-30 岁男性变成 30+ 女性、转化 3% → 6%、流量规模 ×3。

---

## 四、SKU 维度：三种角色

| SKU 类型 | 作用 | 定价策略 |
|---|---|---|
| **引流 SKU** | 吸引点击 | 低价占位 |
| **利润 SKU** | 主要盈利 | 正常定价 |
| **锚定 SKU** | 衬托主款 | 高价对比 |

---

## 五、详情维度

### 高转化详情页结构
| 模块 | 内容 | 目的 |
|---|---|---|
| **痛点挖掘** | 客户需求分析 | 引起共鸣 |
| **解决方案** | 产品卖点 | 建立信任 |
| **证据链** | 资质 / 检测 / 用户评价 | 消除顾虑 |
| **促销信息** | 活动 / 优惠 | 促进下单 |

> 注意：在淘系当前链路里，**详情页的转化贡献优先级低于 SKU 和主图**（见 `[[conversion-optimization]]`）。详情页的作用是"消除顾虑"，不是"说服下单"。

---

## 六、价格维度：三种定价法

| 方法 | 公式 | 适用 |
|---|---|---|
| **成本定价** | 成本 × (1 + 毛利要求) | 成本结构清晰、竞争不激烈的品 |
| **竞品定价** | 基于竞品价格带 | 标品、需要卡价格力权重 |
| **价值定价** | 基于客户感知价值 | 有差异化卖点、品牌向 |

> **定价必须给活动留空间** —— 完整预留公式见 `[[pricing-margin]]`。

## 七、标准化 SOP：六环节闭环

```
选品 → 上新 → 测图测款 → 爆款孵化 → 数据优化 → 爆款维护
     ↓       ↓        ↓          ↓          ↓         ↓
  七维选品  标题主图  低预算测试   加大投放   顺逆差    持续监控
```

### 各环节核心动作

| 环节 | 核心动作 |
|---|---|
| **选品** | 七维选品法评估、类目洞察表、趋势分析 |
| **上新** | 标题优化（词维度）、主图优化（图维度）、SKU 布局、详情页制作 |
| **测图测款** | 低预算测试 **50-100 元/天**，重点看加购数据，转化率验证 |
| **爆款孵化** | 加大投放、商品分级管理、顺逆差监控 |
| **数据优化** | 投产诊断、顺逆差效率模型、尾部产品淘汰 |
| **爆款维护** | 持续监控评分、评价管理、更新迭代 |

**标准化的价值**：替代个人经验 → 团队可复制 → 持续迭代优化。

## 九、产品分级与流量分级（解决两个具体问题）

**产品分级解决「利润率下滑」**：

| 等级 | 定义 | 运营重点 | 推广方式 |
|---|---|---|---|
| **S 级爆款** | 利润贡献最高、转化最好 | 集中资源打 | 全站 + 关键词双驱动 |
| **A级品** | 有潜力，测试中 | 持续测款优化 | 关键词手动低出高价 |
| **B 级品** | 动销款 | 低价走量 | 全站低价跑量 |

**流量分级解决「广告占比高」**：

| 产品阶段 | 工具选择 | 打法重点 |
|---|---|---|
| 新品冷启动 | 引力魔方半智能 | 测款，获取基础人群标签 |
| 潜力款爬坡 | 关键词手动低出高价 | 拉搜索，建立词权重 |
| S 级爆款放量 | 全站 + 关键词双驱动 | 最大化流量规模 |
| 尾货 / 动销 | 全站低价 | 清库存 |

> ⚠️ **口径提示**：此处 S/A/B 是**选品视角**的分级（看利润贡献与测试状态）；`[[sabc-product-tiering]]` 里的 S/A/B/C 是**战略视角**的分级（看流量与利润占比、生命周期阶段）。两套分级的判定标准不同，不要混用同一张表。
