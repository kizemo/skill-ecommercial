# 速查表 · selection-testing

## 1. 七维选品优先级

| 维度 | 优先级 | 一票否决？ |
|---|---|---|
| 合规性 | **高** | ✅ 否决（资质不齐 / 违禁词） |
| 差异化 | **高** | ✅ 说不出口则不选 |
| 毛利空间 | **高** | ✅ 覆盖不了推广费则不选 |
| 竞争度 | 高 | ❌ |
| 市场容量 | 高 | ❌ |
| 供应链 | 中 | ❌ |
| 时效性 | 中 | ❌ |

## 2. 五大选款法数据门槛

| 方法 | 门槛 |
|---|---|
| 市场选品 | 访客 10 万+ / 买家 1 万+ / 增速为正 |
| 竞店选品 | 拆竞店成交结构 |
| **词路选品** | **搜索人气 15 万+ / 增速 100%+ / 转化 10%+** |
| 趋势选品 | 上升趋势品类 |
| 店铺老品选品 | 加购率 ≥10% / 点击率 ≥5% / 加购回访率 ≥30% |

## 3. 测试指标（按品类）

| 品类类型 | 测试指标 | 关键注意 |
|---|---|---|
| 低客单标品 | 点击率 + 转化率 | 成交周期 ≈1 天 |
| 高客单标品 | 点击率 + 转化率 + 人群精准度 | 盯 L1/L2 比例 |
| 非标品 | **加购率** | 购买周期 ≠1 天 |
| 高复购 | **首购新客成本** | 不是总成交成本 |
| toB / 定制 | **咨询率** | 看咨询量与咨询成本 |

## 5. 流量分级 → 工具选择

| 产品阶段 | 工具 | 打法重点 |
|---|---|---|
| 新品冷启动 | 引力魔方半智能 | 测款、获取基础人群标签 |
| 潜力款爬坡 | 关键词手动低出高价 | 拉搜索、建立词权重 |
| S 级爆款放量 | 全站 + 关键词双驱动 | 最大化流量规模 |
| 尾货 / 动销 | 全站低价 | 清库存 |

## 6. 产品分级（选品视角）

| 等级 | 定义 | 运营重点 | 推广方式 |
|---|---|---|---|
| S 级爆款 | 利润贡献最高、转化最好 | 集中资源打 | 全站 + 关键词双驱动 |
| A 级品 | 有潜力，测试中 | 持续测款优化 | 关键词手动低出高价 |
| B 级品 | 动销款 | 低价走量 | 全站低价跑量 |

> ⚠️ 与 `[[sabc-product-tiering]]` 的 S/A/B/C **不是同一套判定标准**，不要混表。

## 7. 标准化 SOP 六环节

```
选品 → 上新 → 测图测款 → 爆款孵化 → 数据优化 → 爆款维护
```
测图测款阶段预算：**50-100 元/天**

---

## 8. 三类虚假爆款

| 类型 | 识别特征 |
|---|---|
| 数据异常款 | 销量与评价不成比例、评价时间集中 |
| 衰退期款 | 类目大盘在跌，单品历史数据好看 |
| 资源堆款 | 靠堆资源堆销量，产品力未验证 |

**共同判据**：加购率与转化率**同时**达标才算验证通过。

---

## 9. 决策树：新品要不要继续投

```
新品测试期
├─ 指标选对了吗？（按品类查表）
│  └─ 用投产评新品 → 换指标
├─ 样本量够吗？
│  └─ <50 点击 → 再跑，不下结论
├─ 加购率 vs 类目均值
│  ├─ 低于均值 → 换品（先查是不是三类虚假爆款）
│  └─ 高于均值 → 进转化率验证
├─ 转化率达标？
│  ├─ 否 → 看主图/SKU/评价（见 [[conversion-optimization]]）
│  └─ 是 → 进打品阶段（见 [[hit-product-lifecycle]]）
└─ 高复购品类？
   └─ 查首购新客成本，而不是总成交成本
```

---

## 10. 四个最容易犯的错

| 错误 | 纠正 |
|---|---|
| 用投产评新品 | 按品类换指标 |
| 50 个点击没到就下结论 | 满 50 点击再判 |
| 测款周期拖到一个月 | 3-5 天/款 |
| 新品直接测图 | 先测款，有基础销量再测图 |
