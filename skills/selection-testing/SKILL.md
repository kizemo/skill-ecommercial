# 选品与测款

**来源**：`taobao-operation` 知识库（爆款三板斧系列 + 子尤老师精细化运营培训）｜**层级**：L2 域层｜**版本**：2026.10

选品决定 **70%** 的运营效果。这个 skill 解决两件事：**选什么**（七维选品 + 五大选款法），和**怎么验证**（测图 / 测款标准流程）。

---

## 一、运营四字诀：选 → 测 → 打 → 手

| 环节 | 说明 | 重要性 |
|---|---|---|
| **选** | 选对产品 | ★★★★★ |
| **测** | 测准产品 | ★★★★★ |
| **打** | 打爆款 | ★★★ |
| **手** | 做私域 / 复购 | ★★ |

> **强化前两个环节，弱化后两个环节。** 只要选品没问题、测评没问题，哪怕打品动作粗糙也能起来；反过来，品没选好、测评没做好，打品环节完全打不了。

**行动含义**：当一个新品打不起来时，**先怀疑选品和测评，不要先去改推广出价**。

## 二、七维选品法

| 维度 | 评估内容 | 优先级 |
|---|---|---|
| **合规性** | 资质与政策风险 | **高** |
| **差异化** | 卖点与竞争力 | **高** |
| **毛利空间** | 成本与定价 | **高** |
| **竞争度** | 竞品数量与质量 | 高 |
| **市场容量** | 市场规模与增长趋势 | 高 |
| 供应链 | 供货稳定性 | 中 |
| 时效性 | 季节性 / 节点性 | 中 |

**执行七步**（顺序不能乱 —— 前两步决定赛道，后五步决定这个具体品能不能做）：

1. **类目洞察** —— 分析类目市场规模、增长趋势
2. **趋势分析** —— 判断品类处于上升还是下降趋势
3. **竞品分析** —— 评估竞争度与机会点
4. **毛利测算** —— 计算盈利空间
5. **供应链确认** —— 确保供货稳定性
6. **合规检查** —— 确认资质与政策（医械类目见 `[[compliance-medical]]`）
7. **差异化定位** —— 明确竞争卖点

### 三条核心原则

1. **先锁定类目再选品** —— 通过类目洞察 + 趋势分析完成赛道筛选，不要在错误的类目里精挑细拣
2. **标品 vs 非标品打法不同** —— 不可通用
3. **加购数据是新品预判的核心** —— 大促蓄水、爆发变现都靠它

## 三、五大选款法与虚假爆款识别

| 方法 | 关键数据门槛 |
|---|---|
| **市场选品** | 访客 10 万+ / 买家 1 万+ / 增速为正 |
| **竞店选品** | 从竞店成交结构里挖 |
| **词路选品** | 搜索人气 15 万+ / 增速 100%+ / 转化 10%+ |
| **趋势选品** | 上升趋势品类 |
| **店铺老品选品** | 加购率 ≥10%、点击率 ≥5%、加购回访率 ≥30% |

### 三类虚假爆款

| 类型 | 特征 |
|---|---|
| **数据异常款** | 有人为操作痕迹 |
| **衰退期款** | 数据好看但品类已过峰 |
| **资源堆款** | 靠堆资源堆出来的销量，非产品力 |

### 一个真实教训

> 家具商家跟款茶几（加购 3% / 转化 1%），推广 1 个月亏 5 万。
> 改用词路选款「岩板茶几」（加购 15% / 转化 8%），15 天打爆。

**判据**：**加购率与转化率同时达标才算验证通过**，只满足一项说明数据来自收割或资源堆砌。

## 四、测试阶段指标选择（最容易被做错的一步）

**新品测试用"投产"评估是最不科学的。**

| 误区 | 正确认知 |
|---|---|
| 新品投产 = 1，感觉不好 | 新品期前两周投产本来就不到 1，正常 |
| 投产差就该换品 | 投产差不一定是品的问题，可能是**指标选错了** |

### 品类 → 测试指标速查

| 品类类型 | 测试指标 | 注意 |
|---|---|---|
| 低客单标品 | 点击率 + 转化率 | 成交周期 ≈ 1 天 |
| 高客单标品 | 点击率 + 转化率 + **人群精准度** | 人群容易跑偏，重点关注 L1/L2 比例 |
| 非标品 | **加购率** | 购买周期 ≠ 1 天时用 |
| 高复购品类 | **首购新客成本**（不是总成交成本） | 只看总成交成本，所有计划会跑向收割 |
| toB / 定制类 | **咨询率** | 不看加购，看咨询量和咨询成本 |

**高复购品类的死循环**：只看成交成本 → 所有计划跑向收割 → 老客占比越高成交成本越低 → 更没人拉新。破法：观测指标换成**首购新客成本**，关注每个计划的拉新效率而非整体投产。

## 五、测图标准流程

### 前提条件
- 产品**已有基础销量和评价**（否则测图数据不准）
- 无基础销量的新品**不测图**，先做基础优化

### 四步流程
```
Step 1: 建立手动测图计划（非智能计划）
Step 2: 每个创意至少 50 个点击
Step 3: 点击率对比行业均值
Step 4: 差图及时删除（智能计划）/ 保留权重（手动计划）
```

### 判断逻辑（关键）

**先确认整体，再选最优：**
1. 先看整体数据是否达标（对比行业均值）
2. 在**达标**图片中选点击率最高的一张
3. **不要在全部不达标的图片中选"最不差的"**

### 老品测新品图（低成本验证主图）
1. 找一个价格和关键词成交来源一致的**老款**，且该老款有历史关键词投放数据、词权重好
2. 建立手动测图计划
3. 上传 **4-8 张**新图
4. 每个创意 **50 个点击**
5. 选最优图替换主图

## 六、测款标准流程

### 核心原则
1. 测款是测**产品**是否值得投入，不是测图片
2. 测款用**加购率**作为核心指标（标品也参考转化率）

### 四步流程
```
Step 1: 建立测款计划（手动 + 低出高价）
Step 2: 每个款至少 50 个点击
Step 3: 加购率达到类目均值以上
Step 4: 转化率达标后可进入下一阶段（打品）
```

### 测款计划配置

| 配置项 | 建议 |
|---|---|
| 出价方式 | 手动，低出高价 |
| 定向 | 半智能 / 关键词相关人群 |
| 预算 | 能保证 **3-5 天**内跑完 50 个点击 |
| 地域 | 关闭偏远地区 |

## 七、测款效率提升

### 三个常见错误
| 错误 | 后果 |
|---|---|
| 数据量不足就下结论 | 必须 **50 个点击**才有判断力 |
| 测试周期拉太长 | 建议 **3-5 天/款** |
| 用新号测款 | 标签不准，数据失真 |

### 两个效率工具
- **达摩盘** —— 查看人群标签，辅助判断品类匹配度
- **声量（原生意参谋）** —— 多维度对比行业均值

## 八、产品分级与流量分级（解决两个具体问题）

**产品分级解决"利润率下滑"**：

| 等级 | 定义 | 运营重点 | 推广方式 |
|---|---|---|---|
| **S 级爆款** | 利润贡献最高、转化最好 | 集中资源打 | 全站 + 关键词双驱动 |
| **A级品** | 有潜力，测试中 | 持续测款优化 | 关键词手动低出高价 |
| **B 级品** | 动销款 | 低价走量 | 全站低价跑量 |

**流量分级解决"广告占比高"**：

| 产品阶段 | 工具选择 | 打法重点 |
|---|---|---|
| 新品冷启动 | 引力魔方半智能 | 测款，获取基础人群标签 |
| 潜力款爬坡 | 关键词手动低出高价 | 拉搜索，建立词权重 |
| S 级爆款放量 | 全站 + 关键词双驱动 | 最大化流量规模 |
| 尾货 / 动销 | 全站低价 | 清库存 |

## 九、七维度产品布局

产品布局是"打造吸引买家的优质饵料"。

| 维度 | 核心内容 | 目的 |
|---|---|---|
| **词维度** | 标题权重、关键词布局 | 搜索流量 |
| **图维度** | 主图点击率优化 | 获取点击 |
| **SKU 维度** | 规格定价策略 | 提升客单价 |
| **详情维度** | 转化率优化 | 促进成交 |
| **视频维度** | 短视频权重 | 内容流量 |
| **评价维度** | 口碑管理 | 信任背书 |
| **价格维度** | 定价策略 | 利润与转化 |

### 词维度
- 核心词放**两端**（权重最高），长尾词布局中间
- 关键词布局：类目词放前 → 属性词次之 → 长尾词兜底

### 图维度
高点击率主图四要素：**卖点突出 / 差异化 / 场景化 / 信任背书**

**词图匹配** = 搜索什么展示什么（基本要求）
**词图人匹配** = 了解买的人的内心向往（更高境界）

### SKU 维度三种角色
| SKU 类型 | 作用 | 定价策略 |
|---|---|---|
| 引流 SKU | 吸引点击 | 低价占位 |
| 利润 SKU | 主要盈利 | 正常定价 |
| 锚定 SKU | 衬托主款 | 高价对比 |

### 价格维度三种定价法
| 方法 | 公式 |
|---|---|
| 成本定价 | 成本 × (1 + 毛利要求) |
| 竞品定价 | 基于竞品价格带 |
| 价值定价 | 基于客户感知价值 |

## 十、标准化 SOP：六环节闭环

```
选品 → 上新 → 测图测款 → 爆款孵化 → 数据优化 → 爆款维护
     ↓       ↓        ↓          ↓          ↓         ↓
  七维选品  标题主图  低预算测试   加大投放   顺逆差    持续监控
```

- **测图测款阶段**：低预算测试 **50-100 元/天**，重点看加购数据，转化率验证
- **数据优化阶段**：投产诊断 + 顺逆差效率模型 + 尾部产品淘汰（详见 `[[profit-model]]`）

### 九大标准化运营表格

| 表格 | 用途 |
|---|---|
| 类目洞察表 | 市场分析 |
| 类目趋势分析表 | 趋势判断 |
| 新品老品效率对比表 | 产品筛选 |
| 效率对比表 | 产品筛选 |
| 费比核算表 | 投产分析 |
| 补贴核算表 | 活动规划 |
| 顺逆差分析表 | 预算分配 |
| 产品分级表 | 预算分配 |
| 测图测款记录表 | 测试追踪 |
