# 可复用套路 · selection-testing

> 每条格式：**何时用** / **怎么做** / **代价与风险**。

---

## 1. 七维选品体检（选品前必跑）

**何时用**：任何新品立项、拓展新类目、供应商推荐新品时。

**怎么做**：
1. 按七维逐维打分：合规性 / 差异化 / 毛利空间 / 竞争度 / 市场容量（高优先）+ 供应链 / 时效性（中优先）
2. 任一「高优先」维度不达标 → 直接淘汰，不进入下一轮
3. 全部通过后再做差异化定位（一句话说清"为什么买我不买它"）

**代价与风险**：跳过合规性会引发下架与处罚（见 `[[compliance-medical]]`）；跳过毛利空间会得到"投产永远不达标"的品。

---

## 2. 词路选品（最稳的一条选品路）

**何时用**：没有明确方向、只知道类目，不知道选哪个具体的品。

**怎么做**：
1. 拉类目内的搜索词数据
2. 筛：搜索人气 15 万+、增速 100%+、转化 10%+
3. 交叉验证：把候选词的加购率与转化率拉出来，两项同时达标才进候选
4. 用趋势词开款工具把候选词转成具体款式方案（见 `[[trend-keyword-launch]]`）

**代价与风险**：门槛是培训经验值，不是平台标准；新类目需重新校准。

---

## 3. 老品测新品图（最低成本的主图验证）

**何时用**：新品已有基础销量和评价、但主图点击率上不去；或者想低成本试多版主图。

**怎么做**：
1. 找一个价格和关键词成交来源一致的**老款**（词权重要好）
2. 在老款上建**手动**测图计划
3. 上传 4-8 张新图，每创意 50 个点击
4. 只在**点击率达标（对比行业均值）**的图片里选最高的
5. 整体不达标 → 重做图，不要在烂图里选"最不差的"

**代价与风险**：用智能计划会替你筛掉差图，你就拿不到"这张图到底行不行"的答案；智能计划适合放量期的自动优选，不适合验证期。

---

## 4. 按品类选测试指标（防"用错尺子"）

**何时用**：准备给新品定测试指标、或者有人说"这个品投产不到 1，换一个"的时候。

**怎么做**：
1. 低客单标品 → 点击率 + 转化率
2. 高客单标品 → 点击率 + 转化率 + 人群精准度（盯 L1/L2 比例）
3. 非标品 → 加购率
4. 高复购 → **首购新客成本**
5. toB / 定制 → 咨询率

**代价与风险**：用投产评新品是**最不科学**的做法 —— 投产混进了转化率、客单价、退款率等一堆后期变量，新品期它们都还没稳定。

---

## 5. 高复购品类的拉新防死循环

**何时用**：高复购类目，老客占比越来越高、成交成本越来越好看、但新人越来越少。

**怎么做**：
1. 把观测指标从"总成交成本"换成「**首购新客成本**」
2. 看**每个计划**的拉新效率，而不是看整体投产
3. 用领先率交叉验证（见 `[[store-diagnosis]]`）

**代价与风险**：不换指标，所有计划会自发跑向收割 —— 老客越肥，指标越好看，拉新越没人做。

---

## 6. 测款 50 点击原则（防过早下结论）

**何时用**：所有测款/测图决策。

**怎么做**：
1. 每款至少 50 个点击
2. 周期控制在 3-5 天/款
3. 预算按"3-5 天跑完 50 个点击"倒推，不要按"跑满一个月"设
4. 用有历史成交的号测，不用新号

**代价与风险**：25 个点击就下结论，等于用噪声做决策；周期拖太长会锁死资金和迭代速度。

---

## 7. 新品测款 → 测图的正确顺序

**何时用**：新品上架后的前两周。

**怎么做**：
1. 新品无基础销量 → **只测款**（测产品），不测图
2. 积累到基础销量 + 评价
3. 再做**测图**（测主图）

**代价与风险**：顺序反了会得到"图不好"的错误结论 —— 实际是品还没验证，图测了也白测。

---

## 8. 虚假爆款三问（选款时自检）

**何时用**：看到竞品爆了想跟款时。

**怎么做**：
1. 销量与评价比例是否正常（排除数据异常款）
2. 类目大盘是在涨还是在跌（排除衰退期款）
3. 这个爆款是靠什么堆起来的（排除资源堆款）
4. 最后确认：加购率与转化率是否**同时**达标

**代价与风险**：跟款一个虚假爆款，等于把自己的预算投进一个本来就不成立的需求。
