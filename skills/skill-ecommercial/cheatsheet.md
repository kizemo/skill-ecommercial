## 1. 核心指标与健康线

| 指标 | 健康线 | 低于此线的后果 |
|---|---|---|
| 领先率（新客成交/总成交） | 普通店 ≥ 80%，头部 KA ≥ 70% | <50% 资源浪费在收割；<30% 拉新链路已断 |
| 店铺体验分 | ≥ 4.6 | <4.6 失搜索权重 + 无法报名大促 |
| 商品体验分 PXI | ≥ 70 | <70 流量负向；<60 彻底断流 |
| 退款率 | 不超行业均值 2 倍 | 超 2 倍直接限制流量 |
| 盈亏平衡 ROI | `1 ÷ 毛利率`（毛利 60% → 1.67） | ROI < 此值即亏损 |
| 点击率（医疗器械类目） | ≥ 3%（行业 1.5 倍） | 低于则爆款概率大幅下降 |
| 转化率（医疗器械类目） | ≥ 2%（类目均值） | — |

## 2. 爆款四阶段判据

| 阶段 | 时间 | 阶段切换信号 | 标签组合 | 主投工具 |
|---|---|---|---|---|
| 打标期 | 1-7 天 | 有基础销量 + 标签初始化完成 | 新品标 + 首单礼金 + 超级立减 | 测图、直通车 |
| 起量期 | 8-15 天 | 进类目前 20 | 新品标 + 首单礼金 + 秒杀 | 超级短视频、秒杀 |
| 爆发期 | 16-30 天 | 进类目前五 | 热销爆品标 + 秒杀 + 首单礼金 + 购物金 + 淘金币 | 全站推广放量 |
| 稳定期 | 31 天+ | 付费占比下降、开始算利润 | 超级单品标 + 百亿补贴 + 购物金 + 淘金币 | 降付费 + 多链接 + 私域 |

**爆款判定公式**：LQ（导入期）> 0.6 具备潜力 / < 0.4 放弃；BQ（成长期）> 1.2 进爆款通道 / > 1.5 爆款确认；CQ（成熟期）> 0.8 可持续。

## 4. 付费工具选择（按 PPC 与人群精准度）

| 工具 | PPC | 人群精准度 | 适用场景 |
|---|---|---|---|
| 超级短视频 | **最低** | 中 | 所有品类（种草 + 拉新） |
| 引力魔方 | 低 | **极高** | 高客单、竞争渗透 |
| 全站推广 | 中 | 中 | 搜索少的店铺、动销款 |
| 直通车 | 高 | 高 | 标品、高客单 |

**全站推广三大误区**：① 开了就有流量（❌ 前提是产品在搜索池有竞争力）② 吃掉搜索流量（❌ 反而增加自然搜索）③ 推广问题在推广中解决（❌ 要在单品中找答案）。

## 6. 决策树：从症状到动作

```
投产好看但销售下滑
├─ 查间接成交占比
│  ├─ 间接 ≈ 2×直接 → 该品投放完全无效 → 停投（见 store-diagnosis）
│  └─ 间接 < 直接 → 正常拉新，转查转化链路（见 conversion-optimization）
└─ 检查领先率
   ├─ < 50% → 跑收割 → 清理收割型定向（智能推荐/全站）
   └─ ≥ 80% → 拉新正常 → 转查流量规模与人群浓度

新链接没流量
├─ 搜索端有词但没点击
│  ├─ 主图点击率不达标 → 测图（见 keyword-promo）
│  └─ 关键词太泛 → 换精准词/长尾
├─ 搜索端根本没词
│  └─ 补词路选款 + 趋势词开款（见 trend-keyword-launch）
└─ 有展现无转化
   └─ SKU / 主图 / 评价链路（见 conversion-optimization）

推广越投越贵
├─ 人群资产不足 → 先积累人群，不追 ROI（见 customer-asset-ops）
├─ 定向在跑收割 → 切换归因验证（见 store-diagnosis）
└─ 素材疲劳 → 素材节奏与八大入口（见 visual-material）

要投新店/新品
├─ 选品先过七维（见 selection-testing）
├─ 定价先留活动空间（见 pricing-margin）
└─ 爆款四阶段节奏（见 hit-product-lifecycle）
```

## 7. 推广红绿灯：目标怎么定 + 报表怎么出

**两套红绿灯别混**：巡店红绿灯是**相对**（对比自身 7 日均值），推广红绿灯是**绝对**（对比目标 ROI / 目标费比）。

**目标别手工拍，双轨取严**（`domain-growth-ops` ch09）：

| 轨道 | 目标投产比 | 目标去退费比 |
|---|---|---|
| A 利润约束（底线） | `1 ÷ [毛利率 × (1 − 退款率)]` | `(毛利率 − 运营成本率) ÷ (1 − 退款率)` |
| B 历史基线（可达） | 上期实际投产比 | 上期实际去退费比 |
| **取严** | **max(A, B)** | **min(A, B)** |

判定：投产绿 ≥ 目标 / 黄 ≥ 目标×0.8 / 红 < 目标×0.8；费比绿 ≤ 目标 / 黄 ≤ 目标×1.2 / 红 > 目标×1.2。

**出报表**（商品级走 Excel，店铺/计划级走 PG）：

```powershell
python skills\domain-growth-ops\scripts\red_green_report.py --input 推广红绿灯_2026-09.xlsx ^
  --gross-margin 0.30 --opex-rate 0.05 --period-days 30 --out-md 报表.md --out-xlsx 报表.xlsx
python skills\domain-growth-ops\scripts\red_green_report.py --pg-shop all --opex-rate 0.05 --out-md 店铺红绿灯.md
```

⚠️ 商品级红绿灯**只能**走 Excel 通道 —— 商品级 GMV/访客/退款率在生产库里没有对应字段。

## 8. 五大陷阱（容易得出"假好"结论的地方）

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 只看店铺整体投产 | 整体漂亮但单品在亏 | 按花费排序看商品报表 |
| 用默认归因 | 重复计算，看不出真拉新 | 切"第一次/最后一次访问来源" |
| 看推广投产不看总投产 | 高估付费效率 | 对比推广投产 vs 总投产，差值 = 免费流量占比 |
| 把 S 级当利润款 | 利润全被冲量吃掉 | S 级引流、A 级利润 |
| 用单次 ROI 判断人群策略 | 高预算买泛人群 | 看人群资产增量 / 付费消耗 |

## 9. 定价与活动预留

```
最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1−扣佣比例)
```

**不计入最低价**：首单礼金 / 新品礼金 / 店铺优惠券 / 购物金 / 淘金币 / 超级立减 / 会员专享
**计入最低价**：百亿补贴 / 秒杀 / 跨店满减 / 直降
