# 第 4 章 · 选路决策树

> 用途：从一个具体症状出发，判断该调用哪个 skill、第一步做什么。
> 决策树只解决"先做哪一步"，具体执行在对应 skill 里。

---

## 一、主线：按店铺生命周期选 skill

```
新店/新品立项
  └─→ selection-testing      （七维选品 + 测款测图）
        └─→ pricing-margin   （定价必须留活动空间）
              └─→ hit-product-lifecycle  （打标→起量→爆发→稳定）
                    └─→ wanxiangtai-wujie  （爆发期放量与计划组合）
                          └─→ profit-model（算账：ROI 是否过斩杀线）
                                └─→ customer-asset-ops（稳定期沉淀复购）

每日例行（开店检查）
  └─→ daily-store-patrol   （自动巡店：红绿灯表 + 今日行动清单 + 机会清单）
        └─→ 按行动清单分流 ↓

日常经营（已有在售链接）
  └─→ store-diagnosis       （先诊断，再动任何推广参数）
        ├─ 诊断结论指向货盘问题  → sabc-product-tiering
        ├─ 诊断结论指向计划问题  → wanxiangtai-wujie（怎么建）/ domain-growth-ops（加不加钱）
        ├─ 诊断结论指向转化问题  → conversion-optimization
        └─ 诊断结论指向人群问题  → customer-asset-ops

大促周期
  └─→ campaign-playbook（节奏与报名）→ pricing-margin（价盘）→ compliance-medical（文案审查）
```

## 二、按症状选 skill

| 症状 | 先看什么 | 去哪个 skill |
|---|---|---|
| 投产很好看但销售在跌 | 直接/间接成交比、领先率 | `[[store-diagnosis]]` |
| 某品花了钱没效果 | 该品领先率是否 <50% | `[[store-diagnosis]]` → `[[sabc-product-tiering]]` |
| 新链接没展现 | 有没有词、词准不准 | `[[keyword-promo]]` |
| 有展现没点击 | 主图点击率 | `[[keyword-promo]]`（测图）→ `[[conversion-optimization]]` |
| 有点击没转化 | SKU / 主图 / 评价 | `[[conversion-optimization]]` |
| 推广越投越贵 | 人群资产厚度、是否在收割 | `[[customer-asset-ops]]` → `[[store-diagnosis]]` |
| 钱花了 ROI 好看但不赚钱 | 退款率、间接成交占比 | `[[profit-model]]` |
| 不知道该给哪个品加预算 | 该品的顺逆差 | `[[profit-model]]` → `[[sabc-product-tiering]]` |
| **费比超了，该加该减** | 目标 ROI / 目标费比 → 两轴三色 | `[[domain-growth-ops]]`（ch06 红绿灯四场景） |
| **某个引流款费比高要不要砍** | 间接成交占比 | `[[domain-growth-ops]]`（ch06 病例①，可能是绿灯不是红灯） |
| **不知道投的是收割还是拉新** | 引潜比（引导访问潜客占比） | `[[domain-growth-ops]]`（ch05/ch06） |
| **左侧拉新看不到效果** | 末次归因导致 ROI 必然为零 | `[[domain-growth-ops]]`（ch06 达摩盘两步验证） |
| 计划该怎么搭、参数怎么设 | 全站/关键词/精准人群组合 | `[[wanxiangtai-wujie]]` |
| 爆款突然不爆了 | 处于哪个阶段、权重是否掉 | `[[hit-product-lifecycle]]` |
| 全店利润越来越薄 | 产品结构、预算分配 | `[[sabc-product-tiering]]` → `[[profit-model]]` |
| 大促报名被踢 | 价格力、体验分 | `[[pricing-margin]]`、`[[compliance-medical]]` |
| 老客不复购 | 人群分层与召回 | `[[customer-asset-ops]]` |
| 不知道做什么新品 | 趋势词、评价挖掘 | `[[trend-keyword-launch]]`、`[[review-insight-mining]]` |
| **今天该先动哪三件事** | 自动巡店出红绿灯表与行动清单 | `[[daily-store-patrol]]` |

## 四、四条分流铁律

1. **先诊断再动手。** 90% 的"推广问题"是单品问题，改计划只是掩盖。
2. **先资产再流量。** 人群资产厚度决定流量分配，资产不够时加预算等于买更泛的人。
3. **先结构再单点。** 全店结构（产品分级、预算分配）不对时，单点优化会被稀释。
4. **先算账再投入。** 过不了斩杀线的推广，多做多亏。

## 五、什么时候不该用任何 skill

- 需要**当日平台公告 / 规则原文**时 —— skill 里的阈值是快照，会过时
- 需要**竞品实时数据**时 —— skill 提供方法，数据要自己去生意参谋 / 达摩盘拉
- 涉及**非淘系平台**（京东/拼多多/抖音）时 —— 本技能库只覆盖淘系方法论
- 涉及**医疗器械资质具体办理流程**时 —— skill 只覆盖合规红线，不覆盖审批流程
