# 第 2 章 · 核心公式手册（15 条）

> 来源笔记：`淘系运营核心公式`（aiec.fun 电商栏目 + 智篆陪跑）、`2026淘宝运营完整知识体系`
> 用途：诊断工具 / 规划工具 / 复盘工具 / 决策工具 —— 同一个公式，四种用法。

---

## 一、业绩公式（3 条）

### 公式 1：销售额基本公式
```
销售额 = 流量 × 转化率 × 客单价
```
**应用**：流量不足 → 提流量（付费+免费）；转化率低 → 优化主图/详情/SKU；客单价低 → 套餐/关联销售。

### 公式 2：流量结构公式
```
总流量 = 免费流量 + 付费流量 + 内容流量
```
**占比参考**：

| 店铺类型 | 免费 | 付费 | 内容 |
|---|---|---|---|
| 健康店铺 | 60% | 30% | 10% |
| 快速起量 | 40% | 50% | 10% |
| 品牌店铺 | 50% | 30% | 20% |

### 公式 3：人群资产公式
```
AIPL 人群资产 = Awareness + Interest + Purchase + Loyalty
```
**核心逻辑**：人群资产不足 → 高预算也浪费；人群资产积累 → 需要时间和持续投入。

## 二、爆款公式（3 条）

### 公式 4：爆款打造核心公式
```
销售额 = 点击率 × 转化率 × 客单价 × 流量
```
**优先级**：点击率 > 转化率 > 客单价 > 流量
**行业基准（医疗器械类目）**：点击率 ≥3%（行业 1.5 倍）；转化率 ≥2%（看类目均值）；客单价看定位。

### 公式 5：爆款生命周期公式
```
打标期 → 起量期 → 爆发期 → 稳定期 → 衰退期
```
**时间参考**：打标 0-7 天｜起量 7-21 天｜爆发 21-45 天｜稳定 45-90 天｜衰退 90 天后

> ⚠️ 口径提醒：本知识库另有一份口径为 打标 1-7 / 起量 8-15 / 爆发 16-30 / 稳定 31+（见 `2026淘宝运营完整知识体系`），差异来自不同品类与阶段定义，**使用前需确认按哪套口径**。

### 公式 6：动销型爆款群公式
```
全店 GMV = S级爆款 + A级爆款 + B级爆款 + C级爆款
```
**梯队占比参考**：

| 梯队 | 销售额占比 | 预算占比 |
|---|---|---|
| S 级 | 30% | 50% |
| A 级 | 30% | 30% |
| B 级 | 25% | 15% |
| C 级 | 15% | 5% |

## 三、利润公式（3 条）

### 公式 7：利润基本公式
```
利润 = 销售额 × 毛利率 − 运营成本 − 推广费用
```
**运营成本包含**：人工、仓储物流、平台扣点、退款退货、办公杂费。

### 公式 8：ROI 盈亏平衡公式
```
盈亏平衡 ROI = 1 ÷ 毛利率
```
**示例**：毛利率 60% → 盈亏平衡 ROI = 1.67，ROI > 1.67 才盈利。

### 公式 9：斩杀线公式
```
斩杀线 = 固定成本 ÷ (毛利率 − 推广费用占比)
```
低于斩杀线则亏损难以为继。破法：控制固定成本 / 提升毛利率 / 优化推广费用占比。

## 四、效率公式（2 条）

### 公式 10：付费效率公式
```
付费效率 = 人群资产增量 ÷ 付费消耗
```
**核心逻辑**：不看单次 ROI，看人群资产沉淀。人群资产不足 → 优先积累人群；充足 → 追求 ROI 收割。

### 公式 11：新品成功率公式
```
新品成功率 = 测款通过率 × 爆款转化率
```
**核心判断**：99% 的问题出在选品测款。优化方向：提升测款标准（宁缺毋滥）、优化测款效率（缩短周期）。

---

## 五、客户公式（2 条）

### 公式 12：客户生命周期价值
```
LTV = 平均客单价 × 平均购买次数 × 平均生命周期
```
**参考（医疗器械类目）**：客单价 200-500 元，购买 2-3 次/年，生命周期 3-5 年 → LTV 1200-7500 元。

### 公式 13：新老客比例公式
```
健康店铺新老客比例 = 新客 50% : 老客 50%
```
新客成本高 → 提高新客转化效率；老客价值高 → 建会员体系提升复购。

## 六、医疗器械专项公式（2 条）

### 公式 14：医疗器械店铺公式
```
天猫好雅乐旗舰店 GMV = 仪器（流量入口）× 耗材（利润来源）
```
**核心指标**：仪器毛利率 20-30%（做流量）；耗材毛利率 60-70%（做利润）。

### 公式 15：四高人群公式
```
四高人群 = 高血压 + 高血糖 + 高血脂 + 高尿酸
```
以四高人群为核心原点，辐射家庭健康需求，构建医疗器械生态。

## 七、补充：其他体系里的关键公式

| 公式 | 出处 | 说明 |
|---|---|---|
| `成交机会 = 优先展现权激活人数 × 货品曝光场域数量 × 匹配商品数量` | 万相台无界 | 万相台投放的底层核心，详见 `[[wanxiangtai-wujie]]` |
| `成交规模 = AI→P 流转效率 × 人群资产总规模 × TA 人群浓度` | 万相台无界 | 决定能成交多大，不只是有多少流量 |
| `爆款权重 = 基础权重 × (标签权重之和) × 叠加系数` | 叠标体系 | 详见 `[[hit-product-lifecycle]]` |
| `领先率 = 新客成交 ÷ 总成交` | 店铺诊断四层分析法 | 判定"在拉新还是在收割"，详见 `[[store-diagnosis]]` |
| `顺逆差 = 单品成交金额占比 − 单品推广花费占比` | 爆款三板斧·投产诊断 | 正向=预算倾斜依据，负向=优化或淘汰，详见 `[[profit-model]]` |
| `真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交` | 2026-07-27 简报 | 对"投产"去伪，详见 `[[profit-model]]` |
| `最终定价 = 成本价 × (1+毛利率) × 1.2(跨店满减) × 1.05(购物金) × 1.1(淘金币) ÷ (1−扣佣比例)` | 2026淘宝运营完整知识体系 | 活动前定价必须留够空间，详见 `[[pricing-margin]]` |
| `店铺资产 = 兴趣点访客体量（核心）+ 新客沉淀体量` | 店铺资产 | 一切运营的基础，"无资产不标签" |
| `盈亏平衡投产比 = 1 ÷ (毛利率 × (1−退款率))` | 爆款三板斧·七维产品布局 | 定价与投放的共同约束 |

## 使用顺序建议

1. **诊断**：先用公式 1 定位是流量/转化/客单的问题，再用公式 12、13 看客户结构
2. **规划**：用公式 4、5 定爆款节奏，用公式 8、9 算清楚要卖多少才不亏
3. **复盘**：用公式 10、11 看投入产出结构，用顺逆差/真实投产判断单个链接的去留
4. **决策**：用公式 14、15 确认商业模式是否成立，再分配资源
