**素材时代** — 2026 年淘宝全面进入的阶段：**同一个产品，用不同素材，可获得完全不同的人群和流量规模**（来源：素材革命与八大流量入口.md）

**搜推素材** — 搜索推荐一体化素材，2026 年淘宝**投入资源最多**的素材形式；同时在搜索结果页、推荐页、活动页展示（来源：素材革命与八大流量入口.md）

**精选素材** — 被平台标记为"精选"的搜推素材，可获得 **10 倍以上流量**（来源：素材革命与八大流量入口.md）

**基础素材** — 素材时代的基础素材三类：**种草素材、场景图、卖点优化**（来源：素材革命与八大流量入口.md）

**导购标题** — 在常规标题前加"背书 + 数字 + 热点"前缀以提升点击率的标题写法，分数字型 / 名人型 / 热点型 / 特殊符号型四类（来源：素材革命与八大流量入口.md）

**AI万能搜** — 通过分析商品详细参数、属性、描述等信息理解商品功能特点的搜索能力；用户搜"直径 10 厘米的保温杯"时自动匹配所有填写了直径参数的保温杯（来源：素材革命与八大流量入口.md）

**商机发现** — 平台活动报名入口；带"金标"标识的活动可通过提交资料获取金标（来源：素材革命与八大流量入口.md）

**拍立淘扶持金标** — 获得后在**拍立淘搜索中置顶显示**的金标（来源：素材革命与八大流量入口.md）

**搜索推荐金标** — 获得后在**搜索和推荐中获得加权**的金标（来源：素材革命与八大流量入口.md）

**活动优先金标** — 获得后可**优先报名**平台活动的金标（来源：素材革命与八大流量入口.md）

**光合平台** — 发布商品短视频的入口，承接搜索短视频流量（来源：素材革命与八大流量入口.md）

**素材即人群** — 推荐算法通过识别素材内容来匹配人群：素材是"送给自己的礼物"推给自我犒劳人群，是"送给爸爸的礼物"推给孝心人群（来源：素材革命与八大流量入口.md）

**收推素材** — 将**站外内容（经授权）二次投放到淘宝**，降低制作成本、扩大覆盖面；落地形态为将小红书 / 抖音内容二次投放淘宝（来源：28-2026淘宝运营完整知识体系.md / 11-付费推广组合选择逻辑.md）

**选推素材** — ⚠️ **素材未覆盖，未验证**：本次可读素材中未检索到该词，不排除是"收推素材"的笔误（来源：无）

**FABE 主图法则** — Feature 特征 → Advantage 优点 → Benefit 利益 → Evidence 证据；**大多数商家只做到特征和优点，缺少最重要的证据部分**（来源：24-转化率全链路优化.md / 28-2026淘宝运营完整知识体系.md）

**高点击率主图四要素** — 卖点突出 / 差异化 / 场景化 / 信任背书（来源：b12-爆款三板斧-产品布局.md）

**词图匹配** — 搜索什么展示什么，是主图的基本要求（来源：b12-爆款三板斧-产品布局.md）

**词图人匹配** — 了解买的人的内心向往，比词图匹配更高境界（来源：b12-爆款三板斧-产品布局.md）

**主图打标三法** — 系统热销标模拟（鹿班中心 PNG 白底底图）、冠军标打造（定语足够多什么都能是第一）、榜单效应（幸运榜截图）三种做法（来源：24-转化率全链路优化.md）

**鹿班中心** — 上传带热销标签的 PNG 白底图作为背景图、使所有主图显示热销标签的官方素材工具（来源：24-转化率全链路优化.md）

**幸运榜** — 新品最容易上的榜单，只要有一笔成交就可能登上第一名（来源：24-转化率全链路优化.md）

**竞品主图模仿法** — AI 出图方法：找竞品优质主图 → 输入"换一个模特，其他场景保持 80% 不变，文案改成<你的文案>"生成新图（来源：AI智能体应用.md）

**同款模特多产品生成法** — AI 出图方法：豆包上传模特照 → AI 反推提示词 → 上传新产品白底图 → 用提示词生成（来源：AI智能体应用.md）

**市场爆款主图学习法** — AI 出图方法：指令"分析 XX 类目的点击标准，学习前 20 的商品主图，并生成我自己的商品图"（来源：AI智能体应用.md）

**竞品风格复刻法** — AI 出图方法：上传竞品主图 + 自己白底图 → "将竞品的风格沿用到我的白底图上，生成 8 个场景图"（来源：AI智能体应用.md）

**3C 化 / 礼品化转型** — 把医疗器械当作"健康礼品"或"高颜值 3C 设备"呈现的视觉升级方案；核心逻辑是**把"买医疗器械"变成"买健康生活方式"**（来源：视觉升级方案-3C化礼品化.md）
