## 3. 主图要素速查

| 要素 | 内容 | 例子 |
|---|---|---|
| **四要素** | 卖点突出 / 差异化 / 场景化 / 信任背书 | — |
| **F** 特征 | 产品基本属性 | 纯棉材质、防水设计 |
| **A** 优点 | 特征带来的优势 | 透气舒适、不怕雨淋 |
| **B** 利益 | 对消费者的好处 | 穿着舒服、雨天不用愁 |
| **E** 证据 | 证明的证据 | 90 天免费试用、10 万+好评 |

**前三张排布**：第 1 张**卖点** → 第 2 张**背书** → 第 3 张**收益**。
**最常见短板**：缺 **Evidence**。

**主图 vs 素材 vs 详情页的分工**：主图管**点击**，SKU 管**转化**（★★★★★），详情页优先级最低（★★☆☆☆）。

## 4. 决策规则：先做哪个

```
免费流量不足 / 素材没铺
└─ 搜推素材传了吗 → 传（成本≈0）
   └─ 传了 → 30 天未成精选的换掉

搜索有展现没点击
├─ 标题 → 加导购标题前缀（周三测）
└─ 主图 → 四要素 + FABE 补 Evidence

长尾词拿不到排名
└─ 参数填全了吗 → 补参数 + 自然语言描述（周四）

内容流量要增量
├─ 光合平台发了吗（话题改长尾词了吗）
└─ 站外内容能二次利用吗 → 收推素材

客单价上不去（医疗器械）
└─ 3C 化礼品化 → P0 首焦图换场景化 + 礼盒图

一个商品要更多流量
└─ 爆品裂变八大方法（细节素材未覆盖）
```

## 6. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| **只传 1-2 条搜推素材就不管** | 上限太低，拿不到精选流量 | 按周滚动替换，30 天规则 |
| **用 AI 生成视频投搜推素材** | 效果明显差于真实拍摄 | 搜推位坚持实拍，AI 用于其他内容位 |
| **卖点铺 5-6 个** | 等于没有卖点 | 每商品只留 **1-2 个**，可量化 |
| **主图只做 F/A 没有 E** | 用户没被说服 = 跳失 | 补 Evidence（试用/销量/评价） |
| **同时换主图 + 改 SKU + 动详情页** | 无法归因 | 一次只改一个变量 |
| **光合平台用系统推荐话题** | 拿不到长尾词 | 删掉系统话题，手填长尾词 |
| **参数写错凑长尾词** | 被自动匹配到错人群，转化更差 | 参数必须与注册证/实物一致 |
| **AI 出图不人工过** | 医疗类目踩禁用词 | 出图后过合规表 |
| **把收推素材与选推素材当同一概念** | 概念混乱，指令下达错 | 选推素材**素材未覆盖**，先核对 |
| **在爆量期中途换素材表达** | 打断爆款节奏，人群标签乱 | 换在打标期或稳定期 |
| **详情页当主图来救点击率** | 优先级错配，无效投入 | 转化链路：SKU ＞ 主图 ＞ 买家秀 ＞ 详情页 |

## 7. 合规红线提醒（视觉相关）

| 项 | 规则 |
|---|---|
| **禁用词** | 绝对化用语、医疗效果承诺、功效夸大、安全性虚假承诺等 **5 组 50+** |
| **主图高危表达** | "医院同款""治愈""100% 安全""无副作用"——3C 化方案示例里的"医院同款精度"即在禁用范围内 |
| **资质展示** | 只展示真实持有的注册证 / 认证，不得虚构 |
| **灰产手法** | 热销标模拟、冠军标打造、榜单 P 图、"定语足够多什么都能是第一"属灰色手法，平台规则风险自担 |
| **详情页必做** | 医疗器械详情页必须展示注册证；标签强制标注 7 项缺一即违规 |

> 完整红线与处罚分级见 [[compliance-medical]]。
