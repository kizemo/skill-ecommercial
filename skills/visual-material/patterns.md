## 素材换人群法（皮带案例复现法）

**何时用**：一个商品流量见顶 / 转化率被锁死在某个水平 / 想开发第二个人群；尤其当商品本身是"功能品"（皮带、血压计、收纳盒）而非纯审美品。

**怎么做**：
1. 写下当前素材在表达**产品属性**还是**使用场景**（"男士真皮皮带"= 属性；"父亲节礼物"= 场景）；
2. 列出商品的 2-3 种**赠送关系**（送自己 / 送父亲 / 送客户 / 送伴侣）；
3. 每种关系写一条素材表达，跑测；
4. 对比人群年龄性别、转化率、流量规模三项；
5. 保留人群规模与转化率同时提升的那条（皮带案例：25-35 岁男性 3% → 20-30 岁女性 6%，流量 ×3）。

**代价/风险**：改人群 = 改竞争场，同一商品在新人群里是**新对手**，需要重新积累该人群的信任与评价；不要在爆量期中途换素材（会打断爆款节奏），换在打标期或稳定期。

## 搜推素材滚动替换法

**何时用**：每周固定动作；搜推素材上线 30 天后；店铺免费流量占比低。

**怎么做**：
1. 千牛后台 → 素材中心 → 搜推素材 → 上传（1 主图 + 1 文案，填满标题、卖点、标签）；
2. 上传量按"多传"铺（原文案例 39 条）；
3. 每周一检查上周上传素材是否被标记"精选"；
4. **满 30 天未成精选的立即替换**；
5. 记录精选率（案例：25/39 ≈ 64%）与免费流量占比变化（案例：20% → 50%）。

**代价/风险**：素材产能是瓶颈（每条都要单独写文案与卖点）；**30 天规则会带来替换压力**，必须预留产能；用 AI 生成视频省事但效果差，搜推素材位坚持真实拍摄。

## 参数深填（AI万能搜）法

**何时用**：长尾词拿不到排名；周四固定动作；新品上架后。

**怎么做**：
1. 把商品所有参数写全：尺寸、重量、材质、颜色（**尺寸类参数优先**）；
2. 用**用户会说的自然语言**写功能、特点、使用方法（"能放进书包的保温杯"而不是"容积 350ml"）；
3. 主动覆盖长尾关键词表达；
4. 验证：搜"能放进书包的保温杯""12 小时保温的保温杯"是否进前三。

**代价/风险**：参数写错 = 被"自动匹配"到错误人群，转化反而更差；**医疗类目参数必须与注册证一致**（见 [[compliance-medical]]），不能为了覆盖长尾词编参数。

## 导购标题前缀法

**何时用**：搜索有展现但点击率低；周三固定动作；新链接冷启动。

**怎么做**：
1. 取现有标题作为底稿，**一个字不改**；
2. 从四类前缀里选一条加在**最前面**：数字型（"热销 10000 件"）、名人型（"佳琪推荐"）、热点型（"小红书爆款"）、特殊符号型（"㊣正品保证"）；
3. 一次只加一条，测点击率；
4. 保留点击率最高的那条（原文实测提升 25%-40%）。

**代价/风险**：**加前缀不改变标题的搜索匹配逻辑**，只改点击；标题本身仍要按"核心词放两端、长尾词布局中间"组织（见 ch02 §5.3）；堆多个前缀会稀释信息量——每次只加一个。

## 前三张主图三段式排布

**何时用**：主图点击率提升不明显；主图信息过载；进入商品页后跳失。

**怎么做**：
1. 第 1 张：**卖点**（核心卖点 + 差异化，1-2 个，不塞满）；
2. 第 2 张：**背书**（资质 / 销量 / 评价）；
3. 第 3 张：**收益**（Benefit，消费者拿到的好处）；
4. 按 FABE 逐格自检，重点补 **Evidence**；
5. 一次只改一张，按测图 SOP 验证（[[keyword-promo]]）。

**代价/风险**：三张各承担一件事 = 素材成本上升（要分别设计）；"热销标""冠军标"类打标属灰色手法，平台规则风险自担。

## 3C 化礼品化视觉升级法

**何时用**：医疗器械 / 家用器械类目客单价上不去；用户反馈"像生病才需要"；想开送礼场景。

**怎么做**：
1. **先定试点 3 款**：电子血压计（送礼场景强）/ 家用按摩仪（3C 属性最强）/ 体温计血氧仪（低价引流 + 礼品套装高价）；
2. **P0 立即做**：5 张主图按 3C 标准重做，首焦图从白底图换成场景化图，礼盒展示图上线；
3. **配色**：主色深空灰 / 午夜蓝 / 质感白，辅色香槟金 / 玫瑰金，强调色活力橙 / 翡翠绿；
4. **礼盒**：磨砂质感 + 烫金 Logo + 丝带，内含说明书 + 健康卡片 + 手提袋；
5. **详情页**按 9 段 3C 框架重排，重点信息前置；
6. **验收**：对照方案自带四条指标——CTR ≥5%、静默转化率 ≥3%、礼盒装客单价 ≥×1.5、送礼场景订单占比 ≥15%。

**代价/风险**：**首焦图改造影响最大也最贵**（场景主图 3 张/产品，P0 高成本）；方案原文自注"待评审后更新为 verified"，**先出样机内部评审再正式拍摄**；⚠️ **合规冲突高发**：方案示例中的"医院同款精度"属禁用词组，绝对化/医疗效果承诺一律替换（见 [[compliance-medical]]）。

## 收推素材（站外二次投放）法

**何时用**：站内内容产能不足；已有小红书 / 抖音内容资产；内容成交占比考核压力大。

**怎么做**：
1. 确认站外内容**已获授权**（素材原文明确"经授权"）；
2. 把小红书 / 抖音内容二次投放淘宝（超级短视频为常用载体）；
3. 视频按要点制作：**卖点可视化、15-30 秒、真人出镜**；
4. 两类视频配齐：**收割类**（直接引导购买）+ **种草类**（建立认知）；
5. 小红书侧配套：100-1000 粉素人铺笔记、**引导搜索店铺名不放链接**、淘宝首页设专属优惠；
6. 跟踪：内容成交占比、每 1000 小红书流量带来的免费大词流量。

**代价/风险**：**授权是硬前提**，无授权搬运直接违规；站外内容的语气未必适合淘宝成交场景，收割类与种草类混用会拉低转化；投放强度按阶段走——打标期几乎不用超级短视频（★★☆☆☆），爆发期最重（★★★★☆）。

## AI 主图批量出图 + 测图法

**何时用**：主图点击率低于行业 1.5 倍（医械基准 ≥3%）；需要快速产出 A/B 素材；主图风格不统一。

**怎么做**：
1. 选方法：**竞品主图模仿**（换模特保场景）/ **同款模特多产品**（保风格省模特费）/ **市场爆款学习**（学类目前 20 名）/ **竞品风格复刻**（批量出场景图）；
2. 一次生成 **10-20 张**不同风格；
3. 按测图 SOP 跑，选点击率最优的（[[keyword-promo]]）；
4. **人工过一遍文案与画面**：医疗类目必过禁用词表。

**代价/风险**：**盗图风险**——不要完全复制竞品主图，注意细节修改；AI 生成内容**需人工审核**；AI 出的文案容易踩绝对化用语；**AI 生成视频不用于搜推素材位**。

## 素材→人群→成交因果链自检

**何时用**：每周日复盘；素材铺了但流量没起；点击高但转化低。

**怎么做**：
```
① 素材表达对不对人 → ② 人群对不对 → ③ 流量池够不够大
  → ④ 点击率行不行 → ⑤ SKU 承不承接得住 → ⑥ 内容成交占比涨没涨
```
逐环节定位断点，只修**第一个**断点。

**代价/风险**：最常见的误判是"素材没问题"——实际断点在 ④→⑤（SKU 承接），那属于 [[conversion-optimization]]，改素材无效。
