# 速查表 · trend-keyword-launch

> 规则来自知识库原文快照。词语分类与 SAB 分级是经验规则，素材未给量化阈值。

---

## 1. 词语七分类（逐词打标签）

| # | 分类 | 策略 | 示例 |
|---|---|---|---|
| 1 | 强设计元素词 | ✅ **保留** | 魔鬼鱼、月牙、流苏、荷鲁斯之眼 |
| 2 | 结构词 | ✅ **保留** | 锁骨链、吊坠、链条 |
| 3 | 材质词 | ✅ **保留** | 珍珠、宝石、金属 |
| 4 | 风格词 | ⚠️ **辅助参考** | 轻奢、复古、少女 |
| 5 | 品牌词 | ❌ **剔除** | 蒂芙尼、克罗心、英文品牌 |
| 6 | 无效词 | ❌ **剔除** | 夏天、新款、百搭、999 |
| 7 | 场景词 | ⚠️ **弱价值** | 送妈妈、礼服、约会 |

---

## 2. 可开款判据

| | 条件 |
|---|---|
| **必须满足** | ✔ 至少包含「设计元素」或「结构元素」 |
| **必须剔除** | ✘ 品牌词 ／ ✘ 无法形成具体产品结构的词 ／ ✘ 纯形容词（高级感、夏天） |

**三格测试**：词放进「设计元素 / 结构 / 材质」三格，都进不去 → 纯形容词，剔除。

---

## 3. 组合公式

```
开款结构：【元素】+【结构】+【材质/风格】
标题结构：【核心元素】+【结构】+【人群】+【风格】+【使用场景】
```

---

## 4. 词包分层

| 层级 | 示例 | 投放用法 |
|---|---|---|
| 核心词 | 魔鬼鱼项链 | 卡主战场，精准匹配 + 高出价 |
| 扩展词 | 小众项链 / 设计感项链 | 扩量 |
| 长尾词 | 轻奢魔鬼鱼锁骨链 | 精准人群，低出价拉新 |

**每个词必须标：拉新词 / 收割词。**

---

## 5. SAB 分级（趋势强度 + 通用性）

| 等级 | 描述 | 示例 | 打法 |
|---|---|---|---|
| **S 级（爆款）** | 强趋势 + 强设计 | 魔鬼鱼 / 荷鲁斯之眼 | 抢首发、做差异化、全力推 |
| **A 级（放量）** | 通用设计 | 星 / 月牙 / 花朵 | 跟得上就跑量，铺量 |
| **B 级（利润）** | 材质类 | 珍珠 / 宝石 | 靠材质与工艺赚溢价 |

> ⚠️ 与 `[[sabc-product-tiering]]` 的 S/A/B/C **不是同一套判定标准**。

## 8. 数据输入三字段

| 字段 | 说明 |
|---|---|
| 搜索词 | 必填 |
| 搜索增速 | 如有；**趋势 vs 热搜的分界依据** |
| 类目 | 默认饰品-项链/耳环，**换类目必须改写** |

---

## 9. 五条执行纪律

| 纪律 | 违反后果 |
|---|---|
| 逐词输出分类标签，不抽样 | 后面步骤无法执行 |
| 剔除的词也记录原因 | 无法回溯漏掉了什么 |
| 标题必须可搜（核心词在两端） | 拿不到搜索流量 |
| 词包必须标拉新/收割 | 投手只能猜出价策略 |
| SAB 要说清两轴高低 | 无法判断能否改造提级 |

---

## 10. 决策树：产出后往哪走

```
趋势词开款产出
├─ SAB = S（强趋势+强设计）
│  └─ 抢首发，做差异化设计 → 打样 → 上架 → 测款（[[selection-testing]]）
├─ SAB = A（通用设计）
│  └─ 跟速度、比价格 → 铺量 → 全站低价跑量（[[wanxiangtai-wujie]]）
├─ SAB = B（材质类）
│  └─ 做材质与工艺溢价 → 定价走价值定价（[[pricing-margin]]）
└─ 任何等级
   ├─ 先过七维选品（[[selection-testing]]）
   └─ 医械类目先过合规（[[compliance-medical]]）
```
