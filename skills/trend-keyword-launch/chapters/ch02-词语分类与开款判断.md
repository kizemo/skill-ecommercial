# 第 2 章 · 词语分类与开款判断

> 分类与过滤是这个引擎的**核心判断环节** —— 后面 8 步全是机械执行，判断错一步就全错。

---

## 一、为什么"热搜词"是这个引擎要避开的坑

| 类型 | 特征 | 战略含义 |
|---|---|---|
| **热搜词** | 当前热门，**已被市场验证** | 竞争激烈 = **红海**；验证过需求，也验证过所有人能做 |
| **趋势词** | **搜索增速高**，尚未被验证 | 先发优势 = **蓝海机会** |

**本工具包的核心就是趋势词开款。** 输入端就应该喂趋势词榜单（搜索增速词），而不是热搜榜。

> 但要注意一个前提：趋势词意味着**需求还没被验证**。所以产出的品必须走 `[[selection-testing]]` 的七维选品与测款验证，不能因为是"趋势"就直接重仓。

---

## 二、七分类的判定逻辑

分类不是按"这个词好不好"，而是按"**这个词能变成什么**"。

### 保留类（三类）

| 分类 | 判定标准 | 为什么能开款 |
|---|---|---|
| **强设计元素词** | 是产品上看得见的**视觉主体** | 直接决定款式，是差异化的来源 |
| **结构词** | 是产品**形态**（链条、吊坠、锁骨） | 决定产品属于哪一类、怎么挂、怎么卖 |
| **材质词** | 是产品**材料** | 决定成本、定价、毛利空间 |

### 辅助类（两类）

| 分类 | 定位 | 用法 |
|---|---|---|
| **风格词** | 描述**调性**，不描述产品 | 用于标题与视觉方向，**不能单独成款** |
| **场景词** | 描述**使用场合**，不描述产品 | 弱价值：可作标题尾段或人群辅助标签 |

### 剔除类（两类）

| 分类 | 为什么必须剔除 |
|---|---|
| **品牌词** | 别人的商标，不能用在标题与开款里；且它指向的是已被占据的词位 |
| **无效词** | 泛化词汇，跟任何产品都能沾边 → **无法指导开款**（"999""百搭""新款"） |

## 三、过滤判据的三条硬线

```
必须满足：
✔ 至少包含「设计元素」或「结构元素」

必须剔除：
✘ 品牌词
✘ 无法形成具体产品结构的词
✘ 纯形容词（高级感/夏天）
```

### 第 1 条为什么是"或"而不是"且"
材质词单独就能成款（珍珠耳环、宝石戒指）—— 所以"元素或结构"里，材质归到元素侧时才成立；**材质 + 结构**是最低配组合。

### 第 3 条：纯形容词是最大的漏斗
「高级感」「夏天」「新款」这类词：
- 搜索量可能很大（看起来是好词）
- 但**开不出款** —— 你不知道要做什么产品
- 在标题里也只能占辅助位

**判别动作**：把词放到"元素/结构/材质"三个格子里试一遍，**三个都放不进去就是纯形容词**。

## 四、从词到款的拆解动作

对每个通过过滤的词，逐个回答四个问题：

| 问 | 答 | 缺失时 |
|---|---|---|
| **核心元素是什么？** | 视觉主体（魔鬼鱼） | 该词不该通过过滤 |
| **结构是什么？** | 产品形态（吊坠/锁骨链/鱼线链） | 只能做单品，做不了系列 |
| **材质是什么？** | 材料属性（珍珠/金属/透明） | 成本与毛利无法估 |
| **风格是什么？** | 调性（轻奢/复古/少女） | 标题与视觉缺方向 |

### 组合公式

```
【元素】+【结构】+【材质/风格】
```

材质与风格是**二选一或并列**的组合位 —— 因为它们在不同品类里的优先级不同：
- 饰品：材质优先（珍珠 > 风格）
- 服装：风格优先（版型/风格 > 材质）
- 家电：结构与参数优先

> **类目不同，四要素的映射要重写。** 素材默认是饰品-项链/耳环。

## 五、SAB 分级：两轴判断

依据是「**趋势强度 + 通用性**」，不是流量或利润。

| 等级 | 描述 | 示例 | 打法 |
|---|---|---|---|
| **S 级（爆款）** | 强趋势 + 强设计 | 魔鬼鱼 / 荷鲁斯之眼 | 抢首发，做差异化设计，全力推 |
| **A 级（放量）** | 通用设计 | 星 / 月牙 / 花朵 | 跟得上就能跑量，做通用款铺量 |
| **B 级（利润）** | 材质类 | 珍珠 / 宝石 | 用材质溢价做利润款，款式不重要 |

**读法**：
- **趋势强 + 设计强** → S：既是蓝海又有辨识度，值得押注
- **设计通用** → A：谁都能做，拼的是速度与价格
- **本质是材质** → B：款式可替代，只能靠材质与工艺赚溢价

## 六、常见误判与纠正

| 误判 | 后果 | 纠正 |
|---|---|---|
| 把热搜词当趋势词输入 | 追红海，投放成本高、没有先发优势 | 确认输入是**搜索增速**榜单 |
| 保留"夏天""新款" | 开款方向为空，后面 8 步全跑偏 | 过一遍"元素/结构/材质"三格测试 |
| 只按词面分类不看能否成款 | 分类正确但开不出款 | 过滤步骤必须执行 |
| 风格词当核心元素 | 标题空泛，搜不到词 | 风格只能进辅助位 |
| 换类目不改四要素映射 | 产出饰品结构套到别的类目 | 换类目必须重写结构词与人群标签 |
| SAB 只给等级不说两轴 | 无法排期 | 每次分级要说明趋势强度与通用性各是高还是低 |

## 七、产出的下游衔接

```
趋势词开款
  ├─ 开款方向 → 供应链打样
  ├─ 标题     → 上架（标题权重：核心词两端，长尾词中间）
  ├─ 词包     → 投放计划（核心/扩展/长尾，拉新/收割标注）
  ├─ 人群标签 → 定向设置
  └─ SAB 分级 → 排期与预算分配
```

对应 skill：
- 标题与词包 → `[[keyword-promo]]`
- 人群标签 → `[[customer-asset-ops]]`
- 分级与预算 → `[[sabc-product-tiering]]`
- 上架后验证 → `[[selection-testing]]`（七维 + 测款）
