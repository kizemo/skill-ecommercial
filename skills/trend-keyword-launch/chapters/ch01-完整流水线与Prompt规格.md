# 第 1 章 · 完整流水线与 Prompt 规格

> 来源笔记：`电商趋势词开款与投放自动化引擎技能包`（智篆商业 少壮老师，第二次线下坐诊 2026-05-10）
> 本文是该技能包的**可直接执行规格**，可整段作为系统提示词使用。

---

## 一、Prompt 头部（技能目标 + 数据输入）

```
## 技能目标
将「淘宝搜索增速词榜单」自动转化为：
- 可开款趋势词
- 产品结构方案
- 标题生成
- 投放词包
- SAB分级策略

## 数据输入
你现在有一份趋势词榜单（搜索增速词）。
请读取数据，并提取以下字段：
- 搜索词
- 搜索增速（如有）
- 类目（默认饰品-项链/耳环）
```

---

## 二、词语分类（核心判断引擎）

```
请对每一个词进行分类，必须输出以下分类标签：
```

| 分类 | 说明 | 示例 |
|---|---|---|
| 1. 强设计元素词（保留） | 核心视觉元素 | 魔鬼鱼、月牙、流苏、荷鲁斯之眼 |
| 2. 结构词（保留） | 产品形态 | 锁骨链、吊坠、链条 |
| 3. 材质词（保留） | 材料属性 | 珍珠、宝石、金属 |
| 4. 风格词（辅助） | 调性描述 | 轻奢、复古、少女 |
| 5. 品牌词（剔除） | 知名品牌 | 蒂芙尼、克罗心、英文品牌 |
| 6. 无效词（剔除） | 泛化词汇 | 夏天、新款、百搭、999 |
| 7. 场景词（弱价值） | 使用场景 | 送妈妈、礼服、约会 |

---

## 三、筛选过滤（可开款判据）

```
## 四．只保留符合以下条件的词

必须满足：
- ✔ 至少包含「设计元素」或「结构元素」

必须剔除：
- ✘ 品牌词
- ✘ 无法形成具体产品结构的词
- ✘ 纯形容词（高级感/夏天）

输出结果：
### 五．👉【可开款趋势词列表】
```

---

## 四、开款结构拆解与公式

```
针对每一个"可开款词"，自动拆解生成：
- 核心元素（如：魔鬼鱼）
- 结构（吊坠/锁骨链/鱼线链）
- 材质（珍珠/金属/透明）
- 风格（轻奢/复古/少女）

并组合为：
> 开款结构公式：【元素】+【结构】+【材质/风格】
```

---

## 五、标题生成

```
## 六．标题生成
根据开款结构，生成电商标题：

标题结构：
【核心元素】+【结构】+【人群】+【风格】+【使用场景】

要求：
- 符合淘宝搜索习惯
- 覆盖核心关键词
- 可用于直通车/自然搜索
```

---

## 六、投放词包

```
## 七．投放词包
为每个产品生成关键词包，包含：
- 核心词（如：魔鬼鱼项链）
- 扩展词（如：小众项链/设计感项链）
- 长尾词（如：轻奢魔鬼鱼锁骨链）

并标记：拉新词 / 收割词
```

---

## 七、人群匹配

```
## 八．人群匹配
根据产品类型，自动匹配人群：
- 性别（女性）
- 年龄段（18-35）
- 消费力（L3-L5）
- 兴趣标签（轻奢/小众/设计感/潮流）
```

---

## 八、SAB 分级

```
## 九．SAB分级
根据趋势强度+通用性进行分级：

| 等级 | 描述 | 示例 |
| S级（爆款） | 强趋势+强设计 | 魔鬼鱼/荷鲁斯之眼 |
| A级（放量） | 通用设计 | 星/月牙/花朵 |
| B级（利润） | 材质类 | 珍珠/宝石 |

输出：SAB等级 + 操作优先级
```

## 九、最终输出表格（11 字段）

```
## 十．最终输出表格字段

| 趋势词 | 核心元素 | 结构 | 材质 | 风格 | 开款方向 | 标题 | 投放关键词 | 人群标签 | SAB分级 | 优先级 |
```

---

## 十、字段含义速查

| 字段 | 含义 | 下游用途 |
|---|---|---|
| 趋势词 | 原始输入词 | 溯源 |
| 核心元素 | 视觉主体 | 设计需求单 |
| 结构 | 产品形态 | 打样、链接结构 |
| 材质 | 材料属性 | 供应链、定价 |
| 风格 | 调性 | 视觉与内容方向 |
| 开款方向 | 元素+结构+材质/风格 | 交给供应链开款 |
| 标题 | 五段式标题 | 直接上架用 |
| 投放关键词 | 核心/扩展/长尾 + 拉新/收割标注 | 投放计划（见 `[[keyword-promo]]`） |
| 人群标签 | 性别/年龄/消费力/兴趣 | 定向设置（见 `[[customer-asset-ops]]`） |
| SAB分级 | 趋势视角的优先级 | 排期（见 `[[sabc-product-tiering]]`） |
| 优先级 | 操作顺序 | 执行排期 |

---

## 十一、执行纪律

1. **分类标签必须逐词输出** —— 不能抽样、不能概括。"每个词都要打标签"是这个引擎能用的前提。
2. **可开款列表要完整** —— 步骤 3 剔除的词也要记录剔除原因，否则无法回溯漏掉了什么。
3. **标题必须可搜** —— 生成后自检：核心词是否在两端、长尾词是否覆盖人群+场景。
4. **词包必须标拉新/收割** —— 未标注的词包无法直接用于建计划。
5. **SAB 分级两轴都要说清** —— 只给等级不说"趋势强度 vs 通用性"哪个高，等于没分。
