# 术语表 · trend-keyword-launch

> 每条标注来源笔记。

**搜索增速词 / 趋势词** — 搜索增速高的词，尚未被市场验证 = 蓝海机会。与已被验证的**热搜词**（红海）相对。本工具包的核心输入。（来源：`电商趋势词开款与投放自动化引擎技能包`）

**热搜词** — 当前热门词，已被市场验证，同时意味着竞争激烈 = 红海。（来源：`电商趋势词开款与投放自动化引擎技能包`）

**强设计元素词** — 核心视觉元素词，分类 1，保留。示例：魔鬼鱼、月牙、流苏、荷鲁斯之眼。（来源：`电商趋势词开款与投放自动化引擎技能包`）

**结构词** — 产品形态词，分类 2，保留。示例：锁骨链、吊坠、链条。（来源：同上）

**材质词** — 材料属性词，分类 3，保留。示例：珍珠、宝石、金属。（来源：同上）

**风格词** — 调性描述词，分类 4，辅助参考。示例：轻奢、复古、少女。（来源：同上）

**品牌词** — 知名品牌词，分类 5，剔除。示例：蒂芙尼、克罗心、英文品牌。（来源：同上）

**无效词** — 泛化词汇，分类 6，剔除。示例：夏天、新款、百搭、999。（来源：同上）

**场景词** — 使用场景词，分类 7，弱价值。示例：送妈妈、礼服、约会。（来源：同上）

**开款结构公式** — 【元素】+【结构】+【材质/风格】。对每个可开款词拆解出核心元素、结构、材质、风格后组合而成。（来源：同上）

**标题结构（五段式）** — 【核心元素】+【结构】+【人群】+【风格】+【使用场景】。要求符合淘宝搜索习惯、覆盖核心关键词、可用于直通车与自然搜索。（来源：同上）

**投放词包** — 分核心词 / 扩展词 / 长尾词三层，每个词须标记**拉新词 / 收割词**。（来源：同上）

**SAB 分级（趋势词视角）** — 按「趋势强度 + 通用性」两轴分级：S 级（爆款，强趋势+强设计）、A 级（放量，通用设计）、B 级（利润，材质类）。输出等级 + 操作优先级。（来源：同上）

**11 字段输出表** — 趋势词 / 核心元素 / 结构 / 材质 / 风格 / 开款方向 / 标题 / 投放关键词 / 人群标签 / SAB分级 / 优先级。（来源：同上）

**三阶引擎** — 聚焦投资 → 产品优化 → 计划落地 的三层货盘经营工具。第一层用 SAB 分级确定推广优先级，第二层用 8 维度考核验证产品力。本技能包的 SAB 输出即第一层输入。（来源：`三阶引擎工具表-说明`）
