# 术语表 · sabc-product-tiering

> 每条格式：`**术语** — 定义（来源：<笔记名>）`
> 来源笔记均为 `taobao-operation` 知识库正文截取。

---

**SABC 分级体系** — 将店铺所有产品按战略价值、销售贡献、利润贡献和生命周期阶段分为 S/A/B/C 四级的运营方法论；核心逻辑是在资源永远稀缺的约束下，把 80% 的资源投入 20% 的高价值产品，实现流量获取效率与利润产出最大化（来源：SABC分级体系）

**S 级** — 核心爆款，店铺的「流量发动机」，核心使命是击穿类目、获取人群资产；体量 1-2 个（最多 3 个），流量贡献 60-70%，利润贡献低/微利，生命周期 6-12 个月+（来源：SABC分级体系）

**A 级** — 次爆款，店铺的「利润奶牛」，核心使命是精准收割、转化利润；体量 3-5 个，流量贡献 20-30%，利润贡献 60-70%，生命周期 3-6 个月（来源：SABC分级体系）

**B 级** — 平销款，店铺的「产品线补充」，使命是丰富产品线、提高用户停留时间和转化率；体量 10-20 个，流量贡献 5-10%，利润贡献 10-20%，生命周期 1-3 个月（来源：SABC分级体系）

**C 级** — 滞销款，店铺的「负资产」，需及时淘汰释放资源；体量越少越好（≤10%），流量贡献 < 5%，利润贡献为负利润，生命周期结束（来源：SABC分级体系）

**流量发动机** — S 级的角色称谓，指该链接的主要价值是把流量引进店铺而不是自己赚钱（来源：SABC分级体系）

**利润奶牛** — A 级的角色称谓，指该链接的主要价值是把流量转化成利润（来源：SABC分级体系）

**关联销售率** — 一个链接带出其他产品成交的比例；S 级要求 > 30%，A 级要求 > 20%，是判断链接是否在为全店导流的核心指标（来源：SABC分级体系）

**金字塔结构** — S/A/B/C 的分布形态：S 级在塔尖，A 级在第二层，B 级在第三层，C 级在塔基（来源：SABC分级体系）

**实施五步法** — 产品盘点 → 产品分级 → 资源分配 → 差异化运营策略 → 动态迭代（来源：SABC分级体系）

**产品盘点** — 五步法第一步：导出销售/流量/利润/库存数据，计算各关键指标，形成盘点报告（来源：SABC分级体系）

**分级公示执行** — 五步法第二步的收尾动作，分级结论必须公示到人、公示到计划，否则执行回到平均主义（来源：SABC分级体系）

**保底利润率阶梯** — 三阶引擎第一层为每个等级设定的最低利润率要求：S 品 10% / A 品 15% / B 品 20% / C 品 25%（来源：智篆陪跑第二次线下坐诊-核心提炼，汇总报告）

**超额利润** — 实际利润减去保底利润的部分，是可以拿去投流量的钱（来源：智篆陪跑第二次线下坐诊-核心提炼，汇总报告）

**全店可投费用池** — 所有产品超额利润汇总而成的店铺可投推广费用总额（来源：智篆陪跑第二次线下坐诊-核心提炼，汇总报告）

**三阶引擎** — 聚焦「投资→产品优化→计划落地」的全店货盘运营三步标准化工具：店为品投资（利润重构/SAB 分级）→ 品为店贡献（8 维度考核）→ 人为店提效（人群再营销）（来源：三阶引擎工具表-说明）

**SAB 分级** — 三阶引擎第一层使用的分级字母（S/A/B 三级），与 SABC 四级不是同一套（来源：三阶引擎工具表-说明）

**8 维度考核** — 三阶引擎第二层用于筛选值得推广的产品的八个指标：搜索展现价值、搜索支付转化率、平均停留时长、跳失率、退款率、连带购买率、连带购买叶子类目宽度、复购率（来源：三阶引擎工具表-说明）

**准入标准（8 维度）** — 8 维度考核 6 分以上才值得推广，6 分以下必须先优化（来源：三阶引擎工具表-说明）

**全店付费矩阵** — 按产品等级分配推广计划类型与预算比例的表：S 级（全站+直通车+引力魔方，50%）、A 级（控投产+好货快投，30%）、B 级（好货快投+趋势明星，15%）、C 级（好货快投+新品运营中心，5%）（来源：产品分级与全店矩阵运营）

**流量闭环** — S 级产品引流 → 关联销售导流 → 动销产品收割 → 私域沉淀 的全店协同链路（来源：产品分级与全店矩阵运营）

**人群资产共享** — 店铺内所有产品的人群资产共享；一个用户浏览过任一产品就成为店铺人群资产，可反哺 S/A 级产品提高转化率（来源：产品分级与全店矩阵运营）

**红绿灯监控法** — 用红/黄/绿三色跟踪指标完成情况的战略执行监控工具，灵感来自丹纳赫公司 DBS 业务系统；每部门不超过 3 个关键指标，核心目的是找到问题持续改进，不直接与绩效考核挂钩（来源：红绿灯监控法）

**红绿灯表** — 红绿灯监控法的载体，格式为：指标名称 | 目标值 | 实际值 | 完成率 | 颜色 | 改进措施（来源：红绿灯监控法）

**产品分级表** — 九大标准化运营表格之一，用于预算分配（来源：爆款三板斧-标准化SOP）

**顺逆差分析表** — 九大标准化运营表格之一，用于预算分配（来源：爆款三板斧-标准化SOP）

**费比核算表** — 九大标准化运营表格之一，用于投产分析（来源：爆款三板斧-标准化SOP）

**新品老品效率对比表** — 九大标准化运营表格之一，用于产品筛选（来源：爆款三板斧-标准化SOP）

**测图测款记录表** — 九大标准化运营表格之一，用于测试追踪（来源：爆款三板斧-标准化SOP）

**类目洞察表** — 九大标准化运营表格之一，用于市场分析（来源：爆款三板斧-标准化SOP）

**类目趋势分析表** — 九大标准化运营表格之一，用于趋势判断（来源：爆款三板斧-标准化SOP）

**补贴核算表** — 九大标准化运营表格之一，用于活动规划（来源：爆款三板斧-标准化SOP）

**借壳复制法** — 复制历史拉新/追投/收割各 3-5 个计划换品，保持场景/出价/人群/创意不变，启动观察 3-7 天，确定性提升 80%+（来源：智篆陪跑第二次线下坐诊-核心提炼，汇总报告）

**拉新 / 追投 / 收割** — 三阶引擎第三层的人群计划分层：拉新（盈亏比 > 0.8 + 新客比 > 80%）、追投（盈亏比 < 0.5 + 新客比 > 50%）、收割（盈亏比 < 0.4 + 新客比 < 40%）（来源：三阶引擎工具表-说明）

**超级模型** — 高 ROE、可复制的最小业务单元（来源：智篆陪跑战略方法论包，汇总报告）

**北极星目标** — 统一全公司长期战略方向的量化目标，与 SABC 分级同属「超级战略」方法论包（来源：SABC分级体系 相关页面）

**第二曲线** — 与 SABC 分级同属战略层方法论包的第二增长曲线概念（来源：SABC分级体系 相关页面）

**TOC 约束理论** — 瓶颈即机会 / ROE 分析法 / 产能放大，与 SABC 分级同属战略层方法论包（来源：智篆陪跑战略方法论包，汇总报告）

**标准计划** — 直通车计划类型之一；S 级用达摩盘分析标准计划带来销量中有多少回到 S 级产品，是判定 S 级是否真在引流的手段（来源：产品分级与全店矩阵运营）

**好货快投** — 直通车全自动智能投放方案，用于动销款与 B/C 级（来源：产品分级与全店矩阵运营、2026淘宝运营完整知识体系）

**趋势明星** — 辅助推广计划类型，用于 S/A/B 级（来源：产品分级与全店矩阵运营）

**极限回流** — 辅助推广计划类型，用于 A/B 级（来源：产品分级与全店矩阵运营）

**市场渗透** — 辅助推广计划类型，用于 S/B 级；直通车低渗透率词渗透方案适用高客单（来源：产品分级与全店矩阵运营、2026淘宝运营完整知识体系）

**新品运营中心** — 平台提供的新品测试工具，用于 C 级新品快速上架测试、优胜劣汰（来源：产品分级与全店矩阵运营）

**控投产计划** — 推广计划类型，用于 A 级，用于提高盈利能力、控制投产（来源：产品分级与全店矩阵运营）

**首购新客成本** — 高复购品类改用的观测指标（而非总成交成本），因为只看总成交成本会让所有计划跑向收割（来源：选品测款标准流程）

**动销款** — 有稳定销量、能给店铺带来持续成交的产品；在分级中对应 B 级（来源：产品分级与全店矩阵运营）

**阶梯占比** — 核心公式手册公式6 给出的梯队结构：S 级全店销售额 30%/预算 50%，A 级 30%/30%，B 级 25%/15%，C 级 15%/5%（来源：淘系运营核心公式）

**爆款群矩阵** — 3384 体系中的产品体系模块，由核心/潜力/动销/形象四类组成，对应五梯队模型（来源：电商功守道：3384 利润公式）
