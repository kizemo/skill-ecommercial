# 速查表 · sabc-product-tiering

> 所有阈值均为知识库原文快照（2026 上半年口径）。平台规则与行业均价会变，落地前核对当期数据。

---

## 1. 分级判定阈值（判定标准要"同时满足"）

| 级别 | 必须同时满足的阈值 | 体量 | 流量贡献 | 利润贡献 | 生命周期 |
|---|---|---|---|---|---|
| **S 级** | 流量占比 > 50% + 销售额占比 > 40% + 关联销售率 > 30% + 符合店铺定位 | 1-2 个（最多 3 个） | 60-70% | 低/微利 | 6-12 个月+ |
| **A 级** | 利润占比 > 50% + 关联销售率 > 20% + 毛利率 > 30% + 与 S 级互补 | 3-5 个 | 20-30% | 60-70% | 3-6 个月 |
| **B 级** | 月销 10-100 件 + 毛利率 20-30% + 满足细分需求 + 不需大量推广 | 10-20 个 | 5-10% | 10-20% | 1-3 个月 |
| **C 级** | 连续 30 天无销量 + 月销 < 10 件 + 毛利率 < 20% + 库存周转 < 1 次/年 | 越少越好（≤10%） | < 5% | 负利润 | 结束 |

**判定顺序**：先流量/销售筛 S → 再利润/毛利筛 A → 再月销/毛利切 B → 剩余全 C。**反序会把高毛利小件错判成 A。**

---

## 2. 预算占比：三套口径（冲突，需先定一套）

| 级别 | A：超级战略 SABC | B：超级店长训练营/核心公式手册 | C：爆款三板斧"推广费占比" |
|---|---|---|---|
| S 级 | **60-70%** | **50%** | **20-25%** |
| A 级 | **20-25%** | **30%** | 逐步递减 |
| B 级 | **5-10%** | **15%** | 更少 |
| C 级 | **0%** | **5%** | 0-5%（与 D 级合并） |

**先定一套、写进表头、锁一个季度。** 别月度之间换口径。

---

## 3. 数量占比：两套口径

| 级别 | 口径 A（超级战略 SABC，绝对个数） | 口径 B（训练营，链接数量占比） |
|---|---|---|
| S 级 | 1-2 个（最多 3 个） | 5% |
| A 级 | 3-5 个 | 15% |
| B 级 | 10-20 个 | 30% |
| C 级 | 越少越好（≤10%） | 50% |

口径 A 是**目标态**（资源只够养 1-2 个 S），口径 B 是**现状分布**（大部分链接是 C）。混用会得出"同时要 1 个 S 又要 5% 的 S"这种矛盾结论。

---

## 4. 全店付费矩阵（口径 B 配套）

| 等级 | 主要推广计划 | 辅助推广计划 | 预算占比 |
|---|---|---|---|
| S 级 | 全站推广、直通车标准计划、引力魔方 | 市场渗透、趋势明星 | 50% |
| A 级 | 控投产计划、好货快投 | 趋势明星、极限回流 | 30% |
| B 级 | 好货快投、趋势明星 | 市场渗透、极限回流 | 15% |
| C 级 | 好货快投、新品运营中心 | 无 | 5% |

**爆款三板斧的"计划数量"口径**（是计划条数，不是链接数）：S 级 8-10 个计划 / A 级 4-6 / B 级 2-3 / C/D 级 1-2。

## 5. 调级决策规则（当 X 时做 Y）

| 触发条件 | 动作 | 依据 |
|---|---|---|
| A 级表现好（销售额占比、关联销售率、毛利率均达标） | **升级 S**，加预算至 S 档，提前排供应链 | S 级使命是打类目 |
| B 级表现好 | **升级 A**，配控投产计划 + 好货快投 | A 级利润占比 > 50% |
| S 级表现差 | **降级 A**，收回大部分预算，改 100-120% 均价 | S 级不为短期利润负责，但也不能一直亏 |
| A 级表现差 | **降级 B**，转低预算养人群 | B 级要求月销 10-100 + 毛利 20-30% |
| B 级连续 3 个月表现差 | **清仓处理**（降价/捆绑/直播/报废） | 清仓处理规则 |
| 连续 30 天无销量 或 月销 < 10 或 毛利 < 20% 或 周转 < 1 次/年 | **判 C 级**，本月内出处理结论 | C 级判定标准 |
| 8 维度得分 < 6 分 | **先修产品，不升不降** | 8 维度准入标准 |
| 真实投产 < 盈亏平衡 ROI | **不升级，先停投重测** | 见 [[profit-model]] |
| 顺逆差为负仍在加预算 | **停加预算，优化或淘汰** | 顺逆差模型 |
| 推广投产 < 店铺均值 | **禁止盲目增加预算** | 投产判断原则 |
| 推广投产 > 店铺均值 | 可适当增加预算 | 投产判断原则 |
| 总投产持续下滑 | 检查产品竞争力 | 投产判断原则 |

## 6. 调级频率

| 级别 | 频率 |
|---|---|
| S 级 | 每月（三阶引擎口径：SAB 每 30 天重评一次） |
| A 级 | 每半月 |
| B 级 | 每周 |
| C 级 | 每日 |

---

## 7. 类目差异

| 类目 | 关键差异 |
|---|---|
| **标品** | S 级更少（通常 1 个）；价格更低**甚至亏钱**；A 级与 S 级必须明显差异化；标品 PPC 校准：客单 < 100 盯 PPC，> 300 盯投产 |
| **非标品** | S 级可 2-3 个；生命周期短（3-6 个月）；B 级占比更高（70-80%）；退款率高（女装 30-50%）→ 必须走真实投产算账 |
| **虚拟类目** | S=低价引流课，A=高价核心课，B=中价增值课 |
| **医疗器械等强监管** | 仪器=流量入口（毛利 20-30%）、耗材=利润来源（毛利 60-70%），即"仪器引流、耗材盈利" |

---

## 8. 规模差异

| 规模 | 策略 | 禁忌 |
|---|---|---|
| 初创（0-50 万/月） | 集中打造 1 个 S 级 | 尽量不做 B/C 级 |
| 成长型（50-500 万/月） | 1-2 个 S + 3-5 个 A，逐步加 B | 别急着上 B 级矩阵 |
| 成熟型（500 万+/月） | 多个 S 级覆盖不同细分市场，完善 A/B 体系 | 1 个 S 级打全店会卡住细分 |

---

## 9. 与爆款四阶段叠加

| 阶段 | 时间 | 在分级里的位置 | 目标 |
|---|---|---|---|
| 打标期 | 第 1-7 天 | C 级候选 | 新品标签初始化 |
| 起量期 | 第 8-15 天 | C → B | 进类目前 20 |
| 爆发期 | 第 16-30 天 | B → A | 进类目前五 |
| 稳定期 | 第 31 天+ | A 级收割期（可争 S） | 整体盈利 |

**级别决定"配什么工具"，阶段决定"用多狠"。**

## 10. 红绿灯监控法

| 颜色 | 含义 | 行动 |
|---|---|---|
| 🟢 | 指标达成目标 | 总结经验，保持 |
| 🟡 | 接近目标 | 分析原因，及时调整 |
| 🔴 | 未达成目标 | 重点关注，制定改进计划 |

- **每部门 ≤ 3 个关键指标**
- 快指标按周、慢指标按月
- 表格式：`指标名称 | 目标值 | 实际值 | 完成率 | 颜色 | 改进措施`
- **不要与绩效考核直接挂钩**（挂上奖金 = S 级使命失效）

## 11. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| S 级开 5-6 个 | 预算摊薄，类目打不穿 | 严格 1-2 个，最多 3 个 |
| 把利润高的列 S | S 级变成"贵一点的 A 级"，失去打类目能力 | S 级任务是获取流量 |
| 把高流量不赚钱的列 A | A 级承担不起利润指标 | A 级任务是赚利润 |
| 舍不得淘汰 C 级 | 库存与权重被负资产吃掉 | 果断淘汰，不抱侥幸 |
| 分级一成不变 | 货盘老化，跟不上流量变化 | S/月、A/半月、B/周 |
| 平均分配资源 | 80/20 原则失效 | 60-70/20-25/5-10/0 |
| 只看销量做分级 | 忽略利润占比与关联销售率 | 五指标同看：销量/销售额/投产/利润率/增长率 |
| 用投产看板调级 | 收割型高投产被误升 | 真实投产 + 顺逆差双闸门 |
| 月度之间换口径 | 所有环比作废 | 口径锁定一个季度 |
| 分级直接挂奖金 | S 级不敢亏钱 → 体系崩 | 红绿灯与考核脱钩 |
| 把"链接数"当"计划数" | 以为 S 级要开 8-10 个链接 | 8-10 是推广计划条数 |
| C 级当废物 | 断掉新品流水线 | C 级是测试位，每年更新 30% 产品 |

## 12. 口径冲突登记（落地前必须先定）

| # | 冲突点 | 版本 |
|---|---|---|
| 1 | S 级预算占比 | 60-70% / 50% / 20-25% |
| 2 | A 级预算占比 | 20-25% / 30% / 逐步递减 |
| 3 | C 级预算占比 | 0% / 5% / 0-5% |
| 4 | 各级数量占比 | 绝对个数（1-2 个 S） / 百分比（5% S、50% C） |
| 5 | 分级字母 | SABC 四级 / S/A/B/C/D 五级 / SAB 三级 |
| 6 | S 级角色定义 | 流量发动机、利润低微利 / 利润贡献最高、转化最好 |
| 7 | 调级周期 | A 级每半月 / SAB 全量每 30 天 |
| 8 | 爆款阶段时间窗 | 1-7/8-15/16-30/31+ 天 vs 0-7/7-21/21-45/45-90/90+ 天 |

**仲裁办法**：S 级角色冲突用**达摩盘回流数据**仲裁（回流高 = 自我成交 = 其实是 A 级）；预算占比冲突用**店铺利润结构**仲裁（毛利薄则走 60-70% 集中口径，毛利厚可走 50/30/15/5 分散口径）。
