# ch02 · 实施五步法与付费矩阵

> 用途：把分级从"结论"变成"每周能执行的表和预算"。

---

## 一、五步法全流程

```
Step 1  产品盘点    导出销售/流量/利润/库存数据 → 算关键指标 → 形成盘点报告
Step 2  产品分级    初分 → 战略调整 → 评审确认 → 公示执行
Step 3  资源分配    S 60-70% / A 20-25% / B 5-10% / C 0%
Step 4  差异化运营  各级不同定价/推广/关联/服务策略
Step 5  动态迭代    S/月、A/半月、B/周、C/日 监控调整
```

### Step 1 产品盘点：四张源表

盘点不是拉一遍生意参谋就完事。三阶引擎工具表把源数据固定为四张，**分级结论必须能追溯到这四张表**：

| 源表 | 下载路径 | 用来算 |
|---|---|---|
| 生意参谋商品排行榜 | 生意参谋 → 商品 → 商品排行榜 → 最近 30 天 | 销量、销售额、库存 |
| 达摩盘货盘表 | 达摩盘 → 人群 → 货盘分析 → 全网下载 | 人群资产、货盘层级 |
| 推广商品主体报表 | 万相台 → 推广 → 商品推广 → 汇总数据（近 30 天） | 投产、花费、直接/间接成交 |
| 推广人群报表 | 万相台 → 人群管理 → 最近 3 个月 → 全选下载 | 拉新/收割、领先率 |

盘点报告至少包含：各链接的**流量占比、销售额占比、利润占比、关联销售率、毛利率、月销量、库存周转率**——前 4 个直接对应 S/A 判定标准。

### Step 2 产品分级：四段动作

| 动作 | 做什么 | 为什么不能省 |
|---|---|---|
| **初分** | 按 ch01 的判定顺序机械执行 | 保证标准一致 |
| **战略调整** | 结合店铺定位与战略修正初分 | 分级是战略选择，不是纯数据排序 |
| **评审确认** | 店长/负责人过一遍 | 挡住"因为它卖得多就升 S"的主观偏差 |
| **公示执行** | 分级结论公示到人、公示到计划 | 不公示 = 执行层回到平均主义 |

**这一步的隐藏要求**：初分结果必须留档（谁在什么日期把哪个链接从哪级调到哪级、依据什么指标），否则下次复盘无法判断是货变了还是标准变了。

### Step 3 资源分配：两套算法

#### 算法 A：固定比例（超级战略 SABC 口径）

| 级别 | 预算占比 |
|---|---|
| S 级 | **60-70%** |
| A 级 | **20-25%** |
| B 级 | **5-10%** |
| C 级 | **0%** |

#### 算法 B：保底利润率 + 费用池（三阶引擎口径）

这套算法把"总投多少"从拍脑袋变成从利润里长出来：

```
保底利润率阶梯：S 品 10% / A 品 15% / B 品 20% / C 品 25%
超额利润 = 实际利润 − 保底利润
全店可投费用池 = 所有产品超额利润汇总
```

**读法**：保底利润率是"保住这一级身份"的最低要求；超出保底的部分才是可以拿去投流量的钱。**注意保底利润率是随等级递减的（S 最低、C 最高）**——C 级不投流，只能靠自身毛利活着，所以保底要求最高。

**输出字段（三阶引擎看板1）**：月去退销售额、月利润预估（按 S/A/B 保底利润率分层）、月 GMV 机会、月机会市场销售缺口、全店可投费用。

#### 算法 C：梯队销售额/预算倒推（核心公式手册口径）

| 等级 | 全店销售额 | 投入预算 |
|---|---|---|
| S 级 | 30% | **50%** |
| A 级 | 30% | 30% |
| B 级 | 25% | 15% |
| C 级 | 15% | 5% |

> **三套算法并存，口径冲突，需复核**。差别很大：算法 A 的 S 级拿 60-70% 预算，算法 C 只给 50%，爆款三板斧口径甚至给 S 级 20-25% 推广费。**先定一套并写进分级表表头**，别月度之间换口径。

### Step 4 差异化运营策略

| 级别 | 定价 | 推广 | 关联/服务 |
|---|---|---|---|
| **S 级** | 市场均价 80-90% | 全站推广、直通车标准计划、引力魔方；全方位推广 | 详情页/购物车/订单页大量关联 A/B 级；积极参加平台活动快速起量 |
| **A 级** | 市场均价 100-120% | 控投产计划、好货快投；针对 S 级人群精准推广 | 从 S 级流量中导流；顺丰包邮、7 天无理由、上门取件；会员制度 |
| **B 级** | 市场均价 | 好货快投、趋势明星；长尾关键词少量投放 | 持续优化主图/详情页/标题；重点积累人群资产 |
| **C 级** | 降价清仓 | 好货快投、新品运营中心；新品快速上架测试，优胜劣汰 | 捆绑销售、直播清仓、捐赠或报废 |

## 二、全店付费矩阵

| 产品等级 | 主要推广计划 | 辅助推广计划 | 预算占比 |
|---|---|---|---|
| **S 级** | 全站推广、直通车标准计划、引力魔方 | 市场渗透、趋势明星 | **50%** |
| **A 级** | 控投产计划、好货快投 | 趋势明星、极限回流 | **30%** |
| **B 级** | 好货快投、趋势明星 | 市场渗透、极限回流 | **15%** |
| **C 级** | 好货快投、新品运营中心 | 无 | **5%** |

**读法**：S 级用"重工具"打（能出量的全站+直通车+引力魔方），A 级用"控成本"的工具（控投产计划），B 级用高投产的轻工具（好货快投、趋势明星），C 级只用最低成本的方式测。

**S 级配套动作**：定期用**达摩盘**分析标准计划带来销量中有多少回到 S 级产品。回流多 = 在自我成交，角色错位。

## 三、爆款三板斧口径的「计划数量」维度

超级店长训练营口径只给预算比例，爆款三板斧口径给的是**每级的推广计划数量**：

| 等级 | 定义 | 推广费占比 | 计划数量 |
|---|---|---|---|
| **S 级** | 镇店爆款，销售额前几名 | **20-25%** | **8-10 个** |
| **A 级** | 动销款，稳定销售 | 逐步递减 | 4-6 个 |
| **B 级** | 平销款 | 更少 | 2-3 个 |
| **C/D 级** | 尾部链接 | 0-5% | 1-2 个 |

**三条配套执行原则**：
1. 推广投产低于店铺均值 → **禁止盲目增加预算**
2. S 级爆款 → **多计划配合，整体盈亏平衡**（不是靠单计划爆）
3. C/D 级尾部 → **用低价计划筛选**（好货快投、新品运营中心）

> 注意：这里的"计划数量"是**推广计划条数**，不是链接数。S 级 8-10 个计划是分计划、分词路、分人群用的，不是开 8-10 个链接。

## 四、分级表字段模板

**《产品分级表》至少要有这些列**（对应九大标准化运营表格中的"产品分级表"）：

```
链接ID | 商品名 | 当前等级 | 流量占比 | 销售额占比 | 利润占比 | 关联销售率
      | 毛利率 | 月销量 | 库存周转 | 推广费占比 | 目标等级 | 调整理由
      | 调整日期 | 审批人
```

**配套表**：
- 《顺逆差分析表》→ 预算分配依据
- 《费比核算表》→ 投产分析
- 《新品老品效率对比表》/《效率对比表》→ 产品筛选
- 《测图测款记录表》→ C 级候选的测试追踪
- 《类目洞察表》《类目趋势分析表》→ 选品侧
- 《补贴核算表》→ 活动规划

**标准化流程**（爆款三板斧 SOP 6 步，与分级的关系）：
```
选品 → 上新 → 测图测款 → 爆款孵化 → 数据优化 → 爆款维护
  ↓       ↓        ↓          ↓          ↓         ↓
七维选品 标题主图 低预算测试 加大投放   顺逆差   持续监控
                    50-100元/天
```
分级不是独立环节，它嵌在**"爆款孵化"和"数据优化"两步**：孵化时给新链接定级（C 级起步），优化时用顺逆差与投产做升降级判定。

## 五、落地检查清单

- [ ] 四张源表已下载并统一口径（同一时间窗、同一去退规则）
- [ ] 分级初分表完成，字段齐全
- [ ] 战略调整与评审确认有记录
- [ ] 分级结论已公示，分级表已冻结
- [ ] 预算按锁定口径分配到链接/计划，不留"机动池"
- [ ] 每级配了对应计划类型（S/A/B/C 各有对应的主要+辅助计划）
- [ ] C 级链接的处理方式已定（清仓/捆绑/直播/报废）
- [ ] 调级复盘日历已排（S/月、A/半月、B/周、C/日）
