# ch01 · 分级判定标准与角色分工

> 用途：把"一个链接该分到哪一级"这件事，从感觉判断变成可复核的判定。

---

## 一、四级完整判定标准

### S 级 —— 核心爆款，店铺的「流量发动机」

**核心使命**：击穿类目，获取人群资产。

**判定标准（同时满足）**：

| 标准 | 阈值 | 口径说明 |
|---|---|---|
| 流量占比 | **> 50%** | 该链接流量 ÷ 全店流量 |
| 销售额占比 | **> 40%** | 该链接销售额 ÷ 全店销售额 |
| 关联销售率 | **> 30%** | 该链接带出的其他产品成交 |
| 店铺定位 | 符合 | 与店铺主推类目/价格带一致 |

**体量参考**：1-2 个（最多 3 个）；流量贡献 60-70%；利润贡献 低/微利；生命周期 6-12 个月+。

**运营策略**：
- **定价**：低价策略，市场均价的 **80-90%**
- **推广**：全方位推广（直通车 + 钻展 + 短视频 + 直播），分配 **60-70% 预算**
- **活动**：积极参加平台活动快速起量
- **关联**：在详情页/购物车/订单页大量关联 A/B 级产品

**两条容易被忽略的纪律**：
1. S 级产品**可能亏钱/不赚钱**，这是允许的，价值在于带动全店流量和权重。
2. 要有**危机意识**，提前培养下一代 S 级——S 级生命周期 6-12 个月+，不接班就是断档。

### A 级 —— 次爆款，店铺的「利润奶牛」

**核心使命**：精准收割，转化利润。

**判定标准（同时满足）**：

| 标准 | 阈值 |
|---|---|
| 利润占比 | **> 50%** |
| 关联销售率 | **> 20%** |
| 毛利率 | **> 30%** |
| 与 S 级关系 | **互补**（不是同质替代） |

**体量参考**：3-5 个；流量贡献 20-30%；利润贡献 60-70%；生命周期 3-6 个月。

**运营策略**：
- **定价**：中高价策略，市场均价的 **100-120%**
- **推广**：精准推广，针对 S 级产品用户人群，分配 **20-25% 预算**
- **服务**：优质服务（顺丰包邮、7 天无理由、上门取件）
- **会员**：针对购买用户推出会员制度

### B 级 —— 店铺的「产品线补充」

**核心使命**：丰富产品线，提高用户停留时间和转化率。

**判定标准（同时满足）**：

| 标准 | 阈值 |
|---|---|
| 月销量 | **10-100 件** |
| 毛利率 | **20-30%** |
| 细分需求 | 满足某细分人群 |
| 推广依赖 | 不需要大量推广 |

**体量参考**：10-20 个；流量贡献 5-10%；利润贡献 10-20%；生命周期 1-3 个月。

**运营策略**：
- **定价**：市场平均价格
- **推广**：少量推广（长尾关键词），分配 **5-10% 预算**
- **优化**：持续优化主图/详情页/标题
- **筛选**：定期把表现好的升级为 A 级，把差的降级为 C 级

### C 级 —— 店铺的「负资产」

**判定标准（同时满足）**：

| 标准 | 阈值 |
|---|---|
| 连续无销量 | **连续 30 天** |
| 月销量 | **< 10 件** |
| 毛利率 | **< 20%** |
| 库存周转率 | **< 1 次/年** |

**体量参考**：越少越好（≤10%）；流量贡献 < 5%；利润贡献 负利润；生命周期 结束。

**处理方法（按优先顺序）**：
1. 降价清仓
2. 捆绑销售（与 S/A 级产品捆绑）
3. 直播清仓
4. 捐赠或报废

> C 级不是"再观察观察"，是**负资产在占库存和占店铺权重**。C 级的处理结论要当场出，不要留到下次复盘。

## 二、判定顺序：为什么不能先看利润

```
Step 1  先用「流量占比 > 50% + 销售额占比 > 40% + 关联销售率 > 30% + 符合定位」筛 S 候选
Step 2  在剩下的品里用「利润占比 > 50% + 关联销售率 > 20% + 毛利率 > 30% + 与 S 互补」筛 A
Step 3  剩下的按「月销 10-100 + 毛利 20-30%」归 B
Step 4  再剩下的一律 C（连续 30 天无销量 / 月销 < 10 / 毛利 < 20% / 周转 < 1 次/年）
```

**为什么必须这个顺序**：S 级和 A 级的定义锚点不同——S 锚"流量与规模"，A 锚"利润与毛利"。先按利润筛会把高毛利小链接错判成 A（典型：配件、耗材类），而这类链接根本撑不起"击穿类目"的使命。

**同时满足 ≠ 满足其一**：判定表里的每一行都是 AND 关系。S 级"流量占比 > 50%"但"关联销售率 < 30%"的品，说明它吃的是自己的流量，没在给全店导流——这种品最多算 A。

## 三、角色分工的操作含义

### 3.1 S 级与 A 级怎么配合

```
S 级（低价 80-90% 均价，60-70% 预算）
   │  打爆类目、拿人群资产
   ▼
关联销售（详情页/购物车/订单页关联 A/B 级）
   │  把流量导给高毛利品
   ▼
A 级（100-120% 均价，20-25% 预算）
   │  收割利润，毛利率 > 30%、利润占比 > 50%
   ▼
B 级（均价，5-10% 预算）→ 私域沉淀复购
```

### 3.2 人群资产共享的量级

店铺内所有产品的人群资产共享。**一个用户浏览过任一产品就成为店铺人群资产**，可反哺 S/A 级产品提高转化率。

**参考案例**：S 级爆款每天吸引 10000 访客 → 20% 会浏览其他产品 → 即使当时没购买也成为人群资产 → 通过后续收割 5% 转化为购买 → 整体转化率从 **2% 提升到 3%**，销售额提升 **50%**。

**这条是"为什么要养 S 级"的量化答案**：S 级不是烧钱买 GMV，是买**全店免费流量的种子**。

### 3.3 定价带的角色化

| 级别 | 价格带 | 意图 |
|---|---|---|
| S 级 | 市场均价 80-90% | 降低购买门槛，把人拉进店 |
| A 级 | 市场均价 100-120% | 用品质/服务承接溢价，赚利润 |
| B 级 | 市场平均价 | 补齐细分需求 |
| C 级 | 降价清仓 | 回笼现金，不计利润 |

## 四、S 级专属动作：用达摩盘验证"真引流"

**定期用达摩盘分析标准计划带来销量中有多少回到 S 级产品。**

- 大量成交回到 S 级自身 → 说明 S 级在自我成交，没有给全店导流，**它只是个昂贵的 A 级**。
- 成交显著流向 A/B 级 → S 级使命达成，可以继续加预算。

这个动作是 S 级和 A 级角色的**唯一硬性区分器**，比任何流量占比数字都直接。

## 五、误区对照表（做分级时逐条自查）

| 误区 | 正确做法 |
|---|---|
| S 级产品过多（5-6 个） | 严格控制在 1-2 个，最多 3 个 |
| 把利润高的列为 S 级 | S 级的主要任务是获取流量，不是赚钱 |
| 把高流量不赚钱的列为 A 级 | A 级的主要任务是赚取利润 |
| 舍不得淘汰 C 级产品 | 果断淘汰，不抱侥幸心理 |
| 产品分级一成不变 | S 级/月，A 级/半月，B 级/周动态调整 |
| 平均分配资源 | 按 60-70% / 20-25% / 5-10% / 0% 的比例分配 |

## 六、本章数据的口径冲突

- **S 级数量**：本素材为「1-2 个（最多 3 个）」；另一套训练营口径为「数量占比 5%」。两者在链接数少的店铺差距巨大，**口径冲突，需复核**。
- **S 级角色定义**：本素材为「流量发动机、利润低/微利」；选品测款标准流程里 S 级爆款被定义为「利润贡献最高、转化最好的品」。**口径冲突，需复核**——用达摩盘回流数据做仲裁。
- **C 级占比**：本素材为「越少越好（≤10%）」；训练营口径为「数量占比 50%」。前者是**目标态**，后者是**现状分布**，混用会得出矛盾结论。
