# 可复用方法 · sabc-product-tiering

> 每条格式：`## 方法名` + `**何时用**` + `**怎么做**` + `**代价/风险**`

---

## 四表盘点法

**何时用**：每月/每半月的分级复盘前；或者新接手一家店、第一次做分级时。

**怎么做**：
1. 下载四张源表，统一时间窗（建议近 30 天）与去退规则：
   - 生意参谋商品排行榜（生意参谋 → 商品 → 商品排行榜 → 最近 30 天）
   - 达摩盘货盘表（达摩盘 → 人群 → 货盘分析 → 全网下载）
   - 推广商品主体报表（万相台 → 推广 → 商品推广 → 汇总数据，近 30 天）
   - 推广人群报表（万相台 → 人群管理 → 最近 3 个月 → 全选下载）
2. 每链接算出七个字段：流量占比、销售额占比、利润占比、关联销售率、毛利率、月销量、库存周转率。
3. 按判定顺序机械出初分：S 候选 → A → B → C。

**代价/风险**：四张表的时间窗不一致会直接导致占比口径打架，"钱投在哪"的分歧多数从这里开始。另外同一张表里"销售额"和"去退销售额"不是一回事，盘点前先定用哪个。

## 达摩盘回流自检

**何时用**：每季度复核一次 S 级是否名实相符；或者觉得"S 级花了钱但全店没起来"时。

**怎么做**：
1. 用达摩盘分析**标准计划**带来的销量。
2. 看其中有多少**回到 S 级产品自身**。
3. 回流占比高 → S 级在自我成交，它其实是个昂贵的 A 级；回流少 → S 级在给全店导流，可继续加预算。

**代价/风险**：这是 S 级与 A 级角色的唯一硬性区分器，但要看懂达摩盘的人群/计划口径；口径设错会得出反向结论，先用一个已知答案的链接验一遍再看全店。

## 费用池算法（保底利润率 → 超额利润 → 可投费用池）

**何时用**：要决定"这周总共能投多少钱"时；或者老板问"为什么不把预算都给 S 级"时。

**怎么做**：
1. 给每个链接定保底利润率：S 品 10% / A 品 15% / B 品 20% / C 品 25%。
2. 超额利润 = 实际利润 − 保底利润。
3. 全店可投费用池 = 所有产品超额利润汇总。
4. 再按级别的预算比例（60-70% / 20-25% / 5-10% / 0% 或 50/30/15/5）把费用池切给各级。

**代价/风险**：这算法的前提是保底利润率的阶梯口径与店铺实际毛利结构匹配。毛利结构特殊（如耗材占比高的器械店）时，S 品 10% 的保底可能定得太松、费用池虚高。**这套算法原本只覆盖 S/A/B 三级，没有 C 级保底口径**。

## 交叉验证式分级（初分 → 战略调整 → 评审确认 → 公示）

**何时用**：第一次做分级；或者团队内部对某个链接的级别有分歧时。

**怎么做**：
1. **初分**：纯按 ch01 的判定顺序机械执行，不讨论。
2. **战略调整**：结合店铺定位（价格带、类目方向、供应链能力）修正初分。
3. **评审确认**：店长/负责人过一遍，重点看"有没有被主观偏好带偏"。
4. **公示执行**：分级表公示到人、公示到推广计划，冻结。

**代价/风险**：多花一轮时间。但省掉这轮的代价更大：不公示等于执行层回到平均主义，第 3 步的预算分配会名存实亡。

## 八维度准入前置检查

**何时用**：一个链接想升 B 级或 C 级但数据看着还行时；或者 8 维度不过关却在纠结"是不是该加预算"时。

**怎么做**：
1. 打八个分：搜索展现价值、搜索支付转化率、平均停留时长、跳失率、退款率、连带购买率、连带购买叶子类目宽度、复购率。
2. 6 分以上才值得推广；6 分以下先修产品。

**代价/风险**：会筛掉一部分"卖得动但产品有问题"的链接，短期内少一个候选爆款。但这些链接的问题在产品层（比如退款率高、详情页承接差），**加预算只会加速亏钱**。

## 顺逆差预算倾斜法

**何时用**：每周复盘预算分配；或者决定"给谁加钱"的时候。

**怎么做**：
1. 算每个单品的成交金额占比、推广花费占比。
2. 顺逆差 = 成交金额占比 − 推广花费占比。
3. 正向顺差 → 预算倾斜；负向顺差 → 优化或淘汰；零顺差 → 维持观察。
4. 每周复盘一次。

**代价/风险**：顺逆差是**相对指标**，不看绝对值。一家店所有链接顺逆差都为正说明全店都在高效，但可能整体毛利太低。顺逆差必须和真实投产、盈亏平衡 ROI 一起看，公式见 [[profit-model]]。

## 借壳复制法换品

**何时用**：要开新计划但没有把握；或者要测试新品能否复制老品的成功结构时。

**怎么做**：
1. 从历史里挑出跑得好的拉新/追投/收割计划各 3-5 个。
2. 复制换品，**保持场景/出价/人群/创意不变**。
3. 启动后观察 3-7 天。

**代价/风险**：前提是历史计划本身有效。历史计划是在旧价格、旧素材、旧人群下跑出来的，直接复制到新链接上可能水土不服——观察期不要提前下结论。

## 新品流水线（C 级进、S 级出）

**何时用**：货盘老化时；或者一年更新比例掉下来时。

**怎么做**：
1. 持续上新补充 C 级（新品走新品运营中心 + 低预算测试，优胜劣汰）。
2. 每年至少更新 **30%** 产品。
3. 产品矩阵**每月**评估调整。
4. 选出通过测试的升级为 B/A/S。

**代价/风险**：C 级位被新品占着，短期内是负贡献（占库存、占权重）。初创店铺资源不足时"尽量不做 B/C 级"，代价就是没有后备 S 级——**这个取舍要提前决定，不是临时权衡**。

## S 级接班计划

**何时用**：S 级进入稳定期或衰退期时；每季度做一次 S 级健康度检查。

**怎么做**：
1. 看当前 S 级的生命周期位置（S 级设计生命周期 6-12 个月+，但高客单品类爆款周期 45 天以上）。
2. 从 A 级里挑互补的品（与 S 级互补，不是同质）作为候选。
3. 给候选品补预算、补供应链、提前做测图。

**代价/风险**：提前培养接班人会占用 A 级的利润和预算。A 级利润占比要求 > 50%，短期内被侵蚀会影响季度利润目标。**S 级断档是慢性的，代价在 3-6 个月后才显形**，所以接班必须提前一个季度开始。

## 口径锁定法

**何时用**：发现同一件事在知识库/团队内部有两个数字时；或者月度复盘数据对不上时。

**怎么做**：
1. 把冲突写进《产品分级表》的表头/口径页（哪几个冲突点、备选口径分别是什么）。
2. 选一套口径用满一个季度，**写进标题或表头**（例："SABC 分级（口径 A：超级战略 SABC 2026-05）"）。
3. 季度末再切换，切换时同时重算历史数据。

**代价/风险**：锁定期间无法用"另一套更合理的口径"来解释异常波动。但**月度之间悄悄换口径的代价更大**——所有环比作废，且没人知道是货变了还是标准变了。
