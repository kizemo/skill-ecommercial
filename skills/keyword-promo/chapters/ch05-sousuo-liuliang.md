# ch05 · 搜索流量与自然搜索的关系

> 来源：淘系五大流量渠道、全站vs无界选择、2026淘宝运营完整知识体系、素材革命与八大流量入口、付费推广组合选择逻辑、关键词推广体系、b06-3384利润公式。

搜索流量的环境已经变了。**先认清"自然搜索正在变贵、正在变形"，再决定关键词推广怎么打。**

---

## 一、搜索流量的现状

| 变化 | 数据 | 来源 |
|---|---|---|
| 免费访客 | 越来越少（索道搜索、推荐几乎没了） | 淘系五大流量渠道 |
| 付费占比 | 越来越高 | 淘系五大流量渠道 |
| **点击单价** | **从 8 毛 → 8 块（翻了 10 倍）** | 淘系五大流量渠道 |
| 流量结构 | 推荐 + 内容流量占 **85%+** | 2026淘宝运营完整知识体系 |
| 免费搜索流量 | **< 5%**（30 元以上商品） | 2026淘宝运营完整知识体系 |

**推论**：**点击单价翻 10 倍，意味着"同样的钱买同样的流量"已经不可能。**关键词推广的价值不再是"买流量"，而是"买词的位置 + 沉淀词权重"。

**五大流量渠道的优先级**（淘系五大流量渠道）：
新品（高）｜付费（无界 + 全站，必做）｜趋势流量（高）｜短视频（高）｜营销活动（中）。
**付费渠道的原则：不要只用全站，要配合无界。**

## 二、付费搜索与自然搜索怎么互相影响

### 2.1 一条主线

```
付费搜索成交 → 词权重积累 → 自然搜索排名提升 → 免费流量承接
```

平台侧对应的是"搜索推荐逻辑已转变为**推荐最适合的 SKU**"（见 [[conversion-optimization]]）——**哪个 SKU 卖得好，系统就推荐哪个 SKU**。所以关键词推广最终沉淀下来的不是流量，是**词权重 + SKU 权重**。

### 2.2 全站推广会不会抢搜索流量：三条口径互相矛盾（需复核）

| 口径 | 原文表述 | 来源 |
|---|---|---|
| A | "全站推广不抢搜索流量，付费成交反而提升自然搜索权重" | 2026淘宝运营完整知识体系 / 关键词推广十三式战法总纲1 |
| B | "⚠️ 全站推广会压制自然流量，新品期慎用" | 付费推广组合选择逻辑 |
| C | "全站推广会压缩关键词流量" | 关键词推广体系（相关概念） |

**处理原则**：不按任一条直接下结论，用小预算实测（见 [cheatsheet.md](../cheatsheet.md) 决策树）；新品期按 B 的保守口径执行（**不用全站**）。

### 2.3 搜索结果页的形态在变

- **手淘搜索 60-70% 来自短视频**（淘系五大流量渠道）；
- 因此**短视频和主图同样决定搜索点击率**——搜推素材（搜索推荐一体化素材）同时在搜索结果页、推荐页、活动页展示。

**搜推素材四项优势**（素材革命与八大流量入口）：
- 多渠道展示：同时在搜索结果页、推荐页、活动页；
- 算法更精准：人群匹配精度比传统素材高 **30% 以上**；
- 流量池更大：是传统光合平台素材的 **2 倍以上**；
- 制作更简单：只需一张主图 + 一段文案。

**搜推素材运营规则**：
- 优先上传"精选"素材：被标记为精选可获 **10 倍以上流量**；
- **30 天没有成为精选素材立即替换**；
- **不要使用 AI 生成视频**：真实拍摄视频效果更好。

**数据验证**：某家居店上传 **39 条**搜推素材，**25 条**被标记精选，获得 **500 万+ 曝光**，带来 **10 万+ 访客**，**免费流量占比从 20% 提升到 50%**。

## 三、免费搜索流量的三个入口

### 3.1 AI 万能搜：把长尾词变成免费入口

**原理**：AI 万能搜通过分析商品详细参数、属性、描述理解商品功能特点。搜索"直径 10 厘米的保温杯"时，自动匹配所有填写了直径参数的保温杯。

**深度填写方法**：
- 完整填写商品所有参数（尺寸、重量、材质、颜色等）；
- 详细描述商品功能、特点、使用方法；
- 使用用户常用的自然语言描述商品；
- 覆盖尽可能多的长尾关键词。

**案例**：保温杯完整填写所有参数后，搜索"能放进书包的保温杯""12 小时保温的保温杯"等长尾关键词都**排在搜索结果前三位**，**每天获得 200+ 免费流量**。

> AI 万能搜是**唯一一条"不花钱就能拿搜索流量"**的路子，但它要求商品信息填写质量到位。

### 3.2 光合平台短视频

- **权重与图片搜索相同**；**点击率比图片高 30% 以上**；
- **一个优质短视频可覆盖几百个长尾关键词**；
- 发布要点：**删除系统推荐话题，手动添加长尾关键词作为话题**。

### 3.3 站外种草反哺搜索

**数据验证**：**每 1000 个小红书流量 → 额外获得 100 个免费类目大词搜索流量**（2026淘宝运营完整知识体系）。
路径：小红书铺种草笔记（100-1000 粉素人）→ 引导搜索店铺名（不放链接）→ 淘宝首页设置专属优惠承接。

### 3.4 拍立淘与金标

- **拍立淘扶持金标**：获得后在拍立淘搜索中置顶显示；
- **搜索推荐金标**：在搜索和推荐中获得加权；
- **活动优先金标**：可优先报名平台活动；
- 入口：商机发现页面 → 查看带"金标"标识的活动 → 提交报名资料 → 审核通过后自动获得。

## 四、词图匹配：搜索什么就展示什么

| 层级 | 定义 | 要求 |
|---|---|---|
| **词图匹配** | 搜索什么展示什么 | **基本要求**（不过就是浪费钱） |
| **词图人匹配** | 了解买的人的内心向往 | **更高境界** |

**高点击率主图四要素**（爆款三板斧-产品布局）：卖点突出、差异化、场景化、信任背书。
**前三张主图排布逻辑**：**卖点 → 背书 → 收益**，三张各承担一件事，不要第一张就把所有信息塞满。

**直通车核心价值**：**拉新 + 关键词权重提升**。所以直通车即使投产一般，只要沉淀了词权重，仍值得投。

**推广工具选择决策树**（付费推广组合选择逻辑）：

## 六、全站 vs 无界：怎么配合

| 特点 | 全站推广 | 无界推广 |
|---|---|---|
| **优势** | 投产比看起来很高（数据好看） | 可控性强，可调整地域/时间/人群/出价 |
| **劣势** | 可控性弱、受趋势影响大、长时间跑可能亏钱 | 投产比相对低、需要更多人工优化 |
| **适用** | 大促期、KA 商家、利润高的产品 | 新品测款、日常稳定投放、需要精准可控 |

**正确流程**：
```
无界测图测款（2-4 周）
    ↓ 数据稳定
全站放大收割
    ↓ 效果下滑
再转无界维护
```

**选择原则**：新品测图测款**先用无界**；数据稳定后转全站；利润薄产品慎用全站、用无界；大促期全站效果好；需要精准可控用无界；KA 商家全站 + 无界配合。

**全站效果不好的三个原因**：
1. **产品力没做好**：点击率、转化率不够；
2. **底层逻辑**：全站计算包含免费流量，**top 店铺天然有优势**；
3. **核心公式**：**点击率 × 转化率 = 全站效果**。

**万相台迭代注意**：迭代非常快（每月都有新功能）；新功能出来后要第一时间测试（**最低预算 30-50 元**）；红利期短暂，率先使用者获益。
