# ch03 · 测图 SOP 与测图策略矩阵

> 来源：关键词推广体系（科学测图四步法、测图策略矩阵、常见误区）、关键词推广十三式战法总纲1-消化（第一式）、选品测款标准流程（测图标准流程、测款标准流程）、b06-17-电商功守道3384利润公式（测图口径）。

测图是搜索流量体系里**唯一一件"花小钱省大钱"的事**：主图点击率上不去，后面所有卡位、大词、精准词计划的投产都会被点击成本吃掉。

---

## 一、测图策略矩阵：按爆款等级选测法

| 产品等级 | 测图策略 | 核心目标 |
|---|---|---|
| **顶级爆款** | **精细化测图** | 追求极致点击率 |
| **成长爆款** | **标准测图** | 平衡速度与成本 |
| **引流款** | **快速测图** | 快速筛选 |
| **利润款** | **保守测图** | 控制测图成本 |

**怎么判断自己是哪一档**：
- 顶级爆款 = 类目前列、要冲类目排名的品 → 值得为 1 个百分点的点击率多花预算；
- 成长爆款 = 已验证有转化、要放量的品 → 速度与成本平衡；
- 引流款 = 目的是拉流量和测款，不是主图说服 → 快速筛出可用图即可；
- 利润款 = 靠低价和精准词活命 → 测图成本不能吃掉利润。

## 二、科学测图四步法（关键词推广体系）

1. **准备**：准备 **4-8 张**创意图；
2. **测试**：万相台关键词计划，**均匀分配预算**；
3. **数据**：累计 **500+ 点击**后分析点击率；
4. **决策**：点击率 **≥ 行业 1.5 倍**则保留，否则替换。

**关键词推广体系的常见误区**（测图相关）：
- ❌ 测图只看转化率 → ✅ **先看点击率，再看收藏加购，最后看转化**；
- ❌ 大词越贵越好 → ✅ 追求合理出价下的流量最大化；
- ❌ 关键词越多越好 → ✅ 聚焦 20% 核心词；
- ❌ 忽视竞品截流 → ✅ 主动抢夺竞品流量。

## 三、十三式第一式的测图配置（总纲1）

| 配置项 | 值 |
|---|---|
| 关键词 | **≤3 个大词** |
| 出价 | **前三** |
| 智能创意 | **关闭** |
| 单图点击量 | **≥100 点击**定点击率 |
| 日预算 | **300-500 元** |
| 匹配方式 | 精准匹配 |

**每一条都在干什么**：
- 词 ≤3 个 → 数据不被打散，点击率可比；
- 出价前三 → 展现位置接近真实搜索场景；
- **关智能创意** → 智能创意会自行换图，测的就不是你那张图；
- 每图 ≥100 点击 → 点击率才有基本可信度；
- 日预算 300-500 → 保证每张图都能跑满点击量。

## 四、测图标准流程（选品测款标准流程）

### 前提条件（不满足就别测）

- 产品**已有基础销量和评价**，否则测图数据不准；
- **无基础销量的新品不测图**，先做基础优化。

### 四步流程

```
Step 1: 建立手动测图计划（非智能计划）
Step 2: 每个创意至少 50 个点击
Step 3: 点击率对比行业均值
Step 4: 差图及时删除（智能计划）/ 保留权重（手动计划）
```

### 判断逻辑：先确认整体，再选最优

1. 先看整体数据是否达标（对比行业均值）；
2. **在达标图片中选点击率最高的一张**；
3. **不要在全部不达标的图片中选"最不差的"**。

> 这条是测图最常被违反的一条。全部图都不达标时，正确动作是**回去改图/改卖点/改人群**，不是硬挑一张上线。

### 老品测新品图（省事做法）

**条件**：
- 找一个**价格和关键词成交来源一致**的老款；
- 该老款**有历史关键词投放数据，词权重好**。

**流程**：建立手动测图计划 → 上传 **4-8 张**新图 → 每个创意 **50 个点击** → 选最优图替换主图。

## 五、测图 vs 测款：别混

| 维度 | 测图 | 测款 |
|---|---|---|
| **测什么** | 哪张图点击率高 | 这个产品值不值得投入 |
| **核心指标** | 点击率 | **加购率**（标品也参考转化率） |
| **计划配置** | 手动测图计划（非智能计划） | 手动 + **低出高价** |
| **点击量门槛** | 每创意 ≥50 / 每图 ≥100（见下方冲突） | 每款**至少 50 个点击** |
| **周期** | — | **3-5 天/款** |
| **定向** | — | 半智能 / 关键词相关人群 |
| **地域** | — | **关闭偏远地区** |
| **预算** | 300-500 元/天 | 保证 **3-5 天内跑完 50 个点击** |

**测款常见错误**：数据量不足就下结论（必须 50 个点击）；测试周期拉太长（3-5 天/款）；用新号测款（标签不准）。

**新品测试不要用"投产"评估**：新品期前两周投产本来就不到 1，这是正常的；投产差不一定是品的问题，可能是指标选错了。

### 品类测试指标速查表

| 品类类型 | 测试指标 | 注意事项 |
|---|---|---|
| 低客单标品 | 点击率 + 转化率 | 成交周期 ≈ 1 天 |
| 高客单标品 | 点击率 + 转化率 + **人群精准度** | 人群容易跑偏，重点关注 L1/L2 比例 |
| 非标品 | **加购率** | 购买周期 ≠ 1 天时用 |
| 高复购品类 | **首购新客成本**（不是总成交成本） | 只看总成交成本，所有计划会跑向收割 |
| toB / 定制类 | **咨询率** | 不看加购，看咨询量和咨询成本 |

## 六、测图点击门槛：三套口径（冲突，需复核）

| 出处 | 门槛 | 粒度 |
|---|---|---|
| 十三式战法总纲1（第一式） | **每张图 ≥100 个点击** | 单图 |
| 选品测款标准流程 | **每个创意至少 50 个点击** | 单创意 |
| 关键词推广体系（四步法） | **累计 500+ 点击**后分析 | 累计 |
| b06-3384 利润公式 | **≥3 张、2-3 天出结果，点击率 > 行业 1.2 倍** | 批次 + 判定线 |

**冲突点**：前三者的换算关系（单图 / 单创意 / 累计）未给出，判定线也有 1.5 倍与 1.2 倍两档。
**落地建议**：按测图计划统一的"每图 ≥100 点击"执行最稳妥（最严），并把**保留线设为 ≥ 行业 1.5 倍**；但这是取舍，不是素材原文，落地前先复核。
