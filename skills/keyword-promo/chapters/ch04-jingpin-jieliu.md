# ch04 · 竞品截流与品牌攻防

> 来源：关键词推广体系（竞品截流四步法）、关键词推广十三式战法总纲1-消化（第五式相似品跟投、品牌词计划）、b08-关键词推广十三式战法总纲2_王华彬边界-消化（智能选品方向）、付费推广组合选择逻辑。

搜索流量的本质是**抢位置**。大词卡位抢不过、精准词铺不满、预算又不允许全量覆盖时，正面硬刚通常是最差解——**去竞品的词下面截流**。

---

## 一、竞品截流四步法

1. **找竞品**：确定 **3-5 个**主要竞争对手；
2. **分析**：分析**竞品的成交关键词**；
3. **截流**：在竞品关键词上设置**略高出价**；
4. **优化**：监控转化率，持续优化。

**关键细节**：
- **"略高出价"不是"高出价"**。高出太多你就自己把 CPC 推上去了，截流变成抬价；
- **看竞品的成交词，不看竞品的投放词**。成交词是已经被验证过的需求，投放词里很多是无效曝光词；
- 截流计划要看**转化率**而不是只看展现——截来的人不下单，等于花钱给竞品做预热。

---

## 二、第五式：相似品跟投

**核心要点**：**智能出价 + 相似品跟投**；图片可 **1:1 模仿竞品图 / 迭代竞品图 / 镜像竞品图**进行截流。

**具体数字**：**100 元/天**，**精准匹配**，可截流**竞品主图和车图**。

**适用场景**：**产品同质化高、竞品流量来源清晰的品类**。

**原文核心观点**：
> 「相似品跟投：竞争是降维的，我们的宝贝竞争力 > 竞品，可搭配人群推广-竞争航线定投竞品截流。」

### 三种图片打法对照

| 打法 | 做法 | 适合什么情况 | 风险 |
|---|---|---|---|
| **1:1 模仿** | 照竞品主图的构图与信息层级重做一张 | 竞品主图已被验证有效，但你换不掉 | 同质化加剧，容易被平台判重复铺货 |
| **迭代** | 在竞品图基础上换卖点 / 换人群 / 换场景 | 竞品图有明显信息空档 | 改动要够大，否则等于 1:1 |
| **镜像** | 针对竞品的**车图**（第二张轮播图）做对应拦截 | 竞品靠车图承接点击 | 需要你也有对应场景素材 |

**与测图联动**：跟投的图也要测点击率。**同一批词下，跟投图点击率低于自己主图，说明词抢到了但人没进来**——这是文案/卖点问题，不是出价问题。参考 [ch03-cetu-sop.md](ch03-cetu-sop.md)。

## 三、品牌攻防

### 3.1 品牌词计划（附加式）的核心要点

- **进攻**：选**竞品品牌词**；
- **防守**：**自己品牌词**；
- **代理品牌时品牌词 = 精准词**，可同步开启收割。

**具体数字**：拉新 **100 元/天**，收割 **200 元/天**。

### 3.2 品牌攻防三条动作线

| 方向 | 目标 | 关键动作 | 判据 |
|---|---|---|---|
| **防守自有品牌词** | 防竞品截流 | 品牌词必须出现在**首条或前三**（与第三式搜索卡位同一标准） | 品牌词排名掉出前三 = 防守失守 |
| **进攻竞品品牌词** | 截竞品流量 | 略高出价抢位，**控成本促点击** | 竞品品牌词下的转化率与投产 |
| **代理品牌收割** | 收割高意向 | 品牌词 = 精准词，可同步开收割计划 | 收割计划投产 |

### 3.3 品牌词的两个硬约束

1. **非品牌商家关限时升舱**（第三式同款要求）：限时升舱是给有品牌承接能力的商家准备的，没品牌词挂上去拿不到位也接不住人；
2. **品牌词不是大词**：品牌词的搜索意图已经被收窄，精准匹配即可，硬出高价只会抬高自己的 CPC。

## 四、竞品截流的数据准备（做之前必须有的三张表）

| 表 | 来源 | 用途 |
|---|---|---|
| **竞品成交词表** | 竞品店铺/生意参谋成交词 | 截流词池（80% 落款成交词优先） |
| **竞品主图与车图** | 竞品详情页 | 1:1 / 迭代 / 镜像三种图片打法的素材来源 |
| **竞品流量来源结构** | 生意参谋（竞品宝贝 ID） | 判断竞品主要靠搜索还是推荐，决定你截流往哪打 |

**竞品筛选标准**（[[wanxiangtai-wujie]] P2 口径，竞品定向三要素）：
- **优先选择**：TA 人群规模 **≥5 万** + TA 人群浓度 **≥30%** + TA 人群未渗透率 **≥60%**；
- **规避选择**：TA 人群规模 **<3 万**、浓度 **<20%**、未渗透率 **<40%**。

## 五、截流效果的判断顺序

```
词抢到了吗？
├─ 没有 → 是出价/预算问题 → 检查是否略高出价、预算是否够跑出展现
└─ 有了
   ├─ 点击率低于自己主图 → 是图的问题 → 回到测图 SOP（ch03）
   ├─ 点击率正常但没转化 → 是承接问题 → SKU / 主图 / 详情页（见 [[conversion-optimization]]）
   └─ 有转化但投产差 → 是利润问题 → 算账（见 [[profit-model]]）
```

**通用原则**：**推广的问题要在单品中找答案。**截流只是把人拉过来，转化和利润仍然由商品自己决定。
