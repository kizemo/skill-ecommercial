# 可复用方法 · keyword-promo

> 每条格式：**何时用** / **怎么做** / **代价与风险**。
> 这些是可重复动作，不是知识点的复述。

---

## 1. 五式搭建顺序（把预算花在刀刃上）

**何时用**：新建一个链接的关键词推广体系；老链接计划混乱要重构。

**怎么做**：
1. **第一式 测图**：≤3 个大词、出价前三、关智能创意、每图 ≥100 点击、日预算 300-500 元；
2. 拿到点击率最高的图 → 换主图；
3. **第三式 搜索卡位**：T1 大词 + T2 精准词，精准匹配，抢首条或前三，非品牌关限时升舱；
4. **第二式 大词计划**：竞品 80% 落款成交词，智能出价拆拉新 100 元/天 + 收割 200 元/天；
5. **第四式 精准词计划**：第二梯队垂直词，拉新 100 元/天 + 收割 200 元/天；
6. **第五式 相似品跟投** + **品牌词计划**（进攻竞品 + 防守自有）。

**代价与风险**：顺序反了（没测图就卡大词）是最大的钱坑——**点击率是所有后续计划的乘数**。另：五式**统一关智选、精准匹配、只投淘搜索**，唯一例外是明确做"流量智选词包计划"时。

---

## 2. 阶段化拉新/收割配比（别用一套比例打全年）

**何时用**：链接从成长期进入爆款期；或反过来从爆款期掉回成长期。

**怎么做**：
1. **成长期**：拉新计划占 **60%-70%** 预算，收割计划拿余下；
2. **爆款期**：收割计划占 **60%-70%** 预算，拉新拿余下；
3. 判断阶段用爆款生命周期口径（打标 1-7 天 / 起量 8-15 天 / 爆发 16-30 天 / 稳定 31 天+）；
4. 收割计划看 ROI，拉新计划看**有效人群比例**（≥60% 优秀 / 40%-60% 良好 / <40% 停），**别用 ROI 判拉新**。

**代价与风险**：拿 ROI 判断拉新计划，等于用错尺子——拉新期的低 ROI 是资产建设成本，不是浪费。反过来，成长期把预算压在收割上，会把人群池做薄，后面想放量拉不动。

---

## 3. 测图判据法（先达标，再选最优）

**何时用**：换主图；新品定图；老品上新图。

**怎么做**：
1. 确认前提：产品**已有基础销量和评价**（否则不测图，先做基础优化）；
2. 建**手动**测图计划（非智能计划），关智能创意；
3. 上传 **4-8 张**新图，每个创意跑满点击量（每图 ≥100 / 每创意 ≥50，取严）；
4. **先看整体是否达标（对比行业均值）**；
5. 达标后**选点击率最高的一张**；
6. 保留线：点击率 ≥ 行业 1.5 倍。

**代价与风险**：最常见的错误是"全部图都不达标，挑最不差的先用"——正确动作是回去改图/改卖点/改人群。硬挑一张上线 = 把不达标固化进主图，后面所有计划替它买单。

---

## 4. 老品测新品图（最省事的换图法）

**何时用**：新品没有历史数据但需要立刻定主图。

**怎么做**：
1. 找一个**价格与关键词成交来源一致**的老款；
2. 确认该老款**有历史关键词投放数据、词权重好**；
3. 在老款上建手动测图计划，上传 **4-8 张**新图；
4. 每个创意 **50 个点击**后，选最优图替换主图（再迁到新品）。

**代价与风险**：前提是"词权重好"。随便找一个爆款去测，词来源不一致，测出来的点击率不能迁。

---

## 5. 词梯队切分法（把预算铺成漏斗）

**何时用**：大词打不过；预算有限；要拓宽度。

**怎么做**：
1. 竞品成交词表 → 按竞争强度切三梯队：**T1 大词**（类目核心）、**T2 精准词**（第二梯队垂直）、**第三梯队长尾词**（相对长尾的核心成交词）；
2. T1 → 第三式搜索卡位抢前三；
3. T2 → 第四式精准词计划；
4. 第三梯队 → 精准词扩词计划（**一个词路一组计划**，日预算 100 元 + 收割 200 元），用主推词权重反哺；
5. 关键词数量占比参考：大词 20% / 精准词 50% / 长尾词 30%。

**代价与风险**：**占比口径未明确是数量还是预算**，先定口径再分。另一个坑是所有词都塞进一个计划——词和人群重叠消耗，每层要独立计划。

---

## 6. 截流三表准备法（截流前必须有的东西）

**何时用**：决定做竞品截流；大词卡位打不动时。

**怎么做**：
1. **竞品成交词表**（分析竞品的成交关键词，不是投放词）；
2. **竞品主图与车图**（1:1 模仿 / 迭代 / 镜像的素材来源）；
3. **竞品流量来源结构**（判断竞品主要靠搜索还是推荐，决定往哪打）；
4. 选竞品时按人群口径筛：规模 ≥5 万 + 浓度 ≥30% + 未渗透率 ≥60% 才算好竞品；
5. 建跟投计划：智能出价 + 相似品跟投，精准匹配，**100 元/天**起步；
6. 出价只**略高**于竞品，不追高。

**代价与风险**：高出价截流 = 自己推高 CPC，截流变抬价。截来的流量点击率低于自己主图，说明图有问题，回测图 SOP；点击率正常但没转化，去改 SKU/详情页，别继续加价。

## 7. 品牌攻防三线法（守比攻便宜）

**何时用**：有品牌词或代理品牌的商家；发现竞品在打你的品牌词。

**怎么做**：
1. **防守线**：自有品牌词必须进首条或前三（与搜索卡位同标准）；
2. **进攻线**：竞品品牌词建计划，控成本促点击、略高出价；
3. **收割线**（代理品牌时）：品牌词 = 精准词，可同步开收割计划；
4. 拉新 **100 元/天** + 收割 **200 元/天** 起步；
5. **非品牌商家关限时升舱**。

**代价与风险**：品牌词不是大词，硬出高价只会抬高自己 CPC。防守线的判定是排名不是投产——**品牌词掉出前三就是失守**，哪怕投产还看。

---

## 8. 免费搜索三入口（不花钱的搜索流量）

**何时用**：付费点击单价从 8 毛涨到 8 块以后；想降低对付费的依赖。

**怎么做**：
1. **AI 万能搜**：把商品参数、属性、描述**填全**，覆盖尽可能多的长尾词，用用户常用自然语言描述（参考"能放进书包的保温杯"这种问法）；
2. **光合平台短视频**：权重与图片搜索相同、点击率高 30%+，一个优质视频覆盖几百个长尾词；发布时**删掉系统推荐话题，手动加长尾关键词做话题**；
3. **站外种草**：小红书铺种草笔记 → 引导搜索店铺名（不放链接）→ 淘宝首页设专属优惠承接（每 1000 小红书流量 → 100 个免费类目大词搜索流量）。

**代价与风险**：三条都要**商品信息填写质量 + 素材质量**做底子，参数没填全 = AI 万能搜匹配不到，站外引流来了也排不进前三。

## 9. 全站 vs 无界分流（按"要不要可控"决定）

**何时用**：新品测款、数据稳定后放大、效果下滑要回调。

**怎么做**：
1. 新品测图测款**先用无界**（可控性强、可调地域/时间/人群/出价）；
2. 数据稳定（2-4 周）→ 转全站放大收割；
3. 效果下滑 → 再转无界维护；
4. 利润薄产品慎用全站用无界；大促期全站效果好；KA 商家全站 + 无界配合；
5. 万相台新功能**第一时间用 30-50 元最低预算试**。

**代价与风险**：**"全站是否压制自然搜索"三条口径互相矛盾**（见 SKILL.md Scope），新品期按保守口径不上全站。另一个坑：全站投产比包含免费流量，**top 店铺天然有优势**，别拿自己的全站投产跟行业均值比。

---

## 10. 一次只调一个变量（归因纪律）

**何时用**：每次改出价、改预算、改图、改匹配方式之后。

**怎么做**：
1. 每次只动**预算 / 人群 / 出价 / 创意 / 匹配方式**中的一个；
2. 改完观察期固定（≥3 天），不要中途又改；
3. 放量每次增幅 **≤50%**；
4. 每次调整留一条记录（改了什么、为什么）。

**代价与风险**：同时改两个变量，数据变好也说不清是谁的功劳；变差也不知道该回退哪个。**推广的问题要在单品中找答案**——推广动作只能放大单品的竞争力，不能修复产品力。
