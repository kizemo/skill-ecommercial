## 3. 决策规则

| 情况 | 判定 | 动作 |
|---|---|---|
| 搜索有展现、点击率低 | 图的问题，不是词的问题 | 走测图 SOP，别加价 → `chapters/ch03-cetu-sop.md` |
| 测图时全部图都不达标 | 整体未过行业均值 | **回去改图/改卖点**，不要挑"最不差的" |
| 大词卡位抢不到前三 | 竞争太激烈 | 降预算转 T2 精准词（第四式）+ 长尾扩词 |
| 大词计划投产低但成交在涨 | 可能在建词权重 | 别砍，先查词权重与领先率 |
| 拉新计划投产低 | **不能用 ROI 判拉新** | 看有效人群比例：≥60% 好 / 40%-60% 可调 / <40% 停 |
| 收割计划投产掉了 | 边际效应下滑阶段 | 减预算 30%-50%，转拉新 |
| 截流有展现没点击 | 跟投图不行 | 1:1 → 迭代 → 镜像，重新测点击率 |
| 截流有点击没转化 | 承接问题 | 改 SKU / 主图 / 详情页，别加价 |
| 品牌词掉出前三 | 防守失守 | 提高品牌词出价抢回位 |
| 点击单价从 8 毛涨到 8 块 | 付费流量红利消失 | 转 AI 万能搜 + 光合视频 + 站外种草补免费搜索 |
| 新功能上线 | 万相台每月迭代 | 30-50 元最低预算第一时间试 |

## 4. 决策树

```
要搭搜索推广
├─ 有高点击率主图吗？
│  ├─ 没有 → 先测图（第一式：≤3 大词 / 出价前三 / 关智能创意 / 每图≥100 点击 / 日预算300-500）
│  └─ 有
│   ├─ 类目词抢不到前三？
│   │  ├─ 是 → T2 精准词（第四式）+ 第三梯队长尾扩词，别硬砸大词
│   │  └─ 否 → 第三式卡位（T1+T2，抢首条或前三，非品牌关限时升舱）
│   ├─ 竞品在打我的词？
│   │  ├─ 是 → 品牌攻防：自有词守前三 + 竞品品牌词进攻
│   │  └─ 否 → 第五式相似品跟投（智能出价 + 100元/天 + 1:1/迭代/镜像竞品图）
│   └─ 计划怎么分预算？
│       ├─ 成长期 → 拉新 60%-70%
│       └─ 爆款期 → 收割 60%-70%

有展现没点击
├─ 点击率低于行业均值 → 测图（ch03）
├─ 词太泛 → 换精准词 / 长尾词
└─ 词太窄 → 检查商品属性与标题是否覆盖了用户搜法

点击率正常但没转化
└─ SKU / 主图 / 详情页 → 转 [[conversion-optimization]]

投产好看但销售下滑
└─ 转 [[store-diagnosis]]（领先率 + 归因切换）

新功能 / 新工具要不要试
└─ 30-50 元最低预算试；数据稳定再放量；万相台每月迭代，红利期短暂
```

## 5. 计划配置冲突表（同一件事不能同时开）

| A | B | 怎么处理 |
|---|---|---|
| 测图计划（关智能创意） | 大词/精准词计划 | **不要合并**，测图要独立计划、独立预算 |
| 流量智选词包（只开词包） | 卖点词包（只开卖点词包） | **互斥**，一个开一个关 |

## 6. 陷阱清单

| 陷阱 | 后果 | 破法 |
|---|---|---|
| 没测图就开大词计划 | 点击率是乘数，后面全被拖垮 | 顺序固定：测图 → 卡位 → 大词 → 精准词 → 截流 |
| 在全不达标的图里挑"最不差的" | 把不达标固化进主图 | 先确认整体达标，再选最高的一张 |
| 一个计划里混拉新+收割+测图 | 归因不了，哪块有效不知道 | 一计划一动作 |
| 智能创意没关就开始测图 | 测的是系统换的图，不是你的图 | 测图计划必须关智能创意 |
| 出价越高越能抢词 | 自己把 CPC 推上去，截流变抬价 | 只**略高**于竞品 |
| 关键词铺得越多越好 | 词和人群重叠消耗 | 聚焦 20% 核心词，按梯队分计划 |
| 用 ROI 判断拉新计划 | 用错尺子，把资产建设误判成浪费 | 拉新看有效人群比例 |
| 用 ROI 判断收割计划以外的一切 | 忽略词权重沉淀 | 直通车核心价值是拉新 + 词权重 |
| 直接照搬"占比 20/50/30" | 不知道是数量占比还是预算占比 | 先定口径（素材未明确） |
| 一次翻倍预算 | 成本失控、模型跑偏 | 每次增幅 ≤50% |
| 全站投产比跟行业均值比 | 全站计算含免费流量，top 店铺天然占优 | 只跟自己比 |
| 把第 6-15 式当成已知照抄 | 素材无正文 | **后 8 式未验证**，回原培训原文补 |

## 7. 口径冲突（需复核，落地前先定一个）

1. **测图点击门槛**：每图 ≥100 / 每创意 ≥50 / 累计 500+ —— 粒度不同，换算关系未给。
2. **测图保留线**：点击率 ≥ 行业 1.5 倍 / > 行业 1.2 倍。
3. **十三式编号**：《关键词推广体系》记 05=竞品截流、06=品牌攻防；《总纲1》第五式=相似品跟投、品牌词=附加。
4. **全站是否压制搜索流量**：不抢（2026体系）/ 压制（付费推广组合）/ 压缩关键词流量（关键词推广体系）—— 三条互相矛盾。
5. **关键词占比口径**：数量占比还是预算占比，素材未明确。
