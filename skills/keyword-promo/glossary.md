# 术语表 · keyword-promo

> 每条标注来源笔记。定义取知识库原文口径。

**十三式战法** — 直通车推广的系统化方法论，把推广按目的分为测图、拦截、收割、防守等计划类型，核心共性是"关智选、精准匹配、手动或智能出价、只投淘搜索"。（来源：`关键词推广十三式战法总纲1-消化`）

**后 8 式未验证** — 知识库导出素材只完整提取到第五式（加品牌词附加式）；《总纲2》讲的是进阶词包与工具计划，不是第六式以后。第六式及以后无可引用正文，本 skill 不代写。（来源：`关键词推广十三式战法总纲1-消化`、`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**测图计划（第一式）** — 关键词 ≤3 个大词、出价前三、关智能创意、每图 ≥100 点击定点击率、日预算 300-500 元、精准匹配。（来源：`关键词推广十三式战法总纲1-消化`）

**大词计划（第二式）** — 选竞品 80% 落款成交词，智能出价拆成拉新计划与收割计划；拉新 100 元/天、收割 200 元/天。（来源：`关键词推广十三式战法总纲1-消化`）

**搜索卡位（第三式）** — T1 大词 + T2 精准词精准匹配，抢首条或前三；控成本促点击，出价前三，非品牌商家关限时升舱。（来源：`关键词推广十三式战法总纲1-消化`）

**精准词计划（第四式）** — 第二梯队垂直精准词（如"臂式血压计"vs"血压计"）精准匹配，数据好可改广泛匹配；拉新 100 元/天、收割 200 元/天。（来源：`关键词推广十三式战法总纲1-消化`）

**相似品跟投（第五式）** — 智能出价 + 相似品跟投，图片可 1:1 模仿 / 迭代 / 镜像竞品图进行截流；100 元/天，精准匹配。（来源：`关键词推广十三式战法总纲1-消化`）

**品牌词计划（附加式）** — 进攻竞品品牌词、防守自有品牌词；代理品牌时品牌词 = 精准词，可同步开启收割；拉新 100 元/天、收割 200 元/天。（来源：`关键词推广十三式战法总纲1-消化`）

**大词** — 高搜索量、高竞争的一类关键词，占比建议 20%，战略价值是"流量制空权"。（来源：`关键词推广体系`）

**精准词** — 中等搜索量、中等竞争的一类关键词，占比建议 50%，战略价值是"利润引擎"。（来源：`关键词推广体系`）

**长尾词** — 低搜索量、低竞争的一类关键词，占比建议 30%，战略价值是"精准人群"。（来源：`关键词推广体系`）

**80% 落款成交词** — 竞品成交词表中末尾 80% 那一段仍带成交的词，是大词计划选词的主要来源。（来源：`关键词推广十三式战法总纲1-消化`）

**T1 大词 / T2 精准词** — 搜索卡位里关键词的两层：T1 是类目核心大词，T2 是第二梯队垂直精准词（如"臂式血压计"）。（来源：`关键词推广十三式战法总纲1-消化`）

**限时升舱** — 搜索卡位场景下的位置玩法；**非品牌商家应关闭**（没有品牌词承接，挂上去拿位也接不住人）。（来源：`关键词推广十三式战法总纲1-消化`）

**车图** — 商品第二张轮播图。相似品跟投时可针对竞品车图做"镜像"截流。（来源：`关键词推广十三式战法总纲1-消化`）

**测图策略矩阵** — 按爆款等级选测图方式：顶级爆款=精细化测图、成长爆款=标准测图、引流款=快速测图、利润款=保守测图。（来源：`关键词推广体系`）

**科学测图四步法** — 准备 4-8 张创意图 → 万相台关键词计划均匀分配预算 → 累计 500+ 点击后分析点击率 → 点击率 ≥ 行业 1.5 倍则保留，否则替换。（来源：`关键词推广体系`）

**关智选** — 关闭流量智选词包，只用手动关键词。是十三式各式的统一配置要求。（来源：`关键词推广十三式战法总纲1-消化`）

**只投淘搜索** — 关键词计划只勾选淘搜索场景，不混投推荐及其他场域。（来源：`关键词推广十三式战法总纲1-消化`）

**流量智选词包** — 系统智能选词的词包。使用时只开词包、不开关键词，适合新品测款和全店动销。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**卖点词包** — 按产品核心卖点匹配流量的词包。与流量智选词包**互斥**（一个开、一个关）。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**省油宝** — 低价引流计划形态，长尾引擎 + 自动优化降低 PPC。核心公式：投产比 = 客单价 × 转化率 ÷ PPC。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**趋势明星** — 选趋势红榜 / 效果红榜主题词的矩阵打法，一个宝贝一个计划，周期预算 350 元，出价目标"稳定投产比"。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**好货快投（智能选品）** — 系统按成交转化 / 潜力新品 / 店铺引流 / 目标人群覆盖四方向自动选品的计划组，周期预算 350 元。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**控成本宝贝点击** — 直通车的一种出价目标，流量智选词包、卖点词包、精准词扩词计划都用它。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**稳定投产比** — 直通车的一种出价目标，趋势明星与智能选品计划用它。（来源：`b08-关键词推广十三式战法总纲2_王华彬边界-消化`）

**竞品截流四步法** — 确定 3-5 个竞品 → 分析竞品成交关键词 → 在竞品关键词上设置略高出价 → 监控转化率持续优化。（来源：`关键词推广体系`）

**词图匹配** — 搜索什么展示什么，是基本要求；更高境界是"词图人匹配"。（来源：`b12-爆款三板斧-产品布局`）

**AI 万能搜** — 通过分析商品详细参数、属性、描述理解商品功能的搜索能力。参数填全后长尾词能排进前三，每天可获 200+ 免费流量。（来源：`素材革命与八大流量入口`）

**搜推素材** — 搜索推荐一体化素材，同时在搜索结果页、推荐页、活动页展示；人群匹配精度高 30%+，流量池是光合平台素材 2 倍以上。（来源：`素材革命与八大流量入口`）

**金标** — 拍立淘扶持金标 / 搜索推荐金标 / 活动优先金标三类流量加权标识，在商机发现页报名获取。（来源：`素材革命与八大流量入口`）

**直通车 ROI 参考区间** — 标品 1:3~1:8，非标品 1:2~1:5。（来源：`付费推广组合选择逻辑`）

**无样本不碰 AI 智能场景** — 三大场景（搜索 / 推荐 / AI 智能）的铁律：先用搜索锁精准意图积累样本，再做推荐，最后才用 AI 智能场景放大。（来源：`三大场景`、`skill-ecommercial`）
