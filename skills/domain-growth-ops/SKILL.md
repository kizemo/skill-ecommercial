# 全域增长操盘体系

**来源**：`taobao-operation` 知识库（智篆商业·老草老师讲座系列：基于人群资产的淘天运营方法1·多品多域思维 / 方法2·推广计划组合分工 / 方法3·推广计划搭建策略 / 方法4·多端数据融合调优；流量渠道重构与付费推广升级；2026-07-29 增长方法论与全域策略；2026-09-06 无界精英班；2026-04 万相台无界课程第3天）｜**版本**：2026.10｜**层级**：L1

**这一层解决什么**：`wanxiangtai-wujie` 教你**怎么把计划搭起来**；本技能教你**钱该加给谁、该停谁的**。推广操盘的决策层。

> **核心立场**：流量分配逻辑已从"销量×反馈"双轮升级为"销量×反馈×人群资产"三轮。**今天没有人群资产 = 没有免费流量。**
> **新店破局 = 主动建立人群资产（先收割后拉新）；老店增长 = 系列化核算 + 三阶段动态调整。**

## 一、流量分配规则：一切判断的前提

| 阶段 | 时间 | 核心原则 | 间接成交 |
|---|---|---|---|
| 下架时间轮播 | 2012 年及以前 | 离下架最近 15 分钟权重最高 | 无意义 |
| 同店打散原则 | 2013 年至去年 | 一个关键词最多展示 2 个宝贝 | 被嗤之以鼻 |
| **人群资产加权** | **2026（当下）** | 多宝贝同店可同时展示 | **香饽饽** |

**人群资产加权 ≥ 30%-40% 量级**（不是旧认知的 1%）——所以搜"网球鞋"这类行业大词，一家店铺近 10 个宝贝可同时曝光，销量从六千五百到三百参差不齐。

**莫茨归因**：15 天时间窗内点过广告，后续成交都算给**最后一次广告点击**的投产。**优先展现权**覆盖搜索/推荐/秒杀/百亿补贴/摆补/狂暑季/淘金币等多个场域。

**AIPL 权重**：A 浏览(15天/低) < I 收藏加购入会(90天/中) < P 购买1次(365天/高) < L 购买多次(最高)。一个消费者与一个店铺**只能有一种身份**，关系建立时权重最高、**随时间衰减**。

## 二、费比红线：能不能花钱的生死线

> 费比 = 推广花费 ÷ 营业额。**每个宝贝都会定费比。**

| 状态 | 后果 | 该做什么 |
|---|---|---|
| 费比没超 | 能继续花 | **敢花** |
| 费比超了 | 生意干赔 | 立刻收手 |
| **费比没花掉** | 白丢机会 | **把剩余额度花出去** |

第三条最易被忽略：能干 30 个点的费比只干了 10 个点，多出的 20 个点变成利润，**整个销售规模的护城河就下来了**。今天不做暴利行业，**要把利润奉献到平台流量池里把护城河做厚**。

**边际递减**：每 100 块依次卖 500 / 420 / 380 / 310 / 280 → 投产瓶颈反过来卡住花费。所以目标不是"拉高投产"，是**保持更高投产让费比不要快速超标**。

**三个费比口径（必须用第三个）**：

| 指标 | 公式 |
|---|---|
| 推广费比 | 推广花费 ÷ 成交金额（**不含退款**） |
| 去推费比 | 推广花费 ÷（成交金额 − 退款金额） |
| **系列去推费比** | (A+B+C 推广花费) ÷ [(A+B+C 成交金额) − (A+B+C 退款金额)] ← **商家应优先使用** |

**间接成交放大花费绝对值**：同样 30% 费比，有间接成交能花 **5 万**，没有只能花 **2 万**。

**推广价值放大公式**（F = 黑箱系数，不可干预）：
```
成交机会 = F × (优先展现权激活数 × 曝光场域数 × 匹配商品数)
成交规模 = F × (人群资产流转效率 × 人群资产规模 × TA 人群浓度)
```
成交机会越大 → 投产越好 → 同费比下能花越多 → 费比上升越慢。

**三阶段动态调整**：爬坡期（牺牲盈利换成长，可超标）/ 热卖期（特别关注费比，超标追不回来）/ 收尾期（控制费比到目标范围，算前两期缺口绝对值）。

## 三、推广红绿灯：两轴三色 + 四场景

| 指标 | 🟢 绿 | 🟡 黄 | 🔴 红 |
|---|---|---|---|
| **投产（ROI）** | ≥ 目标 ROI | ≥ 目标 × 0.8 且 < 目标 | < 目标 × 0.8 |
| **费比** | ≤ 目标费比 | 目标 < 实际 ≤ 目标 × 1.2 | > 目标 × 1.2 |

| 场景 | 决策 |
|---|---|
| **双绿** | **加预算** 20%-30%，系列总增幅不超 30% |
| **投产绿 + 费比红** | 查退款率/间接占比；优化为主；单品减 30%-50% |
| **投产红 + 费比绿** | 观察优化，必要时增加收割预算 |
| **双红** | **减预算 50%-80% 或暂停**，优化后再重启 |

**加预算前提**：双绿且连续 **3 天**稳定；新增预算 ROI ≥ 原有 **80%**；TA 未渗透率 ≥ **50%**；选 ROI 最高的 **3-5 个**单品。
**减预算前提**：双红灯或连续 **3 天**黄灯无改善；退款率持续 **>30%**；间接成交占比 **>70%** 且系列费比红灯。
**观望前提**：波动大；日预算 < **500 元**或推广天数 < **7 天** → 不增不减，监控 7-10 天。
**调整铁律**：每次幅度 **≤ 30%**。

### Gap 公式：今天最多能加多少
```
每日可增加花费 = (过去 N 天平均每天花费 ÷ 当前去退费比) × 去退费比 Gap
累计 Gap      = 历史可支配推广花费 ÷ N 天
合计调整      = 每日可增加花费 + 累计 Gap
```
> 猫零食店实测：241,465 销售额 × 0.42% = 1,014.15；日均花费 44,865÷6 = 7,477.5；7,477.5 ÷ 18.52% × 0.42% = 169.58；累计 Gap 1,014.15÷24 = 42.26；**合计 211.84**。

### 生命周期差异化：同一个红灯，反应完全相反
- **新品冲量期**：GSV 绝对优先，费比红灯但 GSV 在增长 → **默许甚至鼓励超标**（多花 5000 买初始权重+第一批人群资产+入场券，占比小则亏损绝对值可控）。
- **爆款成熟期**：费比红线是生命线。月 GSV 500 万的爆款费比超标 2% = **10 万纯利润损耗**，5% = 25 万 → 果断停加、转移预算。

### 多指标联动诊断：像医生找病因
| 病例 | 判据 | 对策 |
|---|---|---|
| **① 引流先锋官** | 费比高 + ROI 高 + **间接成交占比高** | **这是绿灯不是红灯**——打包进系列看板，系列费比健康就不能砍，酌情加钱 |
| **② 退款率假象** | 费比高 + ROI 高 + **间接占比不高** | 推广成交金额是毛的 → 跳生意参谋退款分析模块找主因 |
| **③ 回炉重造** | 费比高 + 投产低 | 停计划 → 分析同行素材 → AI 重做场景人群与视觉；确认产品力问题就放弃 |

## 四、系列化核算：把货打包花一包钱

**过去核算单品费比，一个宝贝超标就吓得不敢花钱**；但 A 看完买了 B，A 的产出其实是好的。整体销售额由一个一个货盘组成，**每个货盘毛利空间不同 → 必须分开控制**。

**操作路径**：
1. 把主力商品按**心智匹配度**梳理成一个个 SAB 货盘（耳钉与耳圈不能同盘；日系门帘不能延伸到中式门帘——消费者建立的是"想买日系门帘"的人群资产）；
2. 按系列分配月度目标；
3. 按天跟进每个系列的费比：超标扣预算，没超标**应该花出去**；
4. 打包核算底线（如投产 1:3）→ 这个宝贝 1:8 说明**花少了还要多花**，那个 1:14 减预算投产就回来 → 目标是把系列费比拉到可接受极限、**把花费绝对值最大化**。

**货盘厚度 = 有效宝贝数量 × 心智匹配度**（不是 SKU 总数）。69 个有效抱团宝贝的间接成交能力远超 1000 个零散常微品。

**心智匹配度三大反例**：母婴推车（高景观 vs Air 月龄诉求不同）｜羽毛球服（圆领 vs V 领，点击圆领的人不会买 V 领）｜耳环（大耳圈 vs 耳钉）。心智错位 → 看 A 不会买 B → 根本没有间接成交。

**标品 vs 非标品**：非标品靠厚度撑间接成交；标品有货盘就继续做，没有就**分裂场景**（S=客厅设计感垃圾桶 / A=卫生间窄垃圾桶，心智连不上）。**SAB 的衔接性必须好。**

**心智素材 > 点击率**：今天没有质量得分束缚，**图承载的是用户选择品类的决策心智**——L5 人群进店看 L1 素材，点击率再高也没意义。内衣要按**色系+功能+元素三重维度**（黑色/无痕/蕾丝）拆关联度。

**标品人群分层**：类目新客 22,311,915 访客 / 394,491 购买 = **1.77%**；类目熟客 13,049,754 / 2,816,123 = **21.58%**（原文表述"差近 20 倍"，但两数相除约 **12 倍** —— 原文自身不一致，**口径存疑，需复核**）。熟客定义 = 浏览 6 次以上 + 加入购物车（并集）。

**浏览次数 → 转化率阶梯**：1 次 1.27%｜2-5 次 4.14%｜6-10 次 10.12%｜11-20 次 17.23%｜21-50 次 28.07%｜51-100 次 40.25%｜100 次+ 53.37%。
→ 真正想买的用户看一两次就下单是少数，**绝大多数需要多次曝光才会转化** → 优先展现权激活数才是放大成交机会的关键变量。

> ⚠️ **口径冲突，需复核**：原文 3.11.1 单独把「21-50 次浏览」的转化率写成 **300%-400%**，而 3.12 的完整阶梯给的是 **28.07%**。本技能采用完整阶梯的 28.07%；若实操中遇到 21-50 次转化率异常高，以实际后台数据为准。

## 五、引潜比：一个数判断计划属性

```
引潜比 = 引导访问潜客占比
```

**7/29 完整版与第 6 章口径**：≤50% 偏收割 ｜ ≥50% 偏拉新
　20% → AI 收割 ｜ 60% → O 熟客拉新 ｜ 85% → O 新客拉新

**9/06 无界精英班口径**：3% = 专门看收割、不拉新 ｜ 30%几 = 拉新型 ｜ 90%多 = 收割型

> ⚠️ **口径冲突，需复核**：两套分档在"高引潜比 = 收割还是拉新"上**方向相反**（85% 是新客拉新，90%多却是收割型）。
> **实用做法**：先用 **50% 分界**定大方向（偏收割 / 偏拉新），再用 20% / 60% / 85% 三档细分人群类型；遇到 90%+ 的高引潜比计划，**先核对它到底是"新客拉新"还是"专门收割"**，不要直接套用某一档。

> **最大陷阱**：绝大多数商家**只看左边的数（投产），不看右边的数（引潜比）** → 投入越多，流量质量越差。

**收割拉新切换判断**：原来 80% 收割 + 20% 拉新、生意规模 1-2 万 → 减少收割增加拉新后**规模增长 = 对**；**规模下降 = 产品本身成交能力不强，容易被别人收割**。

**左右两侧流量（最重要的方向感）**：

| 维度 | 左侧 AI 人群 | 右侧 O 人群 |
|---|---|---|
| 含义 | 系统侧已建立人群资产关系 | 系统外新流量 |
| 关键观察 | **TA 浓度** | 引潜比 / 投产 |
| 触达方式 | 搜索 + 推荐 | 推荐 + 关键词手动 |

> **心法：左侧看浓度不看投产。** 系统会优先拿右侧流量，右侧转化不好时才去拿左侧。

**TA 三大指标**：TA 规模（天花板）｜TA 浓度 = TA 规模 ÷ 店铺总浏览人群（流量精准度）｜渗透率 = 已建立资产人群 ÷ TA 规模。
**竞品定向优先线**：**TA 规模越大 + TA 浓度越高 + 未渗透率越高（渗透率越低）**的竞品，拉新能力越强。

**UV 价值与出价**：
```
UV 价值 = 客单价 × 转化率
点击单价上限 = UV 价值 ÷ 控投产目标
```
> 客单价 81.1 × 转化率 7.61% = UV 价值 **6.17 元**；控投产 3.32 → 点击单价上限 ≈ **2.29 元**。

**关键词 vs 精准人群**：关键词偏收割（AI 熟客比例高）、全站收割能力弱、引潜占比较低；人群收割+拉新都高、全站收割强、引潜占比较高。

## 六、左侧拉新两步验证（不看 ROI，看后链路行为）

**痛点**：末次归因让左侧 ROI 必然为零（客户先点左侧、几天后点右侧成交，功劳全记右侧）；验证周期长（家装三个月、母婴下个月）。

**第一步 · 类目内后链路成交占比（一票否决）**：达摩盘自定义圈人 → 选"万象台无界版回流再营销"标签、勾选所有场景、用"自定义计划"筛出计划 ID 圈出过去 30 天点击人群 → 新建圈人加"类目行为人群"（自己类目 + 购买 + 过去 30 天）取交集。
> 计划 A（关键词-促点击-控成本）2062 ÷ 5800 = **35.5%**；计划 B（精准人群-促点击-智能人群）511 ÷ 4300 = **11.8%** → **A 的左侧流量质量是 B 的三倍**。

**第二步 · TA 人群浓度**：在人群包上用"交集"加目标客群画像标签（消费力 L3/L4/L5 ∩ 25-39 岁女性）。
> A 52% vs B 40% → A 全面更优。⚠️ **不设绝对标准**（"60% 才算好"是错的），浓度永远**自己跟自己比**，同一严苛标准下横向比较不同渠道。

**终极命题 · 心智壁垒**：产品壁垒（独特设计/功能/调性/专利）或心智壁垒（站外小红书内容 + 站内天猫榜单/大促入选/KOL 直播）。**两者都没有的白牌与标品，不适合重投左侧**，应把预算重心压在右侧收割。

## Scope & Limits

- 本技能覆盖**推广操盘决策层**（费比、系列化、红绿灯、预算加减）；**建计划与多品多域搭建**见 `wanxiangtai-wujie`。
- 案例数据（猫条系列、棉服类目、猫零食店、网球鞋、某内衣品牌、某家纺品牌）**均为单店样本，不是行业均值**。
- **口径冲突（需复核）**：① 费比口径——推广费比不含退款、系列去推费比含退款剥离，两者不可混用；② 投资调整幅度——课程内 P4 口径为每次 ≤30%，加预算策略另给出 20%-30% 与 50%-80% 两档，需按场景选用；③ 人群资产加权占比——原文以"≥30%-40% 量级"表述，为经验推断值，非平台公开参数；④ 各章节内部另有多处口径冲突（ch01 标 5 处、ch08 标 9 处、ch08 与 ch06 的红绿灯口径差异 1 处），已逐条标注「口径冲突，需复核」，取用前先看对应章节。
- 阈值来自知识库原文快照（2026 上半年口径）。平台规则与后台功能会变，**落地前核对当期平台公告**。
