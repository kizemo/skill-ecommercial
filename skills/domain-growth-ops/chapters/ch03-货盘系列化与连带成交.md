# ch03 · 货盘系列化与连带成交

> 来源：智篆商业·老草老师·2026-07-29·增长方法论与全域策略·完整版（智篆商业·老草老师讲座-第 3 章 货盘系列化与连带成交）

本章解决一个问题：**同一个店铺里，钱该在宝贝之间怎么搬**。单品费比高不等于亏——把货盘按系列核算，用间接成交把系列费比拉回红线内，再靠 MTD/DIY 决定给谁加钱、给谁压钱。

---

## 一、系列化看板的搭建与口径

### 1.1 按系列建独立看板

- 货盘系列化的第一步是**按系列建立独立看板**。案例：某耳饰店铺把「夸张大号耳圈」作为一个系列 → 共 **15 个宝贝** → 逐个添加宝贝 ID 到看板中；另一个「小巧耳钉」系列 → **33 个宝贝**。
- **添加系列时，把 15 个宝贝 ID 换行写入 → 即可在看板里看到这个系列的整体数据**。
- 看板可对比「喊短视频」与「不喊短视频」的费比差异：「夸张大号耳圈」系列喊短视频时**费比 15.43**、不喊短视频时**费比 14.78**。
- 后续还会增加「营销托管」的开关按钮 → 用于把托管花费也纳入核算。

### 1.2 短视频花费归宝贝：无界内容匹配插件

- **短视频投放是核算系列费比的最大难点**：超级短视频投了某条视频 → 但挂车的具体是哪个宝贝 → 从报表里完全看不出来。以前的做法是在建计划时把宝贝名字写在计划名里 → 现在没办法这样做。
- **解法：使用「无界内容匹配」插件**
  - 在数据上传界面点一下「识别」
  - 插件会从每条短视频对应的视频 ID **反查到宝贝 ID**
  - 例：**31 个短视频主题**中 → 识别后会剩 **2 个未匹配** → 其余都能一一对应到具体宝贝
- 这样归类算费用时 → 系列里包含的宝贝短视频花费就能正确算进去。

### 1.3 系列划分与看板产出

| 系列 | 归属宝贝 |
|---|---|
| **耳钉系列** | 小巧耳钉 / 中等大小耳钉 / 夸张大号耳钉 |
| **耳圈系列** | 小巧耳圈 / 夸张大号耳圈（单列为耳圈系列） |

- 系列划分后 → 看板就会按系列拆分销售数据：**耳钉系列卖 31000 → 投产 14.64 → 加上短视频后投产可达 15.49**；耳圈系列呈现不同的费比与投产。
- **系列化看板的核心目的 = 做系列化核算 → 而不是逐个宝贝看数据**。

## 二、系列目标、费比红线与间接成交

### 2.1 月度目标与新品/老品的红线差异

系列核算后要给每个系列定月度目标。案例：「小巧耳钉」系列当月目标 **4 万**，参考上个月数据设定：

| 参数 | 取值 |
|---|---|
| 退款率 | 40% |
| 转化率 | 0.5% |
| 客单价 | 650 |
| 直接成交 / 间接成交 | 30% / 70% |
| 投赚 | 1:4 |
| 费比 | 25 |

- **配置好目标后，每天早上看前一天数据 → 逐日盯费比**。
- **费比超标即停投 → 不超即继续花**。例：**7 月 16 日费比 33** → 17 日早上推广同学就要控制费用 → 但还有 **15 天**可调整。
- **新品期可把费比打到 45% 超标以快速起量 → 后期再慢慢回落**。
- **老品则必须控制在费比红线内 → 否则干到月底业务完成但利润赔本**。

### 2.2 间接成交是货盘厚度的核心价值

- **间接成交是撬动系列费比空间的关键**。案例：「小巧耳钉」系列：**33 个宝贝中 17 个在花钱** → **1 万块推广费卖 4 万** → 自己买自己只占 1 万 → 其余 **3 万都是间接成交**。
- 没有这 3 万间接 → 投赚就是 **1:1** → 费比直接到 **25% 上天**；有了间接 → 投赚变成 **1:4** → 费比回落到 **25%**（原文两处均写 25%，口径存疑，需复核）。
- **单宝贝费比高不可怕 → 只要系列整体费比不超标就 OK**。例：某宝贝花了 **960** 卖 **1000** → 单品费比 **60%** → 但因为间接成交占比 **45%** → 拉低了系列整体费比；另一宝贝投赚 **6.12** → 主要是间接成交卖别人多。
- **系列核算下，单品费比高是正常现象 → 关键是整盘综合投产被拉到位**。

### 2.3 同系列间接的心智效应更强

间接成交要分两类看：

| 类型 | 含义 |
|---|---|
| **跨系列连带** | 买耳钉的顺手买手链 =「多买一件」 |
| **同系列间接** | 耳钉带动同元素的其他耳钉 → **心智关联更强 → 转化效率更高** |

- 调计划时要**优先放大同系列间接能力强的宝贝**。案例：某耳钉宝贝总共成交 **9 笔** → **7 笔是间接** → 且间接主要来自同元素耳钉。
- **这种宝贝即便单品投产看起来一般 → 也值得加预算多花**。
- **货盘系列化的精髓 = 把关联心智强的宝贝归到同一系列核算**。

## 三、宝贝层调费：运平投产与最大化花费绝对值

### 3.1 按宝贝调费用以运平投产

- 系列费比出现差异时 → 真正的杠杆动作是**按宝贝调费用 → 以运平投产**。
- 案例：某个宝贝投产高但只花了 **3000** → 另一个投产低却花了 **900**。
- **要做的不是删除低投产宝贝 → 而是把高投产宝贝从 3000 加到 4000 + 把低投产宝贝从 900 加到 2000 → 使其投产向中间靠拢**。
- **运平的目标 = 让整体花费绝对值最大化 → 而不是让单宝贝投产最优**。
- 因此需要先看懂每个宝贝的费比与投产差异 → 再决定钱该往哪个宝贝上搬 → **系列化核算的逻辑才算走通**。

### 3.2 MTD 与 DIY 双指标读法

每个计划看板都提供两套时间维度指标：

| 指标 | 口径 | 回答的问题 |
|---|---|---|
| **MTD** | Month To Day = 本月到当天累计花费 | 这个月累计花了多少 |
| **DIY** | Day In Yesterday 的简化口径 = 过去每一天的单天花费 | 每天分别花多少 |

- 两套数据原本散落在无界等后台 → 现在被横向聚合到一个系列看板里 → 让多个宝贝的计划放在一起对比 → 看出**谁花钱多、谁花钱少、谁是主力、谁是辅助**。
- **MTD 看主力 + DIY 看可加可压空间 → 两者组合才是系列化预算调整的依据**：
  - 案例：某个计划头程数据 **16.2** → 从 **8 号**开始花钱 → 累计花了不少 → 但每天只花 **50** 左右。这种日均消费偏低、知性度不足的计划，在**系列整体费比 14%、整体投产 7.26** 仍有结余的情况下 → 应该往前加钱。
  - 相反：日均已经花到 **1000 多**、知性度已经很高 → 但投产出现下滑 → 要反过来往回压。

### 3.3 优先展现权激活数的购买逻辑与费比硬约束

- 成交机会公式拆解后 → 落地动作是：**先扩匹配商品数 → 再拿费比去买优先展现权激活数**。
- **匹配商品数靠扩宝贝完成**：例：把货盘从 **6 个**扩到 **36 个** → 匹配商品数变多 → 有可能把原本 **20 万**的人群资产放大。
- **优先展现权激活数则需要用推广费去买**：只要费比还有空间 → 就持续投放 → 买到更多优先展现权激活数 → 成交机会才会随之放大。
- **费比是能否追加投放的硬约束**：系列整体费比 **14%-15%**、整体投产 **7.26** → 意味着还有投放空间 → 应当继续追加；一旦费比超过设定阈值 → 必须停投。
- 推广费占营业额的比例不只是一个观察指标 → 而是**直接决定能否继续花钱的开关**。
- **定价时若没有预留推广预算 → 后续就没钱去买曝光** → 优先展现权激活数上不来 → 数字就会持续下滑。**定价即杠杆 → 这一定律贯穿从单品到系列的全部场景**。

## 四、操盘范式迁移：从调关键词到配系统

### 4.1 框架在前，数据必须驱动动作

- 过去推广靠 SOP 和勤奋操作（调关键词 / 调人群 / 调出价）→ 今天主要靠**思考框架在前面** → 操作本身交给 AI 一定比人强 → **思考框架不对，操作毫无意义**。
- **数据分析的价值在于驱动动作**：用 AI 一分钟算出结果 → 九点零一上班就知道前一天该加谁、减谁；用 Excel 算几个小时再决策 → 黄花菜都凉了。
- **分析完纹丝不动等于没分析**。今天推广的核心竞争力：
  - **弄清系列化之后 → 知道该给哪些宝贝加预算、给哪些减预算**
  - **把整盘综合投产拉到可接受极限**
  - **最大化花费绝对值**

### 4.2 系统执行与 AI Agents 提速

- 调整对象从关键词、出价、人群变成了**宝贝**。系列化看板上每个宝贝的费用、投产、累计花费、日均花费都摆出来后 → **要做的决策就只剩一件事：谁该加钱、谁该减钱**。
- 具体执行层面的关键词调整、出价调整、人群调整都不是人工去敲的 → **而是由系统算法根据系列化指令自动跑完**。
- **这意味着今天的推广操盘精力应该放在策略层 → 而不是操作层**。
- 精力分配的下一步是用 **AI Agents** 跑系列化看板：看板本身是即时可用的工具 → 填入数据就能看出谁该加钱谁该减钱；但 AI Agents 不是即插即用 → 需要一定的搭建成本。对商家的建议：**先掌握看板的手工用法 → 把系列化梳理清楚 → 后续再逐步尝试 AI Agents 提速**。
- **从关键词精细化操作转向宝贝级系列化决策 → 因为操作主体由人工迁移到系统算法 → 这是推广操盘逻辑最显著的一次范式迁移**。

## 五、流量质量底座：打磨盘圈人与浏览次数分层

### 5.1 自定义圈人与时间窗口技巧

- 打磨盘的**自定义圈人**功能可以叠加多个标签，操作流程：
  1. 先拖入「耳环-流行视频」的**类目浏览行为**人群 → 默认是**过去三天**浏览过的人
  2. 再交集「耳环-购买」标签 → 默认是**过去三十天**购买过的人
- 这套组合可以直接看到行业大盘数据 → 但**默认时间窗口不够灵活** → 需要手动调整。例：想看 **6 月 1 日到 6 月 30 日**的浏览人群：
  - 浏览标签只允许选近三天
  - **先把标签临时改成购买**（购买标签支持自定义时间区间）→ 把时间改成 6 月 1 日到 6 月 30 日
  - **再改回浏览** → 这时选中的就是整个 6 月份的浏览人群

### 5.2 浏览次数分层与转化率阶梯

- 平台提供的浏览次数维度：**1 次、2-5 次、6-10 次、11-20 次、21-50 次、51-100 次、101 次以上**（**填 101 后留空即代表到无限次**）。
- 下表把 3.12 节的分层表与笔记附的「实际完整数据阶梯」合并（原表空缺行按完整阶梯补齐）：

| 浏览次数分层 | 访客人数（万） | 成交人数（万） | 平台转化率 |
|---|---|---|---|
| **1 次** | 1200 | 15 | **1.27%** |
| **2-5 次** | 约 1000 | - | 4.14% |
| **6-10 次** | - | - | 10.12% |
| **11-20 次** | - | - | 17.23% |
| **21-50 次** | 45 | - | 28.07% |
| **51-100 次** | - | - | 40.25% |
| **101 次以上** | 75 | - | **53.37%** |

> **口径冲突，需复核**：同一份笔记的 3.11.1 节说「21-50 次」转化率**显著拉高到 300%-400% 区间**，而 3.12 节的完整数据阶梯给的是 **28.07%**。两处并列保留，以实际后台数据为准。

- **真正想买的用户看一两次就下单是少数 → 绝大多数需要多次曝光才会转化**。
- **因为单次曝光的转化效率远低于多次曝光 → 所以「优先展现权激活数」才会成为放大成交机会的关键变量**。

### 5.3 数据背后的三层含义

| 层次 | 含义 |
|---|---|
| **流量结构** | 还有 **121 万多人看完没买** → 有可能滑到下一个浏览次数区间 → 也有可能流失到线下、京东、抖音等其他渠道 |
| **广告效率** | 广告砸出去的曝光未必都转化 → 有可能砸到一个第 1 次看的人 → 转化概率远低于多次复看的人 |
| **运营方向** | 运营动作应该向「**让用户多看几次**」倾斜 → 而不是追求单次曝光转化 → **优先展现权激活数 + 内容营销（短视频、直播）需要协同发力** |

## 六、间接成交的归属与产品线延伸（9/06 无界精英班）

### 6.1 末次点击归因

- 多次点击广告后 → **只有最后一次点击的广告计入投产**。
- **15 天内成交**投产算到点击 A；**30 天内购买**也算回（可选）。
- 这条归属规则是系列化核算的前提：间接成交能被算进投产，靠的就是末次点击归因这条链。

### 6.2 产品线延伸的两条原则与实操路径

1. **商品数量越多，间接保卫的金额越多**
2. **关键要素要一致**（日系门帘延伸不能到中式门帘）

实操路径：

1. **提炼关键购买要素**（价格、颜色、穿戴方式、吸盘方式等）
2. **围绕关键要素在延伸线上做组合**
3. **同一价格带内、围绕同一关键要素做不同款式延伸**
4. **每个链接用不同素材吸引不同人，但素材之间不能完全相同**

## 避坑指南

| # | 坑 | 破法 |
|---|---|---|
| 1 | 短视频花费挂不到宝贝头上，系列费比算不准 | 用「无界内容匹配」插件：上传界面点「识别」，从视频 ID 反查宝贝 ID |
| 2 | 看到单品费比高就删宝贝 | 只看系列整体费比；间接成交占比高时，单品费比 60% 属正常现象 |
| 3 | 老品也按新品的打法超费比 | 新品期可把费比打到 45% 超标快速起量；老品必须守在红线内，否则干到月底赔本 |
| 4 | 把钱死磕在一个宝贝上 | 集中一个宝贝 ROI 会越来越低（边际效应递减）→ 按宝贝运平投产，让整体花费绝对值最大化 |
| 5 | 看板建好了却没人动 | 分析完纹丝不动等于没分析；看板的目的就是驱动「谁该加钱、谁该减钱」 |
| 6 | 定价时没预留推广预算 | 费比是能否追加投放的硬约束；没预留预算 → 买不到曝光 → 优先展现权激活数持续下滑 |
| 7 | 追求单次曝光转化率 | 运营动作应向「让用户多看几次」倾斜；优先展现权激活数与内容营销协同发力 |
