# ch07 · 数据分析方法论与 AI 赋能

> 来源：01-智篆商业-老草-增长方法论与全域策略-完整版.md（智篆商业·老草老师讲座-增长方法论与全域策略 第 1 章 1.14、第 7、8 章）、智篆商业-老草-2026-07-29-增长方法论与全域策略-原文.md（原始听录 第 7、8 章）、老草-0906-无界精英班-笔记.md（智篆商业·老草老师讲座-无界精英班 数据关注优先级 / AI 老草系统）

本章解决「后台数据一大堆，动作还是拍脑袋」的问题：同一批报表，先看计划类型锚定了哪一批人群（找人），再看流量被谁买走（资源位），最后落到系列化核算模板（分配预算）。AI 只负责提速与给参考，**加钱减钱仍由人决定**；用数据归因 + AI 提效替代经验拍脑袋，建立可复盘的指标闭环。

## 一、计划类型决定你锚定了哪批人群

### 1.1 出价动作 = 人群样本锚点

| 出价动作 | 锚定的人群样本 |
|---|---|
| 出询单 | 询单人群 |
| 出点击 | 点击人群（**不含**收藏加购和成交） |
| 出成交 | 成交人群（会找类目熟客，因其浏览评测行为更多） |

促进成交的智能计划若做关键词限定 → 会在所有行业的词里面去找。

### 1.2 三类计划的流量与词包差异

| 计划类型 | 流量自选 | 词包方向 | 流量场域 |
|---|---|---|---|
| 关键词促成交 | 关闭/开启均可 | 行业全词 | 主要搜索 |
| 趋势明星促成交 | 固定 | 趋势词/标生词/季节标生词/社媒热点标生词 | 右侧促成交 |
| 全站推广 | 不可控词 | 不限 | 横跨搜索与推荐 |

趋势明星虽然「看起来计划一样」，区别在流量自选与词包 → 因优先匹配趋势词 / 标生词 / 季节标生词 / 社媒热点标生词而经常表现更好。

### 1.3 推荐位的价值不在成交，在关系

全站（以前的货品加速，类似万相台货品运营）横跨搜索和推荐；关键词促成交主要拿搜索、没有推荐。推荐并非只用来成交 → 更核心的是**建立人群资产关系**：用户在推荐上看到的广告建立关系后，后续搜索时系统会优先展现。**推广带来的成交未必产生于推广的资源位** —— 这一思维必须转换。

## 二、全站推荐跑飞与关键词手动分流

### 2.1 推荐跑飞后的三种调整办法

1. 把计划停掉关掉重新建 —— 获得新计划 ID 即可重启流量结构
2. 直接换关键词 —— 换词即不拿推荐
3. 想清楚为什么要从全站里出来 —— 大前提明确才能动计划

以前的货品加速容易出爆发性推荐，现在不会给爆发性推荐，但仍有大量推荐进入导致投产下降的情况。

### 2.2 双联卖锅：什么时候关闭流量自选做关键词手动投放

| 锅款 | 定价 | 投放策略 | 加词方向 |
|---|---|---|---|
| 涂层不粘锅 | 300 元 | 关键词计划 | 仅行业词 |
| 不锈钢锅 | 800+元 | 关键词计划 | 仅品牌词 |
| 不粘健康无涂层款 | 800+元 | 促成交 | 核心品牌词 |

便宜款已能干到 300 元（涂层不粘锅），贵的 800 多元（不锈钢锅、无涂层、需热锅冷油才不粘）。把全站预算分配到关键词定向分流 → **为定向分流而分，不为分而分**。

### 2.3 投产费比决定加钱还是减钱

从全站或关键词智能计划退出做手动前，先问「我要干什么」。投产高了 → 费比内还能多花（加钱）；投产低了 → 跑过量开始溢出、质量变差（减钱）。所有计划都在费比以内运转 → **超标即停、不超即加**。

## 三、套餐包优先级与资源位流量分配

### 3.1 收割计划组合：控制搜索与推荐比例

收割计划包括精准人群推广（促进成交）、行为总值人群最大化或控投产、人群资产转化做智能人群拓展最大化或控投产、超级短视频促长效转化等 —— **这些计划都不拿搜索**，可与全站或关键词计划做组合。想多推荐少搜索时，宝贝从全站退出、用这些计划替代。

### 3.2 套餐包怎么用

套餐包包含流量金卡、行业好货、打爆卡、大促冲刺人群包等。应用场景 = **强量宝贝**；弊端是**每日预算不可变**。组合用法：套餐包花了 80%，想多加一点就加关键词，想减一点就减关键词。套餐包最核心的价值 = **优先级更高**（大促抢量时跑不出来直接上套餐包）。

### 3.3 流量售卖优先级

| 流量售卖类型 | 案例 | 优先级 |
|---|---|---|
| **大单** | 买 20 万个特秀 CPM | **高** |
| **小单** | 套餐包 1 万块 | **中高** |
| **散单** | 日计划 200 元 | **低** |

大促买不到流量，核心原因不是大家都想抢，而是**池塘里的鱼被偷走了一半**：平台把大量流量卖给易搜极限、Showmax、品牌特秀等资源位售卖。日常谁也不会没事买特秀，但大促集中售卖导致整体流量池缩小 —— 这比大家都抢的影响更大。平台卖流量逻辑 = **大单→小单→散单**（套餐包作为小单，优先级比散单高）。

## 四、相似品跟投与竞品词：跟人不跟货

### 4.1 看竞品的人群资产浓度

关键词推广有相似品跟投、自定义竞品功能。以前做自定义竞品是看谁家货跟我像；更细的做法是看竞品**人群资产的人群浓度** —— 他家浓度更高则找他更好。他家货跟你一模一样看起来很准，但他家运营水平低导致进入的流量质量差 → 相似品跟投就要再勾一圈。

### 4.2 达摩盘人群浓度交叉计算

达摩盘有同行宝贝行为人群、同行店铺行为人群、同行品牌行为人群标签。圈出 A 店铺及其 A 宝贝后计算交集人群浓度（例如 **30-49 岁 L5 女性用户**：某家浓度 **10%**、另一家 **40%**），就知道跟投谁。**货一样但人未必一样** —— 跟对了人才能拿到对应的人群资产。

### 4.3 竞品词是建立人群资产关系的广告

收竞品词时用户要么看到你不点、要么点完建立人群资产关系，第二天他搜行业大词时优先展现 → 建人群资产关系即建立优先展现权。

## 五、系列化核算模板与系列看板

### 5.1 按系列而不是单宝贝归类货盘

先确定叶子类目（耳环）→ 所属系列（取简单名字如「银白纯金属中号耳圈」）→ 宝贝 ID 在哪 → 产品特征（耳圈等）→ 产品入口价格。几个宝贝共性为耳圈、纯金属色、中号时可归为同一系列 → **价格差距大的不能是一个系列**。

### 5.2 系列费比汇总成综合费比

模板填写要素：宝贝简称、8 月走、推广、总费用目标、8 月综合费比。每个系列费比不同 → 汇总后综合费比自然得出。

| 系列名称 | 宝贝数 | 7月销售 | 8月销售目标 | 费比 | 可花费用 |
|---|---|---|---|---|---|
| Test 系列 | 某万某 | 5 万 | 6 万 | 30% | 1.8 万 |
| 大系列 A | 某万某 | 6 万 | - | 25% | 1.5 万 |
| 合计 | 某万某 | 某万 | 某万 | 某% | 2.15 万 |

每天盯看板的判断链：1 号卖了多少费比多少 → 跑一个礼拜费比稳下来 **18 个点** → 说明可以加钱 → 加钱后还稳在 18 → 说明钱没花掉继续加 → 费比升到 **36** → 控制一点。这样形成日级别跟进体系。

> **口径冲突，需复核**：合计行可花费用 2.15 万 与两行之和（1.8 万 + 1.5 万 = 3.3 万）对不上；原文该表为示意值（合计列多为「某万某」）。套用时按自家费比重算。

### 5.3 看板跟进的核心是加钱减钱的精细分配

系列一起核算进看板 → 知道他们花多少钱 → **没到费比就多花，到了就空**，然后看谁多花谁少花。例如：某系列花了 **2900**、投产 **10** → 接着花；某系列投产才 **3** → 要少花；某系列花得少但元素匹配度高 → 可以先给 **500** 试试水。系列化核算的核心动作 = 加钱与减钱的精细分配。

## 六、数据体量与 AI 赋能

### 6.1 后台报表的体量风险

宝贝报表无界商品数据下载下来是 **300 兆**，单表 **72 万行**（除以 30 天每天产生 **2.4 万行**），**4 核 CPU、16G 运行内存**直接全部当机。破法：上传时按系列筛选宝贝、不必下全部；或先上传一部分核心系列验证流程 —— 本质上这些问题都可以用表格处理。

### 6.2 AI 替代的三件事

1. **替代算**：AI 一分钟出结果替代 Excel 数小时运算 → 九点上班即可获得决策依据
2. **替代调**：预算、关键词、出价、人群四大调整实际由系统算法完成 → 人应聚焦策略，推广操盘逻辑从「人工调」转变为「配系统」；弄清系列化才知道加减钱
3. **驱动动**：分析完无执行调整则分析本身毫无意义 → 分析必须落到动作

### 6.3 问答题转选择题

先把问答题变成选择题 → 让 AI 给出参考而非最终答案。以**耳环决策优先级**为例：给 AI 人设（高端流行视频消费者、**500-1000 元耳环**、女性 **30-49 岁**、天猫 **L5** 客群），让其排序决策优先级。AI 可能给出：佩戴场景和整体风格 → 轮廓与结构 → 尺寸和视觉量感 → 金属颜色 → 设计识别度 → 上脸修饰效果。

- **硬筛选与优先级要分开**：不要金色是硬筛选，颜色排第 3 是优先级
- 形态通常排第 1、尺寸量感排第 2、金属颜色排第 3（水滴型与大圈型可能有区别）
- 运营未必是自家产品的用户 → 借助 AI 消费者视角可以做改善

> **口径冲突，需复核**：上面的枚举顺序（尺寸量感第 3、金属颜色第 4）与原文另一句「形态第 1、尺寸量感第 2、金属颜色第 3」不一致，原文注明「AI 可能给出」不同排序。落地时把「硬筛选条件」与「可排序维度」分开写死。

### 6.4 AI Agent 货盘梳理：元素+类型双维度打标签

五六年前第一次做货盘梳理非常慢（Excel 表格一个一个搭 + 人工识别一个个打标签）；今天可以把这件事交给 AI Agent：让 AI 看衣服是什么颜色、看上面有没有珍珠元素、看是蕾丝还是豹纹还是刺绣、看耳环是圈还是耳钉。AI 虽然有执行度问题可能跑错，但已经从「一个一个盲改」变成「省下来只改 AI 跑错的那几个」。

打标签路径：用 skill 抓商品前端星球获取 → 搜了 **90 个页面**把所有商品找出来 → 让 AI 采集 → 按**元素**（光面 / 蕾丝 / 刺绣 / 豹纹 / 蛇纹）和**类型**（运动背心型 / 日常无痕型 / 蕾丝内衣型 / 承托聚拢型 / 抹胸型）双维度打标签 → 形成可视化结果。

某家内衣的 AI 识别结果：文胸 **41 个商品** —— 元素上蕾丝 **15 个** / 光面 **14 个** / 豹纹 **4-5 个** / 刺绣 **4 个** / 几何纹 / 蛇纹若干。

> **小众元素的投产陷阱**：蛇纹作为小众元素 → 点了的用户心智独特 → 间接成交机会就弱 → 投产容易起不来、稍微加点钱就崩。

AI 跑完还要人审一遍：某耳饰被 AI 识别为耳夹 → 其实是耳圈 → 直接用自然语言让 AI 改（「把这个分类从耳夹改成耳圈，分配到耳圈里」）→ **AI Agent 当助理的用法：你只要说自然语言，AI 就能执行修改**。每个店铺都应按这个框架梳理，按品类细分（耳钉与耳圈不可同盘 / 内衣蕾丝与豹纹不可同盘），形成可视化货盘视图，为系列化核算与人群资产运营打下基础。

### 6.5 模型选型：按任务性质选，不按名气选

- **豆包**：在大家心智中是日常陪伴角色 → 所以都用快速模型。字节模型体系在声音图像方面极强（语音击败 GPT），处理语音需要时间 → 挤出时间空间要求回答一定要快、减少推理过程、思考过程用小模型 → 因此显得「弱」。豆包也出了专家模型、办公 Pro 会更强
- **一般工作任务**：应把模型推理能力拉满
- **GPT 的 Pro 有次数限制** → 但特殊任务用最强模型

### 6.6 落地四步走（最小闭环）

1. 梳理购买决策优先级（AI 辅助）
2. 将宝贝按决策要素分类分系列
3. 统计系列货盘商品数量
4. 制定 8 月销售目标与营销费比

作业的最小闭环 = **先跑通一个最重要的系列（MVP 先跑通）**。表格只是形式 → 好看是次要 → **最重要是有用**。

## 七、数据关注优先级与 AI 老草系统

### 7.1 先看哪个指标

优先级：① **当前费比**（是否符合当前策略；爬坡期可超标换成长，热卖期控制盈利能力）② **GSV 成长情况**（关注生意榜单市场排行，看产品有没有上升）。

| 场景 | 看什么 |
|---|---|
| 有成交 | 投产 |
| 没有成交 | 收藏加购或 TA 人群浓度 |
| 不同计划带来的人有差异 | 达摩盘交集点击人群和目标人群画像 |
| 不在线上成交、只做询单 | 询单成本 |

### 7.2 AI 老草系统（https://www.ailaocao.com）

邀请制 + 用爱发电。核心流程：创建店铺 → 上传数据 → 自动取数 → 查看**店铺看板 + 系列看板**。数据来源：**生意参谋 / 无界商品 / 无界内容**。

### 7.3 同一份数据怎么读

| 心法 | 对数据动作的含义 |
|---|---|
| 免费流量是给付了费的人，并不是争取了更多免费流量；商家有更多商品，买到的流量不容易流失 | 费比之外必须同时看货盘厚度（商品数） |
| 系统会优先拿右侧的流量，右侧转化不好时才会去拿左侧；拿左侧的流量看不到投产，会去比新领域抢宽度，新领域宽度不够可能拿不到好流量 | 左侧流量看不到投产，别用投产单独评价搜索侧计划 |
| 有品牌搜索的店铺（如线下为主的纸尿裤品牌）品牌自带搜索能吃到品牌资料，但整个天猫拓展新客的能力会因费用受到限制；现在有费比的品牌拉新空间会更大，因为其他品牌都拉不动了 | 品牌搜索占比高的店，拉新空间要按费用约束单列 |
| 用户都是做多段的（住宅家具、床垫等高单价商品一定做多段），不应该追求日费比平衡，而应追求每个阶段的爆发 | 高单价品类按阶段看费比，不做日度平衡 |

## 八、从第 8 章提炼出的可复用判定表

### 8.1 指标口径速查

| 指标 | 口径 / 判据 |
|---|---|
| 费比 | 推广花费 ÷ 营业额；超标即停投，不超即持续投放；是日限额的设定依据 |
| 引潜比（引导访问潜客占比） | 判断计划属性：**≤50% 偏收割 / ≥50% 偏拉新**；越高拉新倾向越强 |
| 间接成交 | 莫茨归因默认 **15 天时间窗**内点过广告后产生的成交，无论是否点同一宝贝；已从被嗤之以鼻变为关键指标 |
| UV 价值 | 客单价 × 转化率；控投产目标设定前必须先算出宝贝的 UV 价值 |
| 人群资产加权 | 搜索排序新权重变量，占比远大于传统认知的 **1%**，可能达 **30-40%** 量级；决定同店多宝贝能否同时曝光 |
| 同店打散原则失效 | 13 年至去年执行的「一个关键词最多展示两个宝贝」逻辑已被打破，第三、第四个宝贝不再被降权 |
| 优先展现权 | 覆盖搜索 / 推荐 / 营销活动场域 / 百亿补贴 / 摆补 / 狂暑季 / 秒杀 / 白补 / 淘金币等 |

### 8.2 案例 → 判定规则

| 现象 | 判定结论 |
|---|---|
| 同一家店铺近 10 个宝贝同时获得曝光（销量六千五百 / 三千 / 五百 / 三百 / 400 参差） | 人群资产加权在起作用 |
| 拉新计划触达人群与店铺历史成交人群交集不到 **2%** | 内容营销在用户无搜索时主动拉新，质量高于货架图文 |
| 某全站计划表面投产 **5.92**，剔除间接成交后降至 **3 以内** | 全站推广并非纯收割，需用引导访问潜客占比判断属性 |

### 8.3 决策流程

1. 推广已进入全域竞争阶段 → 从单品爆款转向全店货盘竞争
2. 货盘竞争依赖人群资产底盘 → 先做人群分层与渗透拉升
3. 人群分层与货盘系列化共同驱动客单价 → 连带成交率成为核心考核指标
4. 连带率提升需稳定流量结构 → 用全站推广 + 计划组合平衡费比与投产
5. 费比与投产动态平衡依赖数据反馈 → 用数据分析 + AI 赋能替代经验决策

## 避坑指南

| # | 坑 | 破法 |
|---|---|---|
| 1 | 把推荐位只当成交位 | 推荐的核心价值是建立人群资产关系；推广带来的成交未必产生于推广的资源位 |
| 2 | 相似品跟投只看货像不像 | 看竞品人群资产的人群浓度（30-49 岁 L5 女性用户：10% vs 40%），货一样但人未必一样 |
| 3 | 推荐跑飞就随手换计划 | 先问「我要干什么」；投产高加钱、投产低减钱，超标即停、不超即加 |
| 4 | 按单宝贝核算费比 | 按系列核算并汇总综合费比；价格差距大的不能归为一个系列 |
| 5 | 一口气下载全量报表 | 无界商品数据 300 兆 / 72 万行会让 4 核 16G 直接当机；上传时按系列筛选宝贝 |
| 6 | 把 AI 当答案机 | 问答题转选择题、给 AI 人设、只取参考不取最终答案；硬筛选与优先级分开写 |
| 7 | 分析完不落到加钱减钱 | 分析完无执行调整则毫无意义；系列化核算的核心动作就是加钱减钱的精细分配 |
| 8 | 把项目专属阈值当通用规则 | 第 8 章三阶段行动清单（货盘分层≥3 层、全店连带率提升≥15%、人群资产总量 +20% 等）与 9/06 陪跑项目参数（日均可调预算 ≥ 100 元、系列去推费比达标 ≥ 95%）都是特定项目目标；只迁移「先诊断分层 → 再资产运营 → 最后跑费比×投产模型」的顺序与「先算可调空间再动预算」的逻辑，阈值按自家重设 |
| 9 | 把费比超标一律停投 | 第 8 章口径是「超标即停、不超即加」，9/06 口径是「爬坡期可超标换成长、热卖期控制盈利能力」——口径冲突，需复核：按爬坡 / 热卖 / 收尾三阶段分别定红线 |
