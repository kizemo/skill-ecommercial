## 二、计划组合怎么分工：预算配比与资金循环

### 2.1 资金循环：收割是基础，拉新是弹药

〔56 篇〕核心命题把组合逻辑收成两句话：

- **"收割是基础，拉新是弹药"**：没有收割转化，拉新带来的人群就是"空仓"；没有拉新积累资产，收割就是"涸泽而渔"
- **"边际拐点决定预算上限"**：全站推广的 ROI 不是线性增长，而是"上升→放缓→下滑"三阶段，必须用"新增产出 ÷ 目标 ROI"作判断标准，及时从"加预算"切换为"加竞品拉新"

**为什么先做收割**：收割直接"产粮"——某东阿阿胶店铺全站日均 **500 元**、ROI **4.2**，仅收割计划就贡献店铺 **60%** 成交；且成交有时效性，错过即被竞品抢走。〔56 篇〕2.1

**最实操结论**（配比数值见 2.2）：**拉新 ROI 即使 <1.5 也要坚持投放**，长期人群资产价值远高于即时亏损。〔56 篇〕核心命题

> ⚠️ **口径冲突，需复核**：ch05 4.3 的收割拉新起点配比是 **80% 收割 + 20% 拉新**，〔56 篇〕给的起点配比是 **60%-70% 收割 / 25%-30% 拉新 / 5%-10% 追投**。两个起点在本技能内并存，素材未说明二者是否同一讲义的不同版本。执行前先定自己用哪一套起点。

### 2.2 三套配比口径（原表并列）

| 配比口径 | 分配 | 出处 |
|---|---|---|
| 收割 : 拉新 : 追投 | **60%-70% : 25%-30% : 5%-10%**（长周期品类） | 〔56 篇〕核心命题 |
| 全站 : 其他收割补充 | **50%-60% : 40%-50%**（关键词 / 精准人群 / 流量金卡 / 竞对人群） | 〔55 篇〕核心收获 |
| 追投日预算占总推广 | **10%-15%** | 〔55 篇〕2.3 |

> ⚠️ **口径冲突，需复核**：追投占比 **5%-10%**（〔56 篇〕）vs **10%-15%**（〔55 篇〕）；全站占收割预算 **50%-60%**（〔55 篇〕）vs 〔56 篇〕实战案例里全站只占收割预算的 **30%**。数字对不上，按自己店铺流量结构取，不要两套混用。
>
> ⚠️ **口径冲突，需复核**：同一篇〔56 篇〕内部也不一致——"核心命题"写 **60%-70% / 25%-30% / 5%-10%**，而"七、我的判断"把四大计划类型整合成"**60-30-10**"预算分配公式（**知识库笔记作者判断，非讲座原文**）。两处数值口径不同，引用时注明取自哪一节。

### 2.3 客单价决定拉新工具组配比（300 元分水岭）

〔56 篇〕核心收获：**≥300 元中高客单**走"关键词手动 + 达摩盘"（预算 **40% + 30% + 30%**），**<300 元中低客单**走"相似品跟投 + 竞争航线"（预算 **50% + 50%**）。〔55 篇〕把 300 元客单价称为"**第一性原则**"的分水岭——它同时决定关键词匹配方式、出价高低、人群溢价幅度。

（各策略的搭建参数与后台操作详见 [[wanxiangtai-wujie]]，本章只定"钱分给哪一组"。）

### 2.4 组合案例：配比长什么样

〔56 篇〕2.6 · 霍尼韦尔除甲醛店铺（标品、客单价 **198 元**、25-35 岁 L4/L5、新房装修；推广目标 ROI **3.5+**）：

| 计划类型 | 预算占比 | 效果数据 |
|---|---|---|
| 收割-全站控投产 | **30%** | 投产 3.8 |
| 收割-行业词 | **20%** | 投产 4.2、CPC 1.6 |
| 收割-流量金卡 | **10%** | 投产 3.9 |
| 拉新-竞争航线 | **25%** | 有效人群 68% |
| 拉新-达摩盘 | **15%** | 有效人群 75% |

**组合效果**：全店 ROI **2.8→3.7**，人群资产 **+200%**，收割成交占比 **72%**，费比 **12%**。〔56 篇〕2.6

〔55 篇〕另外两组配比：

- **1500 元高端空净（标品 + 长周期）**：拉新 25% 关键词低出高溢 + 20% 竞争航线 + 收割 30% 全站控投产 + 15% 关键词品牌词 + 10% 店铺种子追投 → 全店 ROI **2.8→3.7**，人群资产 **+180%**，费比 **13%**
- **8000 元高端定制家具（非标品 + 长周期）**：30% 竞争航线 + 25% 全站控投产 + 20% 精准人群资产转化 + 15% 低浏览追投 + 10% 预流失追投 → ROI **2.5→3.2**，挽回率 **28%**，费比 **14%**

> 三组案例的合计结构（按上表各项占比直接相加）：收割 **60% / 45% / 45%**，拉新 **40% / 45% / 30%**，追投 **0% / 10% / 25%**——**没有一组把全部预算压在收割上**。

## 三、边际拐点：收割计划什么时候该加、该停

〔55 篇〕2.2 / 〔56 篇〕2.2 用"**新增产出 ÷ 目标 ROI**"判断收割计划的边际：

| 阶段 | 新增产出 | 动作 |
|---|---|---|
| **上升阶段** | ≥ 目标 ROI × 1 元 | 持续加预算 |
| **放缓阶段** | 目标 ROI × 0.6 ~ × 1 | 停止加预算，维持观察 **3-5 天** |
| **下滑阶段** | < 目标 ROI × 0.6 | 减收割预算 **30%-50%**，转移至拉新 |

**触发线**：连续 **3 天**新增投产 < 目标 ROI × 0.6，必须减预算。〔56 篇〕核心收获

**实战案例（东阿阿胶全站）**：500 元/天、ROI **4.2** → 700 元、ROI **3.9**（放缓）→ 900 元、ROI **2.8**（下滑）→ 回调 700 元 + 转移 200 元至竞争航线拉新 → 1 周后人群资产增加，收割 ROI 回升至 **3.7**。〔56 篇〕2.2

> ⚠️ **口径冲突，需复核**：止损线阈值口径不一致——
> - **ch06** §7.1：加预算前提是"边际效应未显现（新增预算 ROI ≥ **原有 ROI 的 80%**）"，且每次调整幅度不超过 **30%**
> - **〔55/56 篇〕**：判断量是"新增产出 ÷ **目标** ROI"，止损线 **< 0.6 倍**，一次减 **30%-50%**
>
> 一条比"原有 ROI"、一条比"目标 ROI"，且减预算幅度一个写 30% 上限、一个写 30%-50%，**不可互相代入**。另：〔56 篇〕"边际拐点决定预算上限"是结论句，它与 ch06 的 30% 调整铁律如何并存，素材未覆盖。

## 四、效果评估新标准：投产之外还要看什么

### 4.1 传统 ROI 的三个失真点

〔03 篇〕2.5：

- **全站推广踩踏**：大家都投全站推，ROI 拐点提前
- **归因偏差**：末次点击归因导致拉新计划投产显示为零
- **付费成交占比高**：某品类付费成交占比高达 **82.23%**——"免费流量"并未消失，而是被计入了付费成交。〔03 篇〕核心命题

### 4.2 人群浓度：拉新质量的新刻度

```
人群浓度 = TA 人群规模 ÷ 总触达人群规模
```

〔03 篇〕2.5 案例：TA 人群 **4518** ÷ 总人群 **9205** = **49.08%** 浓度。

**应用价值**：对比不同拉新计划的人群浓度，**保留高浓度计划、优化预算**，从而提高 AI 熟客规模，最终抬高收割计划的边际拐点。〔03 篇〕2.5

**可落地阈值**：立即盘点本店各拉新计划浓度，**淘汰 <20% 的**。〔03 篇〕可落地方法

### 4.3 有效人群比例：拉新计划的真相指标

〔56 篇〕2.4：

| 有效人群比例 | 判断 | 动作 |
|---|---|---|
| **≥ 60%** | 优秀 | 加预算、扩定向 |
| **40%-60%** | 良好 | 优化人群标签、调整出价溢价 |
| **< 40%** | 较差 | 暂停，重新筛选竞品 / 标签 |

**计算口径**：有效人群数 ÷ 拉新计划总人群数（导出计划人群 ID 与目标画像取交集后）；导出与交集的操作步骤见 [[wanxiangtai-wujie]]。

**案例**：除甲醛拉新总人群 **8791 人** → 交集后有效 **4810 人** → 有效比例 **54.7%**（良好）→ 剔除 L1/L2、溢价从 **80%** 提升至 **100%**，1 周后有效比例提升至 **62%**。〔56 篇〕2.4

**坚持线**：拉新 ROI 受末次点击归因影响偏低，**有效比例 ≥40% 即值得坚持**；拉新 ROI 即使 <1.5 也要投。〔56 篇〕核心命题 / 核心收获

> ⚠️ **口径冲突，需复核**：**"浓度"的定义与"要不要设绝对线"两处冲突**——
> - **〔03 篇〕人群浓度** = TA 人群规模 ÷ 总触达人群规模（衡量"触达里有多少是 TA"），给出**绝对淘汰线 <20%**
> - **〔56 篇〕有效人群比例** = 交集目标画像后的有效人数 ÷ 拉新计划总人数（衡量"有多少人符合目标画像"），给出 **≥60% 优秀 / <40% 暂停**
> - **ch06** §8 的 **TA 人群浓度** = 符合 TA 画像的精确人数占比，并明确写"**不要纠结绝对标准（'达到 60% 才算好'是错的）**"，只做同一标准下的横向比较
>
> 三套口径的分子分母各不相同，阈值**不可互换**；更要命的是"设不设绝对线"这件事，ch06 与新素材正相反。先确认自己采用哪一套，再谈阈值。

## 五、数据监控体系：单轴红绿灯 vs 两轴红绿灯

〔03 篇〕2.6 给出的是**单轴**预警：

- **数据融合**：生意参谋（GSV、退款率）+ 万相台（花费、费率）→ 综合监控（**按系列 / 品类**）
- **🟢 绿灯**：花费进度与销售进度匹配，正常推进
- **🔴 红灯**：花费超前或费率超标，存在亏损风险，需及时干预
- **阈值**：花费 / 销售比例 **>1.2** 触发红灯。〔03 篇〕可落地方法
- **监控各计划的人群激活人数**（优先展现权激活＝点击广告即建立关系）。〔03 篇〕可落地方法

**间接成交的处理原则**：A 宝贝推广带来大量 B 宝贝成交时，A 宝贝表面投产高但实际亏损 → **必须以"系列"或"品类"为单位整体分析**，避免单品误判。〔03 篇〕2.6（与 ch05 4.2、ch02 的系列化核算同向，不重复展开）

> ⚠️ **口径冲突，需复核**：**红绿灯口径**——
> - **〔03 篇〕**：单轴两色，阈值 = **花费 / 销售比例 > 1.2**
> - **ch06** §二：两轴三色（投产 × 费比），费比红 = **实际费比 > 目标费比 × 1.2**
>
> 两处都出现"1.2"，但一个是花费对销售的进度比，一个是费比对目标费比的倍数，**含义完全不同，不可互换**。本章不重复 ch06 的判定表，详见 (ch06-推广红绿灯与预算决策.md)。

> ⚠️ **口径冲突，需复核**：**费比口径与阈值**——
> - **〔56 篇〕2.5**：费比 = 推广花费 ÷ 净成交金额 × 100%，阈值写死（绿 ≤15%、红 >20%），且用在**单个计划**上
> - **ch02** §二：三个费比口径（推广费比 / 去推费比 / 系列去推费比），并明确"**商家应优先使用系列去推费比**"
> - **ch06** §二：费比红 = 实际费比 > **目标** 费比 × 1.2（阈值随店铺自定的目标费比浮动，不是固定 15%）
>
> 三处的分母层级（单计划净成交 / 系列去退费 / 店铺目标费比）与阈值来源（写死 15% / 目标费比）都不同，**不可混算**。

## 六、什么时候该建哪类计划：四把尺子与追投准入线

### 6.1 人群资产层级 → 承接计划

〔55 篇〕2.2 给出人群资产层与承接计划的对应：

| 人群资产层 | 承接计划 |
|---|---|
| **A（浏览人群）** | 关键词行业词收割 |
| **I（收藏加购）** | 全站控投产 + 关键词品牌词 |
| **P（购买人群）** | 精准人群老客复购 + 流量金卡 |
| **L（复购人群）** | 自定义老客 + 人群超市 |

### 6.2 四把尺子（决定建哪类计划）

〔55 篇〕2.4 用四把尺子做最终分流（参数级搭建见 [[wanxiangtai-wujie]]）：

| 尺子 | 分档 | 计划取向 |
|---|---|---|
| **客单价** | ≥300 元 / <300 元（分水岭见第二节） | ≥300：手动低出高溢 + 竞争航线 + 全站控投产 + 关键词品牌词 + 老客复购；<300：智能控点击成本 + 相似品跟投 + 全站最大化 + 行业词 + 流量金卡 |
| **转化周期** | ≤7 天 / >15 天 | ≤7 天**不建追投**；>15 天**三类追投全上** |
| **人群类型** | 本店人群 / 竞对人群 | 本店人群 → 关键词手动 + 精准人群 + 全站 + 老客复购 + 人群超市核心；竞对人群 → 竞争航线 + 相似品跟投 + 竞品品牌词 |
| **品类** | 标品 / 非标品 | 标品：关键词 + 全站 + 流量金卡，聚焦搜索端；非标品：智能控成本 + 竞争航线 + 全站多目标 + 人群资产转化 + 人群超市，覆盖搜推双场域 |

**竞品三要素**（拉新的前提）：规模 ≥5 万 + 浓度 ≥30% + 未渗透率 ≥60%；**规模 ≥10 万的竞品单独建计划，3-5 万的竞品组合建计划**。〔55 篇〕2.1

### 6.3 追投的准入线（什么时候才该建）

〔55 篇〕2.3 + 核心收获：

- **只服务转化周期 >15 天的品类**（高端家电、定制家具、高客单价滋补品）
- **转化周期 ≤7 天的品类（零食、日用品）做追投是浪费**
- **>15 天不做追投会流失人群——20%-30% 的人群会在 15 天后流失**
- 三类：种子人群追投 / 低浏览人群激活（提升浏览频次至 3 次+）/ 预流失人群挽回（定向浏览 ≥2 次 + 15 天未访，挽回率 25%）
- 监控指标：**浏览频次提升率 + 挽回率 + 30 天转化率**；日预算占总推广 **10%-15%**，出价高于行业均值 **20%-30%**

### 6.4 三段式矩阵：拉新 → 追投 → 收割

〔03 篇〕把单计划思维换成矩阵思维：**拉新（关键词 + 人群）→ 追投（智能 + 达摩盘）→ 收割（全站 + 智能）**——"**不是单一计划，是计划矩阵协同**"。〔03 篇〕核心收获 / 可落地方法

提高收割拐点的三条路径：① 调整商品架构（矩阵化）；② 从 O 熟客中找流量（挖竞品）；③ 搭建拉新-追投-收割的投放矩阵。〔03 篇〕2.5

### 6.5 落地优先级（知识库笔记作者判断，非讲座原文）

以下三段均为三篇笔记"**七、我的判断**"一节的内容，属**知识库笔记作者的落地排序建议，不是讲座原话**，仅供排期参考：

- **〔03 篇〕**：P0 立即应用 —— ① 建立"人群浓度"指标；② 核心标品做场景裂变（40+ 链接思路）。P1 月度运营 —— ③ 拉新-追投-收割三段式计划；④ 按系列 / 品类核算投产。
- **〔55 篇〕**：先把"竞品三要素洞察"和"客单价分层"跑通，再用"边际拐点判断"做日常监控。
- **〔56 篇〕**：先把"红绿灯看板 + Excel 融合表"做出来让日常监控可视化，再逐步优化"竞品三要素 + 有效人群比例"；并提示医疗器械类目的费比红线需从 15% 上调到 20%、投产拐点反应要更灵敏（该提示针对医疗器械类目，通用类目不适用）。
