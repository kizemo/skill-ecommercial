# ch04 · 人群资产分层与四象限投放

> 来源：智篆商业·老草老师·2026-07-29·增长方法论与全域策略·完整版（智篆商业·老草老师讲座-第 4 章 人群资产分层与渗透 + 第 5 章 拉新与心智加深策略）；老草 · 2026-09-06 无界精英班 · 笔记摘要（智篆商业·老草老师讲座-TA 人群指标 / 达摩盘人群分层 / 收割拉新判断）

本章解决一个问题：**这笔钱该打给谁**。先验证计划触达的人群本身有没有商业价值，再按行为确定性把人分成类目新客与类目熟客，最后落到「来过/没来过 × 新客/熟客」四象限与引潜比上决定加钱、减钱还是调拨。

---

## 一、流量质量先验证：反向验证法

### 1.1 反向验证流量池商业价值

- 不同推广计划触达的人群存在本质差异 → **评估计划流量质量不能只看表面投产数据** → 而需用**反向验证法**判断流量池本身的商业价值：
  1. 用达摩盘「万相台无界版回流再营销」标签圈出计划触达人群（如某计划看过的人 **1600 人**）
  2. 交集「类目成交行为人群」标签 → 看这部分人在类目的购买比例
- 判断示例：**A 计划触达人群中有 60% 在淘宝任何店铺产生过购买 → B 计划只有 10%** → 则 B 计划流量质量天然偏差（这 10% 的人中很多天生在整个淘宝谁家都不买 → 商业价值天然偏低）。
- 行业实践：**促进成交的计划与全站推广通常投产相对较好**；**关键词标准计划、手动计划投产经常偏差 → 本质原因就在流量池差异**。

### 1.2 素材与客群错位的反证案例

- 案例：某店铺做**卫生巾拉新计划**，用同一方法圈出计划人群 → 交集类目成交行为中**过去一年在卫生巾品类消费过的人** → 结果**不到 2%**。
- 意味着 **98% 的人群对该店铺没有意义** → **反向证明计划素材吸引的人与目标客群严重错位**。

## 二、人群资产二分类：类目新客与类目熟客

### 2.1 按行为确定性划分

- 人群资产可按行为深度分为**类目新客**与**类目熟客**两类，核心区分标准是**行为确定性的强弱** → 确定性越强的人群转化效率越高。
- 耳环类目 6 月数据案例：整个 6 月份在淘宝**看过耳环的人共 3500 万** → 其中 **1000 万是浏览 6 次以上**的（更熟）→ **500 万是把某家宝贝加入购物车**的（更熟）→ 用**并集逻辑（满足其一即可）**→ 这 **1300 万人**定义为**类目熟客**；剩余人群为**类目新客**（需求尚未充分激活）。

| 人群 | 访客 | 购买 | 转化率 |
|---|---|---|---|
| **类目新客** | 22,311,915 | 394,491 | **1.77%** |
| **类目熟客** | 13,049,754 | 2,816,123 | **21.58%** |

> **口径冲突，需复核**：转化率差值，完整版写「**差约 12 倍（差近 20 倍）**」，原始听录版写「**差近 20 倍**」。两处并列保留。

- **做计划时应优先找确定性强的熟客人群 → 不同计划打不同人 → 这就是计划间流量分层的本质**。

### 2.2 高转化计划都打在熟客池

- **行业好货打包卡有时转化率能上 40% 但点击成本很高** → 正是因其**专门找好的池子**（类目已看多次、已加购某家宝贝的人）。
- **全站、关键词出成交、流量金卡等计划也是同一逻辑**。

## 三、筛选目标客群与店铺渗透率

### 3.1 消费力、性别、年龄三维筛选

- 做目标客群画像需先从类目大盘筛选出对店铺有意义的潜在人群 → 再计算店铺实际渗透率 → **只有精准筛选后的人群规模才能反映真实增长空间**。
- **筛选维度**（每个维度都要同时看**转化效率**与**人群规模**）：**消费力（L1-L6）/ 性别 / 年龄 / 城市级别**。
- 某耳环店铺案例演示流程：**3000 万最近 30 天看过耳环的人**中 → 去掉最近一个月买过耳环的人（**约 200 万**）→ 剩余 **3000 万**属于「看了还没买，有真实商品需求」的待渗透人群。

| 维度 | 关键数据 | 结论 |
|---|---|---|
| **消费力** | **L5 占比 83.27%** 是核心；**L4 仅占 36.07%**、转化率差**四倍**、占销售仅 **10%**，两者整体差距约 **8 倍** | 该店铺定位决定主力是 **L5** |
| **性别** | 男性虽转化效率高 → 但仅占 **5%**（浏览 **4.78%** / 购买 **5.83%**）；女性占 **94% / 93.51%** | 商业化考虑效率 → 主力是**女性** |
| **年龄** | **18-24 岁**转化低、**50 岁以上**转化也低；**30-49 岁**三层占比合计超 **80%**（浏览 **83.9%** / 购买 **65%**） | **30-49 岁**是最合适的年龄段 |

### 3.2 核心人群与「直接多花钱」的新逻辑

- 筛掉不符合条件的人后 → 这 **274 万人**才是应该渗透的**核心人群**。
- 把这 274 万**交集店铺浏览行为** → 即可计算出**店铺渗透率**。
- **要提高渗透率**：
  - **过去的逻辑** = 打爆款让免费流量爆发
  - **现在的逻辑** = **直接多花钱**
- **推货盘的目的是把每一毛钱都花掉** → 持续向目标人群投放。

## 四、素材决定人群浓度

### 4.1 浓度测算

- 同一货盘下的不同宝贝 → 因**组图样式与定价不同** → 会吸引不同的消费者点击 → **不同宝贝带来的人群浓度存在显著差异** → 这一差异**直接决定推广的投入产出比**。
- **素材的重要性在于它吸引来什么样的人 → 而非追求绝对的点击率**。
- 测算案例：货盘有**八个宝贝**都去推 → 每个宝贝都点了 **2000 个点击** → 用万相台无界版回流再营销分别圈出每个宝贝的 2000 个点击 → 交集「**女性用户 30-49 岁 L5**」标签。
- 若某宝贝 2000 个点击里有 **400 人**符合条件 → **人群浓度就是 20%**。**八个宝贝去打时 → 浓度必然有所差异**。

### 4.2 浓度与 ROI 的动态平衡

- **浓度越高 → 推广花费的存在空间越大 → 最终 ROI 也越高**。
- **但 ROI 过高时多花钱浓度就会降低 → 因此 ROI 不是用来追求极限高的，过高的 ROI 反而有问题**。
- 素材引来的人与目标人群匹配的浓度越高就越精准 → 精准度高最终的 ROI 才可能越高。

## 五、四象限与投放顺序

### 5.1 按加购与画像划分熟客新客

- 类目耳环浏览人群中：浏览超过 **6 次以上**的有 **110 万人**（总浏览人群 **270 万人**）→ 把至少**加购一次**的合并进来合计 **120 万人** → 这部分构成「**类目熟客**」→ 其余 **140 多万**看了没买但符合目标客群画像的属于「**类目新客**」。
- 如果交集条件改为「**看过但未加购**」→ 得到的就是类目新客。
- 两类人群质量不同 → 分别用不同的计划去打：
  - **关键词手动出价偏左侧（新客）→ 投产较差**
  - **自动出价偏右侧（熟客）→ 投产较好**
- 这与传统认知「手动才是高手、开自动就是技术不行」**完全相反**。

### 5.2 TA 人群总量与成交心智分层

- 耳环类目 **TA 人群总量 274.4 万人** → 过去 30 天**看过本店一次以上**的有 **5.8 万人**（**AI 人群 = 访问兴趣客**）→ **未看过本店**的有 **268.5 万人**（**O 人群 = 未访问兴趣客**）。
- 在 274 万类目 TA 人群中按**成交心智**分层：**类目新客 152.9 万**（刚开始逛，成交概率偏低）/ **类目熟客 121.4 万**（虽同样为 L5，但成交概率更高）。
- **两类人群应先用熟客计划、再用新客计划**。

### 5.3 四象限与转化差异

| 人群象限 | 规模 | 标签含义 |
|---|---|---|
| **AI 熟客** | 4.2 万 | 既访问过本店，又是类目熟客 |
| **O 熟客** | 117.2 万 | 类目熟客但未访问过本店 |
| **O 新客** | 151.3 万 | 类目新客且未访问过本店 |
| **AI 新客** | 1.5 万 | 访问过本店但是类目新客 |

- 广告投放**不可能 100% 命中 L5，会有溢出**：浓度是百分比的概念。
- **转化最好的是 1 区（AI 熟客）→ 其次是 2 区（O 熟客）**；**O 熟客流量比类目新客成交概率高约 20 倍**。
- **AI 熟客虽来过本店仍需继续投放**：只要预算还有就多花 → **货盘越厚 → 留在本店购买的概率越高** → 人群资产多的货盘上新时应继续补货、加深关系。

## 六、人群资产时效性与收割拉新流转

### 6.1 优先展现权的时序衰减

- **人群资产关系并非永久存在 → 会随时间递减**。三天前看过本店、昨天看过竞店的消费者 → 今天再来时**优先展现权更近的店铺**；几天没看过的店铺展现会慢慢消失。
- **优先展现权的时序：时间越近权重越高**。
- **AI 熟客仍需预算投放 → 想多花也花不掉**：刚看过本店的消费者满眼都是你 → 看到的广告少、自然搜索坑位多 → **点击任何一个自然搜索免费坑位都会更新时间序列**；已经**六天没来过**的消费者免费坑位变少 → 但广告还在 → **所以必须持续投放维持关系**。

### 6.2 左右两侧流转路径

| 路径 | 流转链路 | 结果 |
|---|---|---|
| **右侧路径（收割）** | 触达 → 类目中的 **AI 熟客** → 更新人群资产持续 → 让你权重变成最高（五天前看过的与昨天看的权重不同） | 买家眼里都是你 → 成交概率高 → **费比不升高 → 多花钱的空间扩大** |
| **左侧路径（原文标注为「右侧拉新」）** | 类目熟客点完了没有 → 又拉新 → 触达 → 类目中的 **O 熟客** → 建立人群资产关系 → 获得优先展现权 | 与「**左侧拉新**」（类目新客里拉新）路径完全不同 |

> **口径冲突，需复核**：7/29 讲稿把 AI 熟客收割称为「右侧」、O 熟客路径同时被称作「左侧路径」与「右侧拉新」；9/06 笔记摘要则把 **AI 人群叫左侧**、**O 人群叫右侧**。左右标签的所指在不同笔记里不一致，执行前先确认口径。

### 6.3 引潜比判断计划属性

- 判断计划属性靠「**引导访问潜客占比**」（俗称「**引潜比**」）：**1000 个人中引潜比 80% → 80% 是第一次进店、20% 是老客回访**。

| 引潜比 | 计划属性 | 主要流量人群 |
|---|---|---|
| **20%** | AI 收割（全站） | AI 熟客 |
| **60%** | O 熟客拉新 | 类目 O 熟客 |
| **85%** | 新客拉新 | O 新客 |

- **看引潜比高低决定增减投放金额 → 引潜比太高就减费用降低比例**。
- **收割计划不会一直只收割**：**42000 的 AI 熟客**不会每分每秒都开着手机淘宝 → 加钱后流量溢出到 O 熟客甚至类目新客 → **引导访问潜客占比提高、投产降低 → 开始拉新**。
- **典型计划分类**：
  - **偏右侧拉新**：全站、关键词促进成交、人群资产转化、套餐包行业好货打包卡 → 引潜比偏高
  - **偏左侧拉新**：关键词促进点击、关键词手动出价 → 引潜比偏低（**投产天生差一档**）
- 投着投着可能**从 L5 溢出到 L4** 甚至没来过本店的 L5、L4 → **引导访问潜客占比变高、人群浓度变低、ROI 变差** → 但**点击单价不变差 → 因为右侧流量就是贵**。
- 9/06 笔记摘要给出另一套引潜比读法：**占比 30% 几 = 拉新型 / 占比 90% 多 = 收割型 / 占比 3% = 专门看收割、不拉新**。
  > **口径冲突，需复核**：两套读法的方向几乎相反（7/29 用 20%/60%/85% 判定 AI 收割→O 熟客拉新→新客拉新；9/06 用 3%/30% 几/90% 多判定收割与拉新）。以自己后台的实际数值与计划属性对照后再用。
- **最大陷阱**：绝大多数商家**只看左边的数（投产），不看右边的数（引潜比）** → 投入越多，流量质量越差。
- **收割拉新切换判断**：原来 **80% 收割 + 20% 拉新**、生意规模 **1-2 万**时——减少收割增加拉新后生意规模**增长** → **对的**；规模**下降** → 产品本身成交能力不强，容易被别人收割。
- **全店推广收割的实操要点**：做精准的人群推广做收割 → 在消费者还没有搜索的时候主动建立人群资产关系 → 消费者搜索相应关键词时，因为人群资产关系的时间序列更新，展现时就会优先；**最大化拿量必须控制预算上限**（想收割 500 还是 800 还是 1000），最大化拿量有可能价格特别高，有些其实可以不拿到。

## 七、收割与拉新的钱往哪花

### 7.1 加钱、停投与调拨系列

- 当一个计划花到**投产 1:2、费比还剩 10 个点（花了 15%、目标 25%）**时 → 能否继续花是核心决策。逻辑上应当继续花 → 但有三种花法：

| 花钱选择 | 适用条件 | 关键动作 |
|---|---|---|
| **第一种：继续加钱** | 系列内仍有投产可观的宝贝 | 比较**哪个宝贝投产还行就给哪个宝贝花** → 不再死磕一个宝贝（每个宝贝入口素材不同，去的人有差异；标品拆链接卖点不同）→ **集中一个宝贝 ROI 会越来越低（边际效应递减）→ 这是费比逻辑下必然的策略转向** |
| **第二种：不花 / 调拨** | 各个宝贝投产都很差 | 可以选择不花（利润率立刻提高，但**护城河一定会变窄**）→ 也可以**把这个系列的钱调拨给另一个系列** |
| **第三种：内容营销** | 需要主动拉新或加深心智 | **超级短视频**解决两个问题：① 通过内容在用户没有搜索时**主动拉新**（相比货架图文拉新质量更高）② 对已来过本店的人群资产进行**心智加深**（提升转化率）。**信息维度递进：文字 < 图片 < 短视频 < 直播 < 线下体验** |

### 7.2 不花钱会丢权重——预算必须预留

- 花了这笔钱如果让消费者眼里都是你最终成交 → 本质上是**给费比争取了更多空间** → **所以这笔钱不能不花**。
- 只要建了**权重计划、套餐包、关键词出成交、人群资产转化**这类优先打 AI 的计划 → **平台都会收一次钱**（即使该流量你已花过钱）→ **别人花你不花 → 权重就丢了**。
- 要让「花钱再进来的人」进得来 → **定价上必须预留推广预算** → 否则后面没钱买曝光、数字下降。
- **现在没有费比的店铺干不下去 → 费比比别人低也很难受**。

## 八、TA 人群三大指标与达摩盘分层（9/06 无界精英班）

### 8.1 TA 规模、TA 浓度、渗透率

| 指标 | 公式 | 含义 |
|---|---|---|
| **TA 规模** | 符合 TA 画像的消费者基数 | 推广对象可触达的市场天花板 |
| **TA 浓度** | TA 规模 ÷ 店铺总浏览人群 | 流量精准度 |
| **渗透率** | 已建立资产人群 ÷ TA 规模 | 已被渗透程度 |

- **选择原则**：**TA 规模越大 + TA 浓度越高 + 未渗透率越高（渗透率越低）的竞品，作为定向目标的拉新能力越强**。
- 案例：「张胖胖一口苏打」店铺 **190 万**浏览 → **72.5 万** TA → 浓度 **38%** → **27.5 万**来过本店 → 渗透率 **37.9%**。

### 8.2 达摩盘三级颗粒度与人群分层

| 颗粒度 | 适用场景 |
|---|---|
| **店铺级** | 全店商品围绕同一类人群 |
| **店铺类目级** | 不同品类产品差异大（如飞利浦男士理容 vs 美容护肤） |
| **店铺宝贝级** | 同类目下不同产品类型 |

| 人群状态（猫零食罐案例） | 规模 | 说明 |
|---|---|---|
| **类目浏览人群** | 8,043,690 | 最近浏览过类目 |
| **浏览未购人群** | 7,021,063 | 浏览过但还没购买 |
| **浏览未购 TA 人群** | 1,152,770 | 符合 TA 画像的消费者 |
| **已渗透人群** | 63,342 | 浏览过品类 + 符合 TA 画像 + 未购买正装 + 已是店铺人群资产 |
| **未渗透人群** | 1,089,445 | 渗透目标 |
| **类目新客人群** | 810,070 | 浏览次数少且从未加购；购买意向还不确定 |
| **类目熟客人群** | 342,708 | 浏览多次或加入购物车；购买意向相对更高 |

- **突破 30 天限制技巧**：把时间类型改为**购买** → 选年月日区间 → 选好后**改回浏览** → 时间区间保持不变 → 圈到 **90 天**浏览行为人群。

## 避坑指南

| # | 坑 | 破法 |
|---|---|---|
| 1 | 只看投产就判断计划好坏 | 用反向验证法：达摩盘回流再营销标签圈人群 → 交集类目成交行为，看购买比例 |
| 2 | 素材吸引错人却以为流量差 | 交集过去一年在该品类消费过的人占比极低（如卫生巾案例不到 2%）→ 反证素材与客群错位，先换素材 |
| 3 | 不区分新客熟客，所有计划打同一批人 | 按行为确定性分：浏览 6 次以上或已加购 = 类目熟客；先用熟客计划再用新客计划 |
| 4 | 追求绝对点击率 | 素材的价值在于带来什么样的人 → 用「人群浓度」（如 400/2000 = 20%）衡量 |
| 5 | 只看 ROI 不看浓度 | ROI 过高时多花钱浓度会下降 → ROI 不是用来追求极限高的 |
| 6 | 只看左边投产、不看右边引潜比 | 引潜比 = 引导访问潜客占比；太高就减费用降低比例 |
| 7 | 以为不花钱就省钱 | 权重计划、套餐包、关键词出成交、人群资产转化这类优先打 AI 的计划，平台都会收一次钱 → 别人花你不花，权重就丢了 |
| 8 | 把钱全压在一个宝贝或一个计划 | 集中一个宝贝 ROI 越来越低（边际效应递减）→ 运平投产，或把钱调拨给另一个系列 |
| 9 | 定价不留推广预算 | 费比是能否追加投放的硬约束；没预留预算就买不到曝光，优先展现权激活数会持续下滑 |
