# cheatsheet · 全域增长操盘速查

> 一页纸决策表。数字全部来自知识库原文快照（2026 上半年口径），**落地前核对当期平台公告**。

---

## 一、每天开工先回答三问

| 问题 | 去哪看 |
|---|---|
| 一笔追加预算，**加给谁**？ | 红绿灯双绿单品（ROI 最高的 3-5 个）→ 加 20%-30% |
| 老链接投产下滑，**继续观察 / 降预算 / 停掉**？ | 投产红 + 费比绿 → 观察；双红 → 减 50%-80% 或停 |
| 一批新链接各 500 元日预算，三天后**留哪些**？ | 赛马：相同花费比费比 → 黑马；相同费比比规模 → 潜力更大 |

## 二、红绿灯速查

| 指标 | 🟢 | 🟡 | 🔴 |
|---|---|---|---|
| **投产** | ≥ 目标 ROI | ≥ 目标 × 0.8 | < 目标 × 0.8 |
| **费比** | ≤ 目标 | ≤ 目标 × 1.2 | > 目标 × 1.2 |

| 场景 | 动作 | 幅度 |
|---|---|---|
| 双绿 | 加预算 | 单品 +20%~30%，系列 ≤30% |
| 投产绿 + 费比红 | 查退款率/间接占比；优化为主 | 单品 −30%~50% |
| 投产红 + 费比绿 | 观察优化，必要时加收割预算 | 不增不减 |
| 双红 | 减预算或暂停，1-2 周后小预算测试 | −50%~80% |

**加预算三前提**：双绿且连续 **3 天**稳定｜新增预算 ROI ≥ 原有 **80%**｜TA 未渗透率 ≥ **50%**
**减预算三前提**：双红灯或连续 **3 天**黄灯无改善｜退款率持续 **>30%**｜间接成交占比 **>70%** 且系列费比红
**观望触发**：日预算 < **500 元** 或 推广天数 < **7 天** → 监控 7-10 天
**铁律**：每次调整幅度 **≤ 30%**

## 三、费比速查

| 口径 | 公式 | 用途 |
|---|---|---|
| 推广费比 | 推广花费 ÷ 成交金额 | 不含退款，会低估成本 |
| 去退费比 | 推广花费 ÷（成交金额 − 退款金额） | 剔退款 |
| **系列去推费比** | (A+B+C 花费) ÷ [(A+B+C 成交) − (A+B+C 退款)] | **优先用这个** |

| 状态 | 含义 | 动作 |
|---|---|---|
| 没超 | 还能花 | **敢花** |
| 超了 | 生意干赔 | 立刻收手 |
| 没花掉 | 白丢机会 | **把剩余额度花出去** |

**阶段决定容忍度**：爬坡期可超标换成长｜热卖期超标过多追不回来｜收尾期控制到目标范围

## 四、公式卡

```
成交机会   = F × (优先展现权激活数 × 曝光场域数 × 匹配商品数)
成交规模   = F × (人群资产流转效率 × 人群资产规模 × TA 人群浓度)
UV 价值    = 客单价 × 转化率
点击单价上限 = UV 价值 ÷ 控投产目标
费比       = 推广花费 ÷ 营业额
每日可增加花费 = (过去 N 天日均花费 ÷ 当前去退费比) × 去退费比 Gap
累计 Gap   = 历史可支配推广花费 ÷ N 天
合计调整   = 每日可增加花费 + 累计 Gap
```

**Gap 实算样例**：241,465 × 0.42% = 1,014.15 ｜ 日均 44,865÷6 = 7,477.5 ｜ 7,477.5 ÷ 18.52% × 0.42% = 169.58 ｜ 累计 1,014.15÷24 = 42.26 ｜ **合计 211.84**

## 六、诊断决策树

```
费比高？
├─ ROI 也高？
│  ├─ 间接成交占比高 → 引流先锋官 → 绿灯，不是红灯
│  │    → 打包进系列看板；系列费比健康就不能砍，酌情加钱
│  └─ 间接占比不高 → 退款率假象（推广成交金额是毛的）
│       → 跳生意参谋退款分析模块查主因，对症下药
└─ ROI 也低 → 回炉重造
     → 停计划 → 分析同行素材 → AI 重做场景人群与视觉
     → 确认是产品力问题就果断放弃
```

```
左侧拉新 ROI 接近零？
├─ 达摩盘第一步：类目后链路成交占比（交集 ÷ 人群总数）
│    样例 A 2062/5800 = 35.5%  vs  B 511/4300 = 11.8% → A 质量是 B 三倍
└─ 达摩盘第二步：TA 人群浓度（交集目标客群画像）
     样例 A 52% vs B 40%
     ⚠️ 不设绝对标准，只在同一严苛标准下横向比
```

## 七、左右两侧速查

| 维度 | 左侧 AI 人群 | 右侧 O 人群 |
|---|---|---|
| 含义 | 系统侧已建立人群资产关系 | 系统外新流量 |
| 关键观察 | **TA 浓度** | 引潜比 / 投产 |
| 触达方式 | 搜索 + 推荐 | 推荐 + 关键词手动 |
| 心法 | 左侧看浓度不看投产 | 系统优先拿右侧，右侧不行才拿左侧 |

**四象限投放顺序**：AI 熟客 → O 熟客（转化比类目新客高约 20 倍）→ O 新客 → AI 新客
**口诀**：先熟客后新客 → 右侧收割 → 右侧拉新 → 左侧拉新

**TA 三大指标**：TA 规模（天花板）｜TA 浓度 = TA 规模 ÷ 店铺总浏览人群｜渗透率 = 已建立资产人群 ÷ TA 规模

## 八、心智匹配度速查

| 品类 | 核心决策要素 |
|---|---|
| 羽毛球服 | 颜色 + 领型 |
| 耳饰 | 尺寸 / 风格 / 元素 |
| 内衣 | 功能 / 杯型 / 颜色 / 元素（三重维度） |
| 家纺 | 花型 / 颜色 / 风格 |

**三大反例**：母婴推车（高景观 vs Air 月龄诉求不同）｜羽毛球服饰（圆领 vs V 领）｜耳环（大耳圈 vs 耳钉）
**标品 vs 非标品**：非标品靠厚度撑间接成交｜标品有货盘继续做、没有就分裂场景
**货盘厚度 = 有效宝贝数量 × 心智匹配度**（不是 SKU 总数）

## 九、避坑速查

| # | 坑 | 一句话破法 |
|---|---|---|
| 1 | 单链接费比高就砍引流款 | 看间接成交占比，占比高是绿灯不是红灯 |
| 2 | 只看推广 ROI | 成交金额是毛的，必须剔退款 |
| 3 | 同一张红绿灯用到底 | 新品 GSV 优先，成熟爆款费比优先 |
| 4 | 设绝对 TA 浓度标准 | 永远自己跟自己比 |
| 5 | 左侧拉新只看 ROI | 用达摩盘两步验证 |
| 6 | 没有壁垒还猛做左侧 | 白牌/标品预算压右侧收割 |
| 7 | 费比没花完就收手 | 没超就该花出去 |
| 8 | 无界数据两次下载直接比 | 存在归因漂移 |
| 9 | 预算调整幅度失控 | 每次 ≤30% |
| 10 | 心智错位的宝贝放同一盘 | 按品类核心决策要素拆盘 |

## 十、数据下载与核对

| 来源 | 路径 | 关键动作 |
|---|---|---|
| 生意参谋 | 商品 → 商品排行 → 「日」维度 → 指标选择(5/30) → 下载 | 每天花一分钟 |
| 万相台无界商品 | 报表 → 商品报表 → 过去 15 天 → 时间粒度分天 → 报表模板全部计划 | **必须勾「商品+计划+时间」三项** |
| 达摩盘 | 我的人群 → 自定义圈人 → "万象台无界版回流再营销"标签 | 勾选所有场景 + 自定义计划筛 ID |

**核对**：以生意参谋的宝贝 ID 为准统一无界数据；按"系列"汇总避免跨系列重复计算；核对总成交与总推广花费与模板汇总一致。
