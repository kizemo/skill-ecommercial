## 二、红绿灯速查

| 指标 | 🟢 | 🟡 | 🔴 |
|---|---|---|---|
| **投产** | ≥ 目标 ROI | ≥ 目标 × 0.8 | < 目标 × 0.8 |
| **费比** | ≤ 目标 | ≤ 目标 × 1.2 | > 目标 × 1.2 |

| 场景 | 动作 | 幅度 |
|---|---|---|
| 双绿 | 加预算 | 单品 +20%~30%，系列 ≤30% |
| 投产绿 + 费比红 | 查退款率/间接占比；优化为主 | 单品 −30%~50% |
| 投产红 + 费比绿 | 观察优化，必要时加收割预算 | 不增不减 |
| 双红 | 减预算或暂停，1-2 周后小预算测试 | −50%~80% |

**加预算三前提**：双绿且连续 **3 天**稳定｜新增预算 ROI ≥ 原有 **80%**｜TA 未渗透率 ≥ **50%**
**减预算三前提**：双红灯或连续 **3 天**黄灯无改善｜退款率持续 **>30%**｜间接成交占比 **>70%** 且系列费比红
**观望触发**：日预算 < **500 元** 或 推广天数 < **7 天** → 监控 7-10 天
**铁律**：每次调整幅度 **≤ 30%**

### 2.3 目标从哪来：双轨取严（ch09）

| 轨道 | 目标投产比 | 目标去退费比 |
|---|---|---|
| A 利润约束（底线） | `1 ÷ [毛利率 × (1 − 退款率)]` | `(毛利率 − 运营成本率) ÷ (1 − 退款率)` |
| B 历史基线（可达） | 上期实际投产比 | 上期实际去退费比 |
| **取严** | **max(A, B)** | **min(A, B)** |

目标链：目标 GSV（净）= 上期 GSV｜目标 GMV（毛）= 上期 GSV ÷ (1 − 上期退款率)｜目标推广花费 = 目标 GSV（净）× 目标去退费比｜目标流量 = 目标 GMV ÷ (上期客单价 × 上期转化率)｜目标进度 = 目标值 ÷ 周期天数 × 已过天数

> ⚠️ **毛净不能混**：费比分母是 GSV，目标花费必须用**净** GSV 乘费比。
> ⚠️ 投产比下限取 [[profit-model]] 更严版；去退费比上限由利润公式推导，**原文没这个公式**。

## 三、费比速查

| 口径 | 公式 | 用途 |
|---|---|---|
| 推广费比 | 推广花费 ÷ 成交金额 | 不含退款，会低估成本 |
| 去退费比 | 推广花费 ÷（成交金额 − 退款金额） | 剔退款 |
| **系列去推费比** | (A+B+C 花费) ÷ [(A+B+C 成交) − (A+B+C 退款)] | **优先用这个** |

| 状态 | 含义 | 动作 |
|---|---|---|
| 没超 | 还能花 | **敢花** |
| 超了 | 生意干赔 | 立刻收手 |
| 没花掉 | 白丢机会 | **把剩余额度花出去** |

**阶段决定容忍度**：爬坡期可超标换成长｜热卖期超标过多追不回来｜收尾期控制到目标范围

## 四、公式卡

```
成交机会   = F × (优先展现权激活数 × 曝光场域数 × 匹配商品数)
成交规模   = F × (人群资产流转效率 × 人群资产规模 × TA 人群浓度)
UV 价值    = 客单价 × 转化率
点击单价上限 = UV 价值 ÷ 控投产目标
费比       = 推广花费 ÷ 营业额
每日可增加花费 = (过去 N 天日均花费 ÷ 当前去退费比) × 去退费比 Gap
累计 Gap   = 历史可支配推广花费 ÷ N 天
合计调整   = 每日可增加花费 + 累计 Gap
```

**Gap 实算样例**：241,465 × 0.42% = 1,014.15 ｜ 日均 44,865÷6 = 7,477.5 ｜ 7,477.5 ÷ 18.52% × 0.42% = 169.58 ｜ 累计 1,014.15÷24 = 42.26 ｜ **合计 211.84**

## 六、计划分工与预算配比（ch08）

### 6.1 计划类型三套口径（先对齐再谈分工）

| 口径来源 | 划分维度 | 计划类型 |
|---|---|---|
| ch05 第五节（**讲座原文**） | 按投放工具 / 渠道 | 全站推广 / 关键词推广 / 精准人群推广 |
| 〔03 篇〕 | 按目标人群 + 核心目的 | 收割计划 / 拉新计划 / 竞品流量 |

⚠️ **口径冲突**：「竞品流量」是独立计划类型（〔03 篇〕）还是拉新 / 收割下的子策略（〔55/56 篇〕）—— 执行前先统一。

### 6.2 四把尺子（决定建哪类计划）

| 尺子 | 分档 | 计划取向 |
|---|---|---|
| **客单价** | ≥300 元 / <300 元 | ≥300：手动低出高溢 + 竞争航线 + 全站控投产 + 关键词品牌词 + 老客复购；<300：智能控点击成本 + 相似品跟投 + 全站最大化 + 行业词 + 流量金卡 |
| **转化周期** | ≤7 天 / >15 天 | ≤7 天**不建追投**；>15 天**三类追投全上** |
| **人群类型** | 本店人群 / 竞对人群 | 本店 → 关键词手动 + 精准人群 + 全站 + 老客复购 + 人群超市；竞对 → 竞争航线 + 相似品跟投 + 竞品品牌词 |
| **品类** | 标品 / 非标品 | 标品：关键词 + 全站 + 流量金卡，聚焦搜索端；非标品：智能控成本 + 竞争航线 + 全站多目标 + 人群资产转化 + 人群超市，覆盖搜推双场域 |

### 6.3 边际拐点（收割计划该加还是该停）

| 阶段 | 新增产出 | 动作 |
|---|---|---|
| **上升阶段** | ≥ 目标 ROI × 1 元 | 持续加预算 |
| **放缓阶段** | 目标 ROI × 0.6 ~ × 1 | 停止加预算，维持观察 **3-5 天** |
| **下滑阶段** | < 目标 ROI × 0.6 | 减收割预算 **30%-50%**，转移至拉新 |

**触发线**：连续 **3 天**新增投产 < 目标 ROI × 0.6，必须减预算。

> ⚠️ **与 ch06 §7.1 冲突**：ch06 用「新增预算 ROI ≥ **原有 ROI 的 80%**」且调整幅度 ≤ **30%**；〔55/56 篇〕用「新增产出 ÷ **目标** ROI」、止损线 **0.6 倍**、一次减 **30%-50%**。**两条不可互相代入。**

### 6.4 三组案例的合计结构（收割 : 拉新 : 追投）

| 案例 | 收割 | 拉新 | 追投 | 结果 |
|---|---|---|---|---|
| 霍尼韦尔除甲醛（标品 198 元） | 60% | 40% | 0% | ROI 2.8→3.7｜人群资产 +200%｜费比 12% |
| 1500 元高端空净（标品长周期） | 45% | 45% | 10% | ROI 2.8→3.7｜人群资产 +180%｜费比 13% |
| 8000 元高端定制家具（非标品长周期） | 45% | 30% | 25% | ROI 2.5→3.2｜挽回率 28%｜费比 14% |

**没有一组把全部预算压在收割上。**

### 6.5 三类追投

| 类型 | 打法 |
|---|---|
| **种子人群追投** | 对种子人群追加 |
| **低浏览人群激活** | 提升浏览频次至 **3 次**+ |
| **预流失人群挽回** | 定向浏览 ≥2 次 + 15 天未访，挽回率 **25%** |

**监控指标**：浏览频次提升率 + 挽回率 + 30 天转化率。

### 6.6 人群资产层 → 承接计划

| 人群资产层 | 承接计划 |
|---|---|
| **A（浏览人群）** | 关键词行业词收割 |
| **I（收藏加购）** | 全站控投产 + 关键词品牌词 |
| **P（购买人群）** | 精准人群老客复购 + 流量金卡 |
| **L（复购人群）** | 自定义老客 + 人群超市 |

### 6.7 三段式矩阵

```
拉新（关键词 + 人群）→ 追投（智能 + 达摩盘）→ 收割（全站 + 智能）
```

**提高收割拐点的三条路径**：① 调整商品架构（矩阵化）；② 从 O 熟客里挖流量（挖竞品）；③ 搭建拉新-追投-收割的投放矩阵。

## 七、诊断决策树

```
费比高？
├─ ROI 也高？
│  ├─ 间接成交占比高 → 引流先锋官 → 绿灯，不是红灯
│  │    → 打包进系列看板；系列费比健康就不能砍，酌情加钱
│  └─ 间接占比不高 → 退款率假象（推广成交金额是毛的）
│       → 跳生意参谋退款分析模块查主因，对症下药
└─ ROI 也低 → 回炉重造
     → 停计划 → 分析同行素材 → AI 重做场景人群与视觉
     → 确认是产品力问题就果断放弃
```

```
左侧拉新 ROI 接近零？
├─ 达摩盘第一步：类目后链路成交占比（交集 ÷ 人群总数）
│    样例 A 2062/5800 = 35.5%  vs  B 511/4300 = 11.8% → A 质量是 B 三倍
└─ 达摩盘第二步：TA 人群浓度（交集目标客群画像）
     样例 A 52% vs B 40%
     ⚠️ 不设绝对标准，只在同一严苛标准下横向比
```

## 八、左右两侧速查

| 维度 | 左侧 AI 人群 | 右侧 O 人群 |
|---|---|---|
| 含义 | 系统侧已建立人群资产关系 | 系统外新流量 |
| 关键观察 | **TA 浓度** | 引潜比 / 投产 |
| 触达方式 | 搜索 + 推荐 | 推荐 + 关键词手动 |
| 心法 | 左侧看浓度不看投产 | 系统优先拿右侧，右侧不行才拿左侧 |

**四象限投放顺序**：AI 熟客 → O 熟客（转化比类目新客高约 20 倍）→ O 新客 → AI 新客
**口诀**：先熟客后新客 → 右侧收割 → 右侧拉新 → 左侧拉新

**TA 三大指标**：TA 规模（天花板）｜TA 浓度 = TA 规模 ÷ 店铺总浏览人群｜渗透率 = 已建立资产人群 ÷ TA 规模

## 十、避坑速查

| # | 坑 | 一句话破法 |
|---|---|---|
| 1 | 单链接费比高就砍引流款 | 看间接成交占比，占比高是绿灯不是红灯 |
| 2 | 只看推广 ROI | 成交金额是毛的，必须剔退款 |
| 3 | 同一张红绿灯用到底 | 新品 GSV 优先，成熟爆款费比优先 |
| 4 | 设绝对 TA 浓度标准 | 永远自己跟自己比 |
| 5 | 左侧拉新只看 ROI | 用达摩盘两步验证 |
| 6 | 没有壁垒还猛做左侧 | 白牌/标品预算压右侧收割 |
| 7 | 费比没花完就收手 | 没超就该花出去 |
| 8 | 无界数据两次下载直接比 | 存在归因漂移 |
| 9 | 预算调整幅度失控 | 每次 ≤30% |
| 10 | 心智错位的宝贝放同一盘 | 按品类核心决策要素拆盘 |
| 11 | 讨论"计划类型"时各说各的 | 三套口径（按工具/按人群/按角色）先对齐，再说分工 |
| 12 | 只看投产决定收割计划该不该加钱 | 用边际拐点：新增产出 ÷ 目标 ROI，< 0.6 倍即减 30%-50% 转拉新 |
| 13 | 拉新计划投产低就停 | 末次点击归因让拉新投产天然偏低，用**有效人群比例**判断（≥40% 即值得坚持） |
| 14 | 把两套红绿灯的"1.2"当同一个数 | 〔03 篇〕是花费/销售 > 1.2；ch06 是费比 > 目标费比 × 1.2，含义不同 |
| 15 | 短周期品类硬上追投 | 追投只服务转化周期 > 15 天；≤7 天做追投是浪费 |
| 16 | 目标永远照抄上月 | 双轨取严：利润约束给底线，历史基线给可达 |
| 17 | 大盘用明细逐行相加 | 取模板自己的汇总行，差额行单独立账对账 |
| 18 | 万相台三表相加算总花费 | 按计划 ID 去重、费用取最大值；且它是月度快照，只能按自然月取 |
| 19 | 目标花费用毛 GMV × 净费比 | 费比分母是 GSV，必须用净 GSV 乘目标费比 |

## 十一、数据下载与核对
