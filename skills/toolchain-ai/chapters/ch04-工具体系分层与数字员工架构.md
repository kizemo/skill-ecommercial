## 一、先分清三层，别混着说

这是本 skill 最容易出错的地方 —— 知识库里至少有三套切法，**说的不是同一层的东西**。

| 层 | 名称 | 定位 | 能力范围 |
|---|---|---|---|
| **平台层** | **千牛 AI** | 千牛工作台内置的 AI 经营**平台**；底层阿里通义大模型（Qwen 系列），支持多模态（文本/图像/视频），基于店铺数据每店独立微调 | **5 大 AI 能力**：诊断 / 报告 / 客服 / 内容 / 数据 |
| **模块层** | **生意管家** | 千牛 AI 下的**具体功能模块**，调用平台底层能力 | **4 大功能**：诊断 / 报告 / 客服 / 内容 |
| **工具层** | **生意管家 AI 经营** | 平台上面向商家的 **AI 经营 agent**，官方免费 | **1 店长 + 6 数字员工**（7 大模块） |

**类比**（原文口径）：千牛 AI 像「App Store」，生意管家像「App Store 里的某个 App」。

**接入方式**：千牛工作台 → AI 中心 → 申请开通（平台层）；千牛 AI 内打开「生意管家」入口（模块层）。

**数据范围**：仅阿里系店铺（天猫 / 淘宝 / 天猫国际 / 淘特）。**拼多多店不适用**，要改用拼多多商家版。

### 1.1 另一套切法：六大核心功能

aiec.fun《千牛AI经营工具生意管家全教程》把商家侧感知到的能力切成**六大核心功能**：AI 巡店、商品运营、人群策略、行业洞察、AI 店长、AI 数据分析（详见第 1 章）。

> ⚠️ **口径差异（切面不同，不是冲突）**：官方口径按**产品层级**切（平台 / 模块 / 工具），aiec 教程按**商家使用场景**切。商家实际在后台看到的是"六大功能"入口，但底层都挂在生意管家上。**两套口径都能站住，答题前先确认问的是哪一层。**

### 1.2 模块内部四大功能

| 功能 | 关键行为 | 后台路径 |
|---|---|---|
| **AI 诊断** | 每天 **9 点**自动推送店铺健康度报告｜流量 / 转化 / 客单 / 复购 **4 维雷达图**｜同比/环比下降 **20%** 自动提醒 | 千牛 → AI 中心 → 生意管家 → 诊断 |
| **AI 报告** | 日报（昨日流量/转化/GMV）｜周报（销售+流量+客户+竞品 4 维）｜月报（月度总览+下月建议）｜自定义（选指标+时间范围+对比维度） | 千牛 → AI 中心 → 生意管家 → 报告 |
| **AI 客服** | **50+** 预设问答库｜意图识别自动分流｜**连续 2 轮**答不出自动转人工｜⚠️ 医械禁忌症/副作用**必须人工** | 千牛 → 客服 → 智能客服配置 |
| **AI 内容** | AI 标题生成 **10 个**候选｜详情页文案 + 配图｜短视频脚本 30 秒 / 60 秒｜⚠️ 医械**必须人工合规审查后**上架 | 千牛 → AI 中心 → 生意管家 → 内容 |

## 二、1 店长 + 6 数字员工（工具层全景）

| # | 模块 | 职责 | 关键能力 |
|---|---|---|---|
| 1 | **AI 店长**（AI 巡店） | 一屏洞察全店 | 核心经营指标自动汇总（T-1 日）｜全维度风险实时巡检（物流/售后/合规/库存）｜主力商品异常诊断与归因｜竞品流失分析与一键对标 |
| 2 | **AI 数据分析师** | 一句话出分析 | 覆盖销售、流量、商品、竞争、市场、客户**六大场景**；一句话自动完成分析 + 诊断 + 策略 |
| 3 | **AI 营销工具运营** | 方案 → 一键代理配置 | 满件折｜立减券｜评价有礼｜连带销售 |
| 4 | **AI 美工专家** | 素材生产 | 创意策划｜批量生图 / 生视频｜素材测试 |
| 5 | **AI 客服** | 应答降本 | 智能客服应答，降低人工成本 |
| 6 | **AI 订单** | 履约管理 | 订单全流程管理，异常订单预警 |
| 7 | **AI 人群** | 精准运营 | 用户画像分析、人群精准运营 |

**官方口径的规模数据**：服务商家 **超 500 万**，效率提升 **1.5 倍**，核心功能**免费**。（来源：`淘宝生意管家AI经营工具`）

### 2.1 入口

| 端 | 路径 |
|---|---|
| **电脑端** | 千牛**右上角**「管家」标志（部分文档写作右上角「生意管家」图标 / 闪电标志） |
| **手机端** | 千牛**底部**第三个 tab「管家」；看不到就去 千牛左上角 → 通用设置 → 底部功能设置，把管家置顶 |
| **提问入口** | 生意管家「群聊」或「数据」入口；也可在**生意参谋右下角 → 生意管家解读**提问 |

### 2.2 提问技巧（直接决定回答质量）

官方给的提问结构：

```
分析 店铺/商品id + 关键数据指标
（需要特定时间周期时，前缀加上具体时间）
```

| 提问类型 | 指令 |
|---|---|
| 基础 | 帮我分析一下昨天的店铺数据并给出建议 |
| 竞对对比 | 对比下店铺与 top3 竞店的数据表现 |
| 趋势解读 | 帮我解读最近的趋势卖点 |
| 精准报告 | 帮我生成上周女装类目店铺周报，重点分析流量和商品数据 |
| 问题诊断 | 帮我分析本月老客复购问题，并给出可落地的解决方案 |
| 流失分析 | 昨日流失情况分析 |

**分析场景覆盖 20+ 种**：整体销售、商品分析、流量分析、营销分析、市场竞争分析、流失情况分析等。

### 2.3 三种提问方式的成本差异

| 问法 | 得到什么 | 代价 |
|---|---|---|
| **泛问**（「店铺数据怎么样」） | 面面俱到的报告 | **没有行动指向**，还得自己再问一轮 |
| **精准指令**（「分析 + 对象 + 指标」） | 聚焦到能落地的问题 | 需要你先想清楚要问什么 |
| **商品 ID 级**（「分析商品 xxx 的搜索渠道流量表现」） | 直接落到单品的流量/转化结构 | 需要先拿到准确的商品 id |

## 三、官方 agent 口径的七大能力

### 3.1 店铺运营 agent —— AI 店长 / AI 巡店
AI 巡店：一眼看清店铺整体经营情况及异动，标出**待办和风险**。

### 3.2 数据 agent —— AI 数据分析师
7×24 小时数据分析管家。商家侧三个典型痛点：**缺经验**（数据下降不会分析、不知分析是否准确）｜**缺时间**（商品多工作多，没时间细致分析）｜**后台分析低效**（要打开多个页面查至少十几个指标）。

7 大类分析能力：

| 类别 | 内容 |
|---|---|
| **店铺整体销售分析** | 围绕流量/转化等销售关键因子，综合诊断店铺整体销售与重点品表现 |
| **流量分析** | 支持流量、收藏加购、转化等不同场景数据并给建议 |
| **商品分析** | 商品整体分析、商品流量加购转化分析、**潜力品发掘** |
| **竞争分析** | 昨日店铺整体流失情况、指定商品流失竞品及原因 |
| **市场分析** | 洞察行业/类目趋势与机会，默认查**一级类目**，也支持输出关键词查询二级或叶子类目 |
| **客户分析** | 店铺用户画像、老客复购提升诊断 |
| **服务分析** | 退款售后等数据分析诊断 |

### 3.3 营销 agent —— AI 营销助理（6 类方案）
方案生成后**可一键代理配置**：

| 方案 | AI 的依据 |
|---|---|
| **店铺满件折** | 店铺商品热销情况分析 → 商品组合营销设置方案 |
| **商品立减券** | 商品及竞品综合营销诊断 → 设价建议 → **一键采纳**完成配置 |
| **店铺券提客单** | 店铺商品热销情况分析诊断 → 店铺满减券方案 |
| **关注立减** | 店铺经营数据诊断 → 帮拉新或扩大粉丝群体 |
| **老客立减** | 店铺及竞对老客复购数据 → 老客立减方案 |
| **评价有礼** | 店铺品类分层 → 针对新品积累评价、或有差评商品分别诊断给建议 |

### 3.4 订单 agent / 客服 agent / 内容 agent / 美工 agent
订单全流程管理 + 异常订单预警｜买家意图识别 + 自动回复（智能客服 7×24）｜内容与美工模块（详见第 2 章 AI 主图四法与 AI 应用面）。

## 五、生意管家 Claw（从"给建议"到"替你做"）

| 维度 | 线上生意管家 AI agent | **生意管家 Claw** |
|---|---|---|
| **能力边界** | 分析 + 诊断 + 给建议 + 一键代理配置 | **拆解任务、调用工具、执行**；能操作本地电脑文件与应用，产出最终交付物 |
| **独有能力** | — | **定时任务**（按设定时间自动重复完成）｜**长期记忆**（越用越懂经营习惯）｜**本地电脑操作**（数据处理分析、文档创作编辑、浏览器自动采集）｜**快捷自定义技能**｜**内置几十个电商专用 skill**（店铺巡检分析、商品卖点优化诊断、商品优惠方案设计等） |
| **生态打通** | 千牛后台 | 千牛后台 + **生意参谋、营销、客服、订单**；内置浏览器自动化（查竞品在其他平台的价格、小红书前台热点）；可接**钉钉机器人**自动推送到商家群 |

**原文口径的开放时间**：「预计 4 月中开放」，千牛电脑端与移动端均可使用。

**三种低成本自建技能的方式**：① **录制**在千牛后台的操作步骤，AI 自动模拟创建技能；② 在**对话中**直接让 AI 总结创建技能；③ **导入**自己写的工作流程要求。

**上手技巧（原文）**：第一次下发任务尽量**具体描述清楚需求**（如做数据采集要写清获取路径），AI 更能理解你的思路；任务符合诉求后直接发送「**帮我保存为技能并安装**」，后续可重复使用。
