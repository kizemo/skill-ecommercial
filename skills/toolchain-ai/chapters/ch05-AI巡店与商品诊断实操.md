## 一、AI 巡店：五个维度一屏看完

**替代人工 30 分钟的数据整理时间**，覆盖数据概况、店铺巡检、商品诊断、进店流量动态、竞品流失分析五大维度。对应四个痛点：数据收集耗时、异常发现滞后、数据分析繁琐、竞品监控缺失。

**关键优势**：能发现人工盯盘容易遗漏的风险点 —— **违规预警、低库存、超时订单**。

### 1.1 数据概况仪表盘（五类核心指标）

| 数据类别 | 核心指标 | 计算方式 | 运营价值 |
|---|---|---|---|
| **成交数据** | 支付金额、退款金额、推广花费、推广费比 | 退款率 = 退款金额 / 支付金额；费比 = 推广花费 / 支付金额 | 判断店铺盈利能力 |
| **买家 & 加购数据** | 支付买家数、加购人数、总访客数 | 加购率 = 加购人数 / 总访客数 | 识别买家兴趣点 |
| **访客流量数据** | 搜索流量、推荐流量、付费推广流量 | 各渠道流量及环比变化 | 判断流量健康度 |
| **店铺体验数据** | 真实体验分 | — | 决定能否报名官方活动，重点维护 |
| **客服运营数据** | 客服销售额占比、咨询人数、响应时间、满意率 | — | 调整客服排班 |

### 1.2 店铺巡检四类风险预警（含处理优先级）

| 风险类型 | 核心内容 | 优先级 | 实操价值 |
|---|---|---|---|
| **售后异常** | 售后待处理订单、即将超时订单 | **P0** | 避免投诉 |
| **物流异常** | 异常物流订单，主动联系快递 | **P0** | 提升用户体验 |
| **违规预警** | 店铺违规提示，立即整改 | **P0** | 避免扣分降权 |
| **库存异常** | 低库存预警、库存周转天数、热销 SKU 缺货 | **P1** | 防止断货流失 |

> **案例**：某店铺热销 SKU 触发低库存预警，商家第一时间补货，避免了 **7 天销量下滑超 20%** 的损失。

### 1.3 竞品流失分析（最有价值的模块）

**AI 自动总结流失指数最高的 3 家竞品**：

| 维度 | 内容 |
|---|---|
| **TOP3 流失竞品监控** | 展示 7 天流失指数涨跌，判断分流力度 |
| **竞品商品动态** | 监控降价、上新数量，结合营销场景分析策略 |
| **竞品直播运营** | 查看高成交量直播间、新增达人主播 |
| **商品流失对标** | 定位本店流失金额最高的 3 款商品，查看流失金额、流向竞品 |

**流失场景分类 → 对应动作**（这是必须记牢的映射）：

| 流失类型 | 改什么 |
|---|---|
| **浏览流失** | 优化主图、详情页、价格 |
| **搜索流失** | 优化关键词、搜索排名、搜索推广 |

> 官方 agent 侧还有一层巡检能力：**经营异动巡检**（成交与花费、访客与转化、店铺体验分）｜**商品异动分析**（昨日核心商品、潜力新品异动，定位核心异动因子）｜**履约超时**（发货/收件/物流）｜**资损风险**｜**库存风险**｜**违规检测**｜**流失去向商品监控**｜**竞店经营行为监控**（上新、降价、直播、活动）。

### 1.4 巡店适用场景

每日运营晨会（1 分钟掌握全店异动）｜库存风险管理｜竞品动态监控（每周复盘 TOP3 流失数据）｜大促期间监控（转化率、费比波动）｜新店冷启（监控搜索流量占比变化，判断免费流量获取能力）。

## 二、商品智能诊断：三块内容

### 2.1 搜索渠道 —— 词根波士顿矩阵（近 30 天）

**AI 自动把商品标题拆解为词根**，按访客数（Y 轴）与转化率（X 轴）分四象限：

| 象限 | 访客 | 转化 | 动作 |
|---|---|---|---|
| **① 保留并前置** | 高 | 高 | 保留并前置到标题 |
| **② 优化或替换** | 高 | 低 | 优化或替换 |
| **③ 直接删除** | 低 | 低 | 直接删除 |
| **④ 加大推广** | 低 | 高 | 加大推广 |

**配套**：结合竞品高频词提取（**痛点词 / 功能词 / 营销词**）补充高价值词；标题结构 = 品牌词 + 核心卖点 + 品类词 + 人群词 + 痛点解决方案 + 功能词。

**案例数字**：某商品搜索渠道访客 **12800**，支付买家 **665**，转化率 **5.2%**；AI 直接生成 **3-5 个**优化后标题可用。

**投放口径**：重点投放高访客高转化高增长关键词，**屏蔽垃圾流量词**。

### 2.2 推荐渠道 —— 素材全维度诊断（近 7 天）

对视频和图片素材**逐一统计**：曝光、点击人数、点击率、转化率，并标注表现等级（**优秀 / 一般 / 较差**）。

| 表现 | 动作 |
|---|---|
| **优秀素材** | 直接通过人群推广放大曝光 |
| **低效素材** | 立即替换或重新制作，对标本店/竞品优质素材的拍摄风格、卖点展示、视觉设计、文案 |

**核心逻辑**：**点击率低改主图视频，转化率低改详情页。**

**案例数字**：主视频曝光 **52000**、点击率 **5.1%**、转化率 **3.3%**（优秀）；副视频曝光 **21000**、点击率 **2.0%**、转化率 **0.8%**（较差，需替换）。

> 2026.3.26 起巡店新增**素材诊断**：每日发现**搜推高价值商品**，提醒商家补充搜推素材 —— 发布种草素材后可在搜索、推荐等场域获得分发机会。

### 2.3 转化率 —— 四环节漏斗（近 10 天）

| 环节 | 看什么 | 低了改什么 |
|---|---|---|
| **① 认知** | 访客数、停留时长、跳失率 | 主图 / 标题 |
| **② 兴趣** | 加购人数、收藏人数、收藏加购率 | 卖点 / 营销 |
| **③ 购买** | 支付买家数、支付转化率 | SKU / 评价 |
| **④ 复购** | 复购率 | 售后 / 福利 |

结合**流量承接效率诊断**，定位主图、标题、SKU、物流等模块的用户流失节点。

**结论输出四要素**：一句话结论（整体表现）+ 核心优势（优质渠道、高转化模块）+ 存在问题（流量短板、转化偏低）+ 行动建议（初步优化方向）。

### 2.4 按生命周期选分析重点

**新品**侧重流量诊断｜**爆款**侧重转化优化｜**滞销品**侧重问题定位。

> 商品诊断的完整闭环：数据自动诊断 → 核心问题定位 → 竞品对标分析 → 落地优化建议 → 执行效果复盘，支持**全店商品批量分析**。

## 三、AI 报告：日 / 周 / 月

### 3.1 生成效率与四重对比

**1-2 分钟**自动生成专业日/周/月报。报告自带**四重对比维度**：**店铺环比 + 店铺同比 + 同行同层平均 + 同行同层优秀**，并按店铺规模输出差异化建议：

| 店铺类型 | 建议动作 |
|---|---|
| **大店** | 启动智能推广 + 小额测款 |
| **小店** | 先优化详情页卖点、视觉、标题、定价，夯实基础后再小规模测款 |

### 3.2 周报 7 大模块

① **核心结论**（10 秒抓概况：支付金额环比/同比涨跌、排名变动）｜② **核心经营数据**（访客数/转化率/客单价/加购率，四重对比）｜③ **客户结构分析**（新老客 + 流量渠道对比）｜④ **重点商品分析**（核心品/潜力品/新品 + 流失竞品）｜⑤ **竞店动向**（新品/价格/活动）｜⑥ **个性化经营建议**｜⑦ （原文未完整列出）。

**案例**：服饰店铺支付金额环比 **+12%**、同比 **−5%**；核心优势为老客复购率高于同行优秀，主要问题为新客转化率低于同行均值。

### 3.3 报告覆盖的复盘维度（官方口径）

核心指标监控（**支付与退款、访客与转化、付费推广消耗及 ROI**）｜多维异动检查（综合环比 + **同行同层对比**挖掘异动指标）｜流量渠道复盘（全店 Top 渠道的访客、转化率、加购率趋势变化）｜客户结构复盘（新老客，从访客→转化→客单价）｜商品分层（**主力商品** = 支付金额/件数高；**潜力腰部品** = 环比增长靠前）｜周度**中差评分析** + 流失去向分析。

### 3.4 精准指令公式

```
分析 + 对象 + 指标
```

| 目的 | 指令 |
|---|---|
| 基础 | 帮我生成店铺周报 |
| 精准 | 帮我生成上周女装类目店铺周报，重点分析流量和商品数据 |
| 问题 | 帮我分析本月老客复购问题，并给出可落地的解决方案 |

**可分析对象**：整体销售 / 商品分析 / 流量分析 / 营销分析 / 市场竞争分析 / 流失情况分析。

## 四、落地提醒

1. **拼多多店不适用** 生意管家与千牛 AI —— 改用拼多多商家版。
2. **医械场景三条硬线**：AI 客服**不得**回答禁忌症/副作用类问题｜AI 起草的详情页与标题**必须人工合规审查后**才上架｜AI 生成主图同样要过合规（画面里可能带"治疗""治愈"字样）。
3. **AI 报告是聚合口径** —— 与生意参谋、财务报表的数字口径可能不同，跨工具对不上时先确认口径；**素材未覆盖统一口径规则，未验证**。
4. **拿 AI 结论当假设，不当判据** —— 用 `[[store-diagnosis]]` 的四层判据去验证，再动账户。
