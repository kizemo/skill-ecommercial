## 1. 巡店 P0 清零循环（每天 9 点 → 10 点）

**何时用**：每天开工；大促期间加密到每 4 小时 1 次。

**怎么做**：
1. **9 点** —— AI 健康度报告自动推送（流量/转化/客单/复购 4 维雷达图）
2. **10 点前** —— 人工 review 完
3. **只处理 P0** —— 售后异常、物流异常、违规预警三项 **P0 优先**；库存异常是 **P1**
4. 经营异动（成交与花费、访客与转化、店铺体验分）按环比/同比下降 **20%** 自动提醒的阈值捞出来

**代价与风险**：**P0 没清零就去干别的，是最常见的翻车点** —— 违规预警和即将超时订单会直接变成扣分降权和投诉，事后补救成本远高于那 5 分钟巡检。

## 2. 流失场景二分法（别把所有流失都当流量问题）

**何时用**：AI 巡店报出竞品流失，且本店访客在掉。

**怎么做**：
```
流量在掉
├─ 浏览流失 → 改主图、详情页、价格
└─ 搜索流失 → 改关键词、搜索排名、搜索推广
```
再往下定位到单品：**找出本店流失金额最高的 3 款商品**，看它们各自流向哪个竞品。

**代价与风险**：把**浏览流失**当**搜索流失**治，是最贵的错 —— 去改关键词排名解决不了"看到了但不想点"。先分类再动手。

## 3. 词根波士顿矩阵四象限处置

**何时用**：标题点击率低、要优化标题；或新品要规划词路。

**怎么做**：
1. 让 AI 把商品标题**拆成词根**（近 30 天数据）
2. 按访客数（Y）× 转化率（X）分四象限：**高访高转 → 保留并前置**｜**高访低转 → 优化或替换**｜**低访低转 → 直接删除**｜**低访高转 → 加大推广**
3. 结合竞品高频词提取（痛点词 / 功能词 / 营销词）补高价值词
4. 标题结构：品牌词 + 核心卖点 + 品类词 + 人群词 + 痛点解决方案 + 功能词

**代价与风险**：删词有代价 —— 象限③ 的词虽然低访低转，但可能是**防御性词**（品牌词、类目词）。先确认不是承接词再删。

## 4. 素材双指标处置（点击率和转化率是两件事）

**何时用**：主图/视频要优化，或素材投放要加量。

**怎么做**：
1. 逐条统计曝光、点击人数、点击率、转化率（近 7 天）
2. 标等级：**优秀 / 一般 / 较差**
3. **优秀** → 通过人群推广放大曝光
4. **较差** → 立即替换或重做，对标本店/竞品优质素材的拍摄风格、卖点展示、视觉设计、文案
5. 归因口诀：**点击率低改主图视频，转化率低改详情页**

**代价与风险**：只盯点击率会造出"点进来就走"的素材。**优秀素材**的判定同时看点击率与转化率，单看一个都会选错。

## 5. 转化漏斗四环节定位（先定位，再改）

**何时用**：商品转化率异常、详情页优化要排优先级、销量下滑要定原因。

**怎么做**：
1. 看近 10 天漏斗：认知（访客/停留/跳失）→ 兴趣（加购/收藏/收藏加购率）→ 购买（支付买家/支付转化率）→ 复购（复购率）
2. **哪个环节最弱，就改那个环节对应的东西**：

| 环节 | 改了没用 | 要改 |
|---|---|---|
| 认知 | 改详情页 | 主图 / 标题 |
| 兴趣 | 改 SKU | 卖点 / 营销 |
| 购买 | 改主图 | SKU / 评价 |
| 复购 | 改价格 | 售后 / 福利 |

3. 配合流量承接效率诊断，定位到主图、标题、SKU、物流等具体模块

**代价与风险**：**跳过定位直接全面改详情页**，是把所有环节同时改一遍，然后无法归因。漏斗的价值是**缩小改动面**，不是让你干更多活。

## 6. 商品生命周期分层选分析重点

**何时用**：开店店要决定"今天先看哪个商品"。

**怎么做**：
```
新品 → 流量诊断（搜索渠道 + 素材诊断）
爆款 → 转化优化（漏斗 + 详情页）
滞销品 → 问题定位（流失分析 + 竞品对标）
```

**代价与风险**：对爆款做流量诊断是在优化已经最好的环节；对新品做转化优化是**在没流量的地方做转化** —— 顺序错了，两边都白做。

## 7. AI 报告四重对比 + 精准指令公式

**何时用**：周会复盘、月度总结、要向老板汇报。

**怎么做**：
1. 用**精准指令**而不是泛问：`分析 + 对象 + 指标`
   - 「帮我生成上周女装类目店铺周报，重点分析流量和商品数据」
2. 读报告时**必须用四重对比**：**店铺环比 + 店铺同比 + 同行同层平均 + 同行同层优秀**
3. 看商品分层：**主力商品**（支付金额/件数高）与**潜力腰部品**（环比增长靠前）分开看
4. 看客户结构：从**访客 → 转化 → 客单价**拆新老客，不要只看成交总额

**代价与风险**：**只看店铺环比**是最常见的读报告错误 —— 大盘跌的时候环比全绿，看不出自己其实跑输了同行。四重对比里少了「同行同层」这一维，等于没做对标。

## 8. AI 内容起草 + 人工双审（医械场景硬要求）

**何时用**：详情页、标题、短视频脚本、买家秀由 AI 生成。

**怎么做**：
1. AI 起草：标题生成 **10 个**候选｜详情页文案 + 配图｜短视频脚本 30 秒/60 秒｜批量生图/生视频
2. **人工审** —— 运营审内容与卖点准确性
3. **合规审** —— 医械类目必做，检查疗效暗示与违规词
4. 客服侧：禁忌症/副作用类问题**不交给 AI**，**连续 2 轮**答不出自动转人工

**代价与风险**：**一次未审核的 AI 主图就是一次违规扣分** —— AI 画面里也可能带出"治疗""治愈"字样。这条在医械类目是 P0，不是流程冗余。

## 9. AI 任务沉淀成可复用技能

**何时用**：同一件重复活已经手工教过 AI 两遍以上。

**怎么做**：
1. 第一次下发任务时**把需求写具体**（做数据采集要写清获取路径），复杂任务**分步骤训练**
2. 任务跑通后直接说「**帮我保存为技能并安装**」
3. 创建方式三选一：**录制**后台操作步骤｜**对话中**让 AI 总结｜**导入**自己写的工作流程
4. 再进一步 → **定时任务**（每天登录自动跑）+ **钉钉机器人**推送到群

**代价与风险**：沉淀成技能的前提是**任务描述够具体**。描述含糊就存技能，等于把一个模糊的错事固化成每天自动执行的错事。

## 10. 多 Agent 知识库切分与权限分层

**何时用**：团队人多、职责分工清晰、想按角色隔离知识。

**怎么做**：
1. 按职责切 **12 个 Agent 目录**（运营助理/淘宝/京东/拼多多/设计/IT/财务/musk/数据分析/内容营销/人力/trainer）
2. 跨角色通用内容抽到共享区 `public/`（电商通用规范/大促资料/合规文档/工具素材），避免 12 份重复维护
3. 权限**跟着职责走**：musk = admin｜trainer = manager｜其余 = 对应专业角色
4. 落地前逐条检查：每个目录里**只有**相关笔记吗？共享区有没有放不该共享的内容？

**代价与风险**：新增角色要**三处同步**（目录、权限、知识库）—— 只加目录不加权限，等于新角色能力受限；只加权限不加目录，等于新角色什么都看不到。**并发内存是最容易翻车的点**：16GB 是下限，32GB 才是建议值。

## 11. 工具选型：先确认平台与类目，再谈功能

**何时用**：换平台、换类目、给团队开通工具前。

**怎么做**：
```
要用的功能开了吗？
├─ 千牛 AI / 生意管家 → 仅阿里系（天猫/淘宝/天猫国际/淘特）
│  └─ 拼多多店 → 改用拼多多商家版，不适用
├─ 人群策略 → 仅服饰、美妆（其他类目逐步开放）
├─ 行业洞察 → 仅天猫服饰
└─ 生意管家 Claw → 原文口径"预计 4 月中开放"，千牛电脑端与移动端
```

**代价与风险**：**按别人的截图找功能**，是工具类内容最常见的误判来源 —— 同一份资料里的不同笔记更新日期不同，能力开通与否按**当前后台实际入口**为准，用第 4 章的更新日志做参考而不是做保证。
