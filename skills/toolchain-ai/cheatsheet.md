## 1. 三层架构速查（先确认问的是哪一层）

| 层 | 名称 | 定位 | 能力范围 |
|---|---|---|---|
| **平台层** | **千牛 AI** | 千牛工作台内置 AI 经营平台，底层通义大模型 | **5 大能力**：诊断/报告/客服/内容/数据 |
| **模块层** | **生意管家** | 千牛 AI 下的功能模块 | **4 大功能**：诊断/报告/客服/内容 |

## 4. 巡店数据概况：五类指标

| 类别 | 指标 | 计算方式 |
|---|---|---|
| **成交** | 支付金额、退款金额、推广花费、推广费比 | 退款率 = 退款金额/支付金额；费比 = 推广花费/支付金额 |
| **买家&加购** | 支付买家数、加购人数、总访客数 | 加购率 = 加购人数/总访客数 |
| **访客流量** | 搜索流量、推荐流量、付费推广流量 | 各渠道流量及环比 |
| **店铺体验** | 真实体验分 | 决定能否报名官方活动 |
| **客服运营** | 客服销售额占比、咨询人数、响应时间、满意率 | 调整客服排班 |

## 5. 风险预警处理优先级（先 P0）

| 风险类型 | 内容 | 优先级 | 动作 |
|---|---|---|---|
| **售后异常** | 售后待处理订单、即将超时订单 | **P0** | 立即处理，避免投诉 |
| **物流异常** | 异常物流订单 | **P0** | 主动联系快递 |
| **违规预警** | 店铺违规提示 | **P0** | 立即整改，避免扣分降权 |
| **库存异常** | 低库存预警、库存周转天数、热销 SKU 缺货 | **P1** | 及时补货，防止断货 |

**案例**：热销 SKU 低库存预警后第一时间补货，避免 **7 天销量下滑超 20%**。

**自动提醒阈值**：同比/环比下降 **20%**（流量/转化/客单/复购 4 维）。

## 7. 词根波士顿矩阵处置表

| 象限 | 访客 | 转化 | 动作 |
|---|---|---|---|
| **① 保留并前置** | 高 | 高 | 保留并前置到标题 |
| **② 优化或替换** | 高 | 低 | 优化或替换 |
| **③ 直接删除** | 低 | 低 | 直接删除（先确认不是承接词） |
| **④ 加大推广** | 低 | 高 | 加大推广 |

**标题结构**：品牌词 + 核心卖点 + 品类词 + 人群词 + 痛点解决方案 + 功能词
**竞品词三类**：痛点词 / 功能词 / 营销词
**案例**：搜索渠道访客 12800、支付买家 665、转化率 5.2%，AI 给出 3-5 个可用标题。

## 8. 素材双指标处置表

| 指标表现 | 问题在哪 | 改什么 |
|---|---|---|
| **点击率低** | 主图/视频没抓住人 | 改**主图视频** |
| **转化率低** | 点进来了但没买 | 改**详情页** |

| 素材等级 | 动作 |
|---|---|
| **优秀** | 通过人群推广放大曝光 |
| **一般** | 观察，按需迭代 |
| **较差** | 立即替换或重做，对标本店/竞品优质素材 |

**案例**：主视频曝光 52000 / 点击率 5.1% / 转化率 3.3%（优秀）；副视频曝光 21000 / 点击率 2.0% / 转化率 0.8%（较差）。

## 11. AI 报告：四重对比 + 精准指令

**四重对比维度**（缺一不可）：

```
店铺环比 + 店铺同比 + 同行同层平均 + 同行同层优秀
```

**商品分层**：主力商品（支付金额/件数高）｜潜力腰部品（环比增长靠前）｜新品｜流失竞品

**周报 7 模块**：核心结论 → 核心经营数据 → 客户结构 → 重点商品 → 竞店动向 → 个性化建议 → （原文未完整列出）

**精准指令公式**：`分析 + 对象 + 指标`

| 目的 | 指令 |
|---|---|
| 基础 | 帮我生成店铺周报 |
| 精准 | 帮我生成上周女装类目店铺周报，重点分析流量和商品数据 |
| 问题 | 帮我分析本月老客复购问题，并给出可落地的解决方案 |

**按店铺规模的建议**：大店 → 智能推广 + 小额测款｜小店 → 先优化详情页卖点、视觉、标题、定价，夯实基础后再小规模测款。

## 16. AI 主图四法选型

| 方法 | 适用目标 | 关键指令/步骤 |
|---|---|---|
| **竞品主图模仿法**（最常用） | 快速出同风格新图 | 「换一个模特，其他场景保持 80% 不变，文案改成指定文案」 |
| **同款模特多产品生成法** | 省拍摄成本、风格统一 | 豆包上传模特照 → 让 AI 反推提示词 → 上传白底图 → 生成 |
| **市场爆款主图学习法** | 跟随类目点击标准 | 「分析 XX 类目的点击标准，学习前 20 的商品主图，并生成我自己的商品图」 |
| **竞品风格复刻法** | 一次产 8 张场景图 | 上传竞品主图 + 自己白底图 →「将竞品的风格沿用到我的白底图上，生成 8 个场景图」 |

**共同红线**：不要完全复制竞品主图，细节必须改，否则判盗图；**医械必须过 `[[compliance-medical]]`**。

## 18. 五个最容易踩的坑

| 坑 | 纠正 |
|---|---|
| 把生意管家当成"一个工具" | 它是千牛 AI 平台下的**模块**，还有 1 店长 + 6 数字员工这层工具 |
| 按别的截图找功能 | 用第 4 章更新日志做参考，功能是否开通以**后台实际入口**为准 |
| AI 报告只看店铺环比 | 必须补「同行同层平均/优秀」这维，否则看不出跑输大盘 |
| 流失类型搞反 | 浏览流失改主图详情价格，搜索流失改关键词排名 |
| 医械类目直接用 AI 主图/详情页上架 | 人工审 + **合规审**两道都不能省 |
| 拼多多店找千牛 AI 的功能 | 生意管家**不适用**，用拼多多商家版 |
