# 第 3 章 · 爆款生命周期与叠标

> 来源笔记：`爆款打造体系`、`爆款打造四阶段运营SOP`、`爆款叠标打法全解`、`2026淘宝运营完整知识体系`
> 详细执行见 `[[hit-product-lifecycle]]`；本章是总纲层的速览版。

## 一、编译真相

**爆款是验证出来的，不是打造出来的。**

```
销售额 = 展现量 × 点击率 × 转化率 × 客单价
爆款基因 = 产品力 × 时机力 × 价格力      （三者缺一不可）
```

"打造爆款"的说法容易把人带偏：真正能做的是**提高验证通过率** —— 选对品、卡对时机、算对价格，然后让数据告诉你成不成。

---

## 二、四阶段

| 阶段 | 时间 | 核心任务 | 关键指标 | 目标 |
|---|---|---|---|---|
| **测款期 / 打标期** | 0-7 天 | 验证产品力 | 收藏加购率 | 新品标签初始化 |
| **冲量期 / 起量期** | 7-21 天 | 扩大展现 | 坑产超越系数 | 进类目前 20 |
| **提率期 / 爆发期** | 21-45 天 | 优化转化 | 转化率 | 进类目前五 |
| **稳价期 / 稳定期** | 45-90 天 | 保护利润 | 利润率 | 可持续盈利 |

**品类周期差异**：非标品 15-20 天｜中客单标品 3 个月｜低客单标品 5 个月｜高客单 1000 元+ 45 天以上

**阶段切换不是按日期，是按信号**：
- 进入起量期：有基础销量 + 标签初始化完成
- 进入爆发期：进类目前 20
- 进入稳定期：进类目前五，且开始能算清利润

## 三、三公式判爆款

| 公式 | 构成 | 阈值 |
|---|---|---|
| **LQ**（导入期潜力判定） | 收藏加购率×40% + 关键词质量×30% + 价格力×30% | >0.6 具备爆款潜力；<0.4 建议放弃 |
| **BQ**（成长期起爆判定） | 坑产超越系数×45% + 增长率×35% + 转化率×20% | >1.2 进入爆款通道；>1.5 爆款确认 |
| **CQ**（成熟期长效判定） | 利润率×40% + 复购率×30% + 客户满意度×30% | >0.8 可持续爆款；<0.5 昙花一现 |

**用法**：LQ 决定要不要继续投，BQ 决定要不要加注，CQ 决定要不要长期养。三个都过才是真爆款。

## 四、爆款三型

| 类型 | 特征 | 打法 |
|---|---|---|
| **标品爆款** | 销量主导 | 阵地战、价格战 |
| **非标品爆款** | 款式主导 | 布局战、测款战 |
| **半标品爆款** | 混合型 | 偏标 / 偏非标差异化 |

## 五、叠标体系

### 核心公式
```
爆款权重 = 基础权重 × (标签1权重 + 标签2权重 + ... + 标签n权重) × 叠加系数
```

### 标签权重表

| 标签 | 权重 | 可叠加 | 互斥 |
|---|---|---|---|
| **秒杀** | ★★★★★ | 首单礼金 / 新品标 / 超级单品标 / 购物金 / 淘金币 | **百亿补贴** |
| **百亿补贴** | ★★★★★ | 新品标 / 超级单品标 / 购物金 / 淘金币 | **秒杀** |
| **超级单品标** | ★★★★★ | 所有标签 | 无 |
| **首单礼金** | ★★★★☆ | 所有标签 | 无 |
| **热销爆品标** | ★★★★☆ | 所有标签 | 无 |
| **新品标** | ★★★☆☆ | 所有标签 | 无 |

> 秒杀与百亿补贴**互斥**，同时报等于浪费一次机会。

### 四阶段标签组合

| 阶段 | 标签组合 | 逻辑 |
|---|---|---|
| **打标期** | 新品标 + 首单礼金 + 超级立减 | 打基础标签，标签少而准 |
| **起量期** | 新品标 + 首单礼金 + 秒杀 | 借高权重标签撬动展现 |
| **爆发期** | 热销爆品标 + 秒杀 + 首单礼金 + 购物金 + 淘金币 | 全权重叠加抢类目前五 |
| **稳定期** | 超级单品标 + 百亿补贴 + 购物金 + 淘金币 | 换高价值标签守住利润 |

### 标签搭配禁忌
- 打标期**不要堆多个标签** —— 单一精准标签才能让系统识别人群
- 互斥标签（秒杀 / 百亿补贴）不能同时上
- 标签堆到 5 个以上时，边际权重会快速衰减

## 六、爆炸之后：爆款不是终点

**爆款 = 引流工具 + 层级工具**，不直接盈利。所以爆款之后的两件事才是利润所在：

1. **承接**：靠 A 级款与关联销售把流量变现（见 `[[sabc-product-tiering]]`）
2. **沉淀**：靠人群资产与私域复购把一次性成交变成长期收益（见 `[[customer-asset-ops]]`）

**只靠单爆款依赖的店，收入结构脆弱** —— 一旦链接衰退，整店 GMV 断崖。动销策略优于单爆款依赖。
