# 第 1 章 · 运营环境与指标体系

> 来源笔记：`2026淘宝运营完整知识体系`（超级店长训练营 41 章重构）、`淘系运营核心公式`、`淘宝四大核心指标体系`

---

## 一、流量格局：从"搜索为王"到"推荐+内容主导"

| 流量类型 | 占比 | 趋势 |
|---|---|---|
| 推荐流量 + 内容流量 | **85%+** | 主导地位 |
| 付费流量 | 持续扩大 | 全站推广普及 |
| 免费搜索流量 | **< 5%**（30 元以上商品） | 几乎消亡 |

**结论**：爆款 = 引流工具 + 层级工具，不再是直接盈利工具。
路径是：**爆款冲类目前五 → 获平台层级流量扶持 → 关联销售 + 私域复购盈利**。

**推论**：还在把预算全押在搜索词上的店铺，是在为一个占比 5% 的入口付全价。

## 二、算法逻辑：从 UV 价值到 GSV

平台考核演进：
```
转化率 → UV 价值 → 展现价值  ⇒  GSV（总销售额 − 退款）
```

**平台的本质是流量批发商** —— 把流量分配给能给平台带来最高佣金收入的链接。

**GSV 作为第一指标的后果**：
- 退款会直接扣减 GSV → 刷单式增长是负收益
- 佣金类活动（扣佣行为）能提升 GSV → 报名活动不是"让利"，是"买流量"

## 三、四大金刚（平台考核口径）

| 指标 | 定义 | 权重 | 关键动作 |
|---|---|---|---|
| **GSV** | 总销售额 − 退款 | ★★★★★ | 提升客单价、降低退款率、提高复购率 |
| **扣佣行为** | 参与平台佣金活动 | ★★★★★ | 首单礼金 / 秒杀 / 百亿补贴 |
| **内容成交** | 短视频 / 直播渠道成交 | ★★★★☆ | 超级短视频 + 小红书种草 |
| **动态体验分** | 物流 + 商品 + 服务 | ★★★★☆ | 选顺丰、48h 发货、24h 售后 |

### 新增高权重维度

| 维度 | 判定 |
|---|---|
| **退款率** | 超行业均值 2 倍 → 直接限制流量 |
| **复购率** | 越高 → 自然流量扶持越多 |
| **互动率** | 点赞 / 收藏 / 加购 / 评论权重显著提升 |

**行动含义**：体验分与退款率不是"售后工作"，是流量开关。发货时长、客服话术、详情页承诺都会写进流量分配。

## 四、人群与预算的关系（最容易被误解的一条）

**预算决定流量圈层** —— 预算是最核心的变量，不是出价技巧。

| 日预算 | 主要人群 | 潜客占比 |
|---|---|---|
| 50 元以下 | 店铺老客 | < 50% |
| 200-500 元 | 老客 + 少量相似 | 50-60% |
| 1000-2000 元 | 广泛相似 + 行业 | 60-70% |
| 5000 元+ | 全行业泛人群 | > 70% |

**判断口径**：低预算跑出的高 ROI 很可能是收割老客，不是拉新能力强。**看 ROI 之前先看领先率**（见 `[[store-diagnosis]]`）。

### 人群校正五方法

| 方法 | 操作 | 适用场景 |
|---|---|---|
| 直通车手动高溢价 | 核心人群溢价 100%+ | 基础校正 |
| 人群拓展 | 70% 均价 + 100% 拓展溢价 | 扩大流量 |
| 地域拆分 | 一二线 / 三四线分开计划 | 消费分层 |
| 引力魔方屏蔽 | 直接排除 L1-L2 | 精准屏蔽 |
| 主图优化 | 更换风格调整人群 | 源头调整 |

## 五、三大流量场景与"无样本不碰 AI"

| 场景 | 核心工具 | 定位 | 作用 |
|---|---|---|---|
| **搜索** | 关键词推广 | 最能体现实时购物意图 | 锁定精准意图、积累初始样本，是所有运营起点 |
| **推荐** | 人群推广 | 基于搜索沉淀的样本召回相似人群 | 二次/多次触达，提升转化与复购 |
| **AI 智能** | 智能计划 / 全站推广 | 大模型自动分配流量、智能出价 | 前提是有精准样本和充足资产 |

**铁律：无样本不碰 AI 智能场景。**
无样本时 AI 只能识别泛人群，只会推泛流量。正确顺序：先通过搜索 + 推荐建样本、积资产，再用 AI 放大。

**联动要求**：搜索的关键词 = 推荐的兴趣点 = AI 的样本数据。三者割裂，样本会散乱，系统识别不出成交方向。

## 六、店铺资产（一切运营的基础）

```
店铺资产 = 兴趣点访客体量（核心）+ 新客沉淀体量
```

- **新客**：90 天内有收藏/加购行为、180 天内拍下未购买的用户（属于店铺私域流量）
- **兴趣点访客**：通过相同相似购物意图触达、与店铺产生交互的用户（样本建模的核心数据）

| 阶段 | 兴趣点访客 | 新客规模 |
|---|---|---|
| 成熟店铺 | > 5 万 | ≥ 20 万 |
| 成长型 | 2-5 万 | 1-10 万 |
| 新店 | < 1 万 | < 1 万 |

**"无资产不标签"** —— 没有资产就没有标签、没有流量、没有转化。详见 `[[data-metrics]]`。

## 七、内容流量的两条腿

### 站内
| 类型 | 定位 | 要点 |
|---|---|---|
| 超级短视频 | 拉新 + 种草 | 15-30 秒，9:16 竖版，最大化出价 |
| 淘宝直播 | 实时互动转化 | 日销 + 大促爆发 |
| 逛逛 | 种草积累 | 持续发布 |

### 站外（小红书）
1. 铺设种草笔记（100-1000 粉素人）
2. 引导搜索店铺名（**不放链接**）
3. 淘宝承接：首页设置专属优惠
4. **数据验证**：每 1000 个小红书流量 → 额外获得 100 个免费类目大词搜索流量

**收推素材**：把站外内容（经授权）二次投放到淘宝 —— 降低制作成本 + 扩大覆盖面。详见 `[[visual-material]]`。
