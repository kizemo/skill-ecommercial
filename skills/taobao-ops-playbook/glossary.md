# 术语表 · taobao-ops-playbook

> 每条标注来源笔记。定义取知识库原文口径。

**AIPL** — 人群资产四阶段模型：Awareness（曝光触达）、Interest（种草培育）、Purchase（首购转化）、Loyalty（复购维护）。各阶段核心指标分别为曝光量/CTR、收藏量/加购量、转化率/客单价、复购率/会员 LTV。（来源：`客户运营体系`）

**O-AIPL** — 在 AIPL 之前增加 O（Opportunity 机会人群）：高潜购买力但尚未触达的人群，通过达摩盘 lookalike + 行业大盘获取，拉新效率比普通拉新高 50%+。（来源：`O-AIPL`）

**GAIN** — 2025Q4 起天猫正式启用的模型：G 需求驱动增长 / A 高价值人群渗透 / I 用户互动与会员活跃 / N 长期价值增长。与 AIPL 的区别：**AIPL 是流量漏斗逻辑，GAIN 是价值链逻辑**。（来源：`2026淘宝AI时代运营全攻略-核心提炼`）

**GSV** — 总销售额减退款，2026 起平台的第一考核指标。（来源：`2026淘宝运营完整知识体系`）

**扣佣行为** — 参与平台佣金活动（首单礼金/秒杀/百亿补贴），四大金刚之一，权重 ★★★★★。（来源：`淘宝四大核心指标体系`）

**动态体验分** — 物流 + 商品 + 服务构成的综合分，权重 ★★★★☆。店铺体验分 <4.6 会失搜索权重并无法报名大促。（来源：`淘宝四大核心指标体系`、`爆款三板斧-平台规则`）

**领先率（前比）** — 新客成交 ÷ 总成交。判定广告是在拉新还是在收割的唯一单一指标。普通店合格 ≥80%，头部 KA ≥70%，<50% 说明资源浪费在收割，<30% 说明几乎全是老客在买。（来源：`店铺诊断四层分析法`）

**直接成交 / 间接成交** — 直接成交 = 用户通过广告直接点击后成交；间接成交 = 用户点击广告后，又通过其他渠道（如搜索）成交。间接 = 直接的 2 倍时该品投放完全无效。（来源：`店铺诊断四层分析法`）

**第一次访问来源 / 最后一次访问来源** — 生意参谋的两种归因方式。**第一次 = 看拉新，最后一次 = 看收割**。判据：第一次访问转化率 > 最后一次访问转化率 → 在跑拉新。（来源：`店铺诊断四层分析法`）

**顺逆差** — 单品成交金额占比 − 单品推广花费占比。正向 = 花小钱办大事 = 预算倾斜依据；负向 = 优化或淘汰。（来源：`爆款三板斧-投产诊断`）

**推广投产 / 总投产** — 推广投产只含付费成交（仅供参考）；总投产含免费 + 付费（真实效率）。**差值越大 = 免费流量占比越高**。（来源：`爆款三板斧-投产诊断`）

**真实投产** — 投产 ×(1−退款率)×(1−间接成交占比)×拉新成交。用于对"投产"去伪。（来源：`每日学习/2026-07-27`）

**斩杀线** — 固定成本 ÷(毛利率 − 推广费用占比)。低于此线则亏损难以为继。（来源：`淘系运营核心公式`）

**盈亏平衡 ROI** — 1 ÷ 毛利率。毛利率 60% 时为 1.67，ROI 超过才盈利。（来源：`淘系运营核心公式`）

**成交机会** — 万相台无界的底层公式：优先展现权激活人数 × 货品曝光场域数量 × 匹配商品数量。三项中前两项商家可控。（来源：`万相台无界课程总览`）

**成交规模** — AI→P 流转效率 × 人群资产总规模 × TA 人群浓度。（来源：`万相台无界` 4 月课程）

**优先展现权** — 消费者点击广告即激活的优先展示资格。人群越精准，激活后的价值越高。（来源：`P1-人群资产运营方法论`）

**多品多域** — 万相台无界的核心打法：多品增加匹配商品数量（标品场景裂变、非标高频上新），多域增加货品曝光场域数量。（来源：`万相台无界课程总览`）

**同店打散原则** — 传统逻辑下一个用户在一个店内最多看到 2 个商品；人群资产用户可以看到店铺多个商品，曝光提升 230%。（来源：`万相台无界课程总览`）

**爆款权重（叠标公式）** — 基础权重 ×(标签权重之和)× 叠加系数。（来源：`爆款叠标打法全解`）

**LQ / BQ / CQ** — 爆款三阶段判定公式。LQ = 导入期潜力（收藏加购率40% + 关键词质量30% + 价格力30%）；BQ = 成长期起爆（坑产超越系数45% + 增长率35% + 转化率20%）；CQ = 成熟期长效（利润率40% + 复购率30% + 客户满意度30%）。（来源：`爆款打造体系`）

**坑产超越系数** — BQ 公式中衡量单品产出超出类目基准的程度，是"起爆"阶段的关键指标。（来源：`爆款打造体系`）

**店铺资产** — 兴趣点访客体量（核心）+ 新客沉淀体量。新客 = 90 天内有收藏/加购、180 天内拍下未购买。"无资产不标签"。（来源：`店铺资产`）

**兴趣点访客** — 通过相同相似购物意图触达、与店铺产生交互的用户，是样本建模的核心数据。（来源：`店铺资产`）

**小建模** — 5 步法：收集成交词表 → 锁定成交方向 → 布局向量 → 积累店铺资产 → 形成精准样本。覆盖 2000 万以下生意规模。（来源：`小建模`）

**向量召回** — 以语义相似度召回商品的底层路线，与标签匹配是两种不同的召回机制。（来源：`向量召回`）

**三大场景** — 搜索（关键词推广）、推荐（人群推广）、AI 智能（智能计划/全站推广）。铁律：**无样本不碰 AI 智能场景**。（来源：`三大场景`）

**预算决定流量圈层** — 日预算 50 元以下只能买到店铺老客，5000 元以上才会触达全行业泛人群。（来源：`2026淘宝运营完整知识体系`）

**D-S-R / RFM** — RFM 分层按 Recency/Frequency/Monetary 划分客户价值；DSR 是评价管理侧的对应口径。（来源：`RFM分层`、`评价管理`）

**四大金刚** — GSV、扣佣行为、内容成交、动态体验分。平台考核口径。（来源：`淘宝四大核心指标体系`）

**安全补单** — 三大合法场景下的合规销量补充手段，与违规刷单有明确边界。（来源：`安全补单与买家秀`）

**三阶引擎** — 聚焦投资 → 产品优化 → 计划落地 的三层货盘经营工具：SAB 分级（保底利润率阶梯）→ 8 维度考核（准入 ≥6 分）→ 推广落地（拉新/追投/收割三型）。S 级保底利润率 10%、A 级 15%、B 级 20%、C 级 25%。（来源：`三阶引擎工具表-说明`）

**借壳复制法** — 复制历史拉新/追投/收割各 3-5 个计划换品，保持场景/出价/人群/创意不变，启动观察 3-7 天。（来源：`三阶引擎工具表-说明`）
