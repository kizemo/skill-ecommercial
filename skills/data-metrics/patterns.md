# 可复用方法 · data-metrics

> 每条格式：`## 方法名` + **何时用** + **怎么做** + **代价/风险**

---

## 指标口径快照表

**何时用**：每季度复盘前、或不同人给同一个指标不同数字时，先把口径钉死再讨论。

**怎么做**：
1. 列出全部在用指标：GSV、扣佣行为、内容成交、动态体验分、退款率、复购率、互动率、店铺体验分、PXI、费比、ROI、领先率。
2. 每个指标写四列：**口径 / 阈值 / 出处笔记名 / 本季采用版本**。
3. 遇到同一指标有多套写法（如 8 维度命名、S 级预算占比），**全部登记为"口径冲突，需复核"**，本季先选一套并写死。
4. 换口径的时机是季度切换，不是月度复盘中悄悄换。

**代价/风险**：一次定错口径，季度内所有环比对比失效。换口径不做登记，等于把历史数据全部作废。

## 8 维度准入评分法

**何时用**：准备给一个链接加推广预算之前；全店动销盘点；每月 SAB 调级前。

**怎么做**：
1. 拉齐 4 张源表：生意参谋商品排行榜（近 30 天）、达摩盘货盘表、推广商品主体报表（近 30 天）、推广人群报表（近 3 个月全选）。
2. 对每个候选链接按 8 个维度各打 1 分：搜索 UV 价值、转化率、停留时长、跳失率、退款率、连带购买率、复购率、店铺贡献度。
3. **≥ 6 分才进入可推广池；< 6 分先修品**（修哪个维度由最低分那一维决定）。
4. 入选后走三阶引擎第三层落计划：拉新 / 追投 / 收割三选一，按盈亏比 + 新客比判据定出价。

**代价/风险**：8 个维度全靠人工打分，耗时；阈值只有"6 分"一条线，不区分"6 分刚过"和"8 分满分"。打分口径不写死，不同人打出来的分不可比。

## 三层预算池算法（保底利润率法）

**何时用**：定全店这个月总共能投多少钱；给 S/A/B/C 分层排预算。

**怎么做**：
1. 给每个产品定保底利润率阶梯：S 品 10% / A 品 15% / B 品 20% / C 品 25%。
2. 算**超额利润 = 实际利润 − 保底利润**（负数说明连保底都没到，该品的推广费应视为 0）。
3. **全店可投费用池 = 所有产品超额利润汇总**。
4. 费用池再按三阶引擎第三层拆到拉新 / 追投 / 收割三层。

**代价/风险**：保底利润率阶梯是**内部约定值**（10/15/20/25），不是行业标准；一旦中途改这个阶梯，历史费用池不可比。每 30 天需重评一次 SAB 分级。

## 双源融合核算（生意参谋 × 万相台无界）

**何时用**：算真实费比、真实 ROI、系列级投产；每周预算复核前。

**怎么做**：
1. 下载生参商品明细，**必须勾选"退款金额"**，日期统一 `YYYY/MM/DD`。
2. 下载万相台报表中心商品报表，**营销场景必须全选**（取消所有勾选），同一宝贝多计划记录**先按"宝贝ID+日期"汇总**。
3. 粘贴一律"选择性粘贴 → 值"，不动表头与公式单元格。
4. 按"共享人群资产"给宝贝标注类目/系列。
5. 模板自动算总成交、总退款、净成交、总推广花费、总直接成交、总间接成交、系列 ROI、系列费比、退款率。
6. **数据校验**：生参总成交 vs 模板汇总一致；无界总推广花费 vs 模板汇总一致。

**代价/风险**：商务参谋数据与万相台数据**天然对不齐**（颗粒度、归因周期、退款剔除都不同），不要指望两个平台的数直接相等；间接成交跨系列重复计算，必须按系列汇总。

## 净成交费比 + 红绿灯决策

**何时用**：拿到周报决定加不加预算；单个品投产好但费比超标要止损时。

**怎么做**：
1. 算 `系列费比 = 总推广花费 ÷ 净成交金额`（分母用净成交，不用成交金额）。
2. 按红绿灯规则判色：投产 ≥ 目标 ROI 为绿、≥ 目标×0.8 为黄、低于为红；费比 ≤ 目标为绿、（目标, 目标×1.2] 为黄、> 目标×1.2 为红。
3. 按四场景动作执行：双绿加预算（核心单品 +20%-30%，系列总增幅 ≤ 30%）、单绿单红优化、投产红费比绿观察、双红立即减 50%-80% 或暂停。
4. 加预算前额外查两条：连续 3 天数据稳定、新增预算 ROI ≥ 原有 ROI 的 80%、TA 人群未渗透率 ≥ 50%。
5. 减预算的量化触发：退款率持续 > 30% 且无法快速优化；间接成交占比 > 70% 且系列费比红灯。

**代价/风险**：红绿灯是**规则判定不是诊断**——它告诉你"该动还是不该动"，不告诉你"为什么"。双红时必须回到 ch03 查退款率、ch05 查间接成交占比，才能知道是货的问题还是人群的问题。降价/加预算的单次幅度不要超 30%。

## 建模选路（小 / 大 / 样本）

**何时用**：新店起步阶段规划；老店换增长瓶颈；"加了预算就是买不到精准人群"时回头查。

**怎么做**：
1. 先看规模：≤ 2000 万走小建模，≥ 5000 万走大建模，中间区间先小建模收口方向。
2. 小建模五步：收集成交词表 → 锁定成交方向 → 布局向量 → 积累店铺资产 → 形成精准样本。
3. 中途每一步用门槛自检：兴趣点访客是否过基础线 2-5 万？新客沉淀是否到位（成长型 1-10 万 / 成熟店 ≥ 20 万）？
4. 只有资产达标后，才开 AI 智能场景（智能计划 / 全站推广）。
5. 三场联动自检：搜索场景的关键词 = 推荐场景的兴趣点 = AI 场景的样本数据；不一致就先修搜索端。

**代价/风险**：小建模是"做减法"，短期内会**砍掉一部分看起来能出量的词和品**，数据上会掉一块；不解释清楚团队会反弹。大建模需要跨类目能力与供应链承接，盲目扩类目会把流量稀释到不精准人群。门槛值是 2026-05 培训快照，平台策略会变。

## 退款率—费比—预算三联动

**何时用**：店铺"投产不错但不赚钱"；大促后净成交掉了、费比飙升时。

**怎么做**：
1. 先算退款率 = 总退款 ÷ 总成交，和行业均值比。
2. 退款率超行业均值 **2 倍** → 已经触发流量限制，不只是利润问题。
3. 把退款率代入 `真实投产 = 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交`，看真实投产是否还高于盈亏平衡 ROI。
4. 退款率持续 > 30% 且短期改不动 → 按红绿灯减预算，不要硬扛。
5. 落地动作（已有出处的）：包装升级（"包装不是成本，是投资"，同时降退款率与抬品牌溢价）、大促期提高预估退款率、修正详情页与货品一致性。

**代价/风险**：退款率的分层归因（秒退 / 发货前 / 退货退款）在本 skill 中**素材未覆盖**，没有归因就容易把三种问题当一种治。补齐归因前，只用"包装升级 + 预估退款率"这类通用动作。

## 未验证条目登记法

**何时用**：素材缺口、平台规则两套口径、需要外部核实的结论。

**怎么做**：
1. 在对应章节开一个"⚠️ 待补（素材未覆盖）"小节，写清：条目的原口径表述、检索过哪些素材、为什么没找到、落地前该去哪里补。
2. **不写死未经验证的数字**（例如某个秒数阈值）；只保留"任务口径里提到过这个点"这一事实。
3. 补齐后回填：原文出处笔记名 + 原文表述 + 生效时间。
4. 冲突的口径单独列"口径冲突，需复核"表，两版数字并排，不替用户选边。

**代价/风险**：登记本身不解决问题；登记项如果长期挂着却被人当结论用，等于把风险转嫁。建议每季度清一次登记表，把补齐的转正、仍缺的下沉到"本期不适用"。
