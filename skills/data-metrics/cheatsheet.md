## 4. 三阶引擎速查

| 层 | 名称 | 关键参数 |
|---|---|---|
| 第一阶 | 店为品投资 | 保底利润率 S 10% / A 15% / B 20% / C 25%；全店可投费用池 = 超额利润汇总；每 30 天重评 |
| 第二阶 | 品为店贡献 | 8 维度各 1 分，准入 ≥ 6 分 |
| 第三阶 | 人为店提效 | 拉新（盈亏比 > 0.8 + 新客比 > 80%，出价历史 80%）／追投（< 0.5 + > 50%，出价 120%）／收割（< 0.4 + < 40%，出价 150%） |

**借壳复制法**：复制历史拉新/追投/收割各 3-5 个计划换品，场景/出价/人群/创意不变，观察 3-7 天，确定性提升 80%+。

**4 张源表**：生意参谋商品排行榜（近 30 天）｜达摩盘货盘表（全网下载）｜推广商品主体报表（近 30 天）｜推广人群报表（近 3 个月全选）。

## 5. 费比红绿灯

```
系列费比 = 总推广花费 ÷ 净成交金额
```

| | 🟢 投产绿 | 🟡 投产黄 | 🔴 投产红 |
|---|---|---|---|
| **🟢 费比绿** | 双绿 → **加预算**（核心单品 +20%-30%，系列 ≤ 30%） | — | — |
| **🟡 费比黄** | 投产绿+费比黄 → 费比略超，观察 | 黄灯 → **观望**，样本 < 7 天不结论 | — |
| **🔴 费比红** | 投产绿+费比红 → **减 30%-50%**，查退款率与间接成交 | — | 双红 → **立即减 50%-80% 或暂停** |

判定：投产 ≥ 目标 ROI 绿｜≥ 目标 × 0.8 黄｜< 目标 × 0.8 红。费比 ≤ 目标绿｜(目标, 目标×1.2] 黄｜> 目标×1.2 红。

**算例**：成交 11000 / 退款 6100 / 净成交 5600 / 花费 1500 → 退款率 55.45%，系列 ROI 10，系列费比 26.79%（目标 25% → 黄灯）。

## 6. 跳失率 / 退款率动作卡

**跳失率**

- 详情页四段重排：**痛点 → 卖点 → 信任 → 行动**（痛点挖掘 → 解决方案 → 证据链 → 促销信息）
- 防跳失三招：**九宫格后置**｜**长白底图法**｜**底部关联**
- 主图四要素：卖点突出｜差异化｜场景化｜信任背书；FABE 缺 Evidence
- 短视频规格：15-30 秒、9:16 竖版、最大化转化出价
- ⚠️ 前 3 秒 / 前 10 秒判据：**素材未覆盖，未验证**，不要当结论用

**退款率**

- 阈值：超行业均值 2 倍 → 限制流量；持续 > 30% 且改不动 → 减预算
- 大促：凑单退款多，**预估退款率要调高**
- 已知杠杆：**包装不是成本，是投资**（降退款率 + 抬品牌溢价）
- ⚠️ 三类归因（秒退 / 发货前退款 / 退货退款）：**素材未覆盖，未验证**

## 7. 建模选路

```
≤ 2000 万  →  小建模：收集成交词表 → 锁定成交方向 → 布局向量 → 积累店铺资产 → 形成精准样本
≥ 5000 万  →  大建模：多向量布局 → 跨类目扩人群 → 用户/物品协同过滤 → 全渠道放大
```

**铁律**：无样本不碰 AI 智能场景。
**联动**：搜索关键词 = 推荐兴趣点 = AI 样本数据。
**新客定义**：90 天内收藏/加购 + 180 天内拍下未购买。
**店铺资产**：兴趣点访客体量（核心）+ 新客沉淀体量。
