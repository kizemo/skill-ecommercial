# 店铺建模路线

> 来源：36-店铺资产.md、35-三大场景.md、小建模.md、大建模.md、向量召回.md（均整理自《淘系向量召回与店铺资产运营实战》培训，2026-05-14）。

---

## 一、底层前提

```
店铺销售额 = 人群资产体量 × 人群经营效率
```

**店铺资产是一切运营的基础，「无资产不标签」**——没有资产就没有标签、没有流量、没有转化。

这句话是整套建模路线的地基：**先补资产，再谈投放**。在资产不足的店铺上加预算，只是买泛人群；AI 智能场景更是明确要求有精准样本才可用。

## 二、三条路线

| 路线 | 核心动作 | 核心目标 | 适用阶段 | 规模 |
|---|---|---|---|---|
| **小建模** | 收集成交词表 → 锁定成交方向 → 布局向量 → 积累店铺资产 → 形成精准样本 | 让系统识别店铺精准成交向量，提升召回效率，实现稳定转化 | 新店、老店新开、成长型店铺 | **2000 万以下**生意规模 |
| **大建模** | 多向量布局 → 跨类目扩人群 → 用户/物品协同过滤 → 全渠道放大 | 突破流量天花板，打造千万级、亿级店铺 | 成熟型店铺 | **5000 万以上**生意规模 |
| **向量召回** | 平台侧算法机制（2019 下半年引入，现升级为「样本大模型 AI 驱动」） | 识别实时购物需求，召回相似人群 | 全阶段 | — |

### 2.1 小建模：做减法

小建模是**所有店铺的必经阶段**，核心是"做减法、定方向、聚精准"，解决"店铺能承接什么购物意图、做什么人群生意"的问题。

五步路径：

```
1. 收集成交词表      ← 先知道钱是从哪些词赚来的
2. 锁定成交方向      ← 定下这个店到底做什么人群的生意
3. 布局向量          ← 把方向铺成平台能识别的向量
4. 积累店铺资产      ← 访客与新客沉淀
5. 形成精准样本      ← 交回给系统做召回
```

**关键在第 1、2 步**：不是先投钱再想方向，而是先从成交词表反推方向。方向错了，后面三步只是在放大错误。

### 2.2 大建模：做加法

大建模是在小建模基础上做加法、扩人群、放大流量。

四步路径：

```
1. 多向量布局
2. 跨类目扩人群
3. 用户/物品协同过滤
4. 全渠道放大
```

### 2.3 向量召回：机制底座

向量召回是淘系 **2019 年下半年引入**的算法机制，通过 **AI 聚类分析用户行为轨迹（搜索词、点击、收藏、加购、成交）**，识别精准购物意图后召回相似人群。当前已升级为「**样本大模型 AI 驱动**」阶段，依托海量店铺样本数据，召回效率与精准度大幅提升。

三条硬结论：

1. 平台从「**匹配相关性**」彻底转向「**识别实时购物需求**」；
2. **人工干预、刷数据完全失效**，仅真实成交与购物意图能形成有效向量；
3. **向量是店铺在系统中的唯一标识**，决定了系统能召回什么样的人群。

## 三、店铺资产

### 3.1 定义

```
店铺资产 = 兴趣点访客体量（核心）+ 新客沉淀体量
```

| 组成 | 定义 |
|---|---|
| **兴趣点访客** | 通过相同/相似购物意图触达、与店铺产生交互的用户，是**样本建模的核心数据** |
| **新客** | **90 天内有收藏/加购行为、180 天内拍下未购买**的用户，属于店铺私域流量 |

### 3.2 核心指标门槛

| 阶段 | 兴趣点访客 | 新客规模 |
|---|---|---|
| 基础门槛 | **≥ 2-5 万** | — |
| 成熟店铺 | **> 5 万** | **≥ 20 万** |
| 成长型 | **2-5 万** | **1-10 万** |
| 新店 | **< 1 万** | **< 1 万** |

**读门槛的方式**：先看兴趣点访客（新店先过 2-5 万这条基础线），再看新客沉淀量。**兴趣点访客不足时，加新客投放的边际效率最高；两项都到位了，才谈得上放大。**

### 3.3 核心价值

- **决定店铺销售额天花板**
- **降低流量成本**（二次触达 PPC 更低）
- **提升召回精准度**
- **形成店铺私域**（一客多吃）

## 四、三大场景

当前淘系流量分发依托三大营销场景，所有运营动作、付费计划、流量获取都围绕三大场景展开，且**必须实现场景联动、购物意图统一**。

| 场景 | 核心 | 定位 | 作用 |
|---|---|---|---|
| **搜索场景** | 关键词推广 | 最能直接体现用户实时购物意图，作为店铺**流量种子**存在 | 锁定精准购物意图、积累初始样本，**是所有运营的起点** |
| **推荐场景** | 人群推广 | 基于搜索场景沉淀的样本，召回相似人群、放大流量 | 二次/多次触达，提升转化与复购 |
| **AI智能场景** | 智能计划 / 全站推广 | 依托大模型自动分配流量、智能出价 | **前提：店铺必须有精准样本、充足资产** |

### 铁律：无样本不碰 AI 智能场景

- **无样本时，AI 无法识别店铺精准人群，只会推送泛流量**
- 正确逻辑：**先通过搜索 + 推荐建样本、积资产，再用 AI 放大**

### 联动要求

搜索、推荐、AI 三大场景必须实现**购物意图高度统一**：

```
搜索场景的关键词 = 推荐场景的兴趣点 = AI场景的样本数据
```

若场景割裂，**店铺样本会散乱，系统无法识别成交方向**。

## 五、建模选路速判

```
生意规模 ≤ 2000 万  →  小建模（做减法、定方向、聚精准）
生意规模 ≥ 5000 万  →  大建模（加法、扩人群、放大流量）
两者之间             →  先小建模收口方向，资产到位再谈大建模
```

| 症状 | 判断 | 去哪 |
|---|---|---|
| 加预算只买到泛流量、转化差 | 资产不足 / 样本没建 | 回小建模第 3-5 步（布局向量 → 积累资产 → 形成样本） |
| 全站推广/智能计划跑不出量 | 无样本就碰了 AI 场景 | 补搜索 + 推荐场景的样本，再开 AI |
| 三场关键词/兴趣点/样本互相打架 | 场景割裂 | 按"关键词 = 兴趣点 = 样本"重排 |
| 兴趣点访客 > 5 万且新客 ≥ 20 万 | 资产达标 | 可以放大，转大建模 |
