## 一、两大核心数据平台对比

| 平台 | 核心数据类型 | 优势 | 不足 |
|---|---|---|---|
| **生意参谋** | 成交金额、退款金额、净成交、访客数、转化率、客单价 | 财务闭环、精细类目、长效追溯 | 颗粒度粗、归因断裂、ROI 缺失 |
| **万相台无界** | 推广花费、直接成交、间接成交、ROI、宝贝推广明细 | 链路归因、投产直观、推广透视 | 非净值数据、类目缺失、数据延迟 |

### 数据融合的三大痛点

1. **数据分散**：成交、退款在生意参谋，推广花费、ROI 在万相台，无法直接关联。
2. **颗粒度不足**：生意参谋缺推广维度细分，万相台缺类目级别汇总。
3. **归因缺失**：生意参谋无法匹配推广归因周期，万相台无法剔除退款影响。

### 融合的四个目标

- **统一数据口径**：计算"净成交费比""系列 ROI"等核心指标
- **评估单品与系列价值**：分析单个宝贝和同一人群资产下多个宝贝的整体价值
- **建立监控体系**：通过红绿灯规则快速识别推广效果优劣
- **支撑目标拆解**：将销售额、流量、花费目标转化为可落地的推广动作

## 二、融合实操：Excel 模板六步

### 2.1 准备工作

| 项 | 要求 |
|---|---|
| **时间范围** | 建议按天融合，每日更新前一天数据 |
| **宝贝范围** | 按"系列"分类融合（同一类目、同一系列）；**共享人群资产的宝贝需统一评估** |

**核心字段清单**：

| 平台 | 字段 |
|---|---|
| 生意参谋 | 日期、宝贝ID、宝贝名称、总成交金额、退款金额、净成交金额、访客数、转化率、客单价 |
| 万相台无界 | 宝贝ID、推广花费、直接成交、间接成交、ROI |

### 2.2 六步骤

**步骤 1：下载生意参谋数据**
1. 登录生意参谋 → 商品分析 → 商品明细
2. 选择时间范围 → 勾选核心指标 → 点击"下载报表"
3. **关键注意**：**必须勾选"退款金额"**，日期格式统一为 `YYYY/MM/DD`

**步骤 2：下载万相台无界数据**
1. 登录万相台无界 → 报表中心 → 商品报表
2. 选择时间范围 → **营销场景"全选"** → 维度选择"商品明细" → 勾选核心指标
3. **关键注意**：**营销场景必须全选（取消所有勾选）**，否则会遗漏部分推广计划数据

**步骤 3：粘贴生意参谋数据到模板**
1. 打开模板"生参数据"工作表 → 选中 A2 单元格
2. 选择性粘贴 → **仅粘贴"值"**，排除格式与超链接
3. 调整日期格式为 `YYYY/MM/DD`

**步骤 4：粘贴万相台无界数据到模板**
1. 切换到模板"无界数据"工作表 → 选中 A2 单元格
2. 选择性粘贴 → 仅粘贴值
3. **关键注意**：同一宝贝在无界数据中存在多条记录（不同推广计划），**需先按"宝贝ID+日期"汇总后再粘贴**

**步骤 5：宝贝类目分类标注**
1. 切换到"宝贝类目清单"工作表
2. 从"生参数据"复制所有宝贝ID与宝贝名称 → 粘贴到 A 列和 B 列
3. 按"共享人群资产"原则，给宝贝标注类目/系列 → 填写到 C 列
4. **批量标注技巧**：使用 Excel"筛选"功能按关键词批量标注

**步骤 6：模板自动计算与数据校验**
1. 切换到"系列总红绿灯"工作表 → 选择时间范围和类目
2. 模板自动计算：总成交金额、总退款金额、净成交金额、总推广花费、总直接成交、总间接成交、**系列ROI、系列费比、退款率**
3. **数据校验**：核对生参数据与模板汇总的总成交金额是否一致；核对无界数据与模板汇总的总推广花费是否一致

## 三、费比口径

```
系列费比 = 总推广花费 ÷ 净成交金额
```

**分母必须用净成交金额**（成交 − 退款）。用成交金额当分母算出来的费比会系统性偏低，是"投产假好"的常见来源之一。

**算例（棉服类目，12 月 1-4 日）**：

| 指标 | 数值 |
|---|---|
| 总成交金额 | 11000 元 |
| 总退款金额 | 6100 元 |
| 净成交金额 | 5600 元 |
| 总推广花费 | 1500 元 |
| 系列 ROI | (6800+9200) ÷ 1500 = **10** |
| 系列费比 | 1500 ÷ 5600 ≈ **26.79%** |
| 退款率 | 6100 ÷ 11000 ≈ **55.45%** |

**目标口径**：系列 ROI ≥ 8、费比 ≤ 25%、月净成交 ≥ 15 万元。

## 四、红绿灯监控体系

### 4.1 判定规则

| 指标 | 🟢 绿灯条件 | 🟡 黄灯条件 | 🔴 红灯条件 |
|---|---|---|---|
| **投产（ROI）** | ≥ 目标 ROI | ≥ 目标 ROI × 0.8 且 < 目标 ROI | < 目标 ROI × 0.8 |
| **费比** | ≤ 目标费比 | 目标费比 < 实际 ≤ 目标费比 × 1.2 | > 目标费比 × 1.2 |

### 4.2 四大核心场景解读

| 场景 | 特征 | 原因分析 | 决策 |
|---|---|---|---|
| **1. 投产绿 + 费比绿（双绿灯）** | 效果优秀，投入产出与成本控制均达标 | — | **增加预算**，优先给 ROI 最高宝贝加 **20%-30%**，系列总预算增幅 **≤ 30%**；若新增预算后投产掉到黄灯即停 |
| **2. 投产绿 + 费比红（单绿单红）** | 转化好但成本超标 | ① 退款率过高（净成交偏低）→ 减 30%-50% 预算，优化宝贝质量/服务；② 间接成交占比过高 → 看系列费比，绿灯则保留预算 | **优化为主，不盲目加预算** |
| **3. 投产红 + 费比绿（单红单绿）** | 成本到位但转化差 | ① 免费流量占比高、推广流量转化差；② 推广预算过少、样本不足；③ 拉新计划占比过高、收割计划不足 | **观察优化**，必要时增加收割预算 |
| **4. 投产红 + 费比红（双红灯）** | 转化差且成本超标 | 人群精准度低、宝贝竞争力弱、计划搭建不合理 | **立即减少预算 50%-80%**，甚至暂停推广，全面优化后再重启 |

### 4.3 红绿灯表的通用格式（来自红绿灯监控法）

`指标名称 | 目标值 | 实际值 | 完成率 | 颜色 | 改进措施`

原则：**每部门不超过 3 个关键指标**；目的是**找到问题持续改进，不直接与绩效考核挂钩**。业务变化快的指标（如素材爆款率）按周监控，业务变化慢的（如新品上架数量）按月监控，每月开复盘会。

## 五、预算调整策略

### 5.1 核心原则

- **数据驱动**：所有调整基于融合数据的红绿灯状态，不依赖主观判断
- **循序渐进**：每次调整预算幅度不超过 **30%**
- **聚焦核心**：优先调整表现优秀/较差的单品，而非整个系列
- **动态优化**：调整后持续监控数据，效果未改善则及时二次调整
- **结合场景**：日常推广与大促推广的调整逻辑不同

### 5.2 加预算（双绿灯场景）

**适用条件**：系列/单品双绿灯且**连续 3 天数据稳定**｜边际效应未显现（新增预算 ROI ≥ 原有 ROI 的 **80%**）｜人群资产充足（**TA 人群未渗透率 ≥ 50%**）

**操作**：筛选双绿灯且 ROI 最高的 **3-5 个单品** → 每个核心单品加 **20%-30%** 预算、系列总预算增加 **≤ 30%** → 监控边际效应，ROI 保持绿灯继续加、降至黄灯即停。

### 5.3 减预算（红灯场景）

**适用条件**：系列/单品双红灯，或**连续 3 天黄灯无改善**｜**退款率持续 > 30% 且无法快速优化**｜**间接成交占比 > 70% 且系列费比红灯**

**操作**：双红灯单品减 **50%-80%** 或暂停；费比红灯但投产绿灯的单品减 **30%-50%**；把减少的预算转移至双绿灯单品或增加收割计划预算；暂停的单品 **1-2 周后小预算测试**，仍红灯则长期暂停。

### 5.4 观望优化（黄灯场景）

**适用条件**：系列/单品黄灯且数据波动大｜**数据样本不足（推广日预算 < 500 元，或推广天数 < 7 天）**｜外部因素影响（季节变化、平台活动）

**操作**：维持预算不增不减；优化细节（收割计划优化关键词、调整控投产目标；拉新计划更换 1-2 个竞品、调整人群溢价）；积累样本 **7-10 天**；转绿则加、转红则减。

## 六、大促预算调整特殊策略

| 阶段 | 重点 | 预算占比 | 关键动作 |
|---|---|---|---|
| **预热期** | 积累人群资产 | **拉新 60%-70%** | 若拉新有效人群 ≥ 60%，增加 30%-50% 预算 |
| **爆发期** | 抢占流量高峰 | **收割 70%-80%** | 开启"最大化拿量 + 防停投"，投产达标时自动加预算 |
| **返场期** | 收割剩余人群资产 | **收割 ≤ 30%** | 切换无界数据出价目标为"净成交金额" |

## 七、平台侧强制约束

| 约束 | 内容 |
|---|---|
| **商业化保费比强制** | 广告花费占比**不低于去年同期**，否则消费券从"平台全资"降为"商家混资/全资" |
| **淘客无效** | **淘客佣金不计入商业化权重**，无法提升店铺权重 |
| **天猫 > 淘宝** | 扣点更高，权重天然更高 |
| **行业推广费比均值** | 约 **5%**，上下浮动约 **1%** |
| **平台流量分配偏好** | 只扶持两类商家：① 业绩每月环比正增长的店铺；② 付费推广花费同比提升的商家 |

## 九、避坑指南

1. **模板公式失效**：粘贴时必须"选择性粘贴 → 值"，不修改表头和公式单元格
2. **数据不一致**：以生意参谋的宝贝ID为准，统一无界数据的宝贝ID
3. **间接成交重复计算**：按"系列"汇总数据，避免跨系列重复计算
4. **退款率异常**：大促期间凑单退款多，需在目标拆解时提高预估退款率
