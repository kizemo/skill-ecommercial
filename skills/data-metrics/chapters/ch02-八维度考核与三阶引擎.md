## 二、三阶结构概览

### 第一阶：店为品投资（看板1）

**核心思想**：利润重构，统一调度，集中力量办大事。

**输入数据**：生意参谋商品排行榜 + 达摩盘货盘表。

**输出**：每个产品的月利润规划 → 全店可投费用池 → SAB 分级。

**关键字段**：月去退销售额｜月利润预估（按 S/A/B 保底利润率分层）｜月 GMV 机会｜月机会市场销售缺口｜全店可投费用。

**保底利润率阶梯（SAB）**：**S 品 10% / A 品 15% / B 品 20% / C 品 25%**。**超额利润 = 实际利润 − 保底利润**；**全店可投费用池 = 所有产品超额利润汇总**。分级**每 30 天重新评估一次**。

### 第二阶：品为店贡献（看板2）

**核心思想**：用 8 维度筛选值得推广的产品。

**输入数据**：推广商品主体报表。

### 第三阶：人为店提效（看板3）

**核心思想**：分层人群精准触达，提升复购。

| 计划类型 | 人群 | 盈亏比 / 新客比判据 | 出价 |
|---|---|---|---|
| 拉新 | 智能推荐人群等 | 盈亏比 > 0.8 + 新客比 > 80% | 历史 80% |
| 追投 | 流失摇摆 / 频繁搜索 / 喜欢本店 | 盈亏比 < 0.5 + 新客比 > 50% | 历史 120% |
| 收割 | 历史购买 / 会员 / 复购人群 | 盈亏比 < 0.4 + 新客比 < 40% | 历史 150% |

## 三、8 维度考核指标

**打分方式**：每个维度 **1 分**。**准入标准：6 分以上才值得推广，6 分以下必须先优化。**

| # | 维度 | 说明 |
|---|---|---|
| 1 | 搜索 UV 价值 | 搜索点击率 × 转化率 × 客单价 |
| 2 | 转化率 | 搜索成交访客 ÷ 搜索总访客 |
| 3 | 停留时长 | 详情页承接能力 |
| 4 | 跳失率 | 页面跳出比例 |
| 5 | 退款率 | 货品质量与描述一致性 |
| 6 | 连带购买率 | 多品类协同能力 |
| 7 | 复购率 | 用户粘性 |
| 8 | 店铺贡献度 | 跨类目覆盖度 |

> **口径冲突（命名差异），需复核**：
> 上述命名取自《2026-05-10 第二次线下坐诊·核心提炼》。《三阶引擎工具表-说明.md》把第 1/2/3/7 维度写作**「搜索展现价值 / 搜索支付转化率 / 平均停留时长 / 连带购买叶子类目宽度」**。
> 两套写法的**分值（各 1 分）与准入（≥ 6 分）完全一致**；但第 8 维度「店铺贡献度」与工具表的「连带购买叶子类目宽度」是否指同一件事，素材未交代。
> **落地做法**：在评分表表头写死"本表采用的口径 + 出处"，一套用满一个季度再换。

### 8 维度的"读法"

8 个维度不是并列打分，它们分别对应链接生命周期的一段漏斗：

| 维度 | 对应的问题 | 出问题先动什么 |
|---|---|---|
| 搜索 UV 价值 | 搜索进来的流量值不值钱 | 标题/主图点击率、客单价 |
| 转化率 | 搜进来的人买不买 | SKU、评价、问大家 |
| 停留时长 | 页面讲清楚了没有 | 详情页承接 |
| 跳失率 | 人进来马上走没走 | 主图第一眼、详情页结构 |
| 退款率 | 货对不对版 | 质量、描述一致性、包装 |
| 连带购买率 | 能不能带别的品 | 详情页关联、SKU 组合 |
| 复购率 | 会不会再来 | 会员体系、耗材复购 |
| 店铺贡献度 | 对全店资产有多大贡献 | 类目/系列布局 |

**低于 6 分的产品先修品再推流**：把预算灌进一个 5 分品，等于花钱买它现在的问题。

## 五、SOP 操作流程

工具表内置三个下载 SOP（商品源数据 / 达摩盘源数据 / 人群报表源数据），整体使用流程为 8 步：

```
Step1：下载四张原始报表
Step2：分别粘贴到「商品源数据」「达摩盘源数据」「人群报表源数据」三个 Sheet
Step3：在「预填写表」手动填写：对标对手 ID、货品和物流毛利率
Step4：「三阶评估评估法中间表」自动计算 SAB 评级和 8 维度得分
Step5：「看板1」自动输出产品投资优先级和可投费用池
Step6：「看板2」自动输出 8 维度问题诊断和优化建议
Step7：「看板3」自动输出人群再营销分层方案
Step8：「方案输出」汇总最终推广方案
```

## 六、重要提示

- 当前文件为**示例模板**（服装类目数据），换用时需替换为自己的数据。
- 工具表内含宏公式和 VBA，数据粘贴后需验证计算结果。
- **SAB 分级每 30 天重新评估一次**。
- 源数据下载的两个必做动作：生参商品明细**必须勾选"退款金额"**、日期统一 `YYYY/MM/DD`；万相台报表**营销场景必须全选**（取消所有勾选），否则遗漏部分推广计划数据。

## 七、借壳复制法（同源方法，供落地参考）

复制历史拉新/追投/收割各 **3-5 个计划**换品，**保持场景 / 出价 / 人群 / 创意不变**，启动后观察 **3-7 天**，确定性提升 **80%+**。适合 8 维度已达准入线、但从零搭计划费时的场景。
