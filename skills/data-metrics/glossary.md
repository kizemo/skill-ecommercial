# 术语表 · data-metrics

> 每条格式：**术语** — 定义（来源：<笔记名>）

---

**GSV（Gross Sales Value）** — 店铺一段时间内的成交总额（扣除退款后）；平台流量分配的核心依据、活动报名门槛的硬性条件、店铺层级划分的核心指标（来源：26-淘宝四大核心指标体系.md）

**扣佣行为** — 淘宝根据成交金额扣除平台佣金的实际行为数据；真实成交才有佣金，虚假交易被严打，反映店铺真实经营质量（来源：26-淘宝四大核心指标体系.md）

**内容成交** — 通过内容渠道（短视频、直播、图文）带来的成交金额；构成含超级短视频引流成交、淘宝直播成交、逛逛/有好货内容成交、小红书种草引流成交（收推素材）（来源：26-淘宝四大核心指标体系.md）

**动态体验分** — 实时反映店铺服务质量和消费者体验的综合评分；考核客服响应速度和质量、物流时效、退换货处理体验、评价管理（来源：26-淘宝四大核心指标体系.md）

**新增高权重维度** — 2026 年与四大金刚并列考核的三项：退款率、复购率、互动率（来源：28-2026淘宝运营完整知识体系.md）

**领先率（前比）** — 新客成交 ÷ 总成交；普通店铺合格线 ≥ 80%，头部 KA ≥ 70%，< 50% = 主要在跑收割，< 30% = 几乎全是老客在买（来源：01-店铺诊断四层分析法.md）

**直接成交 / 间接成交** — 直接成交 = 用户通过广告直接点击后成交；间接成交 = 用户点击广告后，又通过其他渠道（如搜索）成交；间接成交 = 直接成交的 2 倍时，该品投放完全无效（来源：01-店铺诊断四层分析法.md）

**第一次访问来源 / 最后一次访问来源** — 生意参谋的两种归因方式；看拉新用第一次，看收割用最后一次；第一次访问转化率 > 最后一次访问转化率 → 广告在跑拉新（来源：01-店铺诊断四层分析法.md）

**费比** — 广告花费占比；本文统一采用"净成交费比 / 系列费比"口径 = 总推广花费 ÷ 净成交金额（来源：b05-p4-多端数据融合调研.md）

**净成交金额** — 总成交金额扣除退款金额后的净额，是费比与真实投产的分母（来源：b05-p4-多端数据融合调研.md）

**系列 ROI** — 融合模板按"系列"（同一类目/同一系列）汇总的投产指标；间接成交按系列汇总可避免跨系列重复计算（来源：b05-p4-多端数据融合调研.md）

**商业化保费比** — 平台对广告花费占比的强制要求：不低于去年同期，否则消费券从"平台全资"降为"商家混资/全资"；淘客佣金不计入商业化权重（来源：30-爆款三板斧-平台规则.md）

**店铺体验分 / 商品体验分 PXI** — 真实体验分的一票否决项：店铺体验分 < 4.6 失去搜索权重、无法报名大促；PXI < 70 流量负向，< 60 彻底断流（来源：30-爆款三板斧-平台规则.md）

**8 维度考核** — 三阶引擎第二阶的产品考核体系：搜索 UV 价值 / 转化率 / 停留时长 / 跳失率 / 退款率 / 连带购买率 / 复购率 / 店铺贡献度，每项 1 分，准入 ≥ 6 分才值得推广（来源：2026-05-10-第二次线下坐诊-核心提炼，经三阶引擎工具表-说明.md 佐证）

**三阶引擎** — 全店货盘运营的三步标准化工具表：第一阶店为品投资、第二阶品为店贡献（8 维度）、第三阶人为店提效；配套 10 个 Sheet 的 Excel 工具表（来源：10-三阶引擎工具表-说明.md）

**保底利润率阶梯** — 三阶引擎第一阶的分层参数：S 品 10% / A 品 15% / B 品 20% / C 品 25%；超额利润 = 实际利润 − 保底利润；全店可投费用池 = 所有产品超额利润汇总；每 30 天重新评估（来源：2026-05-10-第二次线下坐诊-核心提炼）

**借壳复制法** — 复制历史拉新/追投/收割各 3-5 个计划换品，保持场景/出价/人群/创意不变，启动观察 3-7 天，确定性提升 80%+（来源：2026-05-10-第二次线下坐诊-核心提炼）

**跳失率** — 8 维度考核中的第 4 维，口径为页面跳出比例；与"停留时长"（详情页承接能力）成对出现（来源：10-三阶引擎工具表-说明.md）

**长白底图法** — 详情页最后放一张长白底图并写"已经到底了"，用于防跳失（来源：24-转化率全链路优化.md）

**九宫格后置** — 把关联销售九宫格放在详情页最后，用于防跳失（来源：24-转化率全链路优化.md）

**FABE 主图法则** — Feature 特征 → Advantage 优点 → Benefit 利益 → Evidence 证据；大多数商家缺少 Evidence（来源：24-转化率全链路优化.md）

**真实投产** — 投产 × (1−退款率) × (1−间接成交占比) × 拉新成交，用于把"假好"的投产还原（来源：2026 利润思维体系）

**顺逆差** — 单品成交金额占比 − 单品推广花费占比；正向 = 花小钱办大事 = 预算倾斜依据，负向 = 优化或淘汰（来源：30-爆款三板斧-产品分级.md）

**包装不是成本，是投资** — 好包装降低退款率 + 提升品牌溢价（来源：2026-05-10-第二次线下坐诊-核心提炼）

**小建模** — 做减法、定方向、聚精准：收集成交词表 → 锁定成交方向 → 布局向量 → 积累店铺资产 → 形成精准样本；覆盖 2000 万以下生意规模（来源：小建模.md）

**大建模** — 做加法、扩人群、放大流量：多向量布局 → 跨类目扩人群 → 用户/物品协同过滤 → 全渠道放大；适用 5000 万以上生意规模（来源：大建模.md）

**向量召回** — 淘系 2019 年下半年引入的算法机制，通过 AI 聚类分析用户行为轨迹（搜索词、点击、收藏、加购、成交）识别精准购物意图后召回相似人群；现已升级为"样本大模型 AI 驱动"（来源：向量召回.md）

**店铺向量** — 店铺在系统中的唯一标识，决定系统能召回什么样的人群（来源：向量召回.md）

**店铺资产** — 兴趣点访客体量（核心）+ 新客沉淀体量；"无资产不标签"，没有资产就没有标签、没有流量、没有转化（来源：36-店铺资产.md）

**兴趣点访客** — 通过相同/相似购物意图触达、与店铺产生交互的用户，是样本建模的核心数据（来源：36-店铺资产.md）

**新客** — 90 天内有收藏/加购行为、180 天内拍下未购买的用户，属于店铺私域流量（来源：36-店铺资产.md）

**三大场景** — 搜索场景（关键词推广，流量种子，所有运营起点）、推荐场景（人群推广，基于搜索样本召回放大）、AI智能场景（智能计划/全站推广，前提是精准样本与充足资产）（来源：35-三大场景.md）

**无样本不碰 AI 智能场景** — 三大场景的联动铁律：无样本时 AI 无法识别精准人群只会推送泛流量；先搜索+推荐建样本积资产，再用 AI 放大（来源：35-三大场景.md）

**红绿灯监控法** — 用红/黄/绿三色表示指标完成情况并对应预算动作；每部门不超过 3 个关键指标，目的为找问题而非奖惩（来源：09-红绿灯监控法.md）

**收推素材** — 将站外内容（经授权）二次投放到淘宝，降低制作成本、扩大覆盖面（来源：28-2026淘宝运营完整知识体系.md）

**MTD 费比** — 知识库中的概念笔记条目（70-数据与诊断），低信息密度；口径与阈值未在导出素材中给出，**未验证**（来源：知识库概念笔记层清单）
