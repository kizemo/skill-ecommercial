## 1. 六模块十二 Prompt 一览

| 模块 | Prompt | 核心问题 | 必须输出 |
|---|---|---|---|
| **1. 数据清洗** | P1 评价筛选器 | 哪些评价值得分析？ | 保留列表 + 删除数量 + 无效类型总结 |
| | P2 高价值标记器 | 值多少分？ | 评价 + 评分 + 理由（筛出 ≥4 分） |
| **2. 评价结构化** | P3 评价拆解器 | 用户说了什么？ | 8 维拆解表 |
| | P4 关键词提取器 | 关键词是什么？ | 功能/痛点/场景/情绪 4 类 + 频次 |
| **3. 需求洞察** | P5 高频需求分析器 | 用户真正想要什么？ | 需求/痛点/场景 各 TOP10（带频次+人群） |
| | P6 需求冲突挖掘器 | 产品卡在哪？ | **≥5 个冲突点** |
| | P7 未被满足需求 | 还有什么没被满足？ | 需求描述 + 证据 + 商业价值评级 |
| **4. 人群拆解** | P8 人群分层器 | 谁在买？ | ≥3 类人群画像 |
| | P9 人群-需求映射 | 谁要什么？ | 人群 × 需求 矩阵 |
| **5. 爆款机会** | P10 产品机会生成器 | 下一个爆款在哪？ | 5 个产品机会 |
| | P11 卖点生成器 | 怎么卖？ | 10 条卖点 + 标题关键词 + 情绪价值 |
| **6. 商业转化** | P12 电商策略生成器 | 怎么落地？ | 产品/定价/内容/评价/爆款路径 五段 |

---

## 2. 评价分级（P2 判据）

| 分数 | 标准 | 是否进入结构化 |
|---|---|---|
| 5 分 | 明确需求 + 痛点 + 场景 | ✅ |
| 4 分 | 明确痛点或对比 | ✅ **门槛** |
| 3 分 | 具体使用反馈 | ❌ |
| 2 分 | 弱信息 | ❌ |
| 1 分 | 无意义 | ❌ |

## 5. P6 冲突点四要素

```
冲突点 = 用户想要 A，但产品只能做到 B
```

| 要素 | 要求 |
|---|---|
| 冲突描述 | A 是什么、B 是什么 |
| 涉及人群 | 哪类人最受困扰 |
| 当前产品问题 | 卡在 B 的哪个具体位置 |
| 潜在解决方向 | 怎么做到 A（方向，非方案） |

**至少 5 个。**

## 6. P8 人群五要素 / P10 机会四要素 / P11 卖点三件套

| Prompt | 要素 |
|---|---|
| **P8** | 人群名称 / 核心需求 / 核心痛点 / 购买驱动因素 / 价格敏感度 |
| **P10** | 目标人群 / 核心功能设计 / 差异化点 / 为什么能成为爆款（基于评价数据） |
| **P11** | 核心卖点 10 条 / 标题关键词 / 情绪价值表达 |

---

## 7. P12 五段策略

| 段 | 内容 |
|---|---|
| 一、产品策略 | SKU 设计 / 功能组合 / 规格建议 |
| 二、定价策略 | 不同人群价格带 / 价格锚点设计 |
| 三、内容策略 | 主图表达重点 / 详情页结构 / 信任构建点 |
| 四、评价策略 | 引导用户产生哪些评价 / 如何设计"高转化评价" |
| 五、爆款路径 | 从 0 到爆的步骤拆解 |

## 8. 执行 SOP 7 步

```
Step1 导入评价
Step2 P1-P2 清洗+筛选
Step3 P3-P4 结构化
Step4 P5-P7 洞察
Step5 P8-P9 人群
Step6 P10-P11 机会
Step7 P12 商业化
```

---

## 9. 三条纪律

| 纪律 | 违反后果 |
|---|---|
| 每个 Prompt 单独开窗口 | 上下文污染，越到后面越像在给前面找证据 |
| 每次加强化指令（类目 + 目标人群） | 输出泛化到全品类 |
| P6 冲突点不可跳过 | 差异化点变成现有卖点换句话说 |

---

## 10. 验收：6 条质量向信号 → 回到哪一步

| 信号 | 回到 |
|---|---|
| 洞察全是"希望更好"这类空话 | P3 重跑结构化 |
| TOP10 频次差异极小 | 补样本或改定性结论 |
| 冲突点都是"太贵" | P3/P5 补场景与体验维度 |
| 5 个机会高度重叠 | P7 找未被满足需求 |
| 价格带只有一个 | P8/P9 重做人群分层 |
| 机会与冲突点对不上 | P10 强制引用冲突点 |

---

## 11. 最终三结果

```
① 用户需求地图   ② 爆款产品方向（≥5）   ③ 可执行电商策略
```
缺一不可。
