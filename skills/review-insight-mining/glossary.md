# 术语表 · review-insight-mining

> 每条标注来源笔记。

**爆款评价挖掘 AI Prompt 工具包** — 6 模块 12 Prompt 的流水线，将用户评价转为可执行电商策略。顺序执行不可跳步。（来源：`爆款评价挖掘AI-Prompt工具包-标准版`）

**冲突点** — 用户想要 A，但产品只能做到 B。至少输出 5 个，每个含冲突描述、涉及人群、当前产品问题、潜在解决方向。是差异化卖点的核心来源。（来源：同上，Prompt 6）

**评价分级（1-5 分）** — 5 分=明确需求+痛点+场景；4 分=明确痛点或对比；3 分=具体使用反馈；2 分=弱信息；1 分=无意义。**仅 4 分以上进入结构化分析**。（来源：同上，Prompt 2）

**数据清洗 / 高价值筛选** — 模块 1（P1-P2）。P1 删除无效评价（很好、不错、可以、物流快）与纯情绪无信息评价；保留含使用场景、使用感受、产品问题、对比描述、改进建议的评价。（来源：同上）

**评价结构化** — 模块 2（P3-P4）。P3 逐条拆解出用户人群、使用场景、购买动机、满意点、不满意点、情绪、是否提到竞品、关键关键词；P4 提取功能类/痛点类/场景类/情绪类关键词并统计频次。（来源：同上）

**需求洞察** — 模块 3（P5-P7）。P5 高频需求/痛点/场景各 TOP10（每点须有频次或占比支撑并标注人群）；P6 冲突点挖掘；P7 未被满足需求（含"如果能…更好"型）。（来源：同上）

**人群拆解** — 模块 4（P8-P9）。P8 至少 3 类人群，每类含人群名称、核心需求、核心痛点、购买驱动因素、价格敏感度；P9 建立人群-需求矩阵（横轴需求、纵轴人群）。（来源：同上）

**爆款机会生成** — 模块 5（P10-P11）。P10 输出 5 个产品机会，每个含目标人群、核心功能设计、差异化点、为什么能成为爆款（基于评价数据）；P11 输出 10 条核心卖点、标题关键词、情绪价值表达。（来源：同上）

**商业转化** — 模块 6（P12）。五段式策略：产品策略（SKU设计/功能组合/规格建议）、定价策略（不同人群价格带/价格锚点设计）、内容策略（主图表达重点/详情页结构/信任构建点）、评价策略（引导哪些评价/如何设计高转化评价）、爆款路径（从 0 到爆的步骤拆解）。（来源：同上）

**强化指令** — 每次使用前在所有 Prompt 前加：`当前类目：<类目名> + `目标人群：<人群标签>``（例如：血压测量仪 / 老人 / 孕妇）。（来源：同上）

**上下文污染** — 前一步的结论带着偏见进入下一步判断。表现是越到后面越像在给前一步找证据。解法是每个 Prompt 单独开对话窗口。（来源：同上 使用说明）

**三必须结果** — ① 用户需求地图 ② 爆款产品方向 ③ 可执行电商策略。缺一不可。（来源：`爆款评价挖掘AI-Prompt工具包`）
