# 第 1 章 · 十二个 Prompt 完整规格

> 来源笔记：`爆款评价挖掘AI-Prompt工具包-标准版`（智篆商业 少壮老师，第二次线下坐诊 2026-05-10，标准版原文）
> 本章 Prompt 规格可直接复制执行。

---

## 零、使用说明（团队统一执行规范）

使用流程必须按顺序执行，不可跳步：

1. 数据清洗
2. 高价值筛选
3. 评价结构化
4. 需求洞察
5. 人群拆解
6. 爆款机会生成
7. 商业转化输出

> **建议每个步骤单独开一个 AI 对话窗口执行，避免上下文污染。**

### 强化指令（每次使用前加）

在所有 Prompt 前增加：
```
当前类目：<类目名>
目标人群：<人群标签>
（例如：血压测量仪 / 老人 / 孕妇）
```

## 模块 1 · 数据清洗

### Prompt 1 · 评价筛选器

```
你是一个电商数据清洗专家，请对以下用户评价进行筛选：

筛选规则：
- 删除无效评价（如：很好、不错、可以、物流快等）
- 删除纯情绪无信息评价
- 保留包含以下信息的评价：
  - 使用场景
  - 使用感受
  - 产品问题
  - 对比描述
  - 改进建议

输出：
- 保留评价列表
- 删除评价数量统计
- 无效评价类型总结
```

### Prompt 2 · 高价值评价标记器

```
请对以下评价进行价值评分（1-5分）：

| 分数 | 标准 |
|------|------|
| 5分 | 包含明确需求 + 痛点 + 场景 |
| 4分 | 有明确痛点或对比 |
| 3分 | 有具体使用反馈 |
| 2分 | 弱信息 |
| 1分 | 无意义 |

输出：评价 + 评分 + 理由，并筛选出4分以上的评价
```

## 模块 2 · 评价结构化

### Prompt 3 · 评价拆解器

```
你是用户研究分析师，请逐条拆解以下评价，每条输出：

- 用户人群
- 使用场景
- 购买动机
- 满意点
- 不满意点
- 情绪（正/负/中）
- 是否提到竞品
- 关键关键词（3-5个）

输出为表格。
```

### Prompt 4 · 关键词提取器

```
请提取以下评价中的关键词，并分类：

| 分类 | 内容 |
|------|------|
| 功能类关键词 | — |
| 痛点类关键词 | — |
| 场景类关键词 | — |
| 情绪类关键词 | — |

输出：关键词 + 分类 + 出现频次
```

---

## 模块 3 · 需求洞察

### Prompt 5 · 高频需求分析器

```
基于以下评价拆解数据，请分析：

- 高频需求 TOP10
- 高频痛点 TOP10
- 高频使用场景 TOP10

要求：每个点必须有数据支撑（出现次数或占比），标注对应人群。
```

### Prompt 6 · 需求冲突挖掘器

```
请分析用户需求中的"冲突点"：

> 冲突点 = 用户想要A，但产品只能做到B

至少输出5个冲突点，每个包含：冲突描述、涉及人群、当前产品问题、潜在解决方向。
```

### Prompt 7 · 未被满足需求挖掘

```
请基于用户评价，推测：

- 用户没有明确说，但可以推断的需求
- 用户表达"如果能…更好"的需求
- 市场当前未满足的需求

输出：需求描述 + 证据评价 + 商业价值评级（高/中/低）
```

---

## 模块 4 · 人群拆解

### Prompt 8 · 人群分层器

```
请根据评价内容，划分用户人群。至少输出3类人群，每类包含：

- 人群名称
- 核心需求
- 核心痛点
- 购买驱动因素
- 价格敏感度
```

### Prompt 9 · 人群-需求映射

```
请建立"人群-需求矩阵"：

- 横轴：需求
- 纵轴：人群

输出：每类人群对应的核心需求（按优先级排序）
```

---

## 模块 5 · 爆款机会生成

### Prompt 10 · 产品机会生成器

```
基于以上分析，请输出5个爆款产品机会，每个包含：

- 目标人群
- 核心功能设计
- 差异化点
- 为什么能成为爆款（基于评价数据）
```

### Prompt 11 · 卖点生成器

```
请将用户需求转化为电商卖点，输出：

- 核心卖点（10条）
- 标题关键词（适合搜索）
- 情绪价值表达（如：安心、方便、无压力）
```

---

## 模块 6 · 商业转化（终极输出）

### Prompt 12 · 电商策略生成器

```
请将以上用户洞察转化为完整电商策略：

一、产品策略
- SKU设计
- 功能组合
- 规格建议

二、定价策略
- 不同人群价格带
- 价格锚点设计

三、内容策略
- 主图表达重点
- 详情页结构
- 信任构建点

四、评价策略
- 引导用户产生哪些评价
- 如何设计"高转化评价"

五、爆款路径
- 从0到爆的步骤拆解
```
