## 3. 大促三阶段与库存

```
预热期（7天）→ 正式期（3-5天）→ 余热期（3天）
  精准人群触达      全站推广放量        库存清理
  老客召回          内容联动            新客沉淀
```

**库存**：预热期备 **100% 销量目标**库存｜爆发期实时监控补货｜余热期预留清仓库存。

## 4. 报名四要点

| 要点 | 核心动作 |
|---|---|
| **① 时间把控** | 前 **1 个月**定方案｜通常提前 **2-4 周**截止报名｜**设提醒** |
| **② 库存准备** | 预热备 100% 目标 → 爆发补货 → 余热留清仓 |
| **③ 价格策略** | 活动价 **≤ 近 30 天最低价**｜过最低价管控｜设**价格保护期** |
| **④ 流量承接** | 站外预热（小红书/抖音）→ 站内承接（逛逛/搜索）→ 成交转化（详情页/直播） |

**三条警戒线**：⚠️ 不要为了冲量亏本大促｜⚠️ 活动后恢复原价要合理｜⚠️ 避免被比价平台抓取

## 8. 618 三大核心问题

## 9. 冲量工具

### 低价引流
| 工具 | 配置 |
|---|---|
| 智选词包 | 30-50 链接｜出价可到 0.1 元以下｜每计划 30-50 元｜不添加关键词 |
| AI 关键词 | 30 链接、0.1 元出价｜只选 AI 关键词，关掉流量之选与关键词 |
| 判据 | 投产 >5 保留｜无投产换链接｜好计划投产 300 左右｜出价可下探 0.05 元｜⚠️ 红利期有限 |
| 品类计划 | 非标品 100-300 元放 10-20 个产品；标品用关键词空点击 + 最大化成交 |

**核心认知**：**第三页、第四页的链接才是真正的利润来源**（案例：点击单价 2.1 → 0.19 元，日销售额 6000 → 6 万元）。**不适用**已有数据的主推款。

### 尾部链接测款流程
```
上新 → 选款 → 投放测试 → 50 个点击 → 点击率与转化率达标 → 才可放全站
```

## 10. 决策树：这个活动报不报

```
要不要报这个活动
├─ 价格力够吗？（活动价 ≤ 近 30 天最低价）
│  └─ 不够 → 先转 [[pricing-margin]] 倒推空间，或不报
├─ 体验分过线吗？（店铺 ≥4.6 / 商品 PXI ≥70）
│  └─ 不过 → 先修体验分，否则报名也白报
├─ 库存够 100% 目标吗？
│  └─ 不够 → 缩量报，或不报
├─ 蓄水能到 O+A > 200w 吗？
│  ├─ 能 → 报，按倒排节点表走
│  └─ 不能 → 先补蓄水（报也白报，爆发期只能加价买量）
└─ 合规过了吗？（医械必查 [[compliance-medical]]）
```

## 12. 双 11 备战 2026 速查

> 2026 口径 · [ch06](chapters/ch06-双11备战2026-流量逻辑转向与链接矩阵.md)。官方报名与价格管控走查见 [ch07](chapters/ch07-双11落地-报名走查与价格管控.md)（**2024/2025 口径**）。

### 12.1 流量逻辑与节奏

| 项 | 结论 |
|---|---|
| 算法转向 | 2022-2023 后流量停止增长 → **爆款驱动 → 资产召回** |
| 召回三类 | 买过型（**90 天**）· 访问型（**7-30 天**）· 互动型（加购/收藏） |
| 前提 | **货盘宽度**够 → 否则被召回时"无可展示产品" |
| 节奏窗口 | **10/15 启动盘货 → 11/14 截止**（约 30 天）；需求分析要在 **10 月中旬前**做完 |
| 盘货三颗粒度 | SKU 结构（选品）· 参数分布（备货）· 用户兴趣标签（卖点） |

### 12.2 链接改造判据

| 检查项 | 合格线 |
|---|---|
| 卖点数量 | **≤ 3 个**；超过 3 个 = 没有卖点 |
| 需求来源 | 评价 + 问大家（案例：200 条评价 + 34 条问大家） |
| 同款折叠四触发 | 商品图过于相似 / 货号重复 / 标题雷同 / 产品角度场景完全一样 |
| 改法顺序 | **先确认货号唯一 → 再做视觉与价格差异** |
| 铺链接最小标准 | 标题 / 视觉 / 场景 / 价格带**四项中至少两项**显著不同 |
| 场景延展 | 必须以**高保真主图做锚点**，保持轮廓/配色/配件一致 |

### 12.3 落地案例（地板行业，改造 90 天）

| 指标 | 改造前 | 改造后 |
|---|---|---|
| 5 条链接合计月销 | 80 单 | **380 单** |
| 平均客单价 | — | **+35%** |
| 系统比价命中率 | **100%** | **12%** |

### 12.4 决策顺序

```
召回 → 差异化 → 视觉升级
```

**AI 视觉**：非标品 > 标品（图案密集型增益大）；秒级出图，多版本测款择优投放成本接近零。

## 13. 双 11 官方走查（2024/2025 口径）

> [ch07](chapters/ch07-双11落地-报名走查与价格管控.md)。**动作骨架可用**；**当年的具体日期与阈值看第 14 节（ch08，2026 官方口径）**。

| 步骤 | 查什么 | 关键动作 |
|---|---|---|
| **① 报名** | 店铺 / 商品 / 特色玩法 / 不生效玩法商品 | 玩法全店生效，但**不报名商品就没有活动氛围与资源** |
| **② 设置** | 玩法比例、活动价、运费险、发货时效、库存 | 活动要求**全部库存报名**；天猫预售与现货退货宝**分别调整** |
| **③ 异常** | 最低标价 / 最低普惠券后价 / 预热期先涨后降 / 活动期涨价 / 同款 sku | 位置：商品管理 → **风险和异常商品** |
| **④ 资损** | **红线价**（必须设）、风险预警、调整红线价、店铺优惠设置 | 位置：千牛-营销-营销风险 |

**先涨后降**：预热期普惠券后价相对监测期最低普惠券后价**上浮 ≤ 20%**。
⚠️ **关键机制**：最低价是**商家在价格校验期内曾设置过的价格**，**不以有成交订单或报入活动为前提** → 报名前把价调下去 = 抬高后面所有时段的基线。

| 维度 | 2026 口径 | 判据 |
|---|---|---|
| **主玩法** | **官方立减**（跨店满减与凑单退出主玩法） | 单件即享、**商家承担让利**、**按店铺维度生效** |

| **发货时效** | **48 小时内发货**且有揽收记录 | — |
| **物流更新** | **揽收后 24 小时内**须有更新 | — |
