## 3. 大促三阶段与库存

```
预热期（7天）→ 正式期（3-5天）→ 余热期（3天）
  精准人群触达      全站推广放量        库存清理
  老客召回          内容联动            新客沉淀
```

**库存**：预热期备 **100% 销量目标**库存｜爆发期实时监控补货｜余热期预留清仓库存。

## 4. 报名四要点

| 要点 | 核心动作 |
|---|---|
| **① 时间把控** | 前 **1 个月**定方案｜通常提前 **2-4 周**截止报名｜**设提醒** |
| **② 库存准备** | 预热备 100% 目标 → 爆发补货 → 余热留清仓 |
| **③ 价格策略** | 活动价 **≤ 近 30 天最低价**｜过最低价管控｜设**价格保护期** |
| **④ 流量承接** | 站外预热（小红书/抖音）→ 站内承接（逛逛/搜索）→ 成交转化（详情页/直播） |

**三条警戒线**：⚠️ 不要为了冲量亏本大促｜⚠️ 活动后恢复原价要合理｜⚠️ 避免被比价平台抓取

## 6. 蓄水 KPI

| KPI | 门槛 |
|---|---|
| O 阶段人群规模 | > 100w |
| O→A 转化率 | > 15% |
| **大促蓄水量（O+A）** | **> 200w** |

**动作**：大促前 30 天建 O-AIPL 计划｜O 阶段预算占 **30%+**｜达摩盘导出 O 阶段人群包｜万相台无界拉新 + 直通车精准组合。

**人群节奏**（汉堡包计划）：蓄水期拉新 **60%**｜爆发期主力 **50%**｜返场期复购 **40%**

## 8. 618 三大核心问题

| 问题 | 表现 |
|---|---|
| 退货率飙升 | 女装→全品类；大件家居 **8%-9% → 50%-60%** |
| 比价退款上涨 | 退了重拍、拍了退 → 推广费浪费 + 库存积压 |
| 付费结构根本变化 | 新店保证金 60-80 万→随便开；**投产比不再是唯一指标** |

**2026 节奏形态**：告白季连续 → 直接接 618 → 21-22 日小高峰 → 23-29 日低数据 → 618 正式活动才出下一个高峰。

**流量结构**：搜索 44%｜推荐 41%｜其他 7.5%

## 9. 冲量工具

### 低价引流
| 工具 | 配置 |
|---|---|
| 智选词包 | 30-50 链接｜出价可到 0.1 元以下｜每计划 30-50 元｜不添加关键词 |
| AI 关键词 | 30 链接、0.1 元出价｜只选 AI 关键词，关掉流量之选与关键词 |
| 判据 | 投产 >5 保留｜无投产换链接｜好计划投产 300 左右｜出价可下探 0.05 元｜⚠️ 红利期有限 |
| 品类计划 | 非标品 100-300 元放 10-20 个产品；标品用关键词空点击 + 最大化成交 |

**核心认知**：**第三页、第四页的链接才是真正的利润来源**（案例：点击单价 2.1 → 0.19 元，日销售额 6000 → 6 万元）。**不适用**已有数据的主推款。

### 尾部链接测款流程
```
上新 → 选款 → 投放测试 → 50 个点击 → 点击率与转化率达标 → 才可放全站
```

## 10. 决策树：这个活动报不报

```
要不要报这个活动
├─ 价格力够吗？（活动价 ≤ 近 30 天最低价）
│  └─ 不够 → 先转 [[pricing-margin]] 倒推空间，或不报
├─ 体验分过线吗？（店铺 ≥4.6 / 商品 PXI ≥70）
│  └─ 不过 → 先修体验分，否则报名也白报
├─ 库存够 100% 目标吗？
│  └─ 不够 → 缩量报，或不报
├─ 蓄水能到 O+A > 200w 吗？
│  ├─ 能 → 报，按倒排节点表走
│  └─ 不能 → 先补蓄水（报也白报，爆发期只能加价买量）
└─ 合规过了吗？（医械必查 [[compliance-medical]]）
```

## 11. 四个最容易踩的坑

| 坑 | 纠正 |
|---|---|
| 按"618 前蓄水半个月"排期 | 2026 按 **5 月上旬 / 10 月上旬**倒排 |
| 活动期猛加付费 | 销售额平稳就别大开大合，保日常费比 |
| 23-29 日数据低就慌 | 平稳型节奏的正常形态 |
| 只看 GMV 复盘 | 加看退款率（<5%）与动态体验分 |
