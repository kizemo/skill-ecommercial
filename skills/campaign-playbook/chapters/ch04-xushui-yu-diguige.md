## 一、蓄水 KPI（O-AIPL）

来源：`O-AIPL`

**模型**：AIPL 的进化版，把「机会人群」独立成 O 阶段 → 5 阶段：**O → A → I → P → L**

| 项 | 内容 |
|---|---|
| **O 机会人群定义** | 高潜购买力 + 尚未触达的人群 |
| **O 阶段来源** | 达摩盘 lookalike + 行业大盘 |
| **O 阶段价值** | 拉新效率比普通拉新高 **50%+** |
| **与 AIPL 的区别** | AIPL = 已有触达后的人群；O-AIPL 把"机会人群"独立出来 |

### 关键 KPI

| KPI | 门槛 |
|---|---|
| O 阶段人群规模 | **> 100w** |
| O→A 转化率 | **> 15%** |
| **大促蓄水量（O+A）** | **> 200w** |

### 实操建议

1. 每次大促前 **30 天**建 O-AIPL 计划
2. **O 阶段预算占 30%+**
3. 达摩盘导出 O 阶段人群包
4. 万相台无界拉新 + 直通车精准组合
5. 每天看 O→A 转化率（健康值 > 15%）

**核心判断**（素材原文）：「**O 阶段蓄水量决定大促爆发力**」。

**适用场景**：大促前蓄水期（重点投入 O 阶段拉新）｜新店冷启动（O 阶段先于 A 阶段）｜老店人群破圈（O 阶段相似人群扩量）｜高潜客户挖掘（行业大盘 + 竞品相似）。

## 二、汉堡包计划（投放结构）

来源：`汉堡包计划`

**一句话**：达摩盘人群组合投放策略，把 3 类人群按"汉堡包"式组合投放，覆盖全链路人群。

| 层 | 人群 | 作用 |
|---|---|---|
| **上层面包** | 高潜人群 + 竞品人群 | 拉新 |
| **中间肉饼** | 精准意向人群 | 主力 |
| **下层面包** | 老客人群 + 忠诚人群 | 复购 |

**工具**：万相台无界智能计划（跨场域）+ 达摩盘人群包（3 类组合）+ 直通车 / 引力魔方（分人群出价）

### 节奏

| 阶段 | 人群占比 |
|---|---|
| **蓄水期** | 拉新 **60%** |
| **爆发期** | 主力 **50%** |
| **返场期** | 复购 **40%** |

**适用场景**：**大促前蓄水（618/双11 提前 30 天）**｜日常投放结构优化｜新品破圈｜多店矩阵（每店建 1 个汉堡包计划）

**投放 SOP**：每月 1 号建立/更新计划 → 3 类人群包从达摩盘导出 → 万相台无界跨场域投放 → 每周看报告（拉新/主力/复购 ROI）→ 月底按 ROI 调整人群包。

## 三、爆款放量三步法（人群资产口径的蓄水）

来源：`人群运营策略`

### 第一步：精准蓄水

**目标**：积累精准人群资产

**动作**：直通车精准拉新 / 超级短视频种草 / 小红书内容种草

**判断标准**：人群包规模达到一定量级 + 标签准确度高

### 第二步：标签放大

**目标**：扩大精准人群规模

**动作**：逐步降低人群精准度 / 扩展相似人群 / 增加推荐流量

**判断标准**：人群规模增长 + **转化率下降不超过 20%**

### 第三步：全站放量

**目标**：最大化 GMV 产出

**动作**：全站推广介入 / 活动配合 / 内容联动

**判断标准**：ROI 达到预期目标 + GSV 持续增长

> **"转化率下降不超过 20%"是这一步唯一的刹车** —— 没有这道闸，标签放大就会变成"泛人群烧钱"。

### 大促节点的人群策略

| 阶段 | 人群策略 |
|---|---|
| 预热期 | 精准人群种草，老客召回 |
| 爆发期 | 全站放量，转化收割 |
| 余热期 | 库存清理，新客沉淀 |
| 日常期 | 人群资产维护 |

**能确认的**：
- 方法名：**优惠券定时失效对冲法**
- 适用命题：**日常与大促同价**
- 归属章节：大促全流程规划 + 蓄水策略

**不能确认的（素材未覆盖）**：面额、失效时点、设置路径、与跨店满减的关系、和大促价盘的切换时点。

### 从方法名可推导的结构（⚠️ 推断，非素材原文）

```
日常：标价 = 活动同款标价（不动最低价）
      + 优惠券生效 → 到手价压到活动水平
大促：优惠券集中生效/加码 → 到手价到位
      + 活动结束 → 优惠券定时失效 → 回到日常到手价
```

**为什么这个结构能同时满足两个约束**：

| 约束 | 如何被满足 |
|---|---|
| 活动价 ≤ 近 30 天最低价 | 日常用优惠券把到手价压下去，**最低价记录自然沉到活动位** |
| 日常最低价不能被拉低 | 让利全部走"不计入最低价"的手段（首单礼金/店铺优惠券/购物金/淘金币/超级立减），**标价不动** |

> ⚠️ **落地前必须核对原笔记**。这里给出的是从方法名到约束的推导，不是素材原文的操作步骤。

## 五、价盘管控方法

素材同样只给出方法名（见上）。**可确认的相关规则**来自 `淘宝活动体系与参与策略` 与 `[[pricing-margin]]`：

| 规则 | 内容 |
|---|---|
| 价格上界 | 活动价格 **≤ 近 30 天最低价** |
| 最低价管控 | 用"不计入最低价"手段让利；用"计入最低价"手段必须真降价并跟住全网比价 |
| 价格保护期 | 设价格保护期，活动后**逐步恢复**，不要大起大落 |
| 比价风险 | 避免被**比价平台抓取** |
| 恢复合理性 | 活动后恢复原价要合理 |

### 价盘管控的四条防线（综合 `[[pricing-margin]]`）

1. **日常线**：最低价记录靠日常优惠券慢慢沉，不靠临时大降
2. **活动线**：活动价 ≤ 近 30 天最低价，且 ≤ 目标活动价
3. **比防线**：全网同款/相似款比价能过（价格力 = 第一权重，不达标直接被踢）
4. **恢复线**：价格保护期 + 逐步恢复 + 不触发比价平台抓取

## 六、蓄水动作速查

| 提前天数 | 人群动作 | 货盘动作 |
|---|---|---|
| **-30 天** | 建 O-AIPL 计划（O 预算 30%+）；达摩盘导人群包；汉堡包计划拉新占比 60% | 定活动方案、选品、备货（100% 销量目标） |
| **-14 天** | — | 完成活动报名，设置活动商品 |
| **-7 天** | 预热启动，老客触达，内容发布；直通车精准拉新 + 超级短视频 + 小红书种草 | — |
| **-3 天** | — | 最后检查、库存确认、客服培训 |
| **当天** | 全站放量，转化收割（放量期主力占比 50%） | 实时监控，及时调整 |
| **之后** | 余热期新客沉淀 + 复购（复购占比 40%）；发布种草内容为下一轮蓄水 | 库存清理，评价维护 |
