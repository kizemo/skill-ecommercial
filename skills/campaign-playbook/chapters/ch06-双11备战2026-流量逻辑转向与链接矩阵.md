## 一、流量逻辑：从爆款驱动转向资产召回

- **2022-2023 年之后平台整体流量停止增长**
- 流量算法发生根本性调整：从**爆款驱动**逻辑迁移到**资产召回**逻辑
- 平台优先展示：消费者**曾经买过**的店铺、**最近访问过**的店铺、**发生过加购/收藏**的店铺
- 迎合召回规则的核心前提：**提前布局足够宽度与深度的货盘**
- 否则消费者资产被召回时，店铺将面临"**无可展示产品**"的窘境

### 三类召回

| 类型 | 触发行为 | 时间口径 |
|---|---|---|
| **买过型召回** | 买过你的店 | **90 天内**历史购买 |
| **访问型召回** | 最近访问过你的店 | **7-30 天**回访 |
| **互动型召回** | 加购 / 收藏 | 互动型召回 |

**这三类历史行为构成召回流量的主要来源，直接决定店铺在大促期间能否承接住平台释放的精准流量。**

### 货盘宽度 ≠ 货盘深度

| | 含义 |
|---|---|
| **宽度** | 覆盖用户需求范围，**≠ 单一产品的深度** |
| **怎么造宽度** | 同一款产品基于**不同用户需求**策划多个差异化产品链接 |

**"做货盘宽度" ≠ 重复铺货** —— 简单复制不会带来召回流量增量。

### 蓝海需求识别法（饰品戒指案例）

1. 让 AI 抓取市场已有关键词 → 语义分析 → **内卷需求 / 强竞争需求 / 弱竞争需求 / 蓝海需求**
2. 分析市场头部商品的**主图定位与售卖逻辑**（地板行业 6 种典型方案：施工场景+服务承诺、母婴场景+健康验证、风格化家具场景、色版陈列、参数堆叠、销量与权威背书）
3. 比对市场榜单与搜索关键词需求 → 定位蓝海机会

**地板行业案例数据**：地板 **300** 商品（强竞争）/ 实木地板 **154** / SPC 实木地板 **187** / **SPC 地板 8 商品（蓝海）** / 木地板自己铺 **19** / SPC 锁扣 + 石塑地板命中更多。

中小卖家的机会方向：旧房改造地板、SPC 石塑地板、拼接地板、出租屋地板（**命中少 = 竞争小**）。

## 二、双11 节奏：10/15 启动盘货，11/14 截止

| 节点 | 时间 | 动作 |
|---|---|---|
| **启动盘货** | **10 月 15 日** | 评价需求抓取与需求清单整理必须**在此之前**完成前置动作 |
| **截止** | **11 月 14 日** | 中间窗口约 **30 天** |

- 2026 年双11 爆发节奏预估**与去年（2025）大致类似** —— 盘货与爆发的**时间锚点**可延续去年的判断逻辑，去年双11 的爆款结构仍可作为今年盘货的参考项
- 节奏上需在 **10 月中旬之前**先完成**评价维度**的需求分析

### 盘货节点三颗粒度

| 颗粒度 | 决定什么 |
|---|---|
| **SKU 结构** | 选品决策 |
| **参数分布** | 备货深度 |
| **用户兴趣标签** | 卖点提炼 |

### 活动周期长但节点密集

- 长周期布局 = 把**多场景需求**全部纳入盘货视野，避免单点爆款判断覆盖不到长尾需求
- **入户地垫案例**：同一款产品的评价数据既覆盖**春节乔迁**类节点需求，也包含**日常入户的尺寸定制**需求
- 节点密集体现在评价数据的多维度细分：**色差 / 图案寓意 / 尺寸精准度**
- 每类反馈聚类为一个细分 SKU 方向，**三条线在双11 周期内同时被激活**

### 工具选择：评价数据怎么抓

| 工具 | 能不能抓阿里体系评价 |
|---|---|
| **千问办公**（阿里旗下产品） | **能** —— 可绕过平台的反爬机制，抓取阿里体系评价数据相对稳定 |
| GPT / Claude 等第三方工具 | **不能**直接访问阿里体系数据 |

**入户地垫实战数据**：链接累积 **1000 条评价** → 剔除无效内容后有效评价约 **160 条** → 色差问题反馈 **67 人次**（红色地垫在不同温度/工况/印次下产生颜色偏差）；图案反馈（吉祥 / 葫芦 / 五帝钱，风水类目复购稳定）；尺寸精准度（非标户型如带倒角的门口，对地垫尺寸合缝要求极高）。

> **千问办公的 AI 备战用法**：生成针对特定行业的用户关键词需求方案，输出**市场 Top 关键词 / 蓝海需求 / 头部商品主图定位**三大维度报告，把盘货盘品、关键词作图、写脚本这些工作交给懂店铺数据的 AI 员工。

## 三、一品多链：从铺货到差异化链接策划

### 3.1 一品多链 ≠ 重复铺货

单个品承载着多类用户需求：厚实有质感 / 防滑不移位 / 无味无胶环保 / 定制服务 / 免洗耐脏好打理 / 发货快。

**把所有需求塞进同一条链接 = "四不像"展示困境** —— 一张图无法承载所有需求信息 → 用户视觉混乱或卖点无感。

> **链接策划核心原则**：一旦产品被赋予**超过三个卖点**，等同于**没有卖点**。

**真实需求挖掘渠道**：**评价信息 + 问大家区域**。
**汽车高压水管案例**：**200 条**真实评价 + **34 条**问大家 → 识别漏水接头 / 长度虚标 / 压力不足 / 耐用性差四类痛点。

### 3.2 六大高频属性差异化

| 需求维度 | 怎么打 |
|---|---|
| 厚实有质感 | 解决地毯地垫品类普遍虚标问题（实打实标注真实毫米数） |
| 防滑不移位 | 面向瓷砖/大理石地面的家庭，老年人进出户防摔严重后果 |
| 无味无胶环保 | 面向健康敏感人群 |
| 定制服务 | 覆盖老房改造、异形门等长尾需求 |
| 免洗耐脏好打理 | 对应懒人经济 |
| 发货快（顺丰包邮、次日达） | 满足乔迁等临时性购买需求 |

### 3.3 多链接分发 = 为每个 SKU 争取独立展示机会

| | 原爆款流量逻辑 | 新的资产召回逻辑 |
|---|---|---|
| 平台怎么给流量 | **只给爆款分配流量** | **店铺每多一个有效链接，平台多一次展示机会** |
| 流量不增长时 | 无法形成增益效应 | **100 个链接 = 100 条链接的曝光可能性** |

**源氏木语案例**：线上线下融合的家具品牌 → 房地产连续多年下滑 **50%** 环境下保持增速 → 核心在**多链接 / 多品类 / 扩货品**形成铺货式增长。

### 3.4 匹配召回机制的多链接布局

- 平台优先展示**近期访问过或购买过**的店铺（消费者信任度更高、付费意愿更强）
- **某生鲜品牌案例**：400 克牛肉定价 500 多元（约同类 **10 倍**以上）→ 单月销售从 **10 万**增长至近 **200 万**（翻了近 **20 倍**）；核心 = 品牌调性定位 + 高客单价链接布局
- **多链接布局核心**：老客返回店铺时，若布局多条链接，则能在搜索与推荐场景中同时展现多个 SKU

> ⚠️ **口径提示**：这里的"近 20 倍"说的是**同一家生鲜品牌自身月销 10 万→近 200 万**的增幅。`[[domain-growth-ops]]` ch01 里另有一句"类目新客/熟客转化率差近 20 倍"，那是**两类人群之间的倍率**（且原文自身两数相除约 12 倍，已在 ch01 标为口径冲突）。**两者不是一回事，不要互相代入。**

## 四、平台搜索升级：SKU 级独立展示

- 平台在 **3 月份**公布搜索升级规则
- 核心方向：**让每个 SKU 获得独立的展示机会** —— "每一个独立的商品链接都会成为被平台召回的独立资产"
- 搜索召回机制主导的流量环境下 → **链接数量直接决定商家在搜索结果页的占位密度**
- 单一链接的覆盖能力被稀释 → 多链接矩阵化布局形成对流量的**批量拦截**
- 搜索升级 = 把每一个 SKU 从"**被合并展示**"切换到"**独立被检索**"

### 4.1 核心目标 = 让用户命中更精准的商品需求

- 用户输入"婴儿衣服"等关键词 → 平台同时召回店铺内多款同类商品
- 按**价格段分层展示**（价格基本都不低于 **150 元**的多个区间）
- SKU 级独立展示的本质 = 把同一个店铺的多条链接变成**可被独立检索的流量入口**
- 每个 SKU 都对应一组**精准的人群标签和搜索意图**

### 4.2 同款被折叠比价的 4 类触发条件

| # | 触发条件 |
|---|---|
| 1 | **商品图过于相似** |
| 2 | **货号重复** |
| 3 | **标题雷同** |
| 4 | **产品角度和场景完全一样** |

系统判定为同款进行比价 → **失去独立展示的机会**。

**改造方法**：重新填写货号 + 重新拟定标题 + 重新搭建产品角度和场景。

**地垫案例**：只是简单换个颜色而主图风格完全一致 → 系统抓取比价；主图 / 标题 / 角度都做出明显差异化 → 系统判定为不同 SKU 并独立展示。

### 4.3 独立展示对多链接策略的支撑

- **基于用户真需求拆解**（高压水管案例）：镀铜管易坏 / 排水晾干麻烦 / 高压冲效果不足 / 标注 10 米但实际 2.5 米或 15 米只有 10 米 → 转换成售卖卖点 → 形成链接清单
- 链接清单按召回逻辑布局到搜索结果页 → 每个链接对应一条独立资产，可被平台**反复召回**
- **儿童哈衣案例**：用户深度浏览后再次搜索"婴儿衣服" → 店铺内多款商品同时展示，价格段分布在 150 元以上的多个区间
- **一品多链的完整链路** = 基于用户真需求拆解链接清单 → 按召回逻辑完成布局 → **用免费的流量换取利润**

## 五、差异化链接：规避系统比价与塑造商品力

### 5.1 货号唯一是第一动作

| 情况 | 后果 |
|---|---|
| **货号相同**（即便主图、价格、SKU 都改了） | 系统仍把两条链接**折叠到同一个比价池** → 价格权重互相牵制 → **拉低所有链接的曝光优先级** |
| **货号不同** | 搜索引擎判定为独立商品 → 单条链接的转化数据被独立计算 → 进入**独立的权重积累通道** |

**大促前链接铺货顺序**：**先确认货号唯一 → 再去做视觉与价格差异**。

**差异化货号的具体要求**：**SKU 编码 / 规格组合 / 商品标题里的型号字段**，至少有一项不同。

### 5.2 标题 + 产品角度 + 场景同时重塑

- 三者同时调整 = 规避同款比价 + 塑造商品力的核心抓手
- 同一款高压水枪如果**只在原图上加一行卖点文案**（标题与角度完全不变）→ 系统仍识别为同款
- **正确路径**：标题换成针对**家庭清洁场景**的具体表述 + 主图角度从平铺改成**使用场景下的特写** → 链接才会在搜索匹配层进入另一条候选集
- **AI 视觉升级案例**：原来 **39.9 元** vs **19.9 元**竞品（地板反射 / 视频清晰度等细节肉眼可见差距）→ AI 视觉升级后把同一款产品放进家庭清洁场景 / 户外冲洗场景 / 宠物清洁场景等多张主图

**场景延展时的产品一致性约束**：

- 多张主图必须保持**商品轮廓、配色、关键配件一致**
- 仅在**背景、道具、使用动作**上做切换
- 若出现产品形态走样 / 配色失真 / 配件缺失 → 反而被买家识别为**虚假宣传**，导致点击率下滑
- 必须以**一张高保真主图作为锚点**，其它场景图都基于该锚点延展

### 5.3 避免自嗨式堆砌

- 铺链接数量**并非越多越好** → 关键在每条链接是否真的具备独立卖点
- **自嗨式堆砌**：十条链接共享同一款主图、同一套标题、同一组 SKU，仅靠改价格铺量 → 系统判定为重复铺货，**权重被摊薄而非叠加**
- **判断链接是否值得铺的最小标准**：**标题、视觉、场景、价格带四项中至少有两项存在显著差异**
  - 只有一项差异 → 铺出去的链接大概率被系统折叠，转化数据合并到主链接上，**新链接白做**
  - 两项以上差异都不存在 → 应优先把精力放在**强化主链接**上，而不是横向复制
- **复杂款式高差异化价值**：法兰银手串 / 马桶刷电 / 地板类产品（视觉细节多、配件组合复杂 → 差异化难度更高）；但恰恰因为这些品类的买家秀阶段看重细节，用 AI 做多角度多场景升级后，**转化提升幅度反而大于标品**
  - ⇒ **差异化难度不应成为拒绝铺链接的理由，反而是优先铺链接的理由**

### 5.4 承接独立展示流量的具体动作

- 把同款商品的**男女款 / 季节款 / 场景款**分别建独立链接
- 让**家庭场景 / 户外场景 / 礼品场景**各自对应一条链接
- 在主推款之外，针对**搜索长尾词**做差异化的副推款 → 让长尾流量有对应的**独立承接页**
- 当两条链接的转化率都跑出来后，再**合并到主链接或保留双链接继续跑数据**
- ⚠️ **全店同款折叠风险**：若全店链接都被识别为同一商品 → 全店只拿到**一份**展示流量，无法承接大促期间的多入口流量
- **实操数据**：原来转化偏弱的链接在视觉升级与场景延展后 → 独立展示流量**从零开始爬升**，进入独立权重积累通道

## 六、AI 视觉升级

| 项 | 内容 |
|---|---|
| **能力** | AI 主图工具能在**秒级**完成视觉重构：自然光照切换、风格变换、变换模特国籍（生成中国模特）、调整拍摄角度 |
| **强项** | **图案密集型商品**（报文、印花服饰等）—— 能覆盖图案细节、面料纹路与色彩还原，**已超过传统设计软件** |
| **弱项** | **标品**（柜子等方正规整品）—— AI 重做与传统设计差异较小，增益主要体现在风格与场景统一上 |
| **结论** | AI 重做对**非标品类的转化价值高于标品类** |

**与差异化主图策略结合**：多版本测款、择优投放的链路在 AI 加持下**成本接近零**；原本只属于头部商家的高频迭代能力下放到中小商家；执行门槛从**设计人力依赖**转向**工具依赖**。

**多品类 Skill 预置**（直播间内置）：珠宝 / 地板 / 日用品 / 保健品 / 家具等常见品类 → 无需逐个类目训练模型。

**门槛降低两点**：① 复杂品类的视觉重构时间从**小时级压缩到秒级**；② 多品类 Skill 预置使商家无需逐个类目训练。

## 七、行动清单与决策流程

### 7.1 决策流程图（原文）

```
召回 → 差异化 → 视觉升级
1. 流量逻辑已转向资产召回 → 双11备战必须把老客激活与历史流量二次利用列为第一阶段核心动作
2. 双11 流量窗口前置（10/15 启动）且平台资源位按筹备度分配 → 一品多链差异化策略需在蓄水期前完成策划与上架
3. 平台搜索升级至 SKU 级独立展示 → 每个 SKU 需配置独立标题与主图以规避系统比价
4. 差异化链接的核心是商品力塑造 → 必须通过 AI 视觉升级提升主图转化效率
5. 环节存在先后依赖 → 按"召回→差异化→视觉升级"顺序推进资源配置
```

### 7.2 三阶段行动清单（原文）

| 阶段 | 时间 | 关键动作 | 量化指标 |
|---|---|---|---|
| **阶段 1** | 0-30 天 | 完成历史流量资产盘点 + 老客召回计划 + 启动双11预热蓄水 | 老客召回触达率 **≥ 60%**，蓄水期加购率提升 **20%** |
| **阶段 2** | 30-90 天 | 落地一品多链策略 + 为爆款单品策划 **≥ 3 条**差异化链接 + 优化 SKU 独立标题 | 差异化链接覆盖核心 SKU **≥ 80%**，搜索曝光提升 **30%** |
| **阶段 3** | 90-180 天 | 全量应用 AI 主图重做方案 + 优先改造高曝光低转化链接 | 主图点击率提升 **25%**，加购转化率提升 **15%** |

### 7.3 落地案例：地板行业一品多链

某地板商家原有一条实木地板主链接，**月销 80 单**，竞品对比价导致利润被压缩。改造后基于 5 类细分需求拆出 5 条独立链接：实木地板（家用 154 个命中词）/ SPC 锁扣地板（自铺 19 个命中词）/ 旧房改造地板（蓝海 4 个命中词）/ 拼接地板 / 防水地板。

5 条链接各自配置独立标题与主图，并应用 AI 重做差异化视觉。**改造 90 天后**：

- 5 条链接合计月销从 **80 单提升至 380 单**
- 平均客单价提升 **35%**
- 系统比价命中率从 **100% 降至 12%**
