## 三、核心玩法：官方立减

| 要点 | 2026 官方口径 |
|---|---|
| **主玩法** | **全阶段核心玩法确定为「官方立减」**；**跨店满减与凑单规则不再出现在主玩法中** |
| **消费者侧** | 购买**单个**活动商品即可享受立减，**无需凑单、无需领券、无需计算凑单门槛** |
| **商家侧** | 被减免的交易金额**由商家承担让利**，商家不因此获得等值现金收入 |
| **生效维度** | **按店铺维度生效** —— 店铺内参与官方立减类目的**全部商品**均生效（取消部分非活动商品的官方立减，须确保至少有一款商品报名并支持该玩法；被取消的商品不再展示官方立减信息） |
| **生效时间** | **预售尾款期及现货活动售卖期间** |
| **让利比例** | 遵循**平台统一设定的各类目最低让利比例**，商家在此基础上可自主提供**更大**的优惠力度 |
| **叠加** | 可与其他**单品优惠**（如前 N、定向优惠）、**店铺优惠**（店铺券、店铺宝、商品券）、**跨店优惠**（品类券等）叠加使用 |

> ⚠️ **让利档位表未验证**：媒体把最低让利比例概括为「不同类目 **1% / 5% / 15%** 不等」，**完整类目档位表须查官方招商规则页的「官方立减参与商品类目及让利折扣」**。本章不把 1%/5%/15% 当成可查表使用。

### 与 2024 口径的差异（ch07 §一 引 2024 官方文档）

| | **2024** | **2026** |
|---|---|---|
| 玩法 | **跨店满减 或 官方立减** —— 平台按行业与商品类目的成交转化、活动爆发情况**适配** | **官方立减为全阶段核心玩法**，跨店满减退出主玩法 |
| 是否叠加 | 跨店满减**不能**与官方立减叠加 | 官方立减**可**与单品/店铺/跨店优惠叠加 |

## 四、价格管控（2026）

**规则形状**（与 2024/2025 一致）：

> 活动商品在活动期间的**标价**及**普惠券后价**，不得高于**价格校验期内已生效或将生效的最低标价与最低普惠券后价**。

- 针对的是**先涨后降、虚假打折**这类影响购物体验的做法
- ⇒ **报名前就要把价格记录理清楚**：最低价是商家**曾设置过**的价格，**不以存在成交订单或报入活动为前提**（机制见 ch07 §二）
- 平台同步提醒避免：**活动期涨价、先涨后降、同款 SKU 价格异常**

⚠️ **以下 2026 细项未验证，必须回千牛后台核对**：

| 事项 | 状态 |
|---|---|
| **价格校验期起止**（2025 口径为 2025-09-20 – 2025-11-14） | **未验证** |
| **预热期涨幅阈值**（2025 口径：对比监测期最低普惠券后价，向上浮动 **≤20%（含 20%）**） | **未验证，2026 是否沿用未知** |
| **是否仍分四段价格管控时段**（2024 分四段，见 ch07 §二） | **未验证** |

## 五、服务规则（2026）

| 项 | 要求 |
|---|---|
| **价保服务** | 活动商品需要提供 |
| **包邮服务** | 活动商品需要提供（**部分特殊类目除外**） |
| **发货时效** | **48 小时内发货**，并确保物流单号有**揽收记录** |
| **物流更新** | **揽收后 24 小时内**须有物流更新记录（特殊情况除外） |

- 商家可在以上基础要求上设置**更优的发货时效**，在活动中**更有优势**
- 官方解读直播的口径：**现在双11 拼的不只是价格，也在拼服务** —— 平台会关注是否具备有竞争力的优惠，也会关注**价格保障、退差、包邮**等服务

## 六、流量与资源（2026）

| 资源层 | 内容 |
|---|---|
| **基础资源** | 店铺首页等相关页面、活动商品详情页等布置活动氛围；活动商品在**搜索结果页、购物车页、商品详情页**等多链路**打标** |
| **官方推荐性推广资源** | 按运营方向与策略，组织搭建**行业 / 类目 / 主题 / 个性化**等多种类型的活动会场页面 |
| **进会场门槛** | 符合**店铺真实体验分**要求的商家，有机会进入搜索「**活动商品标签**」筛选结果页和活动会场（**天猫新品除外**） |
| **会场排序考量** | 动销与成交表现、优惠折扣力度、价格竞争力、优惠竞争力、销售价格、品牌知名度、货品稀缺度、会场主题契合度、店铺类型与主营类目、商品库存、商品信息完整性/准确性、服务及消费者体验保障 |
| **其他流量资源** | 站内资源、淘天生态资源，以及外部媒体、线下媒体、电视广告 |

> **行动含义**：这一节是 ch07「四步曲」里**流量承接**那一环的平台侧对应物 —— 活动会场与打标是**报名后才有**的资源，**不报名就没有活动氛围及活动资源**（ch07 原文口径，2025 年成立，2026 未见相反表述）。
