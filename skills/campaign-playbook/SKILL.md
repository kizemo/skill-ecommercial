# 大促与活动作战

**来源**：`taobao-operation` 知识库（GBRain source `taobao-operation`，2013 页）｜**版本**：2026.10｜**层级**：L2

回答三个问题：**① 一年的大促怎么排？② 这个活动报不报、报哪个？③ 大促期间钱怎么花？**

---

## 一、2026 大促三件事（先记住这个，剩下都是细节）

### ① 强活动化：大促前置、周期拉长、日销只作间隙

| 变化 | 内容 |
|---|---|
| **大促前置** | **618 预计 5 月上旬启动**；**双十一提前至 10 月上旬** |
| **活动周期** | 拉长至 **1.5 个月** |
| **日常活动常态化** | 淘宝秒杀、超级立减、品牌新享常态化 |
| **日销定位** | **日销仅作间隙补充** |
| **运营逻辑** | 全年以"**活动备战**"为核心 |

（来源：`爆款三板斧-平台规则` §4、KB 盘点报告转录 `2026-07-27` 批次）

> **含义**：过去"618 前蓄水半个月、当天爆发"的时间表已经失效。**2026 的日历按 5 月、10 月两个起点倒排。**

### ② 目标从 GMV 转向利润与费比

| 维度 | 旧目标 | 新目标 |
|---|---|---|
| 核心追求 | 销售增长 | **利润** |
| 规模观 | GMV 规模 | **控费比** |
| 客户策略 | 老客复购为主 | **控新客成本，以新客为主，会员同步做** |

（来源：`618大促核心策略转变`）

**付费节奏核心原则**：

> **如果销售额是稳稳稳稳地向前，付费就不要大开大合。**

- ❌ 还没什么数据就猛打付费 —— 上个月销售 1500 万、推广费 890 万、**利润负 450 万**
- ✅ **日常费比，不给活动额外的滤镜和预算**；费比平缓持续；按每个阶段复盘决定下一阶段付费投入

### ③ 价盘是报名前提，不是结果

**价格力 = 第一权重**：活动报名自动对比**全网同款/相似款**价格，**不达标直接被踢出活动**。活动价必须 **≤ 近 30 天最低价**，所以日常最低价记录要**提前铺**。详见 `[[pricing-margin]]`。

## 三、参与分级与日常活动

| 级别 | 参与策略 | 适合场景 |
|---|---|---|
| **S 级大促** | **全面参与**：全店商品参与、最大力度优惠、充足库存备货、客服全力支撑 | 全品类冲量 |
| **A 级活动** | **有选择参与**：主推款参与、中等优惠力度、精准人群投放 | 主推款上新、换季清仓、爆款维护 |
| **日常活动** | 持续参与 | 日销提流量、老客维护 |

| 日常活动 | 频率 | 优惠要求 | 适合场景 |
|---|---|---|---|
| 聚划算 | 按团次 | 全网最低价 | 冲量、清仓 |
| 天天特卖 | 每日 | 折扣 + 券 | 日销提流量 |
| 百亿补贴 | 不定期 | 平台补贴 | 引流获客 |
| 淘金币 | 每日 | 抵扣 + 兑换 | 老客维护 |

**S 级大促时间节奏**：`预热期（7天）→ 正式期（3-5天）→ 余热期（3天）`
预热期 = 精准人群触达、老客召回｜正式期 = 全站推广放量、内容联动｜余热期 = 库存清理、新客沉淀

**库存准备**：预热期备 **100% 销量目标**库存｜爆发期实时监控补货｜余热期预留清仓库存。

## 四、活动报名四要点

| 要点 | 核心动作 |
|---|---|
| **① 时间把控** | 前 **1 个月**确定参与方案；通常提前 **2-4 周**报名截止；**设置提醒** |
| **② 库存准备** | 预热备 100% 目标库存 → 爆发实时补货 → 余热留清仓库存 |
| **③ 价格策略** | 活动价 **≤ 近 30 天最低价**；过最低价管控清单；设**价格保护期** |
| **④ 流量承接** | 站外预热（小红书/抖音）→ 站内承接（逛逛/搜索）→ 成交转化（详情页/直播） |

**价格策略三条警戒线**：⚠️ 不要为了冲量亏本大促｜⚠️ 活动后恢复原价要合理｜⚠️ 避免被比价平台抓取

### 提前准备清单

| 时间节点 | 准备内容 |
|---|---|
| **大促前 30 天** | 确定活动方案，选品，备货（**同时是人群蓄水起跑线**） |
| **大促前 14 天** | 完成活动报名，设置活动商品 |
| **大促前 7 天** | 预热启动，老客触达，内容发布 |
| **大促前 3 天** | 最后检查，库存确认，客服培训 |
| **大促当天** | 实时监控，及时调整 |
| **大促后** | 数据复盘，新客沉淀，评价维护 |

## 五、蓄水策略

### 蓄水 KPI（来源：`O-AIPL`）

| KPI | 门槛 |
|---|---|
| O 阶段人群规模 | > 100w |
| O→A 转化率 | > 15% |
| **大促蓄水量（O+A）** | **> 200w** |

**动作**：大促前 **30 天**建 O-AIPL 计划｜O 阶段预算占 **30%+**｜达摩盘导出 O 阶段人群包｜万相台无界拉新 + 直通车精准组合。

**人群节奏**（来源：`汉堡包计划`）：蓄水期**拉新占比 60%**｜爆发期**主力占比 50%**｜返场期**复购占比 40%**。

**爆款放量三步法**（来源：`人群运营策略`）：精准蓄水 → 标签放大（**转化率下降不超过 20%**）→ 全站放量。

### 日常与大促同价：优惠券定时失效对冲法

> ⚠️ **素材未覆盖，未验证**：素材只保留到方法名与场景 ——「日常与大促同价 = **优惠券定时失效对冲法**；**价盘管控方法**」（KB 盘点报告转录 `2026-05-10` §5.6/§5.7；同一笔记标注"季节性爆品 618 打法（未精读 ⚠️）"）。

**从方法名可确认的结构（推断，非素材原文）**：日常与活动**用同一个到手价**，差别放在**优惠券的生效时间**上 —— 日常让优惠券生效压住到手价，**标价（最低价）保持不动**；大促时优惠券集中生效、活动后定时失效恢复日常价。**具体参数（面额、失效时点、设置路径）素材未覆盖。**

### 价盘管控方法

素材同样只给出方法名。可确认的相关规则：活动价 ≤ 近 30 天最低价｜设价格保护期｜避免被比价平台抓取｜用"不计入最低价"的手段让利而不动最低价。

## 六、618 核心策略转变（2026）

**从集中爆发模式转为全年常态运营，追求利润优先于 GMV，精细化运营成为核心竞争力。**

**平台模式的本质变化**：旧模式（10 年前）大促集中在 618、双11，提前半个月到一个月蓄水，当天集中爆发；新模式（2024 年起）平台全年活动不断，告白季刚结束 618 就接上。**本质影响：已经要买的消费者，在前一个活动节点就已经买过了。**

**三大核心问题**

| 问题 | 具体表现 | 影响 |
|---|---|---|
| **退货率飙升** | 女装→全品类；大件家居从 8%-9% → **50%-60%** | 库存成本大幅增加 |
| **比价退款上涨** | 消费者不断"退了重拍、拍了退" | 推广费浪费，库存积压 |
| **付费结构根本性变化** | 新店保证金 60-80 万→随便开，付费占比持续增长 | 投产比不再是唯一指标 |

**销售节奏对比**

| | 节奏形态 | 具体表现 |
|---|---|---|
| **2025 年 618** | 大冲击式集中爆发 | 预热期 50 万 → 开门红 40-41 万 → 第一波爆发 39-36 万 → 六月爆发超量 |
| **2026 年 618** | **平稳型节奏** | 告白季连续 → 直接接 618 → 21-22 日小高峰 → 23-29 日低数据 → 618 正式活动才出现下一个高峰 |

**可执行步骤**：① 诊断现状（对比去年和今年节奏，判断是否平稳型）→ ② 调整目标（追求利润与控费比）→ ③ 稳住付费（保持日常费比）→ ④ 精细监控（**搜索 44%、推荐 41%、其他 7.5%**）

（来源：`618大促核心策略转变`）

## 八、冲量工具：秒杀、低价引流、尾部链接测款

**秒杀与极速报单**（详见 [ch05-chongliang-gongju.md](chapters/ch05-chongliang-gongju.md)）：2026 秒杀规则、四大渠道优先级（极速报单计划 / 爆品续航版 / 潜力打爆团 / 普通秒杀）、潜力打爆团零门槛报名、极速报单计划操作、5 大另类冲量玩法、叠标十步流程、全站与直通车配合。秒杀标签硬约束：佣金 3%-8%、**计入最低价**、与百亿补贴**互斥**。

> ⚠️ **风险提示**：原文第 2.2 节「GMV 达标方法」（协商发货拍单后退款）、第二步「安全补单」，以及各类「炮灰 SKU / 拆 SKU / 多链接轮流上秒杀」，都属于**平台规则敏感操作**。原文同时记录了清退规则与「30 天内不能再次报名」等后果。是否采用，需自行评估平台规则与店铺风险。

**低价引流 ⇄ 尾部链接测款（配对）**

| 工具 | 关键配置 / 判据 |
|---|---|
| **智选词包** | 30-50 链接；出价可到 0.1 元以下；每计划 30-50 元；不添加关键词 |
| **AI 关键词** | 30 链接、0.1 元出价；只选 AI 关键词，关掉流量之选与关键词 |
| **判据** | 投产 >5 保留｜无投产换链接｜好计划投产 300 左右｜出价可下探到 0.05 元｜⚠️ 红利期有限 |
| **品类计划** | 非标品 100-300 元放 10-20 个产品；标品用关键词空点击 + 最大化成交 |
| **测款流程** | 上新 → 选款 → 投放测试 → 50 个点击量 → 点击率与转化率达标 → 才可放全站 |

**核心认知**：第三页、第四页的链接才是真正的利润来源（学员把点击单价从 **2.1 元**优化到 **0.19 元**，日销售额从 **6000 元**提到 **6 万元**）。**不适用**已有数据的主推款（走全站 + 直通车打爆）。

## 使用说明

1. **先定日历** —— 按"5 月上旬 618 / 10 月上旬双 11"倒排
2. **倒排 30 天** —— 同时是"定方案 + 备货 + 报名 + 建人群计划"的起跑线
3. **过报名四要点** —— 时间把控 / 库存准备 / 价格策略 / 流量承接
4. **算活动价空间** —— 转 `[[pricing-margin]]` 用预留空间公式倒推
5. **控付费** —— 保持日常费比，按阶段复盘再决定下一阶段
6. **复盘** —— 用 §七 的 6 个指标，别只看 GMV

**配合使用**：`[[pricing-margin]]`（定价与费比）、`[[profit-model]]`（算账）、`[[wanxiangtai-wujie]]`（大促期收割与全站）、`[[hit-product-lifecycle]]`（阶段标签与叠标）、`[[customer-asset-ops]]`（蓄水与召回）、`[[compliance-medical]]`（大促前合规审查）、`[[taobao-ops-playbook]]`（总纲）。

- 本 skill 覆盖淘系大促与活动。京东/拼多多/抖音的大促玩法**本轮未 skill 化**。
- 所有阈值与数字均为知识库原文快照（2026 上半年口径）。**平台规则会变，落地前核对当期平台公告。**
- 「优惠券定时失效对冲法」「价盘管控方法」「618 爆发力预判 2-3 倍」来自 **KB 盘点报告的二次转录**，原笔记标注部分内容"未精读 ⚠️"，**具体参数未验证**。
- 《秒杀与极速报单实操指南》正文不在本轮素材内，**仅提纲可确认**。
- 医疗器械类目的大促合规红线见 `[[compliance-medical]]`；本 skill 只负责提醒"大促前要过这一关"。
